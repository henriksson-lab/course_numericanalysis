Exercise: initial value problems and Euler’s method

Goal

By the end of this exercise you should be able to:

  • write an ODE model from rate in − rate out, and state it as an initial value problem,
  • read a direction field and find the equilibria of a one-variable ODE,
  • carry out Euler steps by hand, and write a short Euler function for one equation and for a system,
  • tell local from global error, and measure the order of a method on a log–log plot,
  • estimate the error without an exact solution by halving the step,
  • predict when Euler is unstable (\(|1 - kh| > 1\)) and recognise the symptoms: sign flips, spurious cycles, growing oscillations,
  • rewrite a higher-order ODE as a first-order system.

The by-hand part uses pen, paper and a pocket calculator. The code part checks your hand answers and then works at sizes where only code works. All solvers here are hand-written; the library solvers come in the next unit.

Background

An initial value problem (IVP) is an ODE together with a start value: \[y'(t) = f(t, y), \qquad y(t_0) = y_0.\] \(y\) can be a number or a vector (a system).

  1. Euler’s method. With step \(h\) and \(t_n = t_0 + nh\): \[y_{n+1} = y_n + h\,f(t_n, y_n).\] It comes from the Taylor step \(y(t + h) = y(t) + h\,y'(t) + \tfrac{h^2}{2}y''(\xi)\) with the last term dropped. For a system, the same formula with vectors.
  2. Local error (one step, starting on the exact curve): \(\approx \tfrac{h^2}{2}\,y''\), so \(O(h^2)\). Global error at a fixed time \(T\) (after \(T/h\) steps): \(O(h)\). Euler is order 1: halving \(h\) halves the error, and the slope of \(\log(\text{error})\) against \(\log h\) is 1.
  3. Step halving. For an order-1 method, \(y_h - y_{h/2}\) estimates the error of \(y_{h/2}\). No exact solution needed.
  4. Stability. On \(y' = -ky\) (\(k > 0\)) Euler gives \(y_{n+1} = (1 - kh)\,y_n\). It decays only if \(|1 - kh| < 1\), that is \(h < 2/k\); for \(1/k < h < 2/k\) it decays with sign flips. Near an equilibrium of a nonlinear ODE, the same rule holds with \(k = -f'(y^*)\).
  5. Higher order. Write \(x^{(m)} = g(t, x, x', \dots, x^{(m-1)})\) as a system with \(y_1 = x\), \(y_2 = x'\), …, \(y_m = x^{(m-1)}\). It needs \(m\) start values.

The running examples:

  • Logistic growth \(N' = rN(1 - N/K)\) with \(K = 1.2\) (OD), \(N_0 = 0.05\), \(r = 0.8\) per hour. Exact solution \(N(t) = K / \bigl(1 + (K/N_0 - 1)e^{-rt}\bigr)\).
  • Drug clearance \(C' = -kC\), \(k = 0.8\) per hour, \(C_0 = 10\) mg/L. Exact \(C(t) = C_0 e^{-kt}\).
  • SIR epidemic \(S' = -\beta SI/N\), \(I' = \beta SI/N - \gamma I\), \(R' = \gamma I\) with \(N = 10\,000\), \(\beta = 0.3\) and \(\gamma = 0.1\) per day, \((S, I, R)(0) = (9990, 10, 0)\). Exact peak \(I_{\max} = S_0 + I_0 - \tfrac{N}{R_0}\bigl(1 + \ln\tfrac{R_0 S_0}{N}\bigr) = 3007.96\), with \(R_0 = \beta/\gamma = 3\).
  • 24-hour oscillator \(x'' = -\omega^2 x\), \(\omega = 2\pi/24\) per hour, \(x(0) = 1\), \(x'(0) = 0\). Exact \(x(t) = \cos\omega t\), amplitude \(\sqrt{x^2 + (x'/\omega)^2} = 1\) for all \(t\).

// rust/examples/euler_background.rs  —  cargo run --example euler_background
// Background: a hand-written Euler method on the logistic growth curve.
const K: f64 = 1.2; // OD units
const N0: f64 = 0.05;
const R: f64 = 0.8; // per hour

fn f(_t: f64, n: f64) -> f64 {
    R * n * (1.0 - n / K) // logistic growth: f(t, y); `_t` = argument not used
}

fn exact(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}

// returns (t, y) as two vectors; `impl Fn(f64, f64) -> f64` accepts any f(t, y)
fn euler(f: impl Fn(f64, f64) -> f64, t0: f64, y0: f64, h: f64, n: usize) -> (Vec<f64>, Vec<f64>) {
    let t: Vec<f64> = (0..=n).map(|i| t0 + i as f64 * h).collect();
    let mut y = vec![0.0; n + 1];
    y[0] = y0; // y[i] holds y_i
    for i in 0..n {
        y[i + 1] = y[i] + h * f(t[i], y[i]);
    }
    (t, y)
}

fn main() {
    let (t, y) = euler(f, 0.0, N0, 1.0, 5);
    for i in 0..t.len() {
        println!("{:3.0}  {:.5}  {:.5}", t[i], y[i], exact(t[i]));
    }
}

By hand

B1. Rate in − rate out. Write each model as an ODE with a start value, give the units of each term, and find the steady state(s) (where the right-hand side is 0). (a) A drug is infused at \(u = 2\) mg/h into a blood volume of \(V = 5\) L and cleared at rate \(k = 0.8\) per hour. Start: \(C(0) = 0\). (b) An mRNA is transcribed at \(\alpha = 10\) molecules per minute; each molecule is degraded with rate \(\delta = 0.2\) per minute. Start: \(m(0) = 0\). (c) An oral dose of 100 mg sits in the gut (\(A_g\)) and is absorbed into the blood at rate \(k_a = 1.5\) per hour; in the blood (\(A_b\), in mg) it is cleared at rate \(k = 0.8\) per hour. Write the system for \((A_g, A_b)\). (d) Draw the SIR flow diagram \(S \to I \to R\) with the flow rates \(\beta SI/N\) and \(\gamma I\), and derive the three equations from it. Show that \(S + I + R\) cannot change.

B2. A direction field by hand. For \(N' = 0.8\,N\,(1 - N/1.2)\): (a) Compute the slope at \(N = 0, 0.3, 0.6, 0.9, 1.2, 1.5\). Why does the slope not depend on \(t\)? (b) Sketch the direction field for \(0 \le t \le 6\), \(0 \le N \le 1.6\), and sketch the solutions starting at \(N_0 = 0.05\) and \(N_0 = 1.5\). (c) Where is the solution from \(0.05\) steepest? Which values of \(N\) are equilibria? (d) Why can two solution curves never cross?

B3. Euler steps. For the same logistic ODE with \(N_0 = 0.05\): (a) Take two Euler steps with \(h = 1\) h. Check against the lecture. (b) Take two Euler steps with \(h = 0.5\) h, to reach \(t = 1\). (c) The exact value is \(N(1) = 0.10587\). Compare the errors at \(t = 1\) of (a, first step) and (b). By what factor did the error shrink when \(h\) was halved? What factor would you expect for very small \(h\)?

B4. Clearance and stability. For \(C' = -kC\), \(k = 0.8\) per hour, \(C_0 = 10\) mg/L: (a) Show that Euler gives \(C_n = (1 - kh)^n C_0\). (b) Compute \(1 - kh\) and \(C_2\) (two steps) for \(h = 0.5\), \(1\), \(2\) and \(3\) h. Which are positive, which decay? (c) What is the largest \(h\) for which Euler decays? The largest for which it also never changes sign? What happens at \(h = 1.25\) h exactly? (d) A second drug in the same patient is cleared ten times faster, \(k = 8\) per hour. If you simulate both drugs together with one step size, what is the largest stable \(h\)? (After a few hours the fast drug is gone, but the step-size limit stays: this is stiffness.)

B5. Local and global error on \(y' = y\). With \(y(0) = 1\) the exact solution is \(e^t\), and one Euler step gives \(1 + h\). (a) Compute the local error \(e^h - (1 + h)\) for \(h = 0.1\) and \(h = 0.01\). By what factor does it shrink? Compare with \(h^2/2\). (b) Euler to \(t = 1\) takes \(1/h\) steps, each multiplying by \(1 + h\): \(y_{1/h} = (1 + h)^{1/h}\). Compute the global error \(e - (1.1)^{10}\) and \(e - (1.01)^{100}\) (use a calculator for the powers). By what factor does it shrink? (c) The global error is about \(\tfrac{e}{2}h\). How many steps does Euler need for an error of \(10^{-6}\) at \(t = 1\)?

B6. Reading the order. Each row lists the global error at a fixed time for \(h\), \(h/2\), \(h/4\): (a) \(0.080\), \(0.040\), \(0.020\) (b) \(0.080\), \(0.020\), \(0.005\) (c) \(3.2\times10^{-3}\), \(2.0\times10^{-4}\), \(1.25\times10^{-5}\) (d) A student’s “order 2” method gives \(0.080\), \(0.041\), \(0.0205\). What do you conclude? Give the order of each method.

B7. One SIR step. With \(\beta = 0.3\), \(\gamma = 0.1\) per day, \(N = 10\,000\) and \((S, I, R)(0) = (9990, 10, 0)\): (a) Take one Euler step with \(h = 1\) day. Check that \(S + I + R\) is still \(10\,000\). (b) Early on, \(S \approx N\), so \(I' \approx (\beta - \gamma) I\). What is the doubling time of the epidemic? (c) At the peak of the epidemic \(I' = 0\). Show that this happens when \(S = N/R_0\). How many people are still susceptible at the peak? (d) Late in the epidemic, \(S\) is small and \(I' \approx -\gamma I\). What is the largest stable Euler step for this phase?

B8. Higher order to first order. (a) Write \(x'' = -\omega^2 x\) as a system for \((y_1, y_2) = (x, x')\). Take one Euler step with \(h = 1\) h from \((1, 0)\), with \(\omega = 2\pi/24 = 0.2618\) per hour (\(\omega^2 = 0.06854\)). (b) Compute the amplitude \(\sqrt{y_1^2 + (y_2/\omega)^2}\) before and after the step. Show that for any \((y_1, y_2)\) one Euler step multiplies the squared amplitude by exactly \(1 + \omega^2 h^2\). (c) The hair bundle of an inner-ear hair cell moves like a damped spring, \(m x'' + c x' + \kappa x = 0\). Write it as a first-order system. (d) Write \(x''' = x\,x'' - (x')^2\) as a first-order system. How many start values does it need?

In code

C1. Euler on the logistic curve. (a) Use the Background euler to check your answers to B3 (a) and (b). (b) For \(h = 1\), \(0.5\), \(0.1\) and \(0.01\) h, run to \(t = 10\) h. Print \(N_n\) at \(t = 5\), its error, and the largest error over the whole run. Plot the runs with \(h = 1\) and \(h = 0.1\) over the exact curve. (c) Compute the local error of one step from \(t = 0\) for \(h = 1, 0.5, 0.25, 0.1, 0.01\), and compare it with \(\tfrac{h^2}{2}y''(0)\), where \(y''(0) = r\,f(0, N_0)\,(1 - 2N_0/K)\) (differentiate \(f\) along the solution).

C2. Measure the order, then do without the exact answer. (a) For \(h = 1, 1/2, \dots, 1/1024\) compute the error at \(t = 5\). Print the errors and the ratios of successive errors, fit the slope of \(\log_{10}|\text{error}|\) against \(\log_{10} h\), and plot \(|\text{error}|\) against \(h\) on log–log axes. (b) Pretend you do not know the exact solution. For each pair \((h, h/2)\) compute \(y_h - y_{h/2}\) and compare it with the true error of \(y_{h/2}\). (c) From the smallest \(h\), estimate \(C\) in error \(\approx Ch\). How many steps are needed for an error of \(10^{-6}\) at \(t = 5\)? Run it and check.

C3. Instability. (a) Drug clearance: take 10 Euler steps of size \(h = 0.5\), \(2\), \(2.4\), \(2.6\) and \(3\) h. Print \(1 - kh\), \(C_{10}\) and the exact \(C(10h)\). Which runs are stable? Which are accurate? (b) Logistic growth: take 100 Euler steps of size \(h = 2\), \(2.4\), \(2.6\), \(3\) and \(1.5\) h and print the last four values. (c) What check would have told you, without knowing the true solution, that the \(h = 3\) run is wrong?

C4. A system: the SIR epidemic. (a) Write euler_sys(f, t0, y0, h, n) for a vector \(y\) that stores one row per time point. Run SIR with \(h = 1\) day for 160 days. C5. A second-order equation: the 24-hour oscillator. (a) Write \(x'' = -\omega^2 x\) as a system (B8) and run Euler for 10 days with \(h = 1\), \(0.1\) and \(0.01\) h. Print the amplitude \(\sqrt{x^2 + (x'/\omega)^2}\) at the end, and compare with the prediction \((1 + \omega^2h^2)^{n/2}\) from B8(b). (b) Plot the run with \(h = 1\) h for 2 days in the \((x, x'/\omega)\) plane, together with the exact circle. (c) Using \(\ln(1 + \omega^2h^2) \approx \omega^2 h^2\), find the largest \(h\) for which the amplitude is less than 1 % too large after 10 days. How many steps is that? Check by running it.

E1. (follow the slope) With logistic growth and \(h = 1\), click Reset and then Step three times. After each step write down \(N_n\), the slope \(f(N_n)\) and the exact value, and compare with your table from B3. Where does the dashed grey curve go after each step, and why does Euler fall behind?

Answer E1

\(N_1 = 0.08833\), \(N_2 = 0.15380\), \(N_3 = 0.26107\) against the exact \(0.10587\), \(0.21263\), \(0.38879\): the hand table. The slopes used are \(0.03833\), \(0.06547\), \(0.10727\). Each step follows the tangent at its start, but the curve bends upwards (it is convex below \(N = K/2 = 0.6\)), so the true slope increases during the step and Euler lands below the curve. The dashed grey curve is the exact solution through the current Euler point: after the first step Euler is on a different solution curve, lower than ours, and each further step moves to yet another one. The gap between that curve and the next Euler point is the local error; the gap to the blue curve is the global error.

E2. (order 1) Set \(h = 1\), \(0.5\), \(0.1\) and \(0.01\) with the slider. For each, read the error at \(t = 5\) and the ratio \(\text{error}(h)/\text{error}(h/2)\). Where does the large dot sit in panel (b)? How many steps would four correct digits at \(t = 5\) cost?

Answer E2

Errors \(-0.2004\), \(-0.09399\), \(-0.01703\), \(-0.001660\); ratios \(2.13\), \(2.12\), \(2.03\), \(2.00\). Dividing \(h\) by 10 divides the error by 10, and halving \(h\) halves it: order 1. The dot moves down the slope-1 line \(0.17\,h\), so an error of \(10^{-4}\) needs \(h \approx 10^{-4}/0.17 = 6\times10^{-4}\), about 8300 steps to reach \(t = 5\) (C2(c)). At \(h = 1\) the ratio is not yet 2 and the dot lies slightly off the line: the step is too large for the leading error term to dominate.

E3. (instability) Switch to drug clearance. Try \(h = 0.5\), \(1.25\), \(2\), \(2.4\) and \(3\), and use Step to watch the first few steps. Read the factor \(1 - kh\) and \(C\) at \(t = 12\) h. Which runs decay, which change sign, which grow? What happens in panel (b) as \(h\) passes \(2/k = 2.5\)?

Answer E3

\(h = 0.5\): factor \(0.60\), monotone decay, \(C(12) = 5\times10^{-5}\) (exact \(6.8\times10^{-4}\)). \(h = 1.25\): factor \(0\), the first step lands exactly on \(C = 0\) and stays there. \(h = 2\): factor \(-0.60\), the sign flips every step but the size decays (\(C(12) = 0.467\)). \(h = 2.4\): factor \(-0.92\), still decaying but slowly (\(C(12) = -6.59\)). \(h = 3\): factor \(-1.40\), the sign flips and the size grows; after two steps the solution leaves the plot, and \(C(12) = 38.4\) (the introduction’s example). In panel (b) the error at \(t = 6\) follows the slope-1 line for small \(h\), bends away for \(h\) around 1–2, and jumps to \(19.5\) in the shaded range \(h > 2.5\). A small \(h\) is accurate; a large one is not even stable, and the limit \(2/k\) depends only on the rate.

E4. (a confident wrong answer) Back on logistic growth, click the preset logistic h = 3, 60 h and step through it. What does Euler settle into? Compare \(h = 2.6\), \(2.4\) and \(1.5\) (time span 60 h). Which step sizes give the wrong long-term behaviour, and what single check would have shown it without the exact solution?

Answer E4

With \(h = 3\) (\(1 - rh = -1.40\)) the culture first grows like the true curve, then overshoots \(K = 1.2\) and settles into a boom–bust cycle between about \(0.75\) and \(1.44\) (the lecture’s 2-cycle \(0.77 \leftrightarrow 1.43\), reached after more steps). With \(h = 2.6\) (\(-1.08\)) there is a smaller cycle, \(1.01 \leftrightarrow 1.34\). With \(h = 2.4\) (\(-0.92\)) the oscillation around \(K\) is damped, \(1.18 / 1.22\) after 60 h, and with \(h = 1.5\) (\(-0.20\)) the run sits at \(K\). Above \(h = 2/r = 2.5\) the long-term behaviour is wrong: a regular cycle that the logistic ODE does not have. The check: halve the step. Hints

Hint 1 — models and equilibria (B1, B2)

Each term is an amount per unit time. Something that leaves “at rate \(k\)” leaves as \(k\) times the amount present. For a steady state set the right-hand side to 0 and solve. In a system, what leaves one compartment enters the next with the same expression.

Hint 2 — Euler by hand (B3, B7, B8)

Write a table with columns \(t_n\), \(y_n\), \(f(t_n, y_n)\), \(y_{n+1} = y_n + h f\). Keep 5 significant digits. For a system, compute all slopes from the old values first, then update all components.

Hint 3 — stability (B4, C3)

A geometric sequence \(a^n\) shrinks if \(|a| < 1\), grows if \(|a| > 1\), and changes sign every step if \(a < 0\). For a nonlinear model, look at a small deviation \(N - K\) from the equilibrium: \(f(N) \approx f'(K)\,(N - K)\), so the deviation behaves like \(y' = -ky\) with \(k = -f'(K)\).

Hint 4 — order from errors (B5, B6, C2)

If error \(\approx Ch^p\), halving \(h\) divides the error by \(2^p\), and dividing \(h\) by 10 divides it by \(10^p\). The slope of \(\log(\text{error})\) against \(\log h\) is \(p\): in R fit it with lm, in Python with np.polyfit (degree 1). Use tail(x, 1) (Python: y[-1]) for the last value of a run.

Hint 5 — systems in code (C4, C5)

Store the solution as a matrix with one row per time point and one column per variable. In R, f returns a vector made with c(); in Python, a numpy array, so that Y[i] + h * f(...) works element-wise. Find the peak with which.max (Python: np.argmax); remember that R’s row 1 is time \(t_0\). Plot several columns at once with matplot (Python: plt.plot(t, Y)).

Hint 6 — the amplitude (B8, C5)

After one step, \(y_1^{\text{new}} = y_1 + h y_2\) and \(y_2^{\text{new}} = y_2 - h\omega^2 y_1\). Expand \((y_1^{\text{new}})^2 + (y_2^{\text{new}}/\omega)^2\); the cross terms cancel. After \(n\) steps the amplitude is multiplied by \((1 + \omega^2 h^2)^{n/2}\); take logs to solve for \(h\).

// C1: Euler on the logistic curve: check B3, errors for four step sizes, local error.
const K: f64 = 1.2;
const N0: f64 = 0.05;
const R: f64 = 0.8;

fn f(_t: f64, n: f64) -> f64 {
    R * n * (1.0 - n / K)
}
fn exact(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}
fn euler(f: impl Fn(f64, f64) -> f64, t0: f64, y0: f64, h: f64, n: usize) -> (Vec<f64>, Vec<f64>) {
    let t: Vec<f64> = (0..=n).map(|i| t0 + i as f64 * h).collect();
    let mut y = vec![0.0; n + 1];
    y[0] = y0;
    for i in 0..n {
        y[i + 1] = y[i] + h * f(t[i], y[i]);
    }
    (t, y)
}

}

// C4: the SIR epidemic with a hand-written vector Euler method.
const BETA: f64 = 0.3; // per day
const GAMMA: f64 = 0.1; // per day
const N: f64 = 10000.0; // population size

fn sir(_t: f64, y: &[f64]) -> Vec<f64> {
    let (s, i) = (y[0], y[1]);
    vec![-BETA * s * i / N, BETA * s * i / N - GAMMA * i, GAMMA * i]
}

// one Vec per time point; f takes the state as a slice &[f64]
fn euler_sys(f: impl Fn(f64, &[f64]) -> Vec<f64>, t0: f64, y0: &[f64], h: f64, n: usize) -> Vec<Vec<f64>> {
    let mut ys = vec![y0.to_vec()];
    for i in 0..n {
        let y = &ys[i];
        let slope = f(t0 + i as f64 * h, y);
        let next: Vec<f64> = y.iter().zip(&slope).map(|(yj, fj)| yj + h * fj).collect();
        ys.push(next);
    }
    ys
}

// index and value of the largest I
fn peak(ys: &[Vec<f64>]) -> (usize, f64) {
    ys.iter().enumerate().map(|(i, y)| (i, y[1])).fold((0, f64::MIN), |a, b| if b.1 > a.1 { b } else { a })
}

Where this leads

  • Runge–Kutta and adaptive step size (next unit): methods of order 2 and 4 from a few slope evaluations per step, and library solvers that choose the step size automatically from a tolerance: R’s deSolve::ode, Python’s scipy.integrate.solve_ivp, Rust’s ode_solvers. The SIR model and the logistic test problem return there.
  • Stiffness and implicit methods: the stability bound \(h < 2/k\) when a model has very fast and very slow rates together (B4(d)), and methods without such a bound.
  • Equilibria, stability and the phase plane: equilibria, linearisation (as in C3(b)) and oscillations in the \((x, x')\) plane, for models where the ODE itself, not the method, decides whether solutions grow.
  • Nonlinear least squares and ODE fitting (Part 9): fitting \(r\) and \(K\), or \(\beta\) and \(\gamma\), to data, which needs an ODE solve inside every evaluation of the objective.
