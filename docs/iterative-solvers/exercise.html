Exercise: iterative linear solvers in depth

Goal

By the end of this exercise you should be able to:

  • write Jacobi and Gauss–Seidel as splittings \(\mathbf{x} \leftarrow \mathbf{x} + M^{-1}(\mathbf{b} - A\mathbf{x})\) and run them by hand on a tiny grid,
  • predict their speed from the spectral radius of the iteration matrix, and explain why they slow down by a factor 4 each time the grid is refined,
  • count conjugate gradient iterations as the grid grows and relate them to \(\sqrt{\kappa}\),
  • run CG by hand on a small system and see the Krylov space and the minimisation at work; estimate CG iteration counts from \(\sqrt{\kappa}\),
  • use a preconditioner (diagonal, incomplete Cholesky) and say when it helps,
  • recognise a nonsymmetric system, see CG fail on it, and solve it with GMRES,
  • see restarted GMRES stall, detect it, and try BiCGSTAB, the short-recurrence alternative.

The by-hand part needs pen and paper (and a calculator for B2–B4 and B7). The code part builds on the jacobi and cg functions you wrote in C8 of Structure: symmetric, banded, sparse (there they stopped on an absolute residual of \(10^{-10}\); here on a relative one, fact 7). The solutions define every function they use.

Background

The chamber. (Not the lid chamber of Steady state in two dimensions: a different, scaled problem with the same five-point matrix.) Oxygen in a 1 mm × 1 mm cell-laden gel, supplied through all four walls (concentration 1 = ambient) and consumed uniformly by the cells. The oxygen deficit \(u = 1 - c\) solves \(-\Delta u = \Phi\) with \(u = 0\) on the walls, \(\Phi = 12\). On an \(m \times m\) grid of interior points with spacing \(h = 1/(m+1)\), multiplied through by \(h^2\): \[4u_{ij} - u_{i-1,j} - u_{i+1,j} - u_{i,j-1} - u_{i,j+1} = \Phi h^2,\] a sparse SPD system \(A\mathbf{u} = \mathbf{b}\) with \(n = m^2\) unknowns and five non-zeros per row. The unknowns are numbered row by row: \(u_{ij}\) is entry \(i + m(j-1)\).

Facts used below:

  1. Splitting. With \(A = M - N\): \(\mathbf{x}_{k+1} = \mathbf{x}_k + M^{-1}(\mathbf{b} - A\mathbf{x}_k)\). Jacobi: \(M = D\) (diagonal). Gauss–Seidel: \(M\) = lower triangle of \(A\) including the diagonal; in a sweep, each point uses the neighbours’ newest values.
  2. Error and spectral radius. \(\mathbf{e}_{k+1} = T\mathbf{e}_k\) with \(T = I - M^{-1}A\). The iteration converges for every start if and only if \(\rho(T) = \max_i |\lambda_i(T)| < 1\); the error shrinks by about \(\rho\) per step, so one digit takes \(\ln 10 / (-\ln \rho)\) steps.
  3. On this grid: \(\rho_J = \cos \pi h\), \(\rho_{GS} = \cos^2 \pi h\), and \(\kappa(A) = \cot^2(\pi h/2) \approx 4/(\pi^2 h^2)\).
  4. CG (SPD only) needs about \(\tfrac12\sqrt{\kappa}\,\ln(2/\text{tol})\) iterations at most; in practice the count grows like \(\sqrt{\kappa} \sim 1/h\).
  5. Preconditioned CG replaces \(\mathbf{z} = \mathbf{r}\) by \(\mathbf{z} = M^{-1}\mathbf{r}\) with \(M \approx A\) SPD. Jacobi: \(M = D\). Incomplete Cholesky IC(0): \(M = LL^T\) where \(L\) has the pattern of the lower triangle of \(A\) (fill-in dropped).
  6. GMRES finds the \(\mathbf{x}_k\) in the Krylov space \(\text{span}\{\mathbf{b}, A\mathbf{b}, \dots, A^{k-1}\mathbf{b}\}\) with the smallest residual; it works for nonsymmetric \(A\) but stores all \(k\) basis vectors.
  7. Stopping: in this exercise every method stops when the relative residual \(\|\mathbf{b} - A\mathbf{x}\| / \|\mathbf{b}\| < 10^{-6}\).
  8. Restarted GMRES(\(k\)) keeps at most \(k\) basis vectors, then starts again from the current iterate. It converges for every \(k\) if \(\mathbf{v}^TA\mathbf{v} > 0\) for all \(\mathbf{v} \ne \mathbf{0}\) (the symmetric part \((A + A^T)/2\) is positive definite); otherwise it can stall: the residual stops decreasing.
  9. BiCGSTAB handles nonsymmetric \(A\) with short recurrences: fixed memory (seven vectors), two products with \(A\) per step. Its residual is not monotone, and it can stagnate or break down.

import numpy as np
from scipy import sparse
from scipy.sparse.linalg import spsolve

def lap1(m):
    return sparse.diags([-np.ones(m - 1), 2 * np.ones(m), -np.ones(m - 1)], [-1, 0, 1])

def lap2(m):
    I, T = sparse.identity(m), lap1(m)
    return (sparse.kron(I, T) + sparse.kron(T, I)).tocsr()

def chamber_rhs(m, Phi=12):
    return np.full(m * m, Phi / (m + 1) ** 2)

m = 63; A = lap2(m); b = chamber_rhs(m)
print(A.shape[0], A.nnz)
u = spsolve(A, b)                             # sparse direct solve
print(1 - u[(m * m - 1) // 2])                # oxygen in the centre
# Output:
# 3969 19593
# 0.1161137741104935

By hand

B1. Jacobi and Gauss–Seidel on four points. Take \(m = 2\) (four interior points, numbered 1 2 in the bottom row and 3 4 in the top row) and \(\mathbf{b} = (1, 1, 1, 1)\). (a) Write down \(A\). Check that \(\mathbf{x} = (0.5, 0.5, 0.5, 0.5)\) solves \(A\mathbf{x} = \mathbf{b}\). (b) Do three Jacobi steps from \(\mathbf{x}_0 = \mathbf{0}\). By what factor does the error shrink per step? (c) Do two Gauss–Seidel sweeps from \(\mathbf{0}\), in the order 1, 2, 3, 4. Give the error of point 4 after each sweep and their ratio. (d) Compare (b) and (c) with fact 3 (\(h = 1/3\)).

B2. A spectral radius. For a row of three cells, \(A = \begin{pmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{pmatrix}\). (a) Write down the Jacobi iteration matrix \(T_J = I - D^{-1}A\). Show that \((1, \sqrt2, 1)\) is an eigenvector and find all three eigenvalues (the trace and the other two eigenvectors \((1, 0, -1)\) and \((1, -\sqrt2, 1)\) help). (b) What is \(\rho(T_J)\)? Compare with \(\cos(\pi h)\), \(h = 1/4\). How many Jacobi steps per digit? (c) For the chamber with \(m = 63\): \(\rho_J = \cos(\pi/64) = 0.998795\). How many sweeps per digit, and how many for six digits? Gauss–Seidel? (d) Why does Jacobi diverge for \(\begin{pmatrix}1&2\\2&1\end{pmatrix}\) but converge for \(\begin{pmatrix}2&1\\1&2\end{pmatrix}\)?

B3. Cost of refining. On the chamber, CG took 100 iterations and Jacobi 11 302 sweeps at \(m = 63\). (a) Predict both counts for \(m = 127\) and \(m = 255\) (use \(1/h = m + 1\)). (b) One iteration of either costs about \(2\,\text{nnz} \approx 10n\) floating-point operations for the matrix–vector product. Estimate the total work of CG and of Jacobi at \(m = 255\). (c) A 1 mm³ tissue block at 10 µm resolution: \(m = 100\) in 3D, \(n = 10^6\), seven non-zeros per row. CG’s iteration count depends on \(h\), not on the dimension. Estimate the iterations, the work, and the memory for \(A\) (12 bytes per non-zero) plus four vectors. Compare with the Cholesky factor of about \(6\times10^8\) non-zeros.

B4. A small step is not a small error. A Jacobi run on the chamber with \(\rho = 0.9988\) is stopped when the largest change in one step falls below \(10^{-6}\). (a) Assume each later step is \(\rho\) times the previous one. Sum the geometric series to estimate the distance from the true solution. (b) How many more sweeps would it take to make that error 1000 times smaller? (c) Why is a test on the residual safer? Why is it still not a test on the error?

B5. What a diagonal preconditioner can do. (a) \(A = \begin{pmatrix}100&1\\1&1\end{pmatrix}\). Compute its eigenvalues and \(\kappa(A)\). Then compute \(\kappa\) of \(D^{-1/2}AD^{-1/2}\), \(D = \text{diag}(100, 1)\). (For CG, preconditioning with \(D\) is equivalent to running CG on \(D^{-1/2}AD^{-1/2}\).) (b) For the chamber matrix, \(D = 4I\). What does Jacobi preconditioning change?

B6. CG by hand on three cells. The row of three cells of B2, now with a source in every cell: \(A = \begin{pmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{pmatrix}\), \(\mathbf{b} = (1, 1, 1)\). CG from \(\mathbf{x}_0 = \mathbf{0}\): \(\mathbf{r}_0 = \mathbf{p}_0 = \mathbf{b}\), and in every step \[\alpha_k = \frac{\mathbf{r}_k^T\mathbf{r}_k}{\mathbf{p}_k^TA\mathbf{p}_k},\quad \mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k\mathbf{p}_k,\quad \mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_kA\mathbf{p}_k,\quad \beta_k = \frac{\mathbf{r}_{k+1}^T\mathbf{r}_{k+1}}{\mathbf{r}_k^T\mathbf{r}_k},\quad \mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k\mathbf{p}_k.\] (a) Do two steps. Check that \(A\mathbf{x}_2 = \mathbf{b}\). (b) Check that \(\mathbf{r}_1 \perp \mathbf{r}_0\) and that \(\mathbf{p}_1^TA\mathbf{p}_0 = 0\) (the directions are \(A\)-conjugate). (c) Show that \(\mathbf{x}_1 \in \text{span}\{\mathbf{b}\}\) and \(\mathbf{x}_2 \in \text{span}\{\mathbf{b}, A\mathbf{b}\}\). Show that \(\mathbf{x}_1\) minimises \(f(\mathbf{x}) = \tfrac12\mathbf{x}^TA\mathbf{x} - \mathbf{b}^T\mathbf{x}\) on the line \(\mathbf{x} = t\mathbf{b}\), and compute \(f(\mathbf{x}_0)\), \(f(\mathbf{x}_1)\), \(f(\mathbf{x}_2)\). (d) CG finishes an \(n \times n\) SPD system in at most \(n\) steps (in exact arithmetic). Why did it need only two here? Use the eigenvectors of B2. How many steps would CG need for B1, and why?

B7. The \(\sqrt{\kappa}\) estimate. The CG error bound is \(2q^k\) with \(q = (\sqrt\kappa - 1)/(\sqrt\kappa + 1)\). (a) The chamber at \(m = 63\) has \(\kappa = 1659\). Compute \(q\) and the number of iterations \(k\) for which \(2q^k = 10^{-6}\). Compare with Jacobi’s \(\ln(10^{-6})/\ln(\cos\pi h)\) and with the 100 CG iterations measured in C3. (b) Show that \(\ln q \approx -2/\sqrt\kappa\) for large \(\kappa\), and hence \(k \approx \tfrac12\sqrt\kappa\,\ln(2/\text{tol})\) (fact 4). (c) In C4 the aggregate makes the diagonal range from 0.4 to 4. If that made \(\kappa\) ten times larger, by what factor should the CG count grow? (Measured: 100 → 197.) IC(0) needs 40 iterations instead of 100: if counts scale like \(\sqrt\kappa\), roughly what is \(\kappa(M^{-1}A)\)?

B8. Flow around a loop: when restarts stall. The most extreme nonsymmetric matrix is pure transport without diffusion: three compartments in a closed loop, each receiving from the previous one, \((A\mathbf{x})_i = x_{i-1}\) (with \(x_0 = x_3\)): \[A = \begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}, \qquad \mathbf{b} = (1, 0, 0).\] (a) Compute \(A\mathbf{b}\) and \(A^2\mathbf{b}\). Solve \(A\mathbf{x} = \mathbf{b}\). In which Krylov spaces \(\mathcal{K}_1, \mathcal{K}_2, \mathcal{K}_3\) does the solution lie? (b) GMRES picks \(\mathbf{x}_k \in \mathcal{K}_k\) with the smallest \(\|\mathbf{b} - A\mathbf{x}_k\|\). Show that for \(k = 1\) and \(k = 2\) the best choice is \(\mathbf{x}_k = \mathbf{0}\), with residual 1. What do GMRES(1) and GMRES(2) do after a restart? And full GMRES? (c) Compute \(\mathbf{v}^TA\mathbf{v}\) for \(\mathbf{v} = (1, 0, 0)\) and \(\mathbf{v} = (1, 1, 1)\). The symmetric part \((A + A^T)/2\) has eigenvalues \(1, -\tfrac12, -\tfrac12\). Connect to fact 8.

lapD <- function(m, Dfun) {                  # -div(D grad u), D on cell faces
  h <- 1 / (m + 1); I <- Diagonal(m)
  G1 <- bandSparse(m + 1, m, k = c(0, -1), diagonals = list(rep(1, m), rep(-1, m)))
  Gx <- kronecker(I, G1); Gy <- kronecker(G1, I)
  fx <- expand.grid(x = (1:(m + 1) - 0.5) * h, y = (1:m) * h)   # x-faces
  fy <- expand.grid(x = (1:m) * h, y = (1:(m + 1) - 0.5) * h)   # y-faces
  t(Gx) %*% Diagonal(x = Dfun(fx$x, fx$y)) %*% Gx +
    t(Gy) %*% Diagonal(x = Dfun(fy$x, fy$y)) %*% Gy
}
aggregate_D <- function(x, y) ifelse((x - 0.5)^2 + (y - 0.5)^2 < 0.3^2, 0.1, 1)
ic0 <- function(A, m) {                      # incomplete Cholesky, five-point pattern
  n <- nrow(A); d <- lw <- ls <- numeric(n); dA <- diag(A)
  w <- c(0, diag(A[-1, -n])); s <- c(rep(0, m), diag(A[-(1:m), -((n - m + 1):n)]))
  for (k in 1:n) {
    if (k > 1) lw[k] <- w[k] / d[k - 1]
    if (k > m) ls[k] <- s[k] / d[k - m]
    d[k] <- sqrt(dA[k] - lw[k]^2 - ls[k]^2)
  }
  bandSparse(n, k = c(0, -1, -m), diagonals = list(d, lw[-1], ls[-(1:m)]))
}
def lapD(m, Dfun):                            # -div(D grad u), D on cell faces
    h = 1 / (m + 1); I = sparse.identity(m)
    G1 = sparse.diags([np.ones(m), -np.ones(m)], [0, -1], shape=(m + 1, m))
    Gx = sparse.kron(I, G1); Gy = sparse.kron(G1, I)
    faces, nodes = (np.arange(1, m + 2) - 0.5) * h, np.arange(1, m + 1) * h
    Dx = Dfun(*[g.ravel() for g in np.meshgrid(faces, nodes)])          # x-faces
    Dy = Dfun(*[g.ravel() for g in np.meshgrid(nodes, faces)])          # y-faces
    return (Gx.T @ sparse.diags(Dx) @ Gx + Gy.T @ sparse.diags(Dy) @ Gy).tocsr()

def aggregate_D(x, y):
    return np.where((x - 0.5) ** 2 + (y - 0.5) ** 2 < 0.3 ** 2, 0.1, 1.0)

def ic0(A, m):                                # incomplete Cholesky, five-point pattern
    n = A.shape[0]; d = np.zeros(n); lw = np.zeros(n); ls = np.zeros(n)
    dA = A.diagonal(); w = A.diagonal(-1); s = A.diagonal(-m)
    for k in range(n):
        if k > 0: lw[k] = w[k - 1] / d[k - 1]
        if k >= m: ls[k] = s[k - m] / d[k - m]
        d[k] = np.sqrt(dA[k] - lw[k] ** 2 - ls[k] ** 2)
    return sparse.diags([d, lw[1:], ls[m:]], [0, -1, -m], format="csr")

Hints

Hint 1 — Jacobi and Gauss–Seidel by hand (B1)

Each row of \(A\) for \(m = 2\) has 4 on the diagonal and \(-1\) for the two neighbours inside the grid (point 1 touches 2 and 3, point 4 touches 2 and 3). So one update of point \(i\) is \(x_i = (1 + \text{sum of its two neighbours})/4\). Jacobi uses only old values; Gauss–Seidel overwrites \(x_1\) first and uses the new \(x_1\) when it updates \(x_2\) and \(x_3\).

Hint 2 — eigenvalues (B2, C2)

Multiply \(T_J\) by the vector and see if you get a multiple of it. The eigenvalues of \(T_J\) add up to its trace, 0. A \(2\times2\) matrix \(\begin{pmatrix}0&a\\a&0\end{pmatrix}\) has eigenvalues \(\pm a\). In code, max(Mod(eigen(T)$values)) (R) or np.max(np.abs(np.linalg.eigvals(T))) (Python); use Mod/abs because a nonsymmetric \(T\) may have complex eigenvalues.

Hint 3 — scaling (B3)

Doubling \(m + 1\) halves \(h\). Jacobi’s count grows like \(1/h^2\), CG’s like \(1/h\). At \(m = 255\), \(n = 65\,025\). For memory, 1 GB \(= 10^9\) bytes, and a vector of \(10^6\) doubles is 8 MB.

Hint 4 — the geometric series (B4)

If the last step was \(s\) and every later step is \(\rho\) times the previous one, the remaining distance is \(s(\rho + \rho^2 + \dots) = s\rho/(1-\rho)\). To shrink the error by a factor \(F\) takes \(\ln F / (-\ln\rho)\) steps.

Hint 5 — splittings in code (C1)

R: solve(M, r) with M <- Diagonal(x = diag(A)) or M <- tril(A) dispatches to a cheap diagonal or triangular solve; wrap it in as.vector. Python: for Jacobi use r / A.diagonal(); for Gauss–Seidel spsolve_triangular(sparse.tril(A, format="csr"), r, lower=True). Pass the solve as a function so one splitting serves both.

Hint 6 — counting iterations (C3, C5)

scipy calls callback(xk) once per CG iteration; keep a counter in a list (count = [0], count[0] += 1) so the inner function can change it. In scipy 1.12 and later the tolerance argument is rtol (formerly tol). info = 0 means converged, info > 0 means the iteration limit was reached. For gmres, callback_type="pr_norm" calls the callback once per inner iteration with the residual norm; maxiter counts restart cycles.

Hint 7 — preconditioners (C4)

Jacobi: Minv = function(r) r / d with d <- diag(A). IC(0): with L <- ic0(A, m) and Lt <- t(L), apply \(M^{-1} = (LL^T)^{-1}\) by two triangular solves, solve(Lt, solve(L, r)). Python: LinearOperator(A.shape, matvec=lambda r: spsolve_triangular(Lt, spsolve_triangular(L, r, lower=True), lower=False)) with Lt = L.T.tocsr().

Hint 8 — the advection matrix (C5)

Add Pe * h times a lower bidiagonal matrix (1 on the diagonal, \(-1\) below it) to the 1D operator in \(x\) only, then combine with the \(y\) operator by kronecker as in lap2. Hint 9 — CG by hand (B6)

Compute \(A\mathbf{p}_k\) first; everything else is dot products. \(A\mathbf{b} = (1, 0, 1)\). At the solution, \(f(\mathbf{x}^*) = -\tfrac12\mathbf{b}^T\mathbf{x}^*\). Hint 10 — the bound (B7)

With \(\varepsilon = 1/\sqrt\kappa\), \(q = (1 - \varepsilon)/(1 + \varepsilon)\) and \(\ln(1 \pm \varepsilon) \approx \pm\varepsilon\). Solve \(2q^k = \text{tol}\) for \(k\).

Hint 11 — the loop (B8)

\(A\) moves entry 1 to position 2, 2 to 3, 3 to 1. If \(\mathbf{x} \in \text{span}\{\mathbf{e}_1, \mathbf{e}_2\}\), where can \(A\mathbf{x}\) have non-zeros? Then \(\|\mathbf{b} - A\mathbf{x}\|^2 = 1 + \|A\mathbf{x}\|^2\). A restart throws the Krylov space away and starts from the same residual.

Hint 12 — restarts (C6)

One cycle: r <- b - A x; g <- gmres(A, r, k, tol * norm(b) / norm(r)); x <- x + g$x. The tolerance is rescaled because C5’s gmres measures its residual relative to its own right-hand side, here \(\mathbf{r}\). The bump: v <- as.vector(outer(s, s)) with s <- sin(pi * (1:m) * h) (Python: np.outer(s, s).ravel(); the ordering does not matter for a symmetric bump); then sum(v * (A %*% v)) / sum(v^2).

Hint 13 — BiCGSTAB (C7)

fn splitting(a: &CsMat<f64>, b: &[f64], msolve: impl Fn(&[f64]) -> Vec<f64>,
             tol: f64, maxit: usize) -> (Vec<f64>, usize, Vec<f64>) {
    let mut x = vec![0.0; b.len()];
    let (nb, mut res) = (norm(b), Vec::new());
    let mut it = 0;
    loop {
        let ax = matvec(a, &x);
        let r: Vec<f64> = b.iter().zip(&ax).map(|(p, q)| p - q).collect();
        res.push(norm(&r) / nb);
        if *res.last().unwrap() < tol || it == maxit { break; }
        let dx = msolve(&r);
        for i in 0..x.len() { x[i] += dx[i]; }
        it += 1;
    }
    (x, it, res)
}
fn forward_solve(a: &CsMat<f64>, r: &[f64]) -> Vec<f64> {   // (lower triangle of A) y = r
    let mut y = vec![0.0; r.len()];
    for (i, row) in a.outer_iterator().enumerate() {
        let (mut s, mut d) = (r[i], 0.0);
        for (j, v) in row.iter() {
            if j < i { s -= v * y[j]; } else if j == i { d = *v; }
        }
        y[i] = s / d;
    }
    y
}

    h = 1 / (m + 1); I = sparse.identity(m)

    Gx = sparse.kron(I, G1); Gy = sparse.kron(G1, I)

fn lap_d(m: usize, dfun: impl Fn(f64, f64) -> f64) -> CsMat<f64> {   // -div(D grad u)
    let (n, h) = (m * m, 1.0 / (m + 1) as f64);
    let mut t = TriMat::new((n, n));
    for j in 0..m {
        for i in 0..m {
            let k = i + m * j;
            let (x, y) = ((i + 1) as f64 * h, (j + 1) as f64 * h);     // node
            let (xw, xe) = ((i as f64 + 0.5) * h, (i as f64 + 1.5) * h); // its faces
            let (ys, yn) = ((j as f64 + 0.5) * h, (j as f64 + 1.5) * h);
            let faces = [(dfun(xw, y), i > 0, k.wrapping_sub(1)),
                         (dfun(xe, y), i < m - 1, k + 1),
                         (dfun(x, ys), j > 0, k.wrapping_sub(m)),
                         (dfun(x, yn), j < m - 1, k + m)];
            for (d, inside, l) in faces {
                t.add_triplet(k, k, d);              // every face adds D to the diagonal
                if inside { t.add_triplet(k, l, -d); }
            }
        }
    }
    t.to_csr()
}

// IC(0) for the five-point pattern: diagonal d, west and south entries of L
fn ic0(a: &CsMat<f64>, m: usize) -> (Vec<f64>, Vec<f64>, Vec<f64>) {
    let n = a.rows();
    let (mut d, mut lw, mut ls) = (vec![0.0; n], vec![0.0; n], vec![0.0; n]);
    let g = |i: usize, j: usize| *a.get(i, j).unwrap_or(&0.0);
    for k in 0..n {
        if k > 0 { lw[k] = g(k, k - 1) / d[k - 1]; }
        if k >= m { ls[k] = g(k, k - m) / d[k - m]; }
        d[k] = (g(k, k) - lw[k].powi(2) - ls[k].powi(2)).sqrt();
    }
    (d, lw, ls)
}
// z = (L L^T)^{-1} r by a forward and a backward substitution
fn ic_solve(l: &(Vec<f64>, Vec<f64>, Vec<f64>), m: usize, r: &[f64]) -> Vec<f64> {
    let (d, lw, ls) = l;
    let n = r.len();
    let mut y = r.to_vec();
    for k in 0..n {
        if k > 0 { y[k] -= lw[k] * y[k - 1]; }
        if k >= m { y[k] -= ls[k] * y[k - m]; }
        y[k] /= d[k];
    }
    for k in (0..n).rev() {
        if k + 1 < n { y[k] -= lw[k + 1] * y[k + 1]; }
        if k + m < n { y[k] -= ls[k + m] * y[k + m]; }
        y[k] /= d[k];
    }
    y
}

    let (n, ph) = (m * m, pe / (m + 1) as f64);
    let mut t = TriMat::new((n, n));
    for j in 0..m {
        for i in 0..m {
            let k = i + m * j;
            t.add_triplet(k, k, 4.0 + ph);
            if i > 0 { t.add_triplet(k, k - 1, -1.0 - ph); }
            if i < m - 1 { t.add_triplet(k, k + 1, -1.0); }
            if j > 0 { t.add_triplet(k, k - m, -1.0); }
            if j < m - 1 { t.add_triplet(k, k + m, -1.0); }
        }
    }
    t.to_csr()
}

fn cg_fixed(a: &CsMat<f64>, b: &[f64], steps: usize) -> Vec<f64> {   // plain CG, no stopping
    let n = b.len();
    let (mut x, mut r, mut p) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let mut rr = dot(&r, &r);
    for _ in 0..steps {
        let ap = matvec(a, &p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n { x[i] += alpha * p[i]; r[i] -= alpha * ap[i]; }
        let rr_new = dot(&r, &r);
        for i in 0..n { p[i] = r[i] + (rr_new / rr) * p[i]; }
        rr = rr_new;
    }
    x
}
fn gmres(a: &CsMat<f64>, b: &[f64], k: usize, tol: f64) -> (Vec<f64>, usize) {
    let beta = norm(b);
    let mut q: Vec<Vec<f64>> = vec![b.iter().map(|v| v / beta).collect()];
    let mut h = DMatrix::<f64>::zeros(k + 1, k);
    let mut y = DVector::<f64>::zeros(0);
    let mut jlast = 0;
    for j in 0..k {
        let mut w = matvec(a, &q[j]);                   // one product with A
        for i in 0..=j {
            h[(i, j)] = dot(&q[i], &w);
            for (wl, ql) in w.iter_mut().zip(&q[i]) { *wl -= h[(i, j)] * ql; }
        }
        h[(j + 1, j)] = norm(&w);
        q.push(w.iter().map(|v| v / h[(j + 1, j)]).collect());
        // small least-squares problem: minimise || beta e1 - H y ||
        let hj = h.view((0, 0), (j + 2, j + 1)).into_owned();
        let mut e1 = DVector::<f64>::zeros(j + 2);
        e1[0] = beta;
        let qr = hj.clone().qr();
        y = qr.r().solve_upper_triangular(&(qr.q().transpose() * &e1)).unwrap();
        jlast = j + 1;
        if (&e1 - &hj * &y).norm() < tol * beta { break; }
    }
    let mut x = vec![0.0; b.len()];
    for (l, yl) in y.iter().enumerate() {
        for (xi, qi) in x.iter_mut().zip(&q[l]) { *xi += yl * qi; }
    }
    (x, jlast)
}

// restarted GMRES(k): at most maxit steps in total; returns iterations and relative residual
fn gmres_k(a: &CsMat<f64>, b: &[f64], k: usize, tol: f64, maxit: usize) -> (usize, f64) {
    let (mut x, nb, mut it) = (vec![0.0; b.len()], norm(b), 0);
    loop {
        let r = residual(a, b, &x);
        let nr = norm(&r);
        if nr < tol * nb || it >= maxit { return (it, nr / nb); }
        let (dx, j) = gmres(a, &r, k.min(maxit - it), tol * nb / nr);   // one cycle
        for (xi, d) in x.iter_mut().zip(&dx) { *xi += d; }
        it += j;
    }
}

fn bicgstab(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, Option<usize>) {
    let n = b.len();
    let (mut x, mut r, rh) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let nb = norm(b);
    let (mut rho, mut alpha, mut omega) = (1.0, 1.0, 1.0);
    let (mut v, mut p) = (vec![0.0; n], vec![0.0; n]);
    for it in 1..=maxit {
        let rho_new = dot(&rh, &r);
        let beta = (rho_new / rho) * (alpha / omega);
        rho = rho_new;
        for i in 0..n { p[i] = r[i] + beta * (p[i] - omega * v[i]); }
        v = matvec(a, &p);
        alpha = rho / dot(&rh, &v);
        let s: Vec<f64> = (0..n).map(|i| r[i] - alpha * v[i]).collect();
        let t = matvec(a, &s);
        omega = dot(&t, &s) / dot(&t, &t);                 // a GMRES(1) step
        for i in 0..n {
            x[i] += alpha * p[i] + omega * s[i];
            r[i] = s[i] - omega * t[i];
        }
        if norm(&r) < tol * nb { return (x, Some(it)); }
    }
    (x, None)
}
