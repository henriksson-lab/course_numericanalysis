Exercise: the SVD, rank deficiency and regularisation

Goal

By the end of this exercise you should be able to:

  • compute the SVD of a 2×2 matrix by hand and explain it as rotate – stretch – rotate,
  • read the condition number and the numerical rank off the singular values, and name the badly determined combination of parameters from the smallest right singular vector,
  • write the least-squares solution as \(\sum_i (u_i^Tb/\sigma_i)\,v_i\) and predict how much noise each term picks up,
  • compute the pseudoinverse (minimum-norm) solution of a rank-deficient problem,
  • regularise with the truncated SVD and ridge, and choose \(k\) or \(\lambda\) from the residual and the L-curve,
  • solve a non-negative least-squares problem, check its optimality conditions, and recognise when its answer is not determined by the data.

The running example is the deconvolution of a bulk RNA-seq sample into cell-type proportions, with a simulated signature in which CD4 and CD8 T cells differ by 2 % on two genes. The by-hand part uses pen, paper and a calculator.

Background

A bulk sample is modelled as a mixture of pure cell types: \(b \approx S p\), where \(S\) (genes × cell types) is the signature matrix and \(p\) the vector of proportions. With more genes than cell types this is an overdetermined least-squares problem, \(\min_p \|Sp - b\|\).

Facts used below:

  1. SVD. Every \(m\times n\) matrix (\(m \ge n\)) is \(A = U\Sigma V^T = \sum_i \sigma_i u_iv_i^T\), with orthonormal columns \(u_i\) (data space) and \(v_i\) (parameter space) and singular values \(\sigma_1 \ge \dots \ge \sigma_n \ge 0\). Key relation: \(Av_i = \sigma_i u_i\).
  2. By hand: the \(\sigma_i^2\) are the eigenvalues of \(A^TA\) and the \(v_i\) its eigenvectors; then \(u_i = Av_i/\sigma_i\). (In floating point, do not compute it this way: forming \(A^TA\) squares the condition number.)
  3. \(\|A\|_2 = \sigma_1\) and the condition number is \(\kappa(A) = \sigma_1/\sigma_n\).
  4. Numerical rank: the number of \(\sigma_i\) above a tolerance; for rounding errors \(\max(m,n)\,\varepsilon\,\sigma_1\), for measured data the noise level.
  5. Least squares through the SVD: \(x = \sum_i \dfrac{u_i^Tb}{\sigma_i}\,v_i\). Noise \(\delta b\) adds \(\dfrac{u_i^T\delta b}{\sigma_i}\,v_i\): divided by \(\sigma_i\).
  6. Pseudoinverse: \(A^+ = V\Sigma^+U^T\) with \(1/\sigma_i\) replaced by 0 for (numerically) zero \(\sigma_i\). \(A^+b\) is the least-squares solution of minimum norm.
  7. Truncated SVD: keep the first \(k\) terms of fact 5. Ridge (Tikhonov): \(\min_x \|Ax-b\|^2 + \lambda^2\|x\|^2\), solved by fact 5 with each term multiplied by the filter factor \(f_i = \sigma_i^2/(\sigma_i^2+\lambda^2)\), or as least squares on the stacked system \(\begin{pmatrix}A\\ \lambda I\end{pmatrix}x \approx \begin{pmatrix}b\\0\end{pmatrix}\).
  8. NNLS: \(\min_x\|Ax-b\|\) subject to \(x \ge 0\). With \(w = A^T(b - Ax)\), the solution satisfies \(w_j = 0\) where \(x_j > 0\) and \(w_j \le 0\) where \(x_j = 0\) (no held variable would reduce the residual by increasing).

// The SVD of a 2x2 matrix with nalgebra (R: svd; numpy: np.linalg.svd).
use nalgebra::{DMatrix, DVector};

fn main() {
    let a = DMatrix::from_row_slice(2, 2, &[3.0, 0.0,
                                            4.0, 5.0]);
    let svd = a.clone().svd(true, true);     // sorted, largest first
    let d: DVector<f64> = svd.singular_values.clone();
    let u = svd.u.unwrap();
    let vt = svd.v_t.unwrap();               // like numpy, nalgebra returns V^T
    println!("{} {}", d[0], d[1]);           // singular values
    println!("{}", d[0] / d[1]);             // condition number
    let rebuilt = &u * DMatrix::from_diagonal(&d) * &vt;
    println!("{:e}", (a - rebuilt).abs().max()); // A = U Sigma V^T
}

// 3.0000000000000004

R’s svd returns \(V\); numpy’s np.linalg.svd and nalgebra’s SVD return \(V^T\). The signs of singular vectors are arbitrary and differ between programs; where we print singular vectors we fix a sign first. Rust prints numbers in its own format; the values agree with R and Python to the digits shown unless the text says otherwise.

By hand

B1. The SVD of a 2×2 matrix. Let \(A = \begin{pmatrix} 3 & 0 \\ 4 & 5\end{pmatrix}\). (a) Compute \(A^TA\) and its eigenvalues. What are \(\sigma_1\) and \(\sigma_2\)? (b) Find the eigenvectors \(v_1, v_2\) of \(A^TA\) (unit length, first entry positive), then \(u_i = Av_i/\sigma_i\). Check that \(u_1 \perp u_2\). (c) Check that \(\sigma_1u_1v_1^T + \sigma_2u_2v_2^T = A\). (d) What are \(\|A\|_2\) and \(\kappa(A)\)? Check that \(\sigma_1\sigma_2 = |\det A|\). (e) The unit circle is mapped by \(A\) onto an ellipse. Give the directions and lengths of its half-axes. Which unit vector \(x\) is stretched most?

B2. Two identical cell types. Two cell types have the same signature on three genes: \(A = \begin{pmatrix} 1 & 1 \\ 2 & 2 \\ 2 & 2 \end{pmatrix}\). (a) What is the rank of \(A\)? Compute \(A^TA\), its eigenvalues, and \(\sigma_1, \sigma_2\). (b) Find \(v_1\), \(v_2\) and \(u_1\). Which combination of the two proportions is \(v_2\), and what does \(A\) do to it? (c) The bulk sample is \(b = (3, 6, 6)\). Describe all least-squares solutions \(x\). (d) Compute the pseudoinverse \(A^+ = \sigma_1^{-1}v_1u_1^T\) and the minimum-norm solution \(A^+b\). Is it the solution of (c) with the smallest \(\|x\|\)? (e) With a noisy sample \(b = (3, 6, 7)\), what is \(A^+b\)?

B3. Two nearly identical cell types. Now the second cell type is 2 % higher on gene 2: \(A = \begin{pmatrix} 1 & 1 \\ 1 & 1.02 \end{pmatrix}\). (a) \(A\) is symmetric with positive eigenvalues, so its singular values are its eigenvalues. Compute them (to 3 significant digits) and \(\kappa(A)\). (b) Solve \(Ax = (2, 2.02)\). (c) Now the measurement of gene 2 is off by \(0.01\): solve \(Ax = (2, 2.03)\). Compare the relative change in \(b\) with the relative change in \(x\). Is the amplification below \(\kappa\)? (d) Find the eigenvector belonging to the small eigenvalue. In which direction did \(x\) move in (c)? Interpret it biologically.

B4. Filtering the small singular value. Continue with B3 (\(\sigma_1 \approx 2.01\), \(\sigma_2 \approx 0.00995\), \(v_1 \approx u_1 \approx \tfrac{1}{\sqrt2}(1, 1)\), \(v_2 \approx \tfrac{1}{\sqrt2}(1,-1)\)). (a) Truncated SVD with \(k = 1\) for \(b = (2, 2.03)\): compute \(x_1 = \dfrac{u_1^Tb}{\sigma_1}v_1\). (b) Compute the ridge filter factors \(f_1, f_2\) for \(\lambda = 0.1\) and for \(\lambda = 1\). (c) In B3(c), the change \(\delta b = (0, 0.01)\) moved \(x\) by about \((-0.5, 0.5)\), almost exactly along \(v_2\). Roughly how far does it move the ridge solution with \(\lambda = 0.1\)? (d) If the two cell types really were present in different amounts, say \(x = (1.2, 0.8)\), what would TSVD with \(k = 1\) report? What is the price of regularisation?

B5. NNLS by hand. Three genes, two cell types: \(A = \begin{pmatrix} 1 & 1 \\ 1 & 1 \\ 1 & 1.1 \end{pmatrix}\), \(b = (1, 1, 0.9)\). (a) Solve the unconstrained least-squares problem with the normal equations (\(A^TA\) is 2×2; this is fine by hand). Is the answer a valid set of proportions? (b) Hold \(x_2 = 0\) and solve the one-variable least-squares problem for \(x_1\). (c) Check the optimality condition (fact 8): compute \(w = A^T(b - Ax)\) at your answer from (b). Does increasing \(x_2\) from 0 help? (d) Compare the two answers with the “true” \(x_1 + x_2\), if the truth were a 50/50 mix of the two cell types.

B6. Where the noise goes in the deconvolution. In the simulated signature, the CD4T and CD8T columns are equal except on gene 1 (\(142.074\) and \(139.232\)) and gene 2 (\(145.465\) and \(148.374\)). The smallest singular value is \(\sigma_5 = 2.875\) with \(v_5 \approx \tfrac{1}{\sqrt2}(1, -1, 0, 0, 0)\). (a) Compute \(Sv_5 = (S_{\cdot,\mathrm{CD4}} - S_{\cdot,\mathrm{CD8}})/\sqrt2\). On which genes is it non-zero? Check that its length is \(\sigma_5\), and write down \(u_5 = Sv_5/\sigma_5\). (b) The bulk values of genes 1 and 2 are about 65 and 67, measured with 5 % independent noise. What is the typical size (standard deviation) of \(u_5^T\delta b\)? (c) How large an error does that cause in \(x\) along \(v_5\)? And in CD4 and in CD8 separately? In CD4 + CD8? (d) With CD8 made identical to CD4, R reports \(\sigma = (642.9, 340.6, 278.8, 269.1, 6.6\times10^{-14})\) for the \(40\times5\) matrix. Compute the tolerance \(\max(m,n)\,\varepsilon\,\sigma_1\) and the numerical rank. Why is \(\sigma_5\) not exactly 0?

// rust/examples/svd_setup.rs  —  cargo run --example svd_setup
// The simulated deconvolution problem (nalgebra). Every later svd_c* file repeats signature().
use nalgebra::{DMatrix, DVector};

// The simulated signature matrix S (40 genes x 5 cell types), the true
// proportions, and the noise-free and noisy bulk profiles b0 and b.
fn signature() -> (DMatrix<f64>, DVector<f64>, DVector<f64>, DVector<f64>) {
    let mut s = DMatrix::from_element(40, 5, 10.0);
    for i in 0..16 { s[(i, 0)] = 100.0; s[(i, 1)] = 100.0; }  // T-cell genes
    for i in 16..40 { s[(i, 2 + (i - 16) / 8)] = 100.0; }     // B, NK, Mono markers
    for i in 0..40 {
        for j in 0..5 {                                        // gene-to-gene variation
            s[(i, j)] *= 1.0 + 0.5 * (((i + 1) * (j + 1)) as f64).sin();
        }
    }
    for i in 0..40 { s[(i, 1)] = s[(i, 0)]; }                  // CD8 = CD4 ...
    s[(0, 1)] = 0.98 * s[(0, 0)];                              // ... except gene 1
    s[(1, 1)] = 1.02 * s[(1, 0)];                              //     and gene 2
    let p_true = DVector::from_vec(vec![0.30, 0.15, 0.15, 0.10, 0.30]);
    let b0 = &s * &p_true;
    let b = DVector::from_fn(40, |i, _| b0[i] * (1.0 + 0.05 * (37.0 * (i + 1) as f64).sin()));
    (s, p_true, b0, b)
}

fn main() {
    let (s, _p_true, _b0, b) = signature();
    for i in 0..3 {
        let row: Vec<String> = (0..5).map(|j| format!("{:8.3}", s[(i, j)])).collect();
        println!("{}", row.join(" "));
    }
    println!("{:.3} {:.3} {:.3}", b[0], b[1], b[2]);
}

C6. Non-negative least squares. (a) Check your answer to B5 with nnls::nnls (Python: scipy.optimize.nnls; Rust: hand-written, below). (b) Solve the deconvolution with NNLS. C7. The check: refit with new noise. Generate 500 bulk samples from the same proportions, each with fresh noise: b0 * (1 + 0.05 * rnorm(40)) (Python: rng.standard_normal(40)). Report the mean and standard deviation of the CD4, CD8 and CD4 + CD8 estimates, and how often NNLS sets CD8 or CD4 to exactly 0. Compare the standard deviation of the least-squares CD4 estimate with your prediction in B6(c).

Answer E1

At 5 %: \(x = (0.543, -0.092, 0.149, 0.099, 0.299)\), as on the slides; expected noise 1.202, and 32 of 100 dots fall off the scale (\(-0.6\) to \(1.2\)) for CD4T and for CD8T. At 1 % the noise is 0.240 and the estimate \((0.349, 0.102, \dots)\); at 0 the estimate is exactly \(p\). The noise is proportional to \(s\) (1.202 / 5 = 0.240): least squares has no bias, only noise. The dots for B, NK, Mono and CD4 + CD8 stay in a tight band (CD4 + CD8 = 0.451 at 5 %): the noise lands only along \(v_5 \approx (1, -1, 0, 0, 0)/\sqrt2\), which changes the split but not the total. The multiplier is \(1/\sigma_5 = 1/2.87 = 0.348\), against at most \(1/269 = 0.0037\) for the other components: component 5 amplifies noise about 90 times more.

Hints

Hint 1 — SVD by hand (B1, B2)

The eigenvalues of a symmetric 2×2 matrix \(\begin{pmatrix}a & c\\ c & d\end{pmatrix}\) solve \(\lambda^2 - (a+d)\lambda + (ad - c^2) = 0\). For an eigenvector, solve \((A^TA - \lambda I)v = 0\): one equation is enough, then scale to length 1. For \(u_i\), multiply \(A\) by \(v_i\) and divide by \(\sigma_i\); if \(\sigma_i = 0\), there is no \(u_i\) to compute (and you do not need it for \(A^+\)).

Hint 2 — conditioning (B3, B4)

The inverse of \(\begin{pmatrix}a & b\\ c & d\end{pmatrix}\) is \(\frac{1}{ad - bc}\begin{pmatrix}d & -b\\ -c & a\end{pmatrix}\). Relative change = \(\|\delta b\|/\|b\|\) and \(\|\delta x\|/\|x\|\) in the 2-norm. Ridge acts on each SVD component separately: a change along \(v_2\) is multiplied by \(f_2\).

Hint 3 — NNLS by hand (B5)

Normal equations: \(A^TAx = A^Tb\). With \(x_2\) held at 0, the problem is \(\min_{x_1}\|a_1x_1 - b\|\), solved by \(x_1 = a_1^Tb/a_1^Ta_1\). \(w_2 = a_2^T(b - Ax)\) is minus half the derivative of \(\|Ax - b\|^2\) with respect to \(x_2\): if \(w_2 \le 0\), increasing \(x_2\) does not reduce the residual.

Hint 4 — noise along one direction (B6)

For independent noise \(\delta b_1, \delta b_2\) with standard deviations \(s_1, s_2\), the combination \(c_1\delta b_1 + c_2\delta b_2\) has standard deviation \(\sqrt{c_1^2s_1^2 + c_2^2s_2^2}\). A change \(t\,v_5\) in \(x\) changes CD4 by \(t/\sqrt2\) and CD8 by \(-t/\sqrt2\), and leaves CD4 + CD8 unchanged.

Hint 5 — SVD in code (C1–C4)

R: s <- svd(A) gives s$d, s$u, s$v; crossprod(U, b) is \(U^Tb\). Python: U, d, Vt = np.linalg.svd(A, full_matrices=False); the \(v_i\) are the rows of Vt. Rust (nalgebra): let svd = a.clone().svd(true, true); gives svd.singular_values, svd.u.unwrap(), svd.v_t.unwrap() (rows are \(v_i\)), sorted largest first. To fix a sign, multiply a column of \(V\) and the matching column of \(U\) by \(-1\). Machine epsilon: .Machine$double.eps, np.finfo(float).eps, f64::EPSILON.

Hint 6 — ridge and the L-curve (C5)

Filter factors f <- d^2 / (d^2 + lambda^2), then \(x = V\,(f \cdot U^Tb/d)\). Stacked system in R: qr.solve(rbind(S, lambda * diag(5)), c(b, rep(0, 5))); Python: np.linalg.lstsq(np.vstack([S, lam * np.eye(5)]), np.concatenate([b, np.zeros(5)])). For the plot, use sapply (R) or a list comprehension (Python) over 10^seq(-1, 3, by = 0.05), and plot(..., log = "xy") / plt.loglog.

Hint 7 — NNLS (C6)

R: library(nnls); fit <- nnls(A, b); fit$x (nnls, install with install.packages("nnls")). Python: x, rnorm = scipy.optimize.nnls(A, b) (docs). Rust: there is no NNLS in the allowed crates; the solution has a hand-written Lawson–Hanson active-set method (the algorithm on the slides), built on the QR least-squares solve from the previous unit.

Hint 8 — replicates (C7)

R: replicate(500, { ... }) collects the results of a block into an array; apply(est, c(1, 2), sd) takes the standard deviation over the last dimension. Python: fill an array est[r, :, :] in a loop and use est.std(axis=0, ddof=1). Rust: rand_distr::StandardNormal with a seeded StdRng. The three languages use different random numbers, so the last digit differs.

// Non-negative least squares by the Lawson-Hanson active-set method (hand-written;
// R: nnls::nnls, Python: scipy.optimize.nnls). "free" = allowed to be positive.
fn nnls(a: &DMatrix<f64>, b: &DVector<f64>) -> DVector<f64> {
    let n = a.ncols();
    let mut x = DVector::zeros(n);
    let mut free = vec![false; n];
    let tol = 1e-10 * (a.transpose() * b).abs().max();
    for _outer in 0..3 * n {
        let w = a.transpose() * (b - a * &x);           // -1/2 gradient of ||Ax - b||^2
        // the held variable whose increase reduces the residual fastest
        let j = (0..n).filter(|&j| !free[j] && w[j] > tol)
                      .max_by(|&i, &k| w[i].partial_cmp(&w[k]).unwrap());
        let Some(j) = j else { break };                 // none: optimal (KKT holds)
        free[j] = true;
        loop {
            // least squares on the free variables only
            let idx: Vec<usize> = (0..n).filter(|&i| free[i]).collect();
            let zf = lstsq_qr(&a.select_columns(&idx), b);
            let mut z = DVector::zeros(n);
            for (k, &i) in idx.iter().enumerate() { z[i] = zf[k]; }
            if idx.iter().all(|&i| z[i] > 0.0) { x = z; break; }
            // step from x towards z until the first free variable hits 0
            let alpha = idx.iter().filter(|&&i| z[i] <= 0.0)
                           .map(|&i| x[i] / (x[i] - z[i]))
                           .fold(f64::INFINITY, f64::min);
            x += alpha * (&z - &x);
            for &i in &idx {
                if x[i] <= 1e-14 { x[i] = 0.0; free[i] = false; }   // hold it at 0
            }
        }
    }
    x
}

    let m = v.iter().sum::<f64>() / n;
    (m, (v.iter().map(|x| (x - m).powi(2)).sum::<f64>() / (n - 1.0)).sqrt())
}

fn main() {
    let (s, _p_true, b0, _b) = signature();
    let mut rng = StdRng::seed_from_u64(1);
    // est[method][quantity] = 500 values; quantity 0 = CD4, 1 = CD8, 2 = CD4 + CD8
    let mut est = vec![vec![Vec::new(); 3]; 4];
    for _ in 0..500 {
        let br = DVector::from_fn(40, |i, _| {
            let z: f64 = StandardNormal.sample(&mut rng);
            b0[i] * (1.0 + 0.05 * z)                     // fresh 5% noise
        });
        let xs = [lstsq_qr(&s, &br), tsvd(&s, &br, 4), ridge(&s, &br, 10.0), nnls(&s, &br)];
        for (m, x) in xs.iter().enumerate() {
            est[m][0].push(x[0]);
            est[m][1].push(x[1]);
            est[m][2].push(x[0] + x[1]);
        }
    }
    println!("      ls  tsvd ridge  nnls");
    for (q, name) in ["CD4", "CD8", "sum"].iter().enumerate() {
        let ms: Vec<(f64, f64)> = (0..4).map(|m| mean_sd(&est[m][q])).collect();
        let means: Vec<String> = ms.iter().map(|p| format!("{:5.3}", p.0)).collect();
        let sds: Vec<String> = ms.iter().map(|p| format!("{:5.3}", p.1)).collect();
        println!("{} {}  | sd {}", name, means.join(" "), sds.join(" "));
    }
    let zero = |q: usize| est[3][q].iter().filter(|&&x| x == 0.0).count() as f64 / 500.0;
    println!("{} {}", zero(1), zero(0));
}

The CD4 + CD8 total has a standard deviation of 0.007 with every method: it is well determined. The split is not. Least squares: standard deviation about 0.8 for proportions of 0.30 and 0.15, as B6(c) predicted. NNLS: 0.21, and in roughly 35–45 % of the replicates it sets CD8 to exactly 0, in about as many CD4: a zero from NNLS does not mean the cell type is absent. Ridge: 0.06, closer, but centred near 0.225 each. TSVD: almost no spread, but always the equal split, biased. No method recovers 0.30/0.15, because the data do not contain that information. The fix is biological: a signature with more genes that separate CD4 from CD8, which raises \(\sigma_5\).
