Exercise: numerical differentiation

Goal

By the end of this exercise you should be able to:

  • derive forward, backward, central and second-derivative stencils from Taylor series, with their leading error term,
  • build the weights of any stencil (one-sided, five-point) by solving a small linear system,
  • choose the best step for each stencil from the balance of truncation and rounding error,
  • improve a central difference by Richardson extrapolation, and say what numDeriv::grad does,
  • estimate a growth rate from noisy OD data without amplifying the noise: wider stencils and local fits,
  • compute and check a gradient of a log-likelihood by finite differences, and choose its step relative to each parameter.

The by-hand part needs pen, paper and a pocket calculator. The code part checks your hand answers and then works with a full plate-reader time course.

Background

The running example is the logistic OD curve from Convergence and cost, \(N(t) = K / (1 + (K/N_0 - 1)e^{-rt})\) with \(K = 1.2\), \(N_0 = 0.05\), \(r = 0.8\) per hour. Its derivatives at \(t = 3\) h:

\(N\) \(N'\) \(N''\) \(N'''\) \(N''''\)
0.388788 0.210260 0.059212 \(-0.042270\) \(-0.061704\)

Facts used below:

  1. Stencils (error = leading Taylor term left over):

    formula estimate of error
    \(\dfrac{N(t+h) - N(t)}{h}\) (forward) \(N'\) \(\tfrac{h}{2}N''\)
    \(\dfrac{N(t) - N(t-h)}{h}\) (backward) \(N'\) \(-\tfrac{h}{2}N''\)
    \(\dfrac{N(t+h) - N(t-h)}{2h}\) (central) \(N'\) \(\tfrac{h^2}{6}N'''\)
    \(\dfrac{-3N(t) + 4N(t+h) - N(t+2h)}{2h}\) (one-sided) \(N'\) \(-\tfrac{h^2}{3}N'''\)
    \(\dfrac{N(t+h) - 2N(t) + N(t-h)}{h^2}\) (second difference) \(N''\) \(\tfrac{h^2}{12}N''''\)

  2. Weights of any stencil. For offsets \(s_0, \dots, s_{n-1}\) (in units of \(h\)) the weights \(w_j\) of the \(m\)-th derivative solve \(\sum_j w_j\, s_j^k / k! = [k = m]\) for \(k = 0, \dots, n-1\); then \(N^{(m)}(t) \approx \sum_j w_j N(t + s_j h) / h^m\).

  3. Best step. Truncation \(\approx C h^p\), rounding \(\approx \varepsilon |N| / h^k\) for the \(k\)-th derivative. Balance: \(h^* \approx \varepsilon^{1/(p+k)}\), i.e. \(\varepsilon^{1/2} \approx 1.5\times10^{-8}\) (forward), \(\varepsilon^{1/3} \approx 6\times10^{-6}\) (central), \(\varepsilon^{1/4} \approx 1.2\times10^{-4}\) (second difference), times \(\max(|t|, 1)\).

  4. Richardson. If \(D(h) = N' + c_2h^2 + c_4h^4 + \dots\) (central difference), then \(\dfrac{4D(h/2) - D(h)}{3} = N' + O(h^4)\). Repeating with \(16\), \(64\), … gives a table of ever higher order.

  5. Noise. With independent measurement errors of sd \(\sigma\) at spacing \(\Delta t\), the central difference of neighbours has noise sd \(\sigma/(\sqrt2\,\Delta t)\), the forward difference \(\sqrt2\,\sigma/\Delta t\). A half-width \(h = k\Delta t\) divides the noise by \(k\) but adds truncation error \(\tfrac{h^2}{6}|N'''|\).

  6. Gradients. \(\partial f / \partial \theta_j\) is an ordinary derivative in \(\theta_j\) with the other parameters fixed: one difference per parameter, with a step scaled to \(|\theta_j|\).

The basic tools in each language. R has numDeriv::grad (Richardson); Python has scipy.differentiate.derivative (adaptive, Richardson-like) and scipy.optimize.approx_fprime (forward difference); our Rust crate list has no differentiation crate, so the Rust version is hand-written.

// rust/examples/finite_differences_background.rs  —  cargo run --example finite_differences_background
// Background: central difference at the best step, and a Richardson table.
// Rust has no numDeriv / scipy.differentiate in our crate list: both are hand-written.
const K: f64 = 1.2;
const N0: f64 = 0.05;
const R: f64 = 0.8;

fn od(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}
fn gr(t: f64) -> f64 {
    R * od(t) * (1.0 - od(t) / K) // exact N'(t)
}

fn main() {
    let h = f64::EPSILON.powf(1.0 / 3.0); // best step for central
    let cen = (od(3.0 + h) - od(3.0 - h)) / (2.0 * h);
    println!("{} {:e}", cen, cen - gr(3.0));
    // Richardson, 4 levels from h = 1e-4 * |x| (what numDeriv::grad does)
    let mut d: Vec<f64> = (0..4)
        .map(|i| { let h = 3e-4 / 2f64.powi(i); (od(3.0 + h) - od(3.0 - h)) / (2.0 * h) })
        .collect();
    for j in 1..4 {
        let f = 4f64.powi(j as i32);
        for i in (j..4).rev() { d[i] = (f * d[i] - d[i - 1]) / (f - 1.0); }
    }
    println!("{:e}", d[3] - gr(3.0));
}

By hand

B1. Stencils from Taylor. (a) From the Taylor series of \(N(t-h)\), derive the backward difference and its leading error term. (b) Show that the average of the forward and the backward difference is the central difference. What happens to their \(\pm\tfrac{h}{2}N''\) error terms? (c) Using the derivative table above, predict the errors of the forward, central and second difference at \(t = 3\) with \(h = 0.2\).

B2. Weights by matching Taylor terms. (a) Find \(w_{-1}, w_0, w_1\) such that \(w_{-1}N(t-h) + w_0 N(t) + w_1 N(t+h) = h^2 N''(t) + O(h^4)\). Write down the three equations (for the \(N\), \(hN'\) and \(h^2N''\) terms) and solve them. (b) Without new algebra: what is the one-sided second-order formula at the last time point, using \(N(t)\), \(N(t-h)\), \(N(t-2h)\)? (Hint: replace \(h\) by \(-h\) in the formula at the first point.) (c) Why must the weights of every first- or second-derivative stencil add up to zero?

B3. A plate reader, by hand. The OD at \(t = 2.9\), \(3.0\), \(3.1\) h is \(0.368065\), \(0.388788\), \(0.410103\). (a) Compute the forward, backward and central estimates of \(N'(3)\) with \(h = 0.1\), and the second difference. Compare with the table. (b) The plate reader exports 3 decimals: \(0.368\), \(0.389\), \(0.410\). Recompute the central difference and the second difference. What happened to the second derivative? (c) How large can the rounding error of the second difference be, if each value is off by up to \(0.0005\)?

B4. The best step. (a) Central difference: minimise \(E(h) = a h^2 + b/h\) with \(a = |N'''|/6 = 0.00705\) and \(b = \varepsilon|N| = 8.6\times10^{-17}\). Give \(h^*\) and \(E(h^*)\). (b) Second difference: minimise \(E(h) = c h^2 + 4b/h^2\) with \(c = |N''''|/12 = 0.00514\). Give \(h^*\) and \(E(h^*)\). (c) Noisy data: replace \(b\) in (a) by the noise \(\sigma/\sqrt2\) with \(\sigma = 0.005\), and \(|N'''|\) by its maximum \(r^3K/8 = 0.0768\). What half-width \(h^*\) (in hours and in 10-minute steps) minimises the error?

B5. Richardson by hand. The central differences at \(t = 3\) are \(D(0.2) = 0.2099781463\) and \(D(0.1) = 0.2101892975\). (a) Compute \(R = \tfrac{4D(0.1) - D(0.2)}{3}\) and compare all three with \(N'(3) = 0.2102597349\). (b) The forward difference has error \(c_1h + c_2h^2 + \dots\). Find the combination of \(F(h)\) and \(F(h/2)\) that removes the \(c_1h\) term. Apply it to \(F(0.2) = 0.2158788766\) and \(F(0.1) = 0.2131473499\). (c) Your colleague applies Richardson to central differences of measured OD values. Why is that a bad idea?

B6. Noise in a derivative. A plate reader measures OD every 10 minutes with noise sd \(\sigma = 0.005\). (a) What is the noise sd of the forward difference of neighbours, and of the central difference of neighbours, in OD/h? (b) The same for measurements every 2 minutes. Compare with the peak growth rate \(rK/4 = 0.24\) OD/h. (c) The plate reader rounds to 3 decimals. Rounding errors are uniform on \([-0.0005, 0.0005]\), sd \(0.0005/\sqrt3\). Does the rounding matter next to \(\sigma\)? (d) What is the noise sd of the central difference with half-width \(h = 40\) min?

B7. Automatic differentiation by hand (forward mode). Evaluate \(N(3)\) as a chain of steps and carry the derivative with respect to \(t\) alongside (use \(r = 0.8\), \(K/N_0 - 1 = 23\), \(e^{-2.4} = 0.0907180\)):

step value derivative (w.r.t. \(t\))
\(v_1 = -r t\) \(v_1' = -r\)
\(v_2 = e^{v_1}\) \(v_2' = v_2\,v_1'\)
\(v_3 = 1 + 23\,v_2\) \(v_3' = 23\,v_2'\)
\(v_4 = K / v_3\) \(v_4' = -K\,v_3' / v_3^2\)

Fill in the table. Is \(v_4'\) an approximation? Which step size did you use?

B8. The cost of a gradient. One evaluation of a log-likelihood needs an ODE solve that takes 0.2 s. (a) How long does one gradient take for \(p = 3\) parameters with forward differences, central differences, and numDeriv::grad (8 evaluations per parameter)? And for \(p = 40\)? (b) A BFGS fit takes 100 iterations, each needing one gradient. How long does the \(p = 40\) fit take with central differences? With reverse-mode AD at about 3 evaluations per gradient?

Hints

Hint 1 — Taylor series (B1, B2)

Write \(N(t \pm h) = N \pm hN' + \tfrac{h^2}{2}N'' \pm \tfrac{h^3}{6}N''' + \tfrac{h^4}{24}N'''' \pm \dots\). For a stencil, add \(w_j\) times the row for each point and collect the coefficient of each derivative. For B2(a) the equations are \(w_{-1} + w_0 + w_1 = 0\), \(-w_{-1} + w_1 = 0\), \(\tfrac12 w_{-1} + \tfrac12 w_1 = 1\).

Hint 2 — minimising a + b (B4)

Differentiate \(E(h)\) and set it to zero: for \(ah^2 + b/h\), \(2ah = b/h^2\), so \(h^3 = b/(2a)\). For \(ch^2 + 4b/h^2\), \(2ch = 8b/h^3\), so \(h^4 = 4b/c\).

Hint 3 — noise (B6, C4)

If \(e_1\) and \(e_2\) are independent with sd \(\sigma\), then \(e_2 - e_1\) has sd \(\sqrt2\,\sigma\). Dividing by a constant \(c\) divides the sd by \(c\). In R, y[i + k] - y[i - k] with i <- (k + 1):(n - k) takes all differences at once; in Python, y[2*k:] - y[:-2*k].

Hint 4 — weights by a linear system (C2)

Build the matrix with outer (R) or a nested list comprehension (Python), row \(k\) = \(s_j^k/k!\), and solve with solve (R) or np.linalg.solve (Python); in Rust, nalgebra’s DMatrix::lu().solve. For a five-point stencil the error is \(O(h^4)\), so halving \(h\) should divide it by 16.

Hint 5 — Richardson table (C3)

Fill column 1 in a loop over \(i\); then for each column \(j \ge 2\), loop over the rows \(i \ge j\) and combine A[i, j-1] (the smaller step) with A[i-1, j-1]. Library equivalents: numDeriv::grad (R), scipy.differentiate.derivative (Python).

Hint 6 — smoothing (C5)

The formula is the slope of lm(y ~ t) on the window, with the window centred so that \(\sum j = 0\). The library route, covered in Splines: smooth.spline followed by predict(fit, t, deriv = 1) in R, scipy.interpolate.make_smoothing_spline followed by .derivative() in Python. np.gradient is the central difference of neighbours: it does not smooth.

Hint 7 — gradients (C6)

Loop over the parameters; build a vector e of zeros with h[j] in position j, and difference f(x + e) and f(x - e). Compare with the exact gradient through the relative error \(|g_\text{fd} - g|/|g|\). R’s optim documents ndeps and parscale under Details; Python’s scipy.optimize.minimize takes jac= for an exact gradient.

fn od(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}

// slope of the least-squares line through (x, y)
fn slope(x: &[f64], y: &[f64]) -> f64 {
    let n = x.len() as f64;
    let (mx, my) = (x.iter().sum::<f64>() / n, y.iter().sum::<f64>() / n);
    let sxy: f64 = x.iter().zip(y).map(|(a, b)| (a - mx) * (b - my)).sum();
    let sxx: f64 = x.iter().map(|a| (a - mx).powi(2)).sum();
    sxy / sxx
}

// C6: gradient of a log-likelihood by finite differences, against the exact one.
const SIGMA: f64 = 0.005;
const Y: [f64; 61] = [
    0.047, 0.058, 0.060, 0.081, 0.084, 0.090, 0.108, 0.123, 0.137, 0.150,
    0.177, 0.192, 0.210, 0.226, 0.269, 0.292, 0.322, 0.359, 0.393, 0.428,
    0.466, 0.504, 0.540, 0.569, 0.622, 0.659, 0.698, 0.730, 0.772, 0.812,
    0.851, 0.876, 0.909, 0.935, 0.955, 0.985, 1.007, 1.029, 1.054, 1.069,
    1.079, 1.092, 1.109, 1.120, 1.123, 1.132, 1.145, 1.154, 1.155, 1.166,
    1.168, 1.167, 1.175, 1.171, 1.187, 1.192, 1.183, 1.181, 1.191, 1.189,
    1.203];

fn t(i: usize) -> f64 { i as f64 / 6.0 }

fn loglik(th: &[f64]) -> f64 {
    let (r, k, n0) = (th[0], th[1], th[2]);
    -(0..61).map(|i| (Y[i] - k / (1.0 + (k / n0 - 1.0) * (-r * t(i)).exp())).powi(2))
        .sum::<f64>() / (2.0 * SIGMA * SIGMA)
}

fn grad_exact(th: &[f64], bug: bool) -> [f64; 3] {
    let (r, k, n0) = (th[0], th[1], th[2]);
    let mut g = [0.0; 3];
    for i in 0..61 {
        let e = (-r * t(i)).exp();
        let d = 1.0 + (k / n0 - 1.0) * e;
        let n = k / d;
        let w = (Y[i] - n) / (SIGMA * SIGMA);
        let tr = if bug { 1.0 } else { t(i) };
        g[0] += w * tr * n * (1.0 - n / k);            // dN/dr
        g[1] += w * (1.0 / d - k * e / (n0 * d * d));  // dN/dK
        g[2] += w * k * k * e / (n0 * n0 * d * d);     // dN/dN0
    }
    g
}

fn fd_grad(f: fn(&[f64]) -> f64, x: &[f64], h: &[f64], central: bool) -> [f64; 3] {
    let mut g = [0.0; 3];
    for j in 0..3 {
        let (mut xp, mut xm) = (x.to_vec(), x.to_vec());
        xp[j] += h[j];
        xm[j] -= h[j];
        g[j] = if central { (f(&xp) - f(&xm)) / (2.0 * h[j]) } else { (f(&xp) - f(x)) / h[j] };
    }
    g
}
