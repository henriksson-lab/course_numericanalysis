Exercise: how eigen() works, and big problems

Goal

By the end of this exercise you should be able to:

  • do one step of the QR algorithm by hand and explain why it keeps the eigenvalues,
  • relate the speed of the QR algorithm to ratios of eigenvalues, recognise when it stalls, and show how a shift fixes that,
  • explain why a real nonsymmetric matrix can have complex eigenvalues and what they mean for a biological model,
  • show that eigenvalues of a nonsymmetric matrix can be very sensitive, and run the two checks: the condition number of the eigenvector matrix, and perturb-and-recompute,
  • write a short Lanczos iteration, see its Ritz values converge, and see ghost eigenvalues appear without reorthogonalisation,
  • compute the top principal components of a large sparse single-cell matrix without densifying or centring it, and check the result with residuals.

The by-hand part needs pen, paper and a calculator for square roots. The code part checks your hand answers and then works at sizes where only code works. C6 and C7 build a 20 000 × 2 000 matrix: they need about 2 GB of memory and run for under a minute.

Background

Facts used below:

  1. Similarity. If \(A = QR\) with \(Q\) orthogonal, then \(RQ = Q^TAQ\) has the same eigenvalues as \(A\). The QR algorithm repeats \(A_k = Q_kR_k\), \(A_{k+1} = R_kQ_k\).
  2. Convergence. For eigenvalues ordered \(|\lambda_1| > |\lambda_2| > \dots\), the subdiagonal entry \(a_{i+1,i}\) of \(A_k\) shrinks like \(|\lambda_{i+1}/\lambda_i|^k\). If two eigenvalues have the same modulus it does not shrink.
  3. Shift. \(A_k - \mu I = Q_kR_k\), \(A_{k+1} = R_kQ_k + \mu I\). The rate for the last entry becomes \(|\lambda_n - \mu| / |\lambda_{n-1} - \mu|\). Shifts: \(\mu = a_{nn}\) (Rayleigh: \(a_{nn}\) is a Rayleigh quotient, so this is the Rayleigh quotient iteration of Power iteration and friends acting on the last row), or the Wilkinson shift, the eigenvalue of the trailing 2 × 2 block \(\begin{pmatrix} a & b \\ b & c \end{pmatrix}\) closer to \(c\): \[\mu = c - \frac{\operatorname{sign}(\delta)\, b^2}{|\delta| + \sqrt{\delta^2 + b^2}}, \qquad \delta = \frac{a - c}{2}, \quad \operatorname{sign}(0) = 1.\] Deflation: once \(|a_{n,n-1}|\) is below a tolerance, \(a_{nn}\) is an eigenvalue; remove the last row and column.
  4. 2 × 2 eigenvalues. \(\lambda^2 - \operatorname{tr}(A)\lambda + \det(A) = 0\). A real matrix with \(\operatorname{tr}^2 < 4\det\) has a complex pair \(\lambda = a \pm bi\): in a linear ODE model, an oscillation with period \(2\pi/b\) that grows (\(a > 0\)) or decays (\(a < 0\)).
  5. Sensitivity. Symmetric \(A\): a perturbation \(E\) moves each eigenvalue by at most \(\|E\|\). Nonsymmetric \(A = VDV^{-1}\): by up to \(\kappa(V)\|E\|\). For a chain of \(n\) compartments with one feedback of size \(\varepsilon\), \((\lambda + 1)^n = \varepsilon\), so the eigenvalues move by \(\varepsilon^{1/n}\).
  6. Lanczos. For symmetric \(A\) and a unit start vector \(\mathbf q_1\) (\(\mathbf q_0 = \mathbf 0\), \(\beta_0 = 0\)): \[\mathbf w = A\mathbf q_j - \beta_{j-1}\mathbf q_{j-1}, \quad \alpha_j = \mathbf q_j^T\mathbf w, \quad \mathbf w \leftarrow \mathbf w - \alpha_j\mathbf q_j, \quad \beta_j = \|\mathbf w\|, \quad \mathbf q_{j+1} = \mathbf w/\beta_j.\] The Ritz values after \(m\) steps are the eigenvalues of the tridiagonal \(T_m\) with \(\alpha_1, \dots, \alpha_m\) on the diagonal and \(\beta_1, \dots, \beta_{m-1}\) beside it. In floating point the \(\mathbf q_j\) lose orthogonality unless we reorthogonalise: \(\mathbf w \leftarrow \mathbf w - Q_j(Q_j^T\mathbf w)\).
  7. Implicit centring. With column means \(\boldsymbol\mu\) and \(X_c = X - \mathbf 1\boldsymbol\mu^T\): \(X_c\mathbf v = X\mathbf v - \mathbf 1(\boldsymbol\mu^T\mathbf v)\) and \(X_c^T\mathbf w = X^T\mathbf w - \boldsymbol\mu(\mathbf 1^T\mathbf w)\). PCA needs the top eigenpairs of \(X_c^TX_c\); \(\sqrt{\lambda_i}\) are the singular values of \(X_c\).

The basic calls in each language. R’s eigen does both kinds of matrix; numpy splits them into np.linalg.eigh/eigvalsh (symmetric, ascending order) and np.linalg.eig/eigvals (general); nalgebra has symmetric_eigen (unsorted) and complex_eigenvalues (values only: nalgebra has no eigenvectors for nonsymmetric matrices).

// Background: eigenvalues of a symmetric and a nonsymmetric matrix, and one QR step.
use nalgebra::{Matrix2, Matrix3};

fn main() {
    let a = Matrix3::new(4.0, 1.0, 0.0,
                         1.0, 3.0, 1.0,
                         0.0, 1.0, 2.0);                 // symmetric 3 x 3
    let mut ev: Vec<f64> = a.symmetric_eigen().eigenvalues.iter().cloned().collect();
    ev.sort_by(|x, y| y.partial_cmp(x).unwrap());         // unsorted: sort decreasing
    println!("{:.6?}", ev);
    let j = Matrix2::new(-0.1, -1.0,
                          0.5,  0.0);                     // predator-prey Jacobian
    for z in j.complex_eigenvalues().iter() {
        println!("{:.7} {:+.7}i", z.re, z.im);
    }
    let qr = a.qr();                                      // one QR step: A1 = R Q
    let a1 = qr.r() * qr.q();
    for i in 0..3 {
        println!("{:8.4} {:8.4} {:8.4}", a1[(i, 0)], a1[(i, 1)], a1[(i, 2)]);
    }
}

The signs of \(Q\), \(R\) and eigenvectors are arbitrary and differ between R (LINPACK QR), numpy (LAPACK Householder QR) and nalgebra; that is why the off-diagonal entries above have different signs in Rust. Magnitudes and eigenvalues agree. Rust prints numbers in its own format (1.2e-4 rather than 1.2e-04).

By hand

B1. One QR step. Let \(A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) (eigenvalues 3 and 1). (a) Compute \(A = QR\) by Gram–Schmidt on the columns of \(A\). Keep \(\sqrt5\) as a symbol. (b) Compute \(A_1 = RQ\). Check that the trace and the determinant did not change. (c) The off-diagonal entry went from 1 to \(a_{21}^{(1)}\). Asymptotically it shrinks by \(\lambda_2/\lambda_1\) per step. Roughly how many more steps until it is below \(10^{-12}\)?

B2. A QR step that does nothing. A cell switches between two states every generation; \(P = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\). (a) Find \(Q\) and \(R\) with \(P = QR\) (hint: the columns of \(P\) are already orthonormal). What is \(RQ\)? (b) What are the eigenvalues of \(P\), and why does fact 2 predict (a)? (c) With shift \(\mu = 0.5\), what are the eigenvalues of \(P - \mu I\), and at what rate does the shifted algorithm converge? Which shift between 0 and 1 would you choose, and why?

B3. A complex pair. The predator–prey Jacobian from the lecture is \(J = \begin{pmatrix} -0.1 & -1 \\ 0.5 & 0 \end{pmatrix}\). (a) Compute its eigenvalues from fact 4. (b) What are the period of the oscillation and the factor by which the amplitude shrinks per period? (c) Check: the sum of the eigenvalues is the trace and the product is the determinant. (d) Why can the QR algorithm in real arithmetic never turn \(J\) into a triangular matrix?

B4. Sensitive and insensitive eigenvalues. (a) \(N = \begin{pmatrix} -1 & \varepsilon \\ 1 & -1 \end{pmatrix}\) (two transit compartments with feedback \(\varepsilon\)). Compute its eigenvalues for \(\varepsilon = 10^{-4}\), \(10^{-10}\) and \(10^{-16}\). (b) Do the same for the symmetric \(S = \begin{pmatrix} -1 & \varepsilon \\ \varepsilon & -1 \end{pmatrix}\). (c) For the 10-compartment chain of the lecture, how far do the eigenvalues move for \(\varepsilon = 10^{-10}\) and for \(\varepsilon = 10^{-16}\) (rounding)? And for a chain of 20 compartments with \(\varepsilon = 10^{-16}\)? (d) A modeller reports “the slowest decay rate of this 20-compartment model is 0.84 per hour”. What do you tell them?

B5. Two Lanczos steps. \(A = \begin{pmatrix} 4 & 1 & 0 \\ 1 & 3 & 1 \\ 0 & 1 & 2 \end{pmatrix}\) (eigenvalues \(3 \pm \sqrt3 = 4.732, 1.268\) and \(3\)). (a) Run Lanczos from \(\mathbf q_1 = \mathbf e_1 = (1, 0, 0)\): compute \(\alpha_1, \beta_1, \mathbf q_2, \alpha_2, \beta_2, \mathbf q_3, \alpha_3\). (b) Give the Ritz values after 2 steps (the eigenvalues of \(T_2\)). Compare with the true largest and smallest eigenvalue. Which side are they on? (c) What is \(T_3\), and why? (d) Repeat (b) from \(\mathbf q_1 = \mathbf e_3\). Which eigenvalue is now approximated better?

B6. Cost and memory. A double takes 8 bytes. The single-cell matrix of the lecture has 20 000 cells × 2 000 genes, 13 % non-zero; R’s sparse format takes 12 bytes per non-zero. (a) How much memory do the dense and the sparse matrix take? (b) The same for 100 000 cells. How large is the 2 000 × 2 000 gene covariance matrix, and how large would a 100 000 × 100 000 cell–cell matrix be? (c) Dense eigen of a 2 000 × 2 000 symmetric matrix took 1.8 s. Estimate the time for 20 000 × 20 000. (d) One Lanczos step for PCA computes \(X_c^T(X_c\mathbf v)\) implicitly. About how many floating-point operations is that, for the 20 000-cell matrix? How many steps fit in the work of a dense SVD of \(X_c\) (about \(4np^2\) operations for \(n\) cells and \(p\) genes)?

In code

C1. The QR algorithm. For the 3 × 3 matrix \(A\) of the Background, run 40 unshifted QR steps. Every 10 steps print \(|a_{21}|\) and \(|a_{32}|\) next to \((\lambda_2/\lambda_1)^k\) and \((\lambda_3/\lambda_2)^k\). At the end, compare the diagonal with the eigenvalues and check \(A_k = \hat Q_k^TA\hat Q_k\) with \(\hat Q_k = Q_1\cdots Q_k\). Finally check that \(\hat Q_5\) is the \(Q\) factor of \(A^5\) (up to the signs of its columns). Python: np.linalg.qr, np.linalg.matrix_power.

C2. Shifts and deflation. Write qr_eig(A, type) that runs the shifted QR algorithm with deflation (tolerance \(10^{-12}\), at most 500 steps) and returns the eigenvalues and the number of steps, for type = no shift, Rayleigh shift \(a_{nn}\), and Wilkinson shift (fact 3). Run it on \(A\) and on \(B = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\). Compare the step counts with B1(c). What does the Rayleigh shift return for \(B\), and how would you notice that something went wrong?

C3. Complex eigenvalues. Compute the eigenvalues of \(J\) and the period. Then run 200 unshifted QR steps on \(J\) and print \(a_{21}\) and the diagonal after 50, 51 and 200 steps. Compute the eigenvalues of the final 2 × 2 matrix from its trace and determinant.

C4. Sensitivity. Build the 10-compartment chain (fact 5). (a) For \(\varepsilon = 10^{-14}, 10^{-12}, \dots, 10^{-2}\), put \(\varepsilon\) in the top-right corner and print the largest \(|\lambda + 1|\) next to \(\varepsilon^{1/10}\). For comparison, put \(\varepsilon\) symmetrically in entries (1, 3) and (3, 1) of the matrix \(A\) from C1 and print the largest change in its eigenvalues. (b) For \(\varepsilon = 10^{-10}\), compute the condition number of the eigenvector matrix (R: kappa; Python: np.linalg.cond; skip in Rust), and for \(A\). (c) Perturb and recompute: add \(10^{-12}\) times a matrix of standard normal numbers to the chain and look at how far the eigenvalues move from the circle of radius 0.1.

C5. Lanczos and its ghosts. Use the diagonal test matrix of the lecture: eigenvalues 10, 9, 8 and 197 values evenly spaced in \([0, 5]\), applied as a function Afun(v) = spec * v (the matrix is never stored). Write lanczos(Afun, n, m, reorth) from fact 6, starting from \(\mathbf q_1 = (1, \dots, 1)/\sqrt n\), and a function that returns the Ritz values after \(m\) steps. (a) With reorthogonalisation, print the top three Ritz values after 5, 10, 20 and 60 steps. (b) Without reorthogonalisation, print the top eight Ritz values after 60 steps, and count the Ritz values above 7.5 in both runs. (c) Print \(\max|Q^TQ - I|\) for both runs.

C6. PCA of 20 000 cells: full vs truncated. Simulate the single-cell matrix with the function in the solution (10 cell types, Poisson counts, log1p, stored sparse; cells × genes). (a) Print the fraction of non-zeros and the memory of the sparse and of the dense matrix. (b) Full routes: centre a dense copy and compute all singular values (R: svd; Python: np.linalg.svd(..., compute_uv=False)), and all eigenvalues of \(X_c^TX_c\). Time both. (c) Truncated route: the top 10 singular values of \(X_c\) without forming it: R irlba(X, nv = 10, center = mu); Python scipy.sparse.linalg.svds on a LinearOperator that applies fact 7. Time it and compare the top singular values with (b). Rust has no truncated SVD in our crates; do only the covariance route there (sprs matrix, nalgebra SymmetricEigen), and C7 by hand. (d) Print singular values 9–13. Where is the gap?

C7. Matrix-free Lanczos for PCA. Continue from C6. Write a function Cv(v) that returns \(X_c^TX_c\mathbf v\) using fact 7, and run 40 Lanczos steps with full reorthogonalisation on it. Return the Ritz values and the Ritz vectors \(\mathbf y_i = Q_m\mathbf s_i\) (\(\mathbf s_i\) the eigenvectors of \(T_m\)). (a) Print \(\sqrt{\theta_i}\) for the top 12 and compare with C6. (b) The check: print the relative residuals \(\|C\mathbf y_i - \theta_i\mathbf y_i\|/\theta_i\) for the top 12. Which Ritz pairs can you trust? (c) R: compare with RSpectra::eigs_sym on the same function. Python: scipy.sparse.linalg.eigsh on a LinearOperator.

Answer E1

\(A_1\) has \(4.41\), \(3.15\), \(1.43\) on the diagonal and \(0.691\) and \(-0.538\) beside it: the Background’s R %*% Q (same signs as R and numpy). At \(k = 10\), \(20\), \(30\) the entries are \(|a_{21}| = 0.0133\), \(1\times10^{-4}\), \(1\times10^{-6}\) and \(|a_{32}| = 2\times10^{-4}\), \(4\times10^{-8}\), \(8\times10^{-12}\): the points lie on straight lines parallel to the dashed \(0.634^k\) and \(0.423^k\) (C1 prints \(1.33\times10^{-2}\), \(1.39\times10^{-4}\), \(1.46\times10^{-6}\) and \(2.31\times10^{-4}\), \(4.19\times10^{-8}\), \(7.63\times10^{-12}\)). \(|a_{32}|\) is faster because \(\lambda_3/\lambda_2 = 1.268/3 = 0.423\) is the smaller ratio; it crosses \(10^{-12}\) at \(k = 33\), and \(1.267949\) turns green. \(a_{21}\) needs \(k = 62\), the 62 steps of C2. The readout shows the diagonal \(4.732051\), \(3.000000\), \(1.267949\) already at \(k = 20\): for a symmetric matrix the error on the diagonal is about the square of the off-diagonal entries, so six correct decimals need off-diagonals of only about \(10^{-3}\)–\(10^{-4}\).

Answer E2

The eigenvalues are \(2.309\), \(2.151\), \(1.191\), \(0.349\) and the rates \(0.932\), \(0.554\), \(0.293\). From \(0.932^k = 10^{-12}\), \(k = 12/0.0306 \approx 390\); the demo finds all eigenvalues after 367 steps (\(a_{43}\) deflates at 23 and \(a_{32}\) at 49, \(a_{21}\) at 367; at \(k = 100\) it is still \(1.5\times10^{-4}\), at \(k = 300\) \(1.1\times10^{-10}\)). With a shift the curves in (b) are no longer straight lines but plunge (several digits per step), and \(\mu\) settles on the eigenvalue being deflated: at \(k = 4\) the Rayleigh shift is \(\mu = 1.190983\), the eigenvalue \(1.190983\) to all six decimals shown. After each deflation the shift is taken from the smaller block and moves to the next eigenvalue. The 5 × 5 matrix (rates \(0.523\), \(0.777\), \(0.885\), \(0.299\)): 213 steps unshifted, 13 Rayleigh, 8 Wilkinson. LAPACK uses shifts for exactly this reason: the cost no longer depends on how close the eigenvalues are.

shift_of <- function(A, type) {
  n <- nrow(A)
  if (type == "none") return(0)
  if (type == "rayleigh") return(A[n, n])
  a <- A[n - 1, n - 1]; b <- A[n, n - 1]; c <- A[n, n]   # Wilkinson
  d <- (a - c) / 2
  s <- if (d >= 0) 1 else -1
  c - s * b^2 / (abs(d) + sqrt(d^2 + b^2))
}
qr_eig <- function(A, type = "rayleigh", tol = 1e-12, maxit = 500) {

      A <- A[-n, -n, drop = FALSE]
    }
  }

}

import numpy as np

def shift_of(A, kind):
    if kind == "none":
        return 0.0
    if kind == "rayleigh":

// C2: shifted QR algorithm with deflation; no shift, Rayleigh shift, Wilkinson shift.
use nalgebra::DMatrix;

fn shift_of(a: &DMatrix<f64>, kind: &str) -> f64 {
    let n = a.nrows();
    match kind {
        "none" => 0.0,
        "rayleigh" => a[(n - 1, n - 1)],
        _ => {                                            // Wilkinson
            let (p, b, c) = (a[(n - 2, n - 2)], a[(n - 1, n - 2)], a[(n - 1, n - 1)]);
            let d = (p - c) / 2.0;
            let s = if d >= 0.0 { 1.0 } else { -1.0 };
            c - s * b * b / (d.abs() + (d * d + b * b).sqrt())
        }
    }
}

fn qr_eig(mut a: DMatrix<f64>, kind: &str, tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let mut lam: Vec<f64> = Vec::new();
    let mut steps = 0;
    while a.nrows() > 1 && steps < maxit {
        let n = a.nrows();
        let mu = shift_of(&a, kind);
        let eye = DMatrix::<f64>::identity(n, n);
        let qr = (&a - &eye * mu).qr();
        a = qr.r() * qr.q() + eye * mu;
        steps += 1;
        if a[(n - 1, n - 2)].abs() < tol {               // deflate
            lam.insert(0, a[(n - 1, n - 1)]);
            a = a.view((0, 0), (n - 1, n - 1)).into_owned();
        }
    }
    let mut vals: Vec<f64> = a.diagonal().iter().cloned().collect();
    vals.extend(lam);
    (vals, steps)
}

// C5: hand-written Lanczos, with and without full reorthogonalisation.
use nalgebra::{DMatrix, DVector};

struct Lanczos { alpha: Vec<f64>, beta: Vec<f64>, q: DMatrix<f64> }

fn lanczos(afun: &dyn Fn(&DVector<f64>) -> DVector<f64>, n: usize, m: usize, reorth: bool) -> Lanczos {
    let mut qm = DMatrix::<f64>::zeros(n, m);
    let (mut alpha, mut beta) = (vec![0.0; m], vec![0.0; m]);
    let mut q = DVector::from_element(n, 1.0 / (n as f64).sqrt());
    let mut q_old = DVector::<f64>::zeros(n);
    let mut b = 0.0;
    for j in 0..m {
        qm.set_column(j, &q);
        let mut w = afun(&q) - &q_old * b;
        alpha[j] = w.dot(&q);
        w -= &q * alpha[j];
        if reorth {                                   // full reorthogonalisation
            let qj = qm.columns(0, j + 1);
            w -= &qj * (qj.transpose() * &w);
        }
        b = w.norm();
        beta[j] = b;
        q_old = q;
        q = w / b;
    }
    Lanczos { alpha, beta, q: qm }
}

fn ritz(l: &Lanczos, m: usize) -> Vec<f64> {          // eigenvalues of the m x m tridiagonal T
    let t = DMatrix::from_fn(m, m, |i, j| {
        if i == j { l.alpha[i] } else if i == j + 1 || j == i + 1 { l.beta[i.min(j)] } else { 0.0 }
    });
    let mut v: Vec<f64> = t.symmetric_eigen().eigenvalues.iter().cloned().collect();
    v.sort_by(|x, y| y.partial_cmp(x).unwrap());
    v
}

// Xc^T Xc v without forming Xc:  w = X v - 1 (mu . v),  out = X^T w - mu (1 . w)
fn cv(x: &CsMat<f64>, mu: &DVector<f64>, v: &DVector<f64>) -> DVector<f64> {
    let mv = mu.dot(v);
    let w: Vec<f64> = x.outer_iterator()
        .map(|row| row.iter().map(|(j, &a)| a * v[j]).sum::<f64>() - mv)
        .collect();
    let wsum: f64 = w.iter().sum();
    let mut out = DVector::<f64>::zeros(v.len());
    for (i, row) in x.outer_iterator().enumerate() {
        for (j, &a) in row.iter() { out[j] += a * w[i]; }
    }
    out - mu * wsum
}

// Lanczos with full reorthogonalisation: Ritz values (decreasing) and vectors
fn lanczos_eig(afun: &dyn Fn(&DVector<f64>) -> DVector<f64>, n: usize, m: usize) -> (Vec<f64>, DMatrix<f64>) {
    let mut qm = DMatrix::<f64>::zeros(n, m);
    let (mut alpha, mut beta) = (vec![0.0; m], vec![0.0; m]);
    let mut q = DVector::from_element(n, 1.0 / (n as f64).sqrt());
    let mut q_old = DVector::<f64>::zeros(n);
    let mut b = 0.0;
    for j in 0..m {
        qm.set_column(j, &q);
        let mut w = afun(&q) - &q_old * b;
        alpha[j] = w.dot(&q);
        w -= &q * alpha[j];
        let qj = qm.columns(0, j + 1);
        w -= &qj * (qj.transpose() * &w);
        b = w.norm();
        beta[j] = b;
        q_old = q;
        q = w / b;
    }
    let t = DMatrix::from_fn(m, m, |i, j| {
        if i == j { alpha[i] } else if i == j + 1 || j == i + 1 { beta[i.min(j)] } else { 0.0 }
    });
    let eig = SymmetricEigen::new(t);
    let mut idx: Vec<usize> = (0..m).collect();
    idx.sort_by(|&a, &b| eig.eigenvalues[b].partial_cmp(&eig.eigenvalues[a]).unwrap());
    let theta: Vec<f64> = idx.iter().map(|&i| eig.eigenvalues[i]).collect();
    let s = DMatrix::from_fn(m, m, |r, c| eig.eigenvectors[(r, idx[c])]);
    (theta, qm * s)
}
