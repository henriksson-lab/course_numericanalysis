Exercise: nonlinear least squares and ODE fitting

Goal

By the end of this exercise you should be able to:

  • write a model fit as nonlinear least squares, with residuals \(r_i = y_i - m_i(\mathbf p)\) and a Jacobian \(J_{ij} = \partial m_i/\partial p_j\),
  • do a Gauss–Newton step by hand for one parameter, and in code for three, with each step a linear least-squares problem solved by QR,
  • show how Gauss–Newton fails from a bad start, and how Levenberg–Marquardt (damping \(\lambda\)) fixes it, and say what the two limits of \(\lambda\) are,
  • read nls’s “singular gradient” and use minpack.lm::nlsLM / nls.lm, scipy.optimize.curve_fit / least_squares, or a hand-written LM in Rust,
  • fit log-parameters to keep rates positive and improve the conditioning,
  • fit an ODE model with the solver inside the residual function, and choose the solver tolerance and the finite-difference step so that they fit together,
  • run a multistart and recognise two minima with the same RSS (the flip-flop).

The by-hand part needs pen, paper and a calculator with exp. The code part checks your hand answers and then fits the three-parameter model, first in closed form, then as an ODE.

Background

After an oral dose \(D\), a drug moves from the gut (\(A_g\)) into the plasma, or central compartment (\(A_c\)), and is eliminated from there:

\[A_g' = -k_a A_g, \qquad A_c' = k_a A_g - k_e A_c, \qquad A_g(0) = D,\ A_c(0) = 0,\]

and we measure the concentration \(C = A_c/V\). This linear ODE has a closed form, the Bateman function

\[C(t) = \frac{D\,k_a}{V(k_a - k_e)}\left(e^{-k_e t} - e^{-k_a t}\right).\]

The data: \(D = 100\) mg, plasma sampled at 12 times over 12 hours. They were simulated from \(k_a = 1\)/h, \(k_e = 0.2\)/h, \(V = 20\) L with noise of SD 0.1 mg/L (set.seed(1) in R, then rounded to 2 decimals), so we know the truth.

Facts used below:

  1. Nonlinear least squares. Parameters \(\mathbf p\), model \(m_i(\mathbf p) = C(t_i)\), residuals \(\mathbf r = \mathbf y - \mathbf m(\mathbf p)\). Minimise \(\text{RSS}(\mathbf p) = \|\mathbf r\|^2\).
  2. Jacobian. \(J_{ij} = \partial m_i / \partial p_j\) (12 × 3). Forward differences: column \(j \approx (\mathbf m(\mathbf p + h_j\mathbf e_j) - \mathbf m(\mathbf p))/h_j\) with \(h_j \approx 10^{-7}\max(1, |p_j|)\).
  3. Gauss–Newton. \(\boldsymbol\delta = \arg\min \|\mathbf r - J\boldsymbol\delta\|^2\), solved by QR (qr.solve(J, r)), then \(\mathbf p \leftarrow \mathbf p + \boldsymbol\delta\). For one parameter: \(\delta = \sum_i J_i r_i / \sum_i J_i^2\).
  4. Levenberg–Marquardt. \(\boldsymbol\delta = \arg\min \|\mathbf r - J\boldsymbol\delta\|^2 + \lambda\|D_g\boldsymbol\delta\|^2\), i.e. \((J^TJ + \lambda D_g^2)\boldsymbol\delta = J^T\mathbf r\), solved as the stacked least-squares problem \(\begin{pmatrix}J\\ \sqrt\lambda D_g\end{pmatrix}\boldsymbol\delta \approx \begin{pmatrix}\mathbf r\\ \mathbf 0\end{pmatrix}\). \(D_g\) = diagonal of the column lengths of \(J\) (or \(I\)). Accept the step and divide \(\lambda\) by 10 if the RSS goes down; otherwise reject it and multiply \(\lambda\) by 10.
  5. Log-parameters. Fit \(\mathbf q = \log\mathbf p\); \(\partial m/\partial q_j = p_j\,\partial m/\partial p_j\).
  6. Flip-flop. \((k_a, k_e, V)\) and \((k_e, k_a, V k_e/k_a)\) give the same \(C(t)\).
  7. Finite differences with noise. If the model values carry an error of size \(\varepsilon\) (rounding, or an ODE solver’s error), the forward-difference error is about \(\tfrac{h}{2}|m''| + 2\varepsilon/h\), smallest near \(h \approx 2\sqrt{\varepsilon/|m''|}\) (Convergence and cost).

import numpy as np
from scipy.optimize import curve_fit

D = 100.0                                                  # oral dose, mg
tt = np.array([0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6, 8, 10, 12])   # hours
y = np.array([1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61])  # mg/L

def bateman(t, ka, ke, V):
    return D * ka / (V * (ka - ke)) * (np.exp(-ke * t) - np.exp(-ka * t))

def rss(p):
    return np.sum((y - bateman(tt, *p))**2)

print(rss([1, 0.2, 20]))                    # at the simulation parameters

# [ 1.01507215  0.19061569 20.21621051]

// Background: the PK data, the Bateman function and the residual sum of squares
const D: f64 = 100.0; // oral dose, mg
const TT: [f64; 12] = [0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, 8.0, 10.0, 12.0]; // h
const Y: [f64; 12] = [1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61]; // mg/L

fn bateman(t: f64, ka: f64, ke: f64, v: f64) -> f64 {
    D * ka / (v * (ka - ke)) * ((-ke * t).exp() - (-ka * t).exp())
}

fn rss(p: [f64; 3]) -> f64 {
    TT.iter().zip(Y.iter()).map(|(&t, &y)| (y - bateman(t, p[0], p[1], p[2])).powi(2)).sum()
}

fn main() {
    println!("{}", rss([1.0, 0.2, 20.0]));                       // at the simulation parameters
    // no nls in Rust: we write Gauss-Newton ourselves in C2; here the RSS at nls's estimate
    println!("{}", rss([1.0150721, 0.1906157, 20.2162104]));
}

In R, nls is Gauss–Newton; minpack.lm::nlsLM has the same formula interface with Levenberg–Marquardt, and minpack.lm::nls.lm takes a residual function. In Python, scipy.optimize.curve_fit takes a model function like nls (Levenberg–Marquardt by default) and scipy.optimize.least_squares takes a residual function (trust-region "trf" by default, method="lm" for MINPACK). In Rust there is no nls: we write Gauss–Newton and Levenberg–Marquardt ourselves with nalgebra’s QR (the argmin crate has a Gauss–Newton solver, but it needs more plumbing than the method itself). ODEs: deSolve::ode, scipy.integrate.solve_ivp, and ode_solvers::Dopri5 in Rust.

By hand

B1. Sensitivities. After an IV bolus, a one-compartment model gives \(C(t) = C_0 e^{-kt}\). (a) Write down \(\partial C/\partial C_0\) and \(\partial C/\partial k\). (b) Evaluate the \(3\times 2\) Jacobian at \(C_0 = 10\) mg/L, \(k = 0.3\)/h for samples at \(t = 1, 2, 4\) h. (c) At which time \(t\) is \(|\partial C/\partial k|\) largest? What does that say about when to sample if you want \(k\)? (d) For the oral model on the slides, the Jacobian column for \(k_a\) is positive at \(t = 0.25\) h and negative at \(t = 12\) h. Explain the sign change in words.

B2. Gauss–Newton by hand. Fit only \(k\) in \(C(t) = 10\,e^{-kt}\) to \(y = (6.0, 3.7, 1.3)\) mg/L at \(t = (1, 2, 4)\) h. (a) From \(k_0 = 0.3\): compute \(\mathbf m\), \(J\), \(\mathbf r\), the step \(\delta = \sum J_i r_i/\sum J_i^2\) and \(k_1\). Compare with the slide. (b) Do the second step from \(k_1\). Compute the RSS at \(k_0\), \(k_1\), \(k_2\). (c) The minimum is at \(k^* = 0.504417\). How many correct digits do \(k_0\), \(k_1\), \(k_2\) have? What kind of convergence does that suggest?

B3. A linear model needs one step. Suppose \(k_e = 0.2\) is known and the model is \(m(t) = a\,e^{-0.2t} + b\) (a decay on top of a baseline \(b\)). (a) Write the Jacobian with respect to \((a, b)\). Does it depend on \((a, b)\)? (b) Explain why Gauss–Newton reaches the least-squares solution in one step from any start. Which unit’s method is it then?

B4. Levenberg–Marquardt between two limits. Take \(J = \begin{pmatrix}1 & 0\\1 & 1\\1 & 2\end{pmatrix}\), \(\mathbf r = (1, 0, 1)\) and \(D_g = I\). (a) Compute \(J^TJ\) and \(J^T\mathbf r\). (b) The Gauss–Newton step: solve \(J^TJ\boldsymbol\delta = J^T\mathbf r\). (c) The LM step with \(\lambda = 1\): solve \((J^TJ + I)\boldsymbol\delta = J^T\mathbf r\). (d) The LM step with \(\lambda = 100\). Compare it with \(J^T\mathbf r/\lambda\). In which direction does a large-\(\lambda\) step point, and why is that “downhill”? (The gradient of \(\|\mathbf r\|^2\) with respect to \(\mathbf p\) is \(-2J^T\mathbf r\).) (e) Order the three steps by length. What does \(\lambda\) control?

B5. Log-parameters. Same data as B2; now fit \(q = \log k\). (a) Use the chain rule to write \(\partial m/\partial q\) in terms of \(\partial m/\partial k\). (b) Do one Gauss–Newton step in \(q\) from \(k_0 = 0.3\) (reuse \(\mathbf r\) and \(J\) from B2(a)). What is \(k_1 = e^{q_1}\)? Is it closer to \(k^*\) than the step in \(k\)? (c) Now start far away, at \(k_0 = 1.5\). There \(\mathbf m = (2.231, 0.498, 0.025)\), \(\partial m/\partial k = (-2.231, -0.996, -0.099)\) and \(\mathbf r = (3.769, 3.202, 1.275)\). Do one Gauss–Newton step in \(k\) and one in \(q\). What is wrong with the first one, biologically?

B6. The flip-flop. (a) Show that swapping \(k_a \leftrightarrow k_e\) and replacing \(V\) by \(V' = V k_e/k_a\) leaves \(C(t)\) unchanged. (b) The fit gives \((\hat k_a, \hat k_e, \hat V) = (1.0151, 0.1906, 20.216)\). What is the mirror solution? (c) The two parameter sets give the same plasma curve. What do they predict differently? Name one experiment that would tell them apart.

B7. Tolerance and finite-difference step. A residual function solves an ODE with an error of about \(\varepsilon_\text{ode}\) in each model value. Take \(|m''| \approx 1\) in the units of the problem. (a) With \(\varepsilon_\text{ode} = 10^{-6}\) (deSolve’s default tolerance), what is the error of a forward-difference derivative with \(h = 10^{-8}\)? With \(h = 10^{-3}\)? (b) Which \(h\) minimises the error, and what is the smallest error? Repeat for \(\varepsilon_\text{ode} = 10^{-10}\). (c) A Levenberg–Marquardt fit of 3 parameters with a forward-difference Jacobian solves the ODE once for the residual, 3 times for the Jacobian, and once for the trial point, per iteration. A multistart from 36 starts takes about 10 iterations each. How many ODE solves is that? At 5 ms per solve, how long?

In code

C1. The data and the model. (a) Plot the data and the curve with the simulation parameters \((1, 0.2, 20)\). Compute the RSS there and at the start \((0.5, 0.1, 10)\). (b) Compute \(t_\text{max} = \ln(k_a/k_e)/(k_a - k_e)\), \(C_\text{max} = C(t_\text{max})\) and \(\text{AUC} = D/(V k_e)\) for the simulation parameters. (c) Evaluate the Bateman function at \(k_a = k_e = 0.2\) and at \(k_a = 0.2 + 10^{-9}\), \(k_e = 0.2\) (print 15 digits), for \(t = 1\) and \(4\) h. Compare with the limit \(D k t e^{-kt}/V\). What happens, and how many digits are lost near \(k_a = k_e\)?

C2. Gauss–Newton. (a) Write a function for the forward-difference Jacobian with step \(h_j = 10^{-7}p_j\), and a Gauss–Newton loop that solves each step by QR and prints the iterates. Start at \((0.5, 0.1, 10)\). (b) How many correct digits does each iteration add near the end? (c) Print \(\kappa(J)\) and \(\kappa(J^TJ)\) at the solution. How many digits would the normal equations lose compared with QR? (d) Compare with nls(..., trace = TRUE) (Python: curve_fit; Rust: skip).

C3. Gauss–Newton fails, Levenberg–Marquardt does not. (a) Take one Gauss–Newton step from \((3, 0.05, 50)\). Where does it go, and what is the RSS there? (b) Write Levenberg–Marquardt with Marquardt’s scaling \(D_g\) (Fact 4), solving the stacked problem by QR. Start at \((3, 0.05, 50)\) with \(\lambda = 0.01\) and print every accepted step with its \(\lambda\). (c) Run nls and nlsLM from the same start (Python: curve_fit and least_squares).

C4. Log-parameters. (a) Rewrite the Jacobian so that it takes any model function f and uses \(h_j = 10^{-7}\max(1, |p_j|)\). Compare \(\kappa(J)\) at the solution in \((k_a, k_e, V)\) and in \(\log(k_a, k_e, V)\). (b) Run Gauss–Newton in log-parameters from \((3, 0.05, 50)\). Do the rates stay positive? Does it converge? (c) Run Levenberg–Marquardt in log-parameters from the same start. Then nlsLM with exp() inside the formula (Python: curve_fit with a wrapper).

C5. Fit the ODE. Pretend there is no closed form. (a) Write pk_ode(p, tol) that solves the two-compartment ODE with rtol = atol = tol and returns \(A_c/V\) at the 12 sampling times. Check it against the Bateman function at \((1, 0.2, 20)\) with tol = 1e-10. (b) Fit \(\log(k_a, k_e, V)\) from \((0.5, 0.1, 10)\) with the ODE inside the residual function: nls.lm with control = nls.lm.control(epsfcn = 1e-10) (Python: least_squares; Rust: your LM with Dopri5). Compare with the closed-form fit.

C6. How tight must the inner solver be? (a) Repeat C5(b) with tol \(= 10^{-2}, 10^{-3}, 10^{-4}, 10^{-6}, 10^{-8}, 10^{-10}\). For each, print the estimates, the RSS the optimiser reports, the true RSS (Bateman function) at the returned parameters, and the number of iterations. In Python, include the solve_ivp default rtol = 1e-3, atol = 1e-6. (b) Along the line \(k_a \in [0.9, 1.1]\) (401 points; \(k_e\), \(V\) at the estimate), compute \(\max|\text{RSS}_\text{ode} - \text{RSS}_\text{exact}|\) for tol \(= 10^{-3}, 10^{-6}, 10^{-10}\). Compare with the RSS change caused by a 1 % change in \(k_a\).

C7. Multistart. Fit from the 36 starts \(k_a \in \{0.03, 0.1, 0.3, 1, 3, 10\}\), \(k_e \in 1.5\times\{0.03, \dots, 10\}\), \(V = 10\), in log-parameters. Tabulate where the fits end (parameters and RSS, rounded to 4 digits). How many minima are there? Are they equally good? Which one would you report, and why?

Explore

The demo below runs the lecture’s Gauss–Newton and Levenberg–Marquardt code on the plasma data in your browser: forward-difference Jacobian, one QR least-squares solve per pass, and for LM Marquardt’s scaling with \(\lambda_0 = 0.01\), divided by 10 after an accepted step and multiplied by 10 after a rejected one. The paths are the iterates of both methods projected onto \((k_a, k_e)\) (vermillion: Gauss–Newton; green: Levenberg–Marquardt); crosses are rejected LM trial points, and a square on the border marks a point off the map. The methods move all three parameters, so the start \(V\) is a slider, and a path need not follow the landscape exactly. Drag the start point (or click on the map) to choose \(k_a\) and \(k_e\). Step does one pass of each method, Run keeps stepping. Panel (b) shows the data and the current curves; the table gives the pass, the parameters, the RSS, \(\lambda\), whether the last step was accepted, and the status. The buttons (ka, ke, V) and log switch between fitting the parameters and their logarithms.

The browser computes in the same IEEE doubles as R, Python and Rust, so the iterates agree with the lecture to the digits shown. The demo also stops when a rejected step is already below the tolerance.

E1. (a good start) Click the good start \((0.5, 0.1, 10)\) and press Step repeatedly. Write down the RSS of both methods after each pass and \(\lambda\) for Levenberg–Marquardt. How many passes does each need? Do the two paths differ much, and why not?

Answer E1

Both start at RSS \(93.53\). Gauss–Newton: \(15.91\), \(0.9775\), \(0.09135\), \(0.06657\), \(0.06646745\), \(0.06646744\), the iterates of the lecture’s gauss_newton and of nls; it stops after 8 passes at \((1.015, 0.1906, 20.22)\). Levenberg–Marquardt: \(12.41\), \(0.8018\), \(0.07744\), \(0.06650\), \(0.06646744\); every step is accepted, so \(\lambda\) falls tenfold per pass from \(0.01\) to \(10^{-9}\), and it stops after 7 passes. With \(\lambda \le 10^{-3}\) the damping rows are tiny and the LM step is almost the Gauss–Newton step: the two paths lie nearly on top of each other along the valley. Near the minimum both gain two to three digits per pass.

E2. (a bad start) Click bad, \((3, 0.05, 50)\), and step. Where does the first Gauss–Newton step go, and what does the table say? Follow Levenberg–Marquardt: which passes are rejected, what happens to \(\lambda\) after each, and how many passes, accepted and rejected steps does it need in total?

Answer E2

Gauss–Newton jumps to \(k_a = -2.225\), \(k_e = 0.1787\), \(V = 0.0443\) with RSS \(6.7\times10^{29}\): off the map (a negative rate cannot be drawn on a log axis), the curve off the scale, status diverged. That is the step that makes nls stop with “singular gradient”. LM rejects pass 1 (trial RSS \(7.0\times10^{21}\), the same wild step slightly damped) and pass 2 (trial RSS \(11.4\)), so \(\lambda\) goes \(0.01 \to 0.1 \to 1\). At \(\lambda = 1\) the step is short and downhill: pass 3 is accepted (RSS \(4.63\), \(\lambda = 0.1\)), pass 4 rejected again (\(\lambda = 1\)), pass 5 accepted (\(3.39\)). Hints

Hint 1 — Jacobian and one-parameter Gauss–Newton (B1, B2, B5)

\(\frac{d}{dk} e^{-kt} = -t\,e^{-kt}\). With one parameter, \(J\) is a single column and the least-squares solution of \(J\delta \approx \mathbf r\) is \(\sum J_i r_i/\sum J_i^2\) (the slope of a line through the origin). Keep 4 significant digits. For \(q = \log k\): \(k = e^q\), so \(dk/dq = k\).

Hint 2 — Levenberg–Marquardt by hand (B4)

A \(2\times2\) system \(\begin{pmatrix}a&b\\c&d\end{pmatrix}\boldsymbol\delta = \mathbf g\) has \(\delta_1 = (d g_1 - b g_2)/(ad - bc)\), \(\delta_2 = (a g_2 - c g_1)/(ad - bc)\). Adding \(\lambda I\) only changes \(a\) and \(d\).

Hint 3 — finite differences with noise (B7)

Truncation error \(\approx \tfrac{h}{2}|m''|\), noise error \(\approx 2\varepsilon/h\) (two noisy values, divided by \(h\)). Set the derivative of the sum with respect to \(h\) to zero. This is the V-shaped error curve of Convergence and cost, with \(\varepsilon_\text{ode}\) in place of machine epsilon.

Hint 4 — QR least squares in each language (C2–C4)

R: qr.solve(A, b) solves a tall system in the least-squares sense; rbind stacks the damping rows under \(J\). Python: Q, R = np.linalg.qr(A) then np.linalg.solve(R, Q.T @ b) (np.linalg.qr); np.vstack stacks. Rust: a.clone().qr(), q_tr_mul and solve_upper_triangular, as in Least squares: normal equations vs QR. Condition numbers: kappa(A, exact = TRUE), np.linalg.cond, ratio of nalgebra’s singular_values().

Hint 5 — library fitters (C2–C4, C7)

R: nls (trace = TRUE prints iterates), nlsLM (same interface), nls.lm(par, fn) where fn returns the residual vector; fit$par, fit$deviance (RSS), fit$niter. Wrap a call that may fail in tryCatch(..., error = conditionMessage). Python: curve_fit(f, t, y, p0) returns (p, cov); least_squares(fun, x0) returns an object with .x, .cost (half the RSS), .nfev.

Hint 6 — an ODE inside the residual (C5, C6)

R: ode(y, times, func, parms, rtol, atol) with func(t, y, parms) returning list(dy); give times = c(0, tt) because the first time is the start, and drop the first row of the output; column 1 is time. Python: solve_ivp(fun, (0, 12), y0, t_eval=tt, args=(ka, ke), rtol=, atol=), solution in sol.y. Rust: Dopri5::new(system, t0, t_end, dx, y0, rtol, atol) and integrate_with_continuous_output_model give the solution at any \(t\) (see Runge–Kutta and adaptive step size). In nls.lm, the finite-difference step is \(\sqrt{\texttt{epsfcn}}\,|q_j|\); with \(\log k_a \approx 0\) the default is far below the ODE error, so set epsfcn = 1e-10.

fn jac(p: &DVector<f64>, h: f64) -> DMatrix<f64> {   // forward differences

    let mut j = DMatrix::zeros(12, 3);

        let mut pe = p.clone();
        let e = h * p[k];
        pe[k] += e;
        j.set_column(k, &((model(&pe) - &m0) / e));
    }
    j
}

// least squares min ||A x - b|| by Householder QR: R x = Q^T b
fn lstsq_qr(a: &DMatrix<f64>, b: &DVector<f64>) -> DVector<f64> {
    let n = a.ncols();
    let qr = a.clone().qr();
    let mut qtb = b.clone();
    qr.q_tr_mul(&mut qtb);
    qr.r().solve_upper_triangular(&qtb.rows(0, n).into_owned()).unwrap()
}

    qr.r().solve_upper_triangular(&qtb.rows(0, n).into_owned()).unwrap()
}

fn rss(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, p: &DVector<f64>) -> f64 {
    (DVector::from_row_slice(&Y) - f(p)).norm_squared()
}

// returns (parameters, RSS, iterations)
fn lev_mar(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, mut p: DVector<f64>)
    -> (DVector<f64>, f64, usize) {
    let (n, m) = (p.len(), Y.len());
    let y = DVector::from_row_slice(&Y);
    let (mut lambda, mut rss_old, mut k) = (0.01f64, rss(f, &p), 0);
    while k < 200 {
        k += 1;
        let j = jac(f, &p);
        let mut a = DMatrix::zeros(m + n, n);
        a.rows_mut(0, m).copy_from(&j);
        for c in 0..n { a[(m + c, c)] = lambda.sqrt() * j.column(c).norm(); }
        let mut b = DVector::zeros(m + n);
        b.rows_mut(0, m).copy_from(&(&y - f(&p)));
        let delta = lstsq_qr(&a, &b);
        if delta.norm() < 1e-8 * (1.0 + p.norm()) { break; }     // converged
        let p_new = &p + &delta;
        let rss_new = rss(f, &p_new);
        if rss_new.is_finite() && rss_new < rss_old {
            p = p_new; rss_old = rss_new; lambda /= 10.0;
        } else {
            lambda *= 10.0;
        }
    }
    (p, rss_old, k)
}

fn g4(x: f64) -> String {
    if !x.is_finite() || x == 0.0 { return format!("{}", x); }
    let e = x.abs().log10().floor() as i32;
    if e < -4 || e >= 4 { format!("{:.3e}", x) } else {
        let s = format!("{:.*}", (3 - e).max(0) as usize, x);
        if s.contains('.') { s.trim_end_matches('0').trim_end_matches('.').to_string() } else { s }
    }
}

fn bateman(t: f64, ka: f64, ke: f64, v: f64) -> f64 {

}

fn jac(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, p: &DVector<f64>) -> DMatrix<f64> {

        let mut pe = p.clone();
        let e = 1e-7 * p[k].abs().max(1.0);
        pe[k] += e;
        j.set_column(k, &((f(&pe) - &m0) / e));
    }

}

use nalgebra::{DMatrix, DVector};

const D: f64 = 100.0;
const TT: [f64; 12] = [0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, 8.0, 10.0, 12.0];
const Y: [f64; 12] = [1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61];

fn f_nat(p: &DVector<f64>) -> DVector<f64> {               // p = (ka, ke, V)
    let (ka, ke, v) = (p[0], p[1], p[2]);
    DVector::from_iterator(12, TT.iter().map(|&t|
        D * ka / (v * (ka - ke)) * ((-ke * t).exp() - (-ka * t).exp())))
}
fn f_log(q: &DVector<f64>) -> DVector<f64> { f_nat(&q.map(f64::exp)) }   // q = log(p)

fn jac(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, p: &DVector<f64>) -> DMatrix<f64> {
    let m0 = f(p);
    let mut j = DMatrix::zeros(m0.len(), p.len());
    for k in 0..p.len() {
        let mut pe = p.clone();
        let e = 1e-7 * p[k].abs().max(1.0);
        pe[k] += e;
        j.set_column(k, &((f(&pe) - &m0) / e));
    }
    j
}

fn lstsq_qr(a: &DMatrix<f64>, b: &DVector<f64>) -> Option<DVector<f64>> {
    let n = a.ncols();
    let qr = a.clone().qr();
    let mut qtb = b.clone();
    qr.q_tr_mul(&mut qtb);
    qr.r().solve_upper_triangular(&qtb.rows(0, n).into_owned())   // None if R is singular
}

fn rss(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, p: &DVector<f64>) -> f64 {
    (DVector::from_row_slice(&Y) - f(p)).norm_squared()
}

// returns (parameters, RSS, iterations)
fn lev_mar(f: &dyn Fn(&DVector<f64>) -> DVector<f64>, mut p: DVector<f64>)
    -> (DVector<f64>, f64, usize) {
    let (n, m) = (p.len(), Y.len());
    let y = DVector::from_row_slice(&Y);
    let (mut lambda, mut rss_old, mut k) = (0.01f64, rss(f, &p), 0);
    while k < 200 {
        k += 1;
        let j = jac(f, &p);
        let mut a = DMatrix::zeros(m + n, n);
        a.rows_mut(0, m).copy_from(&j);
        for c in 0..n { a[(m + c, c)] = lambda.sqrt() * j.column(c).norm(); }
        let mut b = DVector::zeros(m + n);
        b.rows_mut(0, m).copy_from(&(&y - f(&p)));
        let delta = match lstsq_qr(&a, &b) { Some(d) => d, None => break };
        if !delta.iter().all(|v| v.is_finite()) { break; }
        if delta.norm() < 1e-8 * (1.0 + p.norm()) { break; }     // converged
        let p_new = &p + &delta;
        let rss_new = rss(f, &p_new);
        if rss_new.is_finite() && rss_new < rss_old {
            p = p_new; rss_old = rss_new; lambda /= 10.0;
        } else {
            lambda *= 10.0;
        }
    }
    (p, rss_old, k)
}

// like C's %.4g
fn g4(x: f64) -> String {
    if !x.is_finite() || x == 0.0 { return format!("{}", x); }
    let e = x.abs().log10().floor() as i32;
    if e < -4 || e >= 4 { format!("{:.3e}", x) } else {
        let s = format!("{:.*}", (3 - e).max(0) as usize, x);
        if s.contains('.') { s.trim_end_matches('0').trim_end_matches('.').to_string() } else { s }
    }
}

There are two minima with identical RSS (0.06646744 to all printed digits): \((1.015, 0.1906, 20.22)\) and its flip-flop mirror \((0.1906, 1.015, 3.796)\). Starts with \(k_a > k_e\) mostly end in the first, starts with \(k_a < k_e\) in the second. Some starts run off: \(k_a\) to \(10^{15}\) or \(10^{21}\), \(k_e\) or \(V\) to absurd values, with RSS 12–65 (64.54 = \(\sum y_i^2\) means the model predicts zero). Which starts fail differs between nls.lm (1 failure), least_squares (none) and our LM (3), because each takes different steps; always compare the RSS of the ends. The data cannot choose between the two minima; for an immediate-release tablet the usual assumption \(k_a > k_e\) (and a plausible volume of 20 L rather than 3.8 L) points to the first, but that is prior knowledge, not a result of the fit.

Where this leads

  • Identifiability and uncertainty of fitted parameters (next unit): the flip-flop is a structural non-identifiability; the same PK model and data are used there for standard errors from \(J^TJ\), profile likelihoods and practical non-identifiability (long flat valleys like the one in the RSS landscape).
  • Gradient descent, Newton and quasi-Newton: Levenberg–Marquardt’s two limits; Gauss–Newton as Newton with the Hessian approximated by \(J^TJ\); general-purpose optimisers (optim, scipy.optimize.minimize) for objectives that are not sums of squares, such as Poisson or negative-binomial likelihoods.
  • Constraints and linear programming: bounds on parameters as an alternative to log-parameters.
  • Stiffness and implicit methods: a stiff model inside a fit needs an implicit solver (lsoda, BDF, Radau) with tight tolerances; explicit solvers then become the slow part of the fit.
  • Exact Jacobians of ODE models from sensitivity equations or automatic differentiation are not covered here; they replace the finite differences of C5–C6 in professional fitting tools.
