Exercise: stochastic simulation

Goal

By the end of this exercise you should be able to:

  • write down the propensities and stoichiometry of a small reaction network, and the ODE for its mean,
  • write the chemical master equation of a birth–death process and find its steady state (Poisson) by hand,
  • carry out steps of Gillespie’s direct method by hand, and hand-write the algorithm in code,
  • run many simulated cells, compare the mean with the ODE (with a standard error) and the distribution with a known answer,
  • explain how a two-state (telegraph) promoter gives transcriptional bursting, and compute and interpret the Fano factor,
  • spot the event-averaging bug, the negative counts of tau-leaping and the NaNs of Euler–Maruyama at small numbers,
  • estimate the probability that an epidemic started by one case dies out.

The by-hand part uses pen, paper and a pocket calculator (for log and exp). The code part hand-writes the SSA in each language: no simulation package is needed.

Background

Facts used below:

  1. Propensity. Reaction \(j\) fires in the next short time \(dt\) with probability \(a_j(\mathbf x)\,dt\), where \(\mathbf x\) is the vector of molecule counts. It changes \(\mathbf x\) by its stoichiometry (change) vector, column \(j\) of the matrix \(S\). Production at rate \(k\): \(a = k\); first-order decay of \(m\) molecules at rate \(\delta\) each: \(a = \delta m\). The ODE for the mean is \(\mathbf x' = S\,\mathbf a(\mathbf x)\); for propensities linear in \(\mathbf x\) it is exact for the mean.
  2. Chemical master equation (CME). For the birth–death process (\(\varnothing \to M\) at rate \(k\), \(M \to \varnothing\) at rate \(\delta m\)), with \(P_n(t)\) the probability of \(n\) molecules: \[P_n' = k P_{n-1} + \delta (n+1) P_{n+1} - (k + \delta n) P_n.\] Its steady state is Poisson with mean \(k/\delta\).
  3. Gillespie’s direct method (SSA). With \(a_0 = \sum_j a_j\) and two uniform numbers \(u_1, u_2\): \[\tau = -\frac{\log u_1}{a_0} \quad(\text{time to the next reaction}), \qquad j = \text{the reaction whose piece of } [0, a_0) \text{ contains } u_2 a_0.\] Then \(t \to t + \tau\), \(\mathbf x \to \mathbf x + S_{\cdot j}\), recompute the propensities, repeat. A \(u\) that falls exactly on a boundary goes to the next piece.
  4. Telegraph promoter. Promoter state \(g \in \{0, 1\}\): off → on with propensity \(k_\text{on}(1 - g)\), on → off with \(k_\text{off} g\), transcription \(k_m g\). Steady-state mRNA mean and Fano factor: \[\bar m = \frac{k_m}{\delta_m}\,\frac{k_\text{on}}{k_\text{on} + k_\text{off}}, \qquad F_m = \frac{\text{var}}{\text{mean}} = 1 + \frac{k_m k_\text{off}}{(k_\text{on} + k_\text{off})(k_\text{on} + k_\text{off} + \delta_m)}.\] Constitutive transcription (always on) gives Poisson, \(F = 1\). Protein with constitutive mRNA: \(F_p = 1 + k_p/(\delta_m + \delta_p)\).
  5. Tau-leaping. Fixed step \(\tau\): reaction \(j\) fires Poisson\((a_j \tau)\) times. Euler–Maruyama for the chemical Langevin equation \(dm = (k - \delta m)\,dt + \sqrt{k + \delta m}\,dW\): \(\;m_{n+1} = m_n + (k - \delta m_n) h + \sqrt{(k + \delta m_n) h}\; Z_n\), \(Z_n \sim N(0, 1)\).

Parameters used throughout (time in hours): constitutive gene \(k = 10\), \(\delta_m = 1\), translation \(k_p = 2\) per mRNA, protein decay \(\delta_p = 0.2\); telegraph gene \(k_\text{on} = 0.5\), \(k_\text{off} = 4.5\), \(k_m = 100\), same \(\delta_m, k_p, \delta_p\). Both have mean 10 mRNA and 100 protein molecules.

One SSA step from \(m = 10\), where both reactions have propensity 10 per hour. The three languages use different random number generators (R: Mersenne Twister; numpy: PCG64; Rust: ChaCha12), so the same seed gives different numbers: compare statistics between languages, never single trajectories. R’s runif never returns 0; numpy’s and Rust’s generators can, so Python and Rust use \(1 - u\) inside the log (also uniform).

a0 <- sum(a)

// Background: one step of Gillespie's algorithm, with a seeded generator.
use rand::{rngs::StdRng, RngExt, SeedableRng};

fn main() {
    let mut rng = StdRng::seed_from_u64(1);
    let a = [10.0, 10.0]; // propensities at m = 10: make, degrade (per hour)
    let a0: f64 = a.iter().sum();
    let tau = -(1.0 - rng.random::<f64>()).ln() / a0; // waiting time, Exp(a0) by inverse transform
    let r = rng.random::<f64>() * a0; // reaction j with probability a_j / a0
    let j = if r < a[0] { 0 } else { 1 };
    println!("tau = {}  reaction = {}", tau, ["make", "degrade"][j]);
}

By hand

B1. Propensities and the ODE. The constitutive gene has the reactions \(\varnothing \to M\) (\(k = 10\)), \(M \to \varnothing\) (\(\delta_m m\), \(\delta_m = 1\)), \(M \to M + P\) (\(k_p m\), \(k_p = 2\)), \(P \to \varnothing\) (\(\delta_p p\), \(\delta_p = 0.2\)), all per hour. (a) Write the stoichiometry matrix \(S\) (rows \(m\), \(p\); one column per reaction). (b) In the state \((m, p) = (4, 30)\), compute the four propensities, \(a_0\), the probability that each reaction is the next one, and the mean waiting time in minutes. (c) Write the ODE \(\mathbf x' = S\,\mathbf a(\mathbf x)\) and its steady state. (d) The telegraph gene in the state \((g, m, p) = (0, 4, 30)\): which reactions are possible, and what is \(a_0\)?

B2. Gillespie by hand. Birth–death with \(k = 10\), \(\delta = 1\) per hour, starting at \(t = 0\) with \(m = 2\). (Useful: \(\ln 0.5 = -0.693\), \(\ln 0.2 = -1.609\).) (a) Step 1 with \(u_1 = 0.5\), \(u_2 = 0.3\): the waiting time, the reaction, the new \(t\) and \(m\). (b) Step 2 with \(u_1 = 0.2\), \(u_2 = 0.9\). (c) Starting from \(m = 0\): which reaction is certainly the first, and what is its mean waiting time? (d) What plays the role of Euler’s step size \(h\) here?

B3. The master equation of a small gene. Birth–death with \(k = 2\), \(\delta = 1\) per hour. (a) Write \(P_0'\) and \(P_1'\) from Fact 2. (b) At steady state all \(P_n' = 0\). Show that \(P_1 = 2P_0\) and \(P_2 = 2P_0\), and guess \(P_n\). Normalise and compute \(P_0, \dots, P_3\). Which distribution is this? (c) A model with three species, each between 0 and 199 molecules: how many equations does its master equation have? Why does that favour simulation?

B4. The telegraph gene. \(k_\text{on} = 0.5\), \(k_\text{off} = 4.5\), \(k_m = 100\), \(\delta_m = 1\) per hour. (a) Write the ODE for the mean promoter state \(g\) (the fraction of time on) and for \(m\), and find their steady states. Then the protein steady state (\(k_p = 2\), \(\delta_p = 0.2\)). (b) How long is the promoter on, and off, on average? How many mRNA does one burst make on average? (c) Compute the Fano factor of the mRNA (Fact 4) and compare it with the constitutive gene. (d) Keep the mean at 10 but make bursts half as large: \(k_\text{on} = 1\), \(k_\text{off} = 9\), \(k_m = 100\). Compute the mean and the Fano factor.

B5. Fano factors from counts. smFISH counts of two genes in 8 cells: gene A: 6, 12, 8, 14, 10, 7, 13, 10; gene B: 0, 0, 31, 2, 0, 45, 1, 1. (a) Compute the mean, the sample variance (divide by \(n - 1\)) and the Fano factor of each. (b) For a Poisson(10) gene, what is the probability that a cell has no mRNA? How many of the 8 cells of gene B have none? (c) A colleague measures gene A by fluorescence, 50 units per molecule. What Fano factor do they get, and what is wrong with comparing it with 1?

B6. Tau-leaping goes negative. After transcription has stopped (\(k = 0\)), a cell has \(m = 3\) mRNA, \(\delta = 1\) per hour. (a) In one tau-leap of \(\tau = 1.5\) h, how many degradations are expected? (b) The number of degradations is Poisson(4.5); \(P(N \le 3) = 0.342\). What is the probability that the count becomes negative? (c) Why can the exact SSA never produce a negative count? (d) Choose \(\tau\) so that at most 10% of the molecules are expected to go in one leap. What is then the chance of going negative? (\(P(\text{Poisson}(0.3) \ge 4) = 2.7 \times 10^{-4}\).)

B7. Will the outbreak die out? SIR with \(\beta = 0.3\), \(\gamma = 0.1\) per day in a large population (\(S \approx N\)), starting with \(I = 1\). (a) With \(S \approx N\) the infection propensity is \(\beta I\) and the recovery propensity \(\gamma I\). What is the probability that the next event is a recovery? (b) Each infected person independently starts a chain that dies out with probability \(q\). Explain why \(q = 0.25 + 0.75\,q^2\), and solve it. (c) What is the extinction probability with 3 initial cases? With 10 (the start of the SIR example in Initial value problems and Euler’s method)? (d) What does the ODE predict in each case?

In code

C1. Gillespie’s algorithm, hand-written. Birth–death, \(k = 10\), \(\delta = 1\) per hour, \(m(0) = 0\). (a) Write a function that simulates one cell up to \(t = 10\) h and returns all event times and counts. How many reactions happen? (Expected: \(\int_0^{10}(10 + m(t))\,dt \approx 190\).) (b) Simulate 2000 cells and record \(m\) at \(t = 0.5, 1, 2, 10\) h (the count after the last event at or before \(t\): findInterval; Python np.searchsorted). Compare the mean \(\pm\) SE with the ODE \(m(t) = 10(1 - e^{-t})\). (c) At \(t = 10\) h: the variance and Fano factor, and the fractions of cells with 5, 10 and 15 molecules against Poisson(10) (dpois; Python scipy.stats.poisson.pmf).

C2. A general SSA: constitutive versus bursty. Write ssa(x, S, propensity, times) that takes a start state, a stoichiometry matrix (species × reactions), a propensity function and output times, and returns the state at each output time. (a) Simulate 1000 cells of the constitutive gene with protein (B1) from \((0, 0)\) to \(t = 30\) h. Compare the means with the ODE (10 and 99.7 at \(t = 30\) h) and the Fano factors with 1 and \(1 + k_p/(\delta_m + \delta_p) = 2.67\). (b) Simulate 1000 cells of the telegraph gene from \((g, m, p) = (0, 0, 0)\). Compare the means with (a), and the Fano factors with 16 (mRNA, B4) and 32.5 (protein, exact value from the moment equations). (c) What fraction of cells has no mRNA in each model? Compare with Poisson(10).

C3. A bug: averaging over events. Simulate one cell of the birth–death process for 5000 h. After a burn-in of 10 h, compute the mean of \(m\) in two ways: (i) the average of \(m\) after each event, (ii) the time-weighted average \(\frac{1}{T}\int m\,dt\) (each state weighted by how long it lasts). Which is right? Explain the value 10.5 that (i) approaches.

C4. Tau-leaping. Birth–death, \(k = 10\), \(\delta = 1\) per hour, from \(m = 0\) to \(t = 10\) h, with steps \(\tau = 0.01, 0.1, 0.5, 1, 1.5\) h. In each step, add Poisson\((k\tau)\) and subtract Poisson\((\delta m \tau)\) molecules (rpois; Python rng.poisson); if \(m < 0\), record it and set \(m = 0\). Over 2000 runs, print the mean and variance at \(t = 10\) h, the theoretical tau-leap variance \(2k/(\delta(2 - \delta\tau))\) (the exact SSA value is 10), and the fraction of runs that went negative.

C5. Euler–Maruyama. Simulate the chemical Langevin equation of Fact 5 with \(h = 0.01\) h to \(t = 10\) h, 2000 runs (rnorm; Python rng.standard_normal). (a) With \(k = 10\): compare the mean and variance with Poisson(10). (b) With \(k = 0.5\) (mean 0.5 molecules): what fraction of runs end in NaN? Of the others, what fraction ends negative?

C6. Early extinction of an epidemic. SIR with \(N = 10\,000\), \(\beta = 0.3\), \(\gamma = 0.1\) per day. Simulate only the order of events (no times needed): infection with probability \(a_1/(a_1 + a_2)\), \(a_1 = \beta S I/N\), \(a_2 = \gamma I\). Stop when \(I = 0\) (extinct) or \(I = 100\) (established). With 10 000 runs each, estimate the extinction probability for \(I_0 = 1, 2, 3\) with its SE, and compare with \((1/3)^{I_0}\) from B7.

Hints

Hint 1 — propensities and the master equation (B1, B3)

A column of \(S\) is “what this reaction does to each species”: translation does not use up the mRNA. The probability that reaction \(j\) is next is \(a_j/a_0\), and the waiting time has mean \(1/a_0\). For B3, set \(P_0' = 0\) first: it involves only \(P_0\) and \(P_1\). Then use \(P_1' = 0\). The guess \(P_n = (2^n/n!)\,P_0\) sums to \(e^2 P_0\).

Hint 2 — the SSA (B2, C1, C2)

One loop: compute the propensities, \(a_0\), \(\tau = -\log(u_1)/a_0\), then choose the reaction by comparing \(u_2 a_0\) with the cumulative sums (cumsum, findInterval; Python np.cumsum, np.searchsorted(..., side="right"); Rust a running sum or partition_point). Uniforms: R runif; Python rng.random() with rng = np.random.default_rng(1); Rust rng.random::<f64>() with StdRng::seed_from_u64(1) from rand. To record the state at output times, note that the state does not change between events: every output time before the next event time sees the current state. Repeat runs with replicate in R or a list comprehension in Python.

Hint 3 — Fano factors (B4, B5, C2)

\(F = \text{var}/\text{mean}\) with the sample variance: R var, Python x.var(ddof=1) (numpy’s default ddof=0 divides by \(n\)). Multiplying every value by \(c\) multiplies the mean by \(c\) and the variance by \(c^2\). With 1000 cells, a Fano factor is uncertain by roughly \(F\sqrt{2/1000} \approx 4.5\%\) of its value; the mean of a bursty gene is uncertain by \(\sqrt{F \cdot \text{mean}/1000}\).

Hint 4 — events versus time (C3)

For the time-weighted mean, add \(m \cdot \tau\) (the current count times the waiting time) before the jump. Events happen at rate \(a_0 = 10 + m\), so states with large \(m\) are left more often. If a fraction \(P_n\) of the time is spent in state \(n\), a fraction proportional to \(P_n (10 + n)\) of the events happens there. Use \(\mathrm E[m] = 10\), \(\mathrm E[m^2] = 110\) (Poisson).

Hint 5 — tau-leaping and Euler–Maruyama (B6, C4, C5)

\(P(\text{negative}) = P(N > m) = 1 - P(N \le m)\). In Rust, rand_distr::Poisson::new(lambda) refuses lambda = 0, so return 0 yourself in that case; normal numbers from rand_distr::StandardNormal. In R, sqrt of a negative number gives NaN with a warning; in numpy a RuntimeWarning (silence it with np.errstate(invalid="ignore")); in Rust f64::sqrt silently returns NaN. Once a value is NaN, every later step is NaN too.

Hint 6 — extinction (B7, C6)

A chain of infections dies out if the first person recovers before infecting anyone (probability 0.25), or infects someone first and then both the new chain and their own continued chain die out (probability \(0.75\,q \cdot q\)). Solve the quadratic \(3q^2 - 4q + 1 = 0\). In code, the propensities change after every event, so recompute them in the loop; the waiting times are not needed for this question.

fn bd_run(t_end: f64, rng: &mut StdRng) -> (Vec<f64>, Vec<i64>) {
    let (mut t, mut m) = (0.0, 0i64);
    let (mut tt, mut mm) = (vec![0.0], vec![0i64]);
    while t < t_end {
        let (a1, a2) = (K, DELTA * m as f64);
        let a0 = a1 + a2;
        t += -(1.0 - rng.random::<f64>()).ln() / a0; // waiting time
        m += if rng.random::<f64>() * a0 < a1 { 1 } else { -1 };
        tt.push(t);
        mm.push(m);
    }
    (tt, mm)
}

ssa <- function(x, S, propensity, times) {   # S: species x reactions
  out <- matrix(0, length(times), length(x)); t <- 0; i <- 1
  repeat {
    a <- propensity(x); a0 <- sum(a)
    t <- t - log(runif(1)) / a0               # Inf if a0 = 0: nothing more happens
    while (i <= length(times) && times[i] < t) { out[i, ] <- x; i <- i + 1 }
    if (i > length(times)) return(out)
    j <- findInterval(runif(1) * a0, cumsum(a)) + 1   # reaction j w.p. a_j / a0
    x <- x + S[, j]
  }
}

        let a = propensity(&x);
        let a0: f64 = a.iter().sum();
        t += -(1.0 - rng.random::<f64>()).ln() / a0; // inf if a0 = 0
        while i < times.len() && times[i] < t {
            out.push(x.clone());
            i += 1;
        }
        if i == times.len() {
            return out;
        }
        let r = rng.random::<f64>() * a0; // reaction j with probability a_j / a0
        let mut j = 0;
        let mut cum = a[0];
        while cum <= r {
            j += 1;
            cum += a[j];
        }
        for (xi, si) in x.iter_mut().zip(s) {
            *xi += si[j];
        }
    }
}

    let var = v.iter().map(|x| (x - m).powi(2)).sum::<f64>() / (n - 1.0);
    (m, var / m)
}
