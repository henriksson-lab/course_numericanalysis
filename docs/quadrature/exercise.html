Exercise: numerical integration

Goal

By the end of this exercise you should be able to:

  • compute an integral with the left Riemann, midpoint, trapezoid and Simpson rules, by hand for a few points and in code as composite rules,
  • read the order of a rule off a log–log plot of error against the number of intervals, and recognise when a non-smooth integrand lowers it,
  • improve the trapezoid rule with Richardson extrapolation (Romberg), and write a short adaptive Simpson routine,
  • explain why integrate / scipy.integrate.quad can return a confident wrong answer, and fix it by splitting the interval, transforming it or giving the scale,
  • remove an infinite interval or an endpoint singularity by substitution,
  • compute an AUC from blood samples (linear and linear-up/log-down, extrapolated to infinity), a chromatography peak area, and the normalising constant of a posterior density.

The by-hand part needs pen, paper and a pocket calculator (for exp, ln and square roots).

Background

Every rule replaces the integral by a weighted sum of function values, \(\int_a^b f(x)\,dx \approx \sum_i w_i f(x_i)\). With \(n\) intervals of width \(h = (b-a)/n\) and \(f_i = f(a + ih)\):

rule formula error order
left Riemann \(h\,(f_0 + f_1 + \dots + f_{n-1})\) \(\approx \tfrac{(b-a)h}{2} f'\) 1
midpoint \(h \sum_i f(a + (i - \tfrac12) h)\) \(-\tfrac{(b-a)h^2}{24} f''\) 2
trapezoid \(T(h)\) \(h\,(\tfrac12 f_0 + f_1 + \dots + f_{n-1} + \tfrac12 f_n)\) \(\tfrac{(b-a)h^2}{12} f''\) 2
Simpson (\(n\) even) \(\tfrac{h}{3}(f_0 + 4f_1 + 2f_2 + 4f_3 + \dots + 4f_{n-1} + f_n)\) \(\tfrac{(b-a)h^4}{180} f''''\) 4

(The derivatives are evaluated at some unknown point in \([a, b]\).) A rule of order \(p\) has error \(\approx C h^p\): halving \(h\) divides the error by \(2^p\), and on a log–log plot of error against \(n\) the slope is \(-p\). The orders hold only if the derivative in the error term exists and is bounded.

Richardson extrapolation (from Numerical differentiation): if \(T(h) \approx I + Ch^2\), then \(\big(4T(h/2) - T(h)\big)/3\) cancels the \(h^2\) term. Repeating it column by column is Romberg integration. Adaptive Simpson compares Simpson on one panel (\(S_1\)) and on two half-panels (\(S_2\)) of each piece: \(|S_2 - S_1|/15\) estimates the error of \(S_2\); pieces that fail are split in two. Gaussian quadrature chooses the points as well: \(n\) points integrate polynomials up to degree \(2n-1\) exactly.

Libraries. R’s integrate and Python’s scipy.integrate.quad both call QUADPACK: a 21-point Gauss–Kronrod rule on \([a, b]\), then repeated bisection of the piece with the largest estimated error; infinite intervals are mapped to \((0, 1]\). They stop when the estimated error is below \(\max(\text{abs.tol}, \text{rel.tol}\cdot|\text{value}|)\); R’s defaults are rel.tol = abs.tol \(\approx 1.2\times10^{-4}\), SciPy’s epsabs = epsrel \(= 1.49\times10^{-8}\). Rust’s quadrature crate uses the double-exponential (tanh–sinh) rule, whose points crowd towards both ends of the interval; it takes a target absolute error and has no infinite limits. For data, NumPy has np.trapezoid and SciPy scipy.integrate.trapezoid and simpson; base R has no trapezoid function (pracma::trapz exists), but it is one line.

Substitution. \(x = t/(1-t)\) maps \(t \in [0, 1)\) to \(x \in [0, \infty)\) with \(dx = dt/(1-t)^2\). \(x = u^2\) turns \(\int_0^1 g(x)/\sqrt{x}\,dx\) into \(\int_0^1 2g(u^2)\,du\).

The running example. An oral dose of 500 mg; one-compartment model with volume 50 L, absorption rate 1.5 /h and elimination rate 0.2 /h: \[C(t) = \frac{500}{50}\cdot\frac{1.5}{1.5 - 0.2}\left(e^{-0.2t} - e^{-1.5t}\right) \text{ mg/L},\] with \(\mathrm{AUC}_{0-6} = 32.6243601574044\), \(\mathrm{AUC}_{0-24} = 49.5252069010181\) and \(\mathrm{AUC}_{0-\infty} = 50\) mg·h/L. The blood samples are \(C(t)\) at 10 times, rounded to 2 decimals:

import numpy as np
from scipy.integrate import quad

t_h  = np.array([0, 0.5, 1, 2, 3, 4, 6, 8, 12, 24])                         # hours
conc = np.array([0, 4.99, 6.87, 7.16, 6.20, 5.16, 3.47, 2.33, 1.05, 0.09])  # mg/L
def auc_trap(t, y):
    return np.sum(np.diff(t) * (y[:-1] + y[1:]) / 2)
print(auc_trap(t_h, conc))                 # same as np.trapezoid(conc, t_h)
# 51.61750000000001
def model(t):
    return 500 / 50 * 1.5 / 1.3 * (np.exp(-0.2 * t) - np.exp(-1.5 * t))
value, abserr = quad(model, 0, 24)         # adaptive quadrature on a function
print(value)
# 49.52520690101807
print(abserr)
# 1.0343052501277095e-07
// rust/examples/quadrature_background.rs  —  cargo run --example quadrature_background
// Background: trapezoid rule on the blood samples (hand-written) and the
// quadrature crate's integrate (double-exponential rule) on the model.
fn auc_trap(t: &[f64], y: &[f64]) -> f64 {
    (1..t.len()).map(|i| (t[i] - t[i - 1]) * (y[i - 1] + y[i]) / 2.0).sum()
}
fn model(t: f64) -> f64 {
    500.0 / 50.0 * 1.5 / 1.3 * ((-0.2 * t).exp() - (-1.5 * t).exp())
}

fn main() {
    let t_h = [0.0, 0.5, 1.0, 2.0, 3.0, 4.0, 6.0, 8.0, 12.0, 24.0]; // hours
    let conc = [0.0, 4.99, 6.87, 7.16, 6.20, 5.16, 3.47, 2.33, 1.05, 0.09]; // mg/L
    println!("{}", auc_trap(&t_h, &conc));
    let out = quadrature::integrate(model, 0.0, 24.0, 1e-10); // target absolute error
    println!("{}", out.integral);
    println!("{:e}", out.error_estimate);
}

// Output:
// 51.6175
// 49.525206901018045
// 8.958167541095463e-12

By hand

B1. Four rules on a cubic. Take \(\int_0^2 x^3\,dx = 4\). (a) Compute the left Riemann, midpoint and trapezoid approximations with \(h = 1\) (two intervals), and Simpson’s rule with the three points \(0, 1, 2\). (b) Which rule is exact? Why is that not a coincidence? (c) Compute the trapezoid rule with \(h = 0.5\). By what factor did the error shrink? Which order does that suggest? (d) Combine the two trapezoid values by Richardson extrapolation, \((4T(h/2) - T(h))/3\). Compare with (a).

B2. AUC from seven blood samples. A sparser version of the data: \(t = 0, 1, 2, 4, 8, 12, 24\) h, \(C = 0, 6.87, 7.16, 5.16, 2.33, 1.05, 0.09\) mg/L. (a) Compute \(\mathrm{AUC}_{0-24}\) with the linear trapezoid rule (interval by interval). (b) For the falling intervals, use the log-down rule \(\Delta t\,(C_1 - C_2)/\ln(C_1/C_2)\) instead. Useful values: \(\ln(7.16/5.16) = 0.3276\), \(\ln(5.16/2.33) = 0.7951\), \(\ln(2.33/1.05) = 0.7971\), \(\ln(1.05/0.09) = 2.4567\). (c) Estimate the terminal slope \(\lambda_z\) from the last two samples and the extrapolated area \(C_\text{last}/\lambda_z\). What fraction of \(\mathrm{AUC}_{0-\infty}\) is extrapolated? (d) The true area from 12 h to 24 h is 4.76. Which interval contributes most of the error of the linear rule, and why is the log-down rule so much better there? The true area from 0 to 1 h is 4.48: what do both rules do there, and what would you change in the sampling plan?

B3. Order from a table. For \(\mathrm{AUC}_{0-6}\) the absolute errors are:

\(n\) 4 8 16
trapezoid 2.70 0.719 0.183
Simpson 0.664 0.0592 0.00411
  1. Compute the ratios of consecutive errors and the order of each rule.
  2. Assuming error \(= C h^p\) from \(n = 16\) on, how many intervals does each rule need for an error of \(10^{-6}\)?

B4. Two-point Gauss. The 2-point Gauss–Legendre rule on \([-1, 1]\) is \(f(-1/\sqrt3) + f(1/\sqrt3)\). (a) Check that it is exact for \(1, x, x^2, x^3\), and find its result for \(x^4\) (exact: \(2/5\)). (b) Map it to \([0, 2]\) (points \(1 \pm 1/\sqrt3\), weights \(1\)) and apply it to \(\int_0^2 x^3\,dx\). Compare the cost with B1(a).

B5. Why integrate(dnorm, 0, 20000) returns 0. The 21-point Gauss–Kronrod rule on \([-1, 1]\) has its two outermost points at \(\pm 0.99566\) and \(\pm 0.97391\). (a) Map them to \([0, 20000]\) with \(x = 10000(1 + s)\). Where are the two points closest to 0? Estimate \(\log_{10}\) of dnorm at the closest one (\(\text{dnorm}(x) = e^{-x^2/2}/\sqrt{2\pi}\)). What does a double make of it? (b) Same for \([0, 20]\). (c) For which upper limits \(b\) does the closest point lie within 5 standard deviations of 0? Predict whether integrate(dnorm, 0, 2000) and integrate(dnorm, 0, 5000) work. (C5 checks.)

B6. Substitution. (a) Write \(\int_0^\infty e^{-x}\,dx\) as an integral over \(t \in [0, 1)\) with \(x = t/(1-t)\). Evaluate the new integrand at \(t = 0, 0.5, 0.9\) and find its limit as \(t \to 1\). (b) The Jeffreys prior for a proportion is \(\propto 1/\sqrt{x(1-x)}\). Show with \(x = \sin^2\theta\) that its normalising constant \(\int_0^1 dx/\sqrt{x(1-x)}\) is \(\pi\). (c) Turn \(\int_0^1 e^{-x}/\sqrt{x}\,dx\) into a smooth integral with \(x = u^2\), and apply the trapezoid rule with \(h = 0.5\) to the new integral. (Exact: \(1.49365\).) Why could you not apply the trapezoid rule to the original?

In code

C1. (Composite rules and their order) Write functions left, mid, trap and simpson(f, a, b, n) for the composite rules. Apply them to \(\mathrm{AUC}_{0-6}\) of the model for \(n = 2, 4, \dots, 1024\), plot the absolute errors against \(n\) on log–log axes, and fit the slopes for \(n \ge 32\). Do they match the table in the Background and your answers to B3?

C2. (Order needs smoothness) (a) Repeat C1 for \(\int_0^1 \sqrt{x}\,dx = 2/3\) with the trapezoid and Simpson rules. What slopes do you get? (b) \(\int_0^1 e^{-x}/\sqrt{x}\,dx = \sqrt{\pi}\,\mathrm{erf}(1)\). What does the trapezoid rule return? Compute the midpoint rule for \(n = 16, 256, 4096\). (c) Use the substitution of B6(c) and Simpson’s rule with \(n = 2, 4, 8, 16\). Compare with integrate (Python: quad; Rust: quadrature::integrate) on the original integrand.

C3. (Romberg) Write romberg(f, a, b, k) that fills the \(k \times k\) table (row \(i\): trapezoid with \(2^{i-1}\) intervals, then Richardson column by column). (a) For \(\mathrm{AUC}_{0-6}\), print the error of the last diagonal entry for \(k = 4, \dots, 9\), with the number of function values used. Compare with Simpson and 1024 intervals from C1. C4. (Adaptive Simpson) Write the adaptive Simpson routine from the slides. (a) Integrate the model from 0 to 24 h with tolerances \(10^{-4}, 10^{-6}, 10^{-8}\); count the function evaluations and print the errors. How many points would uniform Simpson need for the same accuracy (use C1’s order)? (b) A chromatogram: one peak at 340 s with \(\sigma = 3\) s and height 1000, run from 0 to 600 s: peak(t) = 1000 * exp(-(t - 340)^2 / (2 * 3^2)). Its area is \(1000 \cdot 3\sqrt{2\pi}\). What does your adaptive routine return, and why? (c) Fix it by starting from 60 pieces of 10 s.

C5. (Inside a library routine) (a) Wrap dnorm (Python: scipy.stats.norm.pdf; Rust: statrs’s Normal) in a function that records every \(x\) it is called with, and integrate from 0 to 20000. How many points are used, and where are the smallest ones? Compare with B5. (b) Integrate dnorm from 0 to \(b\) for \(b = 20, 200, 2000, 5000, 20000, \infty\), printing the value and the error estimate. (c) Fix \([0, 20000]\) by splitting at 10. (Python’s quad has an argument points for this.) (d) Integrate the chromatogram of C4 over a one-hour run, \([0, 3600]\) s, and over the peak \(\pm 10\sigma\).

C6. (Peak area versus peak height) A Gaussian peak with \(\sigma = 3\) s and height 1000 centred at 300 s is sampled every \(h\) seconds from 240 s on, with a sampling offset (phase) between 0 and \(h\). For \(h = 9, 6, 4.5, 3, 1.5\) s and 40 offsets each, compute the trapezoid area and the largest sample (the measured height). Report the worst relative area error and the worst height error. How many points across the peak (about \(4\sigma\) wide) do you need for 1 % area? For 5 % height?

C7. (AUC from the blood samples) Use the 10 samples from the Background. (a) For each interval, compute the error of the linear trapezoid and of the linear-up/log-down rule against the exact area of the model on that interval (integrate). Where are the errors? (b) Compute \(\mathrm{AUC}_{0-24}\) with both rules, and \(\mathrm{AUC}_{0-\infty}\) by adding \(C_\text{last}/\lambda_z\), with \(\lambda_z\) from a straight-line fit to \(\log C\) over the last three samples (R: lm; Python: np.polyfit). (c) The model route: integrate the model from 0 to \(\infty\) and compare with Dose\(/(V k_e) = 50\).

C8. (Normalising a posterior) For the zero-truncated Poisson UMI data of Newton and secant methods (100 cells), the log-likelihood is \(\ell(\lambda) = 173\log\lambda - 100\lambda - 100\log(1 - e^{-\lambda})\), with maximum at \(\hat\lambda = 1.2184695258301268\) and standard error 0.1325. With a flat prior, the posterior density is \(e^{\ell(\lambda)}/Z\). (a) Integrate \(e^{\ell(\lambda)}\) over \((0, b)\) for \(b = 10, 100, \infty\). Do the answers agree? (b) Integrate \(g(\lambda) = e^{\ell(\lambda) - \ell(\hat\lambda)}\) instead. Report \(Z_g\), \(\log Z = \ell(\hat\lambda) + \log Z_g\), and the posterior mean \(\int \lambda\,g(\lambda)\,d\lambda / Z_g\). (c) With 10 000 cells (every count multiplied by 100: \(\ell\) times 100, same \(\hat\lambda\), standard error 10 times smaller), integrate the scaled \(g\) over \((0, b)\) for \(b = 10, 100, \infty\), and over \(\hat\lambda \pm 10\) standard errors. Which answers can you trust?

Simpson: 0.66, 0.059, 0.0041, 0.00026, orders 3.49, 3.85, 3.96, 3.99: order 4, reached only once \(h\) is small compared with the absorption phase. On the log–log plot the trapezoid points follow the slope-\(-2\) line, the Simpson points the slope-\(-4\) line. Gauss–Legendre: \(n = 4\) gives \(0.030\), \(n = 8\) gives \(3.2\times10^{-8}\), and from \(n = 16\) on the error sits at the rounding level (\(7\times10^{-15}\)): no straight line, the error falls faster than any power of \(n\). For \(10^{-6}\): the trapezoid needs about \(7\,000\) intervals (\(0.046\cdot(32/n)^2 = 10^{-6}\), off the plot), Simpson about 130 (\(n = 128\) gives \(1.04\times10^{-6}\)), Gauss–Legendre 8 points.

Answer E2

Infusion, Simpson: orders 3.06, 2.97, 3.01 (errors \(2.7\times10^{-3}\), \(3.2\times10^{-4}\), \(4.1\times10^{-5}\)): the kink lowers the order from 4 to 3, because the parabola across the kink cannot bend sharply and its error dominates. At \(n = 12\) and \(24\) a grid point sits on the kink (\(h = 0.5\) and \(0.25\) h; the readout says so): errors \(9.3\times10^{-6}\) and \(5.8\times10^{-7}\), order 4.00 again, 300 times smaller than with \(n = 16\). Putting a point at the kink (splitting there) restores the order. Gauss–Legendre: \(0.28\), \(0.046\), \(0.028\), \(0.0049\): erratic, and only about order 2.5 instead of the plunge of E1; a single high-degree polynomial cannot follow a kink. On \(\sqrt{x}\) Simpson measures 1.50, as in C2. The peak goes the other way: the trapezoid errors are \(4.9\times10^{-2}\) and \(4.0\times10^{-5}\) (relative \(5\times10^{-9}\), as in the lecture), Simpson’s \(2.1\times10^2\) and \(36\).     h * (0..n).map(|i| f(a + i as f64 * h)).sum::<f64>()
}

    let h = (b - a) / n as f64;

}
fn trap(f: fn(f64) -> f64, a: f64, b: f64, n: usize) -> f64 {
    let h = (b - a) / n as f64;
    let inner: f64 = (1..n).map(|i| f(a + i as f64 * h)).sum();
    h * (inner + (f(a) + f(b)) / 2.0)
}
fn simpson(f: fn(f64) -> f64, a: f64, b: f64, n: usize) -> f64 {
    let h = (b - a) / n as f64;
    let s: f64 = (0..=n)
        .map(|i| {
            let w = if i == 0 || i == n { 1.0 } else if i % 2 == 1 { 4.0 } else { 2.0 };
            w * f(a + i as f64 * h)
        })
        .sum();
    h / 3.0 * s
}
// slope of log(e) against log(n) by least squares
fn slope(n: &[f64], e: &[f64]) -> f64 {
    let x: Vec<f64> = n.iter().map(|v| v.ln()).collect();
    let y: Vec<f64> = e.iter().map(|v| v.ln()).collect();
    let (mx, my) = (x.iter().sum::<f64>() / x.len() as f64, y.iter().sum::<f64>() / y.len() as f64);
    let sxy: f64 = x.iter().zip(&y).map(|(a, b)| (a - mx) * (b - my)).sum();
    let sxx: f64 = x.iter().map(|a| (a - mx).powi(2)).sum();
    sxy / sxx
}

fn trap(f: impl Fn(f64) -> f64, a: f64, b: f64, n: usize) -> f64 {
    let h = (b - a) / n as f64;
    let inner: f64 = (1..n).map(|i| f(a + i as f64 * h)).sum();
    h * (inner + (f(a) + f(b)) / 2.0)
}
fn simpson(f: impl Fn(f64) -> f64, a: f64, b: f64, n: usize) -> f64 {
    let h = (b - a) / n as f64;
    let s: f64 = (0..=n)
        .map(|i| {
            let w = if i == 0 || i == n { 1.0 } else if i % 2 == 1 { 4.0 } else { 2.0 };
            w * f(a + i as f64 * h)
        })
        .sum();
    h / 3.0 * s
}
fn mid(f: impl Fn(f64) -> f64, a: f64, b: f64, n: usize) -> f64 {
    let h = (b - a) / n as f64;
    h * (0..n).map(|i| f(a + (i as f64 + 0.5) * h)).sum::<f64>()
}
fn slope(n: &[f64], e: &[f64]) -> f64 {
    let x: Vec<f64> = n.iter().map(|v| v.ln()).collect();
    let y: Vec<f64> = e.iter().map(|v| v.ln()).collect();
    let (mx, my) = (x.iter().sum::<f64>() / x.len() as f64, y.iter().sum::<f64>() / y.len() as f64);
    let sxy: f64 = x.iter().zip(&y).map(|(a, b)| (a - mx) * (b - my)).sum();
    sxy / x.iter().map(|a| (a - mx).powi(2)).sum::<f64>()
}
