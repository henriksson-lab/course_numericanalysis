Exercise: stiffness and implicit methods

Goal

By the end of this exercise you should be able to:

  • compute the amplification factor \(R(h\lambda)\) of Euler, RK4 and backward Euler on the test equation \(y' = \lambda y\), and draw their stability regions,
  • estimate the time scales of a kinetic model from the eigenvalues of its Jacobian, and say whether it is stiff,
  • take backward Euler steps by hand, including the Newton iterations a nonlinear step needs,
  • write backward Euler with Newton in code and run it on the enzyme model with steps 100 times larger than explicit Euler can take,
  • choose a library solver (lsoda, bdf, radau / "LSODA", "BDF", "Radau") and count steps and time to show that it was the right choice,
  • compare the full mass-action enzyme model with the Michaelis–Menten (quasi-steady-state) approximation,
  • recognise the failure of implicit methods: artificial damping of oscillations.

The by-hand part uses pen, paper and a pocket calculator. The code part works at the sizes where only code works: thousands of steps, Robertson’s problem up to \(t = 10^{11}\).

Background

The enzyme model. One enzyme \(E\) binds substrate \(S\) to a complex \(C\), which either falls apart or turns the substrate into product \(P\): \[E + S \underset{k_r}{\overset{k_f}{\rightleftharpoons}} C \xrightarrow{k_{cat}} E + P\] With mass action and \(b = k_f E S - k_r C\) (net binding), \(c = k_{cat}C\) (catalysis): \[S' = -b, \quad E' = -b + c, \quad C' = b - c, \quad P' = c.\] We use \(k_f = 100\ \mu\text{M}^{-1}\text{s}^{-1}\), \(k_r = 100\ \text{s}^{-1}\), \(k_{cat} = 1\ \text{s}^{-1}\), \(S_0 = 10\ \mu\)M, \(E_0 = 1\ \mu\)M, \(C_0 = P_0 = 0\). Two totals are conserved: \(E + C = E_0\) and \(S + C + P = S_0\).

Facts used below:

  1. Test equation. On \(y' = \lambda y\) a one-step method multiplies \(y\) by a fixed factor \(R(z)\) per step, with \(z = h\lambda\): Euler \(R = 1 + z\); RK4 \(R = 1 + z + z^2/2 + z^3/6 + z^4/24\); backward Euler \(R = 1/(1 - z)\). Errors do not grow if \(|R(z)| \le 1\); the set of such \(z\) is the stability region. On the negative real axis: Euler needs \(h|\lambda| \le 2\), RK4 \(h|\lambda| \le 2.785\), backward Euler nothing.
  2. Eigenvalues set the time scales. Near a state, \(\mathbf y' = \mathbf f(\mathbf y)\) behaves like \(\mathbf y' = J\mathbf y\) with \(J\) the Jacobian (\(J_{ij} = \partial f_i / \partial y_j\), Newton for systems of equations). Each eigenvalue \(\lambda\) of \(J\) is a mode with time scale \(1/|\text{Re}\,\lambda|\). For a \(2\times2\) matrix, \(\lambda^2 - (\text{tr}\,J)\lambda + \det J = 0\); if one eigenvalue is much larger than the other, \(\lambda_\text{fast} \approx \text{tr}\,J\) and \(\lambda_\text{slow} \approx \det J / \text{tr}\,J\).
  3. Stiff = the step size of an explicit method is limited by stability (by the fastest mode) rather than by the accuracy needed for the slow solution you care about. Typical sign: a ratio of \(10^3\) or more between the fastest and slowest time scale over the simulated time.
  4. Backward Euler: \(\mathbf y_{n+1} = \mathbf y_n + h\,\mathbf f(\mathbf y_{n+1})\). Each step solves \(\mathbf G(\mathbf y) = \mathbf y - \mathbf y_n - h\mathbf f(\mathbf y) = \mathbf 0\) by Newton: solve \((I - hJ(\mathbf y))\,\boldsymbol\delta = -\mathbf G(\mathbf y)\), set \(\mathbf y \leftarrow \mathbf y + \boldsymbol\delta\), starting from \(\mathbf y = \mathbf y_n\). Order 1.
  5. BDF2: \(\mathbf y_{n+1} - \tfrac43\mathbf y_n + \tfrac13\mathbf y_{n-1} = \tfrac23 h\,\mathbf f(\mathbf y_{n+1})\); Newton matrix \(I - \tfrac23 hJ\). Order 2, needs two start values.
  6. Michaelis–Menten (QSSA): assume \(C' \approx 0\); then \(S' = -V_{\max}S/(K_m + S)\) with \(V_{\max} = k_{cat}E_0\), \(K_m = (k_r + k_{cat})/k_f\). Accurate when \(E_0 \ll S_0 + K_m\).
  7. Library solvers. R: deSolve::ode with method = "lsoda" (default; switches between Adams and BDF), "bdf", "radau", "ode45" (explicit); step counts in attr(out, "istate") or diagnostics(out). Python: scipy.integrate.solve_ivp with method="LSODA", "BDF", "Radau", "RK45" (default, explicit); sol.t.size - 1 steps (when t_eval is not given), sol.nfev evaluations. Rust: the ode_solvers crate has only explicit methods (Dopri5, Dop853, Rk4); Dopri5 runs a stiffness test every 1000 steps and stops with an error (“the problem seems to become stiff”) when it fires repeatedly. The stiff side in Rust is hand-written backward Euler with Newton and nalgebra’s LU.

// Background: the enzyme model E + S <-> C -> E + P with ode_solvers::Dopri5 (explicit RK45).
// ode_solvers has no stiff (implicit) solver: an explicit method works here, but needs many steps.
use ode_solvers::continuous_output_model::ContinuousOutputModel;
use ode_solvers::{Dopri5, System, Vector4};

const KF: f64 = 100.0; const KR: f64 = 100.0; const KCAT: f64 = 1.0; // per uM per s, per s, per s

struct Enzyme;
impl System<f64, Vector4<f64>> for Enzyme {
    fn system(&self, _t: f64, y: &Vector4<f64>, dy: &mut Vector4<f64>) {
        let (s, e, c) = (y[0], y[1], y[2]);
        let bind = KF * e * s - KR * c; // E + S <-> C  (net binding)
        let turn = KCAT * c;            // C -> E + P   (catalysis)
        dy[0] = -bind; dy[1] = -bind + turn; dy[2] = bind - turn; dy[3] = turn;
    }
}

fn main() {
    let y0 = Vector4::new(10.0, 1.0, 0.0, 0.0); // uM: S, E, C, P
    // Dopri5::new(system, t0, t_end, output spacing, y0, rtol, atol)
    let mut s = Dopri5::new(Enzyme, 0.0, 30.0, 30.0, y0, 1e-8, 1e-10);
    let mut dense = ContinuousOutputModel::default(); // the solution at any t
    let st = s.integrate_with_continuous_output_model(&mut dense).unwrap();
    for t in [10.0, 30.0] {
        let y = dense.evaluate(t).unwrap();
        println!("t = {:>2}  S = {:.6e}  E = {:.6}  C = {:.6e}  P = {:.6}", t, y[0], y[1], y[2], y[3]);
    }
    println!("{} steps, {} f evaluations", st.accepted_steps, st.num_eval);
}

By hand

B1. Amplification factors. Drug clearance \(C' = -0.8\,C\) (per hour), as in Initial value problems and Euler’s method. (a) For \(h = 0.5, 2, 3, 10\) hours compute \(z = h\lambda\) and the factor per step of Euler and of backward Euler. Compare with the exact factor \(e^{z}\) (given: \(e^{-0.4} = 0.670\), \(e^{-1.6} = 0.202\), \(e^{-2.4} = 0.0907\), \(e^{-8} = 0.000335\)). Which steps are stable? Which are accurate? (b) The enzyme model’s fastest eigenvalue at the start is \(\lambda = -1201\ \text{s}^{-1}\). What is the largest stable step of Euler and of RK4? How many steps does each need to cover 30 s? (c) What factor does backward Euler apply to this fast mode with \(h = 0.1\) s? What is the exact factor \(e^{-120.1}\), roughly? Does the difference matter?

B2. Backward Euler by hand. A drug is infused at 2 mg/L per hour and cleared at rate 0.8 per hour: \(C' = 2 - 0.8\,C\), \(C(0) = 0\). Exact solution: \(C(t) = 2.5\,(1 - e^{-0.8t})\). (a) Write the backward Euler step and solve it for \(C_{n+1}\) (it is linear: no Newton needed). (b) Take two steps with \(h = 1\) hour, by backward Euler and by Euler. Compare with the exact \(C(1) = 1.377\), \(C(2) = 1.995\). (c) Take one step with \(h = 10\) hours by each method. Compare with \(C(10) = 2.499\). (d) Show that the steady state \(C = 2.5\) is a fixed point of the backward Euler step for every \(h\).

B3. Newton inside a step. Protein monomers dimerise, \(2M \to D\), with \(M' = -kM^2\), \(k = 10\) per \(\mu\)M per s, \(M(0) = 1\ \mu\)M. Exact: \(M(t) = 1/(1 + kt)\). (a) Write the backward Euler equation \(G(y) = 0\) for \(y = M_1\) with \(h = 0.1\) s, and \(G'(y)\). (b) Do two Newton iterations from \(y = M_0 = 1\). (c) Solve \(G(y) = 0\) exactly with the quadratic formula. How many correct digits did two iterations give? Compare \(M_1\) with the exact \(M(0.1)\) and with one Euler step. (d) Repeat (c) with \(h = 0.2\) s. What does Euler give now? (e) Why is \(y = M_n\) a good starting point for Newton?

B4. Eigenvalues of the enzyme model. Use \(E = E_0 - C\) to reduce the model to \[S' = -k_f(E_0 - C)S + k_r C, \qquad C' = k_f(E_0 - C)S - (k_r + k_{cat})C.\] (a) Compute the \(2\times2\) Jacobian \(\partial(S', C')/\partial(S, C)\) in general, then at \(S = 10\), \(C = 0\). (b) Compute its trace and determinant, and the two eigenvalues (exactly, and with the approximations of fact 2). What are the two time scales, and their ratio? (c) Repeat at the end of the reaction, \(S = 0\), \(C = 0\). Is the model still stiff? What is the Euler step limit now?

B5. Robertson’s Jacobian. \(y_1' = -0.04y_1 + 10^4y_2y_3\), \(y_2' = 0.04y_1 - 10^4y_2y_3 - 3\times10^7y_2^2\), \(y_3' = 3\times10^7y_2^2\). (a) Write the \(3\times3\) Jacobian \(J\). (b) Evaluate \(J\) at the start, \(\mathbf y = (1, 0, 0)\). What are its eigenvalues? Is the problem stiff at \(t = 0\)? (c) Evaluate \(J\) at \(t = 40\), where \(\mathbf y \approx (0.7158,\ 9.19\times10^{-6},\ 0.2842)\). Each column of \(J\) sums to 0: what does that say about one eigenvalue (think of \(y_1 + y_2 + y_3\))? The slow eigenvalue is about \(-0.02\). Use the trace to estimate the fast one. (d) RK45 is stable for \(h|\lambda| \lesssim 3.3\). Estimate how many steps it needs from \(t = 0\) to \(40\). (e) Write the Newton matrix \(I - hJ\) of a backward Euler step with \(h = 1\) at \(t = 40\).

B6. BDF2 by hand. Drug clearance \(C' = -0.8\,C\), \(C_0 = 10\), \(h = 1\) hour. (a) Solve the BDF2 formula for \(C_{n+1}\) on this linear equation. (b) Take \(C_1\) from the exact solution, \(C_1 = 10e^{-0.8} = 4.493\), and compute \(C_2\) by BDF2. (c) Compute \(C_1, C_2\) by backward Euler. Compare both with the exact \(C_2 = 2.019\).

B7. Damping and classification. (a) For the oscillator \(x'' = -\omega^2 x\) (fact: the eigenvalues are \(\pm i\omega\)), backward Euler multiplies the amplitude by \(|1/(1 - i\omega h)| = 1/\sqrt{1 + \omega^2h^2}\) per step. With \(\omega = 2\pi/24\) per hour (\(\omega = 0.2618\)) and \(h = 1\) h, what is the factor per step, per day and after 10 days? (b) Stiff or not? Logistic growth of a culture (\(r = 0.8\) per hour) over 24 h; the SIR epidemic over a season; the enzyme model over 30 s; the enzyme model over its first 5 ms; Robertson’s problem to \(t = 10^{5}\); a circadian oscillator over 10 days; diffusion on a fine grid of 1000 points (Implicit schemes and the method of lines). For each, which deSolve/solve_ivp method would you choose?

C6. Robertson’s problem. (a) Solve it from \(t = 0\) to \(40\) with rtol = 1e-6, atol = 1e-10 with an explicit and three stiff solvers; print steps, \(\mathbf f\) evaluations, time and \(y_2(40)\). C7. Backward Euler damps a clock. Run backward Euler on the 24-hour oscillator \(y_1' = y_2\), \(y_2' = -\omega^2 y_1\), \(\mathbf y(0) = (1, 0)\), \(\omega = 2\pi/24\), for 10 days with \(h = 1, 0.5, 0.1, 0.01\) hours, and print the amplitude \(\sqrt{y_1^2 + (y_2/\omega)^2}\) (exact: 1). Then solve the same problem with an explicit library solver and with BDF at rtol = 1e-8, atol = 1e-10, and compare amplitudes and step counts. What would you conclude about the clock from the \(h = 1\) run alone?

Answer E1

At \(h = 0.001\): \(h\lambda_\text{slow} = -0.001\), right next to the origin, and \(h\lambda_\text{fast} = -1\), the centre of the disc (\(R = 0\): Euler kills the fast mode in one step). Hints

Hint 1 — amplification factors (B1, B6, B7)

Compute \(z = h\lambda\) first: \(\lambda = -0.8\), so \(z = -0.4, -1.6, -2.4, -8\). Stable means \(|R| \le 1\); accurate means \(R\) close to \(e^z\). For the step limits in B1(b), solve \(h|\lambda| = 2\) and \(h|\lambda| = 2.785\). In B6, move every \(C_{n+1}\) term to the left: \(C_{n+1}(1 - \tfrac23 h\lambda) = \tfrac43 C_n - \tfrac13 C_{n-1}\).

Hint 2 — an implicit step (B2, B3)

Write the formula with \(C_{n+1}\) on both sides, then collect: B2 is linear, \(C_{n+1}(1 + 0.8h) = C_n + 2h\). In B3 the equation is quadratic: \(y + hky^2 - M_0 = 0\). Newton: \(y \leftarrow y - G(y)/G'(y)\), as in Newton and secant methods.

Hint 3 — Jacobians and eigenvalues (B4, B5)

Row \(i\) of \(J\) holds the partial derivatives of the \(i\)-th rate with respect to each variable, holding the others fixed (Newton for systems of equations). For a \(2\times2\) matrix, \(\lambda = \tfrac12\big(\text{tr} \pm \sqrt{\text{tr}^2 - 4\det}\big)\). In B5(c), if the columns of \(J\) sum to 0, then \((1, 1, 1)\,J = \mathbf 0\), so \(J\) is singular; the eigenvalues add up to the trace.

Hint 4 — backward Euler in code (C2, C5, C7)

Inner loop: delta <- solve(I - h * jac(y), -(y - yold - h * f(y))), stop when the length of delta is below 1e-10. R: solve, diag; Python: np.linalg.solve, np.eye; Rust: (&id - h * jac(&y)).lu().solve(&(-g)) with nalgebra. For BDF2 replace the equation by fact 5 and the matrix by \(I - \tfrac23 hJ\). On the linear oscillator Newton converges in one iteration (a second one confirms it).

Hint 5 — library solvers and counters (C3, C4, C6, C7)

R: attr(out, "istate")[2] is the number of steps, [3] the number of \(\mathbf f\) evaluations; diagnostics(out) prints everything. deSolve limits the step to the spacing of the output times (hmax), so compare step counts for the same times. Python: without t_eval, sol.t holds every step; use dense_output=True and sol.sol(t) to get values at chosen times. Python’s BDF and Radau are written in Python, LSODA in Fortran, so compare their wall times with care. Rust: Dopri5::from_param(..., n_stiff, ...) with n_stiff = u32::MAX switches the stiffness test off; the returned Stats has accepted_steps and num_eval.

use nalgebra::{DMatrix, DVector};

const KF: f64 = 100.0; const KR: f64 = 100.0; const KCAT: f64 = 1.0;

fn f(y: &DVector<f64>) -> DVector<f64> {                // y = (S, E, C, P)
    let b = KF * y[1] * y[0] - KR * y[2];
    DVector::from_vec(vec![-b, -b + KCAT * y[2], b - KCAT * y[2], KCAT * y[2]])
}

fn jac(y: &DVector<f64>) -> DMatrix<f64> {
    DMatrix::from_row_slice(4, 4, &[
        -KF * y[1], -KF * y[0],  KR,         0.0,
        -KF * y[1], -KF * y[0],  KR + KCAT,  0.0,
         KF * y[1],  KF * y[0], -KR - KCAT,  0.0,
         0.0,        0.0,        KCAT,       0.0])
}

fn euler(y0: &DVector<f64>, h: f64, n: usize) -> DVector<f64> {
    let mut y = y0.clone();
    for _ in 0..n { y = &y + h * f(&y); }
    y
}

// returns the last value and the total number of Newton iterations
fn beuler(y0: &DVector<f64>, h: f64, n: usize, tol: f64) -> (DVector<f64>, usize) {
    let mut y = y0.clone();
    let id = DMatrix::<f64>::identity(y.len(), y.len());
    let mut newton = 0;
    for _ in 0..n {
        let yold = y.clone();                            // Newton starts at y_n
        for _ in 0..20 {
            let g = &y - &yold - h * f(&y);
            let delta = (&id - h * jac(&y)).lu().solve(&(-g)).expect("singular I - hJ");
            y += &delta; newton += 1;
            if delta.norm() < tol { break; }
        }
    }
    (y, newton)
}

    for _ in 0..20 {
        let g = &y - c * h * f(&y) - rhs;
        let delta = (&id - c * h * jac(&y)).lu().solve(&(-g)).unwrap();
        y += &delta;
        if delta.norm() < 1e-10 { break; }
    }
    y
}
fn beuler(y0: &DVector<f64>, h: f64, n: usize) -> DVector<f64> {
    let mut y = y0.clone();
    for _ in 0..n { y = implicit_solve(&y, 1.0, h, &y); }          // y - h f(y) = y_n
    y
}
fn bdf2(y0: &DVector<f64>, y1: &DVector<f64>, h: f64, n: usize) -> DVector<f64> {
    let (mut yprev, mut y) = (y0.clone(), y1.clone());
    for _ in 1..n {                                                 // y - 2/3 h f(y) = 4/3 y_n - 1/3 y_{n-1}
        let ynew = implicit_solve(&(4.0 / 3.0 * &y - 1.0 / 3.0 * &yprev), 2.0 / 3.0, h, &y);
        yprev = y; y = ynew;
    }
    y
}

struct Enzyme;
impl System<f64, Vector4<f64>> for Enzyme {
    fn system(&self, _t: f64, y: &Vector4<f64>, dy: &mut Vector4<f64>) {
        let b = KF * y[1] * y[0] - KR * y[2];
        dy[0] = -b; dy[1] = -b + KCAT * y[2]; dy[2] = b - KCAT * y[2]; dy[3] = KCAT * y[2];
    }
}
fn reference(t: f64) -> DVector<f64> {
    let mut s = Dopri5::from_param(Enzyme, 0.0, t, t, Vector4::new(10.0, 1.0, 0.0, 0.0),
                                   1e-12, 1e-14, 0.9, 0.04, 0.2, 10.0, t, 0.0, 10_000_000,
                                   u32::MAX, OutputType::Sparse);
    s.integrate().unwrap();
    DVector::from_column_slice(s.y_out().last().unwrap().as_slice())
}

const W: f64 = 2.0 * PI / 24.0;                       // one cycle per 24 h

fn amp(x: f64, v: f64) -> f64 { (x * x + (v / W).powi(2)).sqrt() } // exact: 1 for ever

struct Osc;
impl System<f64, Vector2<f64>> for Osc {
    fn system(&self, _t: f64, y: &Vector2<f64>, dy: &mut Vector2<f64>) {
        dy[0] = y[1]; dy[1] = -W * W * y[0];
    }
}

fn main() {
    let a = DMatrix::from_row_slice(2, 2, &[0.0, 1.0, -W * W, 0.0]);
    let id = DMatrix::<f64>::identity(2, 2);
    for h in [1.0, 0.5, 0.1, 0.01] {
        // linear ODE: one Newton iteration is exact, so solve (I - hA) y_{n+1} = y_n directly
        let lu = (&id - h * &a).lu();
        let mut y = DVector::from_vec(vec![1.0, 0.0]);
        for _ in 0..(240.0 / h).round() as usize { y = lu.solve(&y).unwrap(); }
        println!("backward Euler h = {:4.2}: amplitude after 10 days {:.6}", h, amp(y[0], y[1]));

    s.set_output(OutputType::Sparse);                 // last output = the step that ends at t = 240

    let y = s.y_out().last().unwrap();
    println!("Dopri5: amplitude {:.6}, steps {}", amp(y[0], y[1]), st.accepted_steps);

From the \(h = 1\) run alone a modeller would conclude that the clock is strongly damped and needs a driving signal to keep oscillating, a wrong biological conclusion. The explicit solver keeps the amplitude to 6 digits with fewer steps than BDF: the oscillator is not stiff, and an implicit method is the wrong tool for it.

Where this leads

  • Equilibria, stability and the phase plane (Part 8): the eigenvalues of the Jacobian come back, now to decide whether a steady state of the biology is stable, not whether a solver is.
  • Nonlinear least squares and ODE fitting (Part 9): fitting rate constants solves the model hundreds of times; with a stiff model, choosing lsoda or bdf decides whether that takes seconds or hours.
  • Implicit schemes and the method of lines (Part 10): a diffusion equation on a grid becomes a large, sparse, stiff ODE system; backward Euler then needs one sparse (tridiagonal) solve per step.
  • We wrote backward Euler with a fixed step and full Newton iterations. Production solvers (lsoda, bdf, radau) also estimate their error, adapt step and order, and reuse the Jacobian and its LU factorisation over many steps.
