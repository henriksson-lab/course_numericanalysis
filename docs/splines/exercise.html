Exercise: splines

Goal

By the end of this exercise you should be able to:

  • interpolate with piecewise linear functions and bound their error by \(\tfrac{h^2}{8}\max|f''|\),
  • explain why a cubic spline needs exactly two extra conditions, and set up and solve its tridiagonal system for the second derivatives \(M_i\), by hand for 3–4 points and in code with the Thomas algorithm,
  • choose between natural, clamped and not-a-knot end conditions, and know which one R and Python use by default,
  • measure the order of spline interpolation on a log–log error table,
  • detect and fix overshoot (negative expression) with a monotone interpolant or a log scale,
  • explain why interpolation and finite differences amplify noise, and estimate a growth rate from noisy OD data with a smoothing spline,
  • choose the smoothing parameter by GCV or cross-validation, report df, and check the residuals.

The by-hand part uses pen and paper (a calculator helps in B1 and B6). The code part checks the hand answers and then works at sizes where only code works.

Background

Data. Two running examples. The OD curve from Convergence and cost: a logistic \(N(t) = K / \big(1 + (K/N_0 - 1)e^{-rt}\big)\) with \(K = 1.2\), \(N_0 = 0.05\), \(r = 0.8\) per hour, read by a plate reader every 15 min for 10 h (41 reads) with measurement noise of sd 0.01. Its true growth rate is \(N'(t) = rN(1 - N/K)\), at most \(rK/4 = 0.24\) OD/h at \(t = 3.92\) h. A gene time course: an immediate-early gene measured at 0, 0.5, 1, 2, 4, 8, 12 and 24 h after stimulation (C4), and a gene along pseudotime in 40 cells (C6).

Facts used below:

  1. Piecewise linear. On \([x_i, x_{i+1}]\) with \(h = x_{i+1} - x_i\): \(p(x) = y_i + \frac{y_{i+1} - y_i}{h}(x - x_i)\), error \(|f(x) - p(x)| \le \frac{h^2}{8}\max|f''|\): order 2.
  2. Cubic spline. A cubic on each of the \(n - 1\) intervals with \(S(x_i) = y_i\) and \(S, S', S''\) continuous: \(4n - 4\) unknowns, \(4n - 6\) conditions, so two end conditions are needed.
  3. Second-derivative form. With \(M_i = S''(x_i)\), \(h_i = x_{i+1} - x_i\), \(s_i = (y_{i+1} - y_i)/h_i\), \(A = (x_{i+1} - x)/h_i\), \(B = (x - x_i)/h_i\): \[S(x) = A y_i + B y_{i+1} + \tfrac{h_i^2}{6}\big[(A^3 - A)M_i + (B^3 - B)M_{i+1}\big],\] \[S'(x) = s_i + \tfrac{h_i}{6}\big[-(3A^2 - 1)M_i + (3B^2 - 1)M_{i+1}\big].\]
  4. The system. Continuity of \(S'\) at each interior \(x_i\): \[h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_iM_{i+1} = 6(s_i - s_{i-1}).\] Tridiagonal and strictly diagonally dominant, so the Thomas algorithm (Structure: symmetric, banded, sparse) solves it in \(O(n)\) without pivoting.
  5. End conditions. Natural: \(M_1 = M_n = 0\). Clamped (slopes \(d_1\), \(d_n\) given): \(2h_1M_1 + h_1M_2 = 6(s_1 - d_1)\) and \(h_{n-1}M_{n-1} + 2h_{n-1}M_n = 6(d_n - s_{n-1})\). Not-a-knot: \(S'''\) continuous at \(x_2\) and \(x_{n-1}\). Defaults: R splinefun/spline use "fmm" (end cubics through 4 points), Python CubicSpline uses not-a-knot. Natural ends are \(O(h^2)\) near the ends; the others \(O(h^4)\); the spline’s slope is \(O(h^3)\).
  6. Noise. A difference quotient of data with independent noise of sd \(\sigma\): forward \((y_{i+1} - y_i)/h\) has noise sd \(\sqrt2\,\sigma/h\); central \((y_{i+1} - y_{i-1})/(2h)\) has \(\sigma/(\sqrt2\,h)\). Smaller \(h\) means more noise.
  7. Smoothing spline. Minimise \(\sum_i (y_i - f(t_i))^2 + \lambda\int f''(t)^2\,dt\). The minimiser is a natural cubic spline with knots at the data; \(\hat{\mathbf y} = A\mathbf y\) with the hat matrix \(A\); df \(= \operatorname{tr}A\) runs from 2 (\(\lambda\to\infty\), straight line) to \(n\) (\(\lambda = 0\), interpolation).
  8. Choosing \(\lambda\). Leave-one-out \(\text{CV}(\lambda) = \frac1n\sum_i\big((y_i - \hat y_i)/(1 - A_{ii})\big)^2\); \(\text{GCV}(\lambda) = n\,\text{RSS}/(n - \text{df})^2\). R’s smooth.spline rescales \(t\) to \([0, 1]\), so Python’s (and our Rust) lam \(=\) R’s lambda \(\times\) (range of \(t\))\(^3\).

// rust/examples/splines_background.rs  —  cargo run --example splines_background
// Background: a natural cubic spline through the noisy OD data, hand-written
// (second derivatives from a tridiagonal solve, then the cubic on each interval).

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

// second derivatives M of the natural spline (M[0] = M[n-1] = 0)
fn spline_m(x: &[f64], y: &[f64]) -> Vec<f64> {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let s: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
    let a: Vec<f64> = h[..n - 2].to_vec();                       // h_{i-1}
    let c: Vec<f64> = h[1..].to_vec();                           // h_i
    let b: Vec<f64> = (0..n - 2).map(|i| 2.0 * (a[i] + c[i])).collect();
    let d: Vec<f64> = (0..n - 2).map(|i| 6.0 * (s[i + 1] - s[i])).collect();
    let mut m = vec![0.0];
    m.extend(thomas(&a, &b, &c, &d));
    m.push(0.0);
    m
}

// value (deriv = 0) or slope (deriv = 1) of the spline at t
fn spline_eval(x: &[f64], y: &[f64], m: &[f64], t: f64, deriv: u8) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0
    } else {
        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}

fn main() {
    let t: Vec<f64> = (0..41).map(|i| i as f64 * 0.25).collect();   // every 15 min

By hand

B1. Piecewise linear. The exact logistic gives \(N(2) = 0.2126\) and \(N(3) = 0.3888\); on \([2, 3]\), \(\max|N''| = 0.0739\). (a) Interpolate linearly at \(t = 2.5\). The true value is \(N(2.5) = 0.2918\). What is the error? (b) Compare with the bound \(\tfrac{h^2}{8}\max|N''|\). (c) How often must the plate reader measure (spacing \(h\)) for the linear-interpolation error to stay below 0.001 OD everywhere? Use \(\max|N''| = 0.0739\) on all of \([0, 10]\). (d) What is the slope of the interpolant on \([2, 3]\)? The true \(N'(2.5) = 0.1767\). Which finite-difference formula is this slope?

B2. Counting conditions. The 41 OD reads are interpolated by a cubic spline. (a) How many cubic pieces, how many unknown coefficients, how many conditions from interpolation and from continuity of \(S'\) and \(S''\)? (b) Someone suggests: “instead of end conditions, also make \(S'''\) continuous at every interior point”. What would \(S\) then be, and why does that not work for 41 points?

B3. A natural spline through three points. Data \((0, 0), (1, 1), (2, 0)\). (a) Write down the single equation for \(M_2\) (natural: \(M_1 = M_3 = 0\)) and solve it. (b) Compute \(S(0.5)\). Compare with linear interpolation and with the parabola through the three points. (c) Compute \(S'(0)\) and \(S'(1)\) from the formula for \(S'\). Is the answer for \(S'(1)\) what you expect?

B4. Four points: Thomas by hand. Data \((0, 0), (1, 1), (2, 0), (3, 1)\), natural ends. (a) Write the \(2\times2\) system for \(M_2, M_3\). Is it diagonally dominant? (b) Solve it with one Thomas forward sweep and back substitution. (c) Compute \(S(1.5)\) and \(S(0.5)\). (d) Uneven spacing: data \((0, 0), (1, 1), (3, 0)\), natural ends. Find \(M_2\).

B5. End conditions. (a) For the data of B4, the not-a-knot spline with 4 points is the single cubic through all four points. Find it (Newton form from Polynomial interpolation) and evaluate it at 0.5. Compare with the natural spline’s \(S(0.5)\) from B4. (b) For the OD curve, \(N'(0) = rN_0(1 - N_0/K) = 0.0383\) and \(N''(0) = 0.028\); at 10 h the culture is close to its plateau. Which end condition is wrong at \(t = 0\): natural, or clamped with \(S'(0) = 0\)? Which end condition is reasonable at \(t = 10\)? (c) A colleague interpolates the same data in R with splinefun(x, y) and you in Python with CubicSpline(x, y). Where will your curves differ, and why?

B6. How differences amplify noise. OD noise sd \(\sigma = 0.01\). (a) Read every \(h = 0.25\) h: noise sd of a forward and of a central difference? Compare with the maximum growth rate 0.24. (b) A faster plate reader measures every 5 min (\(h = 1/12\) h). What happens to the noise of the central difference? (c) The truncation error of the central difference is about \(\tfrac{h^2}{6}|N'''|\) with \(\max|N'''| = 0.0768\). Write the total error \(E(h) = \tfrac{h^2}{6}\cdot0.0768 + \tfrac{\sigma}{\sqrt2\,h}\), find the best \(h\) and the smallest error. Compare with the V-shaped error plot of Convergence and cost: what plays the role of machine epsilon?

B7. Smoothing and GCV. \(n = 41\) OD reads. (a) What does a smoothing spline become for \(\lambda = 0\)? For \(\lambda \to \infty\)? What is df in each case? (b) Four fits give (df, RSS) \(= (6.0,\ 0.00472)\), \((9.4,\ 0.00206)\), \((12.0,\ 0.00179)\), \((20.0,\ 0.00104)\). Compute GCV for each. Which fit does GCV choose? (c) Why can we not choose \(\lambda\) by minimising the RSS? (d) If time is measured in minutes instead of hours, what happens to the best \(\lambda\) (in Python’s units) and to the best df?

Hint 1 — piecewise linear (B1, C1)

The bound comes from the error formula of Polynomial interpolation with two points: \(\tfrac12 f''(\xi)(x - x_i)(x - x_{i+1})\), and \(|(x - x_i)(x - x_{i+1})| \le h^2/4\) in the middle. Hint 2 — setting up the spline system (B3, B4, C2)

List \(h_i\) and the slopes \(s_i\) first; the right-hand side of row \(i\) is 6 × (slope after \(x_i\) − slope before \(x_i\)). For three points there is one interior point and one equation. Hint 3 — end conditions (B5, C3)

Hint 4 — overshoot (C4)

// scientific notation as R and Python print it: 3.04e-02 rather than Rust's 3.04e-2
fn sci(x: f64, digits: usize) -> String {
    let s = format!("{:.*e}", digits, x);
    let (m, e) = s.split_once('e').unwrap();
    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

// second derivatives M of the natural spline (M[0] = M[n-1] = 0)
fn spline_m(x: &[f64], y: &[f64]) -> Vec<f64> {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let s: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
    let a: Vec<f64> = h[..n - 2].to_vec();                       // h_{i-1}
    let c: Vec<f64> = h[1..].to_vec();                           // h_i
    let b: Vec<f64> = (0..n - 2).map(|i| 2.0 * (a[i] + c[i])).collect();
    let d: Vec<f64> = (0..n - 2).map(|i| 6.0 * (s[i + 1] - s[i])).collect();
    let mut m = vec![0.0];
    m.extend(thomas(&a, &b, &c, &d));
    m.push(0.0);
    m
}

// value (deriv = 0) or slope (deriv = 1) of the spline at t
fn spline_eval(x: &[f64], y: &[f64], m: &[f64], t: f64, deriv: u8) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0
    } else {
        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}

// piecewise linear interpolation (R approx, numpy interp)
fn lin_eval(x: &[f64], y: &[f64], t: f64) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    y[i] + (y[i + 1] - y[i]) * (t - x[i]) / (x[i + 1] - x[i])
}

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

// second derivatives M of the natural spline (M[0] = M[n-1] = 0)
fn spline_m(x: &[f64], y: &[f64]) -> Vec<f64> {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let s: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
    let a: Vec<f64> = h[..n - 2].to_vec();                       // h_{i-1}
    let c: Vec<f64> = h[1..].to_vec();                           // h_i
    let b: Vec<f64> = (0..n - 2).map(|i| 2.0 * (a[i] + c[i])).collect();
    let d: Vec<f64> = (0..n - 2).map(|i| 6.0 * (s[i + 1] - s[i])).collect();
    let mut m = vec![0.0];
    m.extend(thomas(&a, &b, &c, &d));
    m.push(0.0);
    m
}

// value (deriv = 0) or slope (deriv = 1) of the spline at t
fn spline_eval(x: &[f64], y: &[f64], m: &[f64], t: f64, deriv: u8) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0

        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}

    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0
    } else {
        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}

// PCHIP slopes (Fritsch-Butland weighted harmonic mean, scipy's end rule)
fn pchip_slopes(x: &[f64], y: &[f64]) -> Vec<f64> {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let s: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
    let mut d = vec![0.0; n];
    for k in 1..n - 1 {
        if s[k - 1] * s[k] > 0.0 {                 // same sign: harmonic mean
            let (w1, w2) = (2.0 * h[k] + h[k - 1], h[k] + 2.0 * h[k - 1]);
            d[k] = (w1 + w2) / (w1 / s[k - 1] + w2 / s[k]);
        }                                          // local extremum: slope 0
    }
    let end = |h0: f64, h1: f64, s0: f64, s1: f64| {
        let d0 = ((2.0 * h0 + h1) * s0 - h0 * s1) / (h0 + h1);
        if d0.signum() != s0.signum() { 0.0 }
        else if s0.signum() != s1.signum() && d0.abs() > 3.0 * s0.abs() { 3.0 * s0 }
        else { d0 }
    };
    d[0] = end(h[0], h[1], s[0], s[1]);
    d[n - 1] = end(h[n - 2], h[n - 3], s[n - 2], s[n - 3]);
    d
}

// cubic Hermite interpolant with values y and slopes d at the knots
fn hermite_eval(x: &[f64], y: &[f64], d: &[f64], t: f64) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let u = (t - x[i]) / h;
    let (h00, h10) = ((1.0 + 2.0 * u) * (1.0 - u).powi(2), u * (1.0 - u).powi(2));
    let (h01, h11) = (u * u * (3.0 - 2.0 * u), u * u * (u - 1.0));
    h00 * y[i] + h10 * h * d[i] + h01 * y[i + 1] + h11 * h * d[i + 1]
}

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

// second derivatives M of the natural spline (M[0] = M[n-1] = 0)
fn spline_m(x: &[f64], y: &[f64]) -> Vec<f64> {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let s: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
    let a: Vec<f64> = h[..n - 2].to_vec();                       // h_{i-1}
    let c: Vec<f64> = h[1..].to_vec();                           // h_i
    let b: Vec<f64> = (0..n - 2).map(|i| 2.0 * (a[i] + c[i])).collect();
    let d: Vec<f64> = (0..n - 2).map(|i| 6.0 * (s[i + 1] - s[i])).collect();
    let mut m = vec![0.0];
    m.extend(thomas(&a, &b, &c, &d));
    m.push(0.0);
    m
}

// value (deriv = 0) or slope (deriv = 1) of the spline at t
fn spline_eval(x: &[f64], y: &[f64], m: &[f64], t: f64, deriv: u8) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0
    } else {
        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}


// Smoothing spline (Reinsch form): minimise sum (y_i - g_i)^2 + lam * int S''^2.
// With Q (n x n-2) and R (n-2 x n-2, tridiagonal) built from the spacings,
// solve (R + lam Q^T Q) gamma = Q^T y; fitted values g = y - lam Q gamma;
// gamma are the second derivatives at the interior knots (natural spline).
struct Fit { g: Vec<f64>, m: Vec<f64>, df: f64 }

fn smooth_fit(x: &[f64], y: &[f64], lam: f64) -> Fit {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let mut q = DMatrix::<f64>::zeros(n, n - 2);
    let mut r = DMatrix::<f64>::zeros(n - 2, n - 2);
    for j in 0..n - 2 {                            // column j <-> interior knot j+1
        q[(j, j)] = 1.0 / h[j];
        q[(j + 1, j)] = -1.0 / h[j] - 1.0 / h[j + 1];
        q[(j + 2, j)] = 1.0 / h[j + 1];
        r[(j, j)] = (h[j] + h[j + 1]) / 3.0;
        if j + 1 < n - 2 { r[(j, j + 1)] = h[j + 1] / 6.0; r[(j + 1, j)] = h[j + 1] / 6.0; }
    }
    let yv = DVector::from_column_slice(y);
    let binv = (&r + lam * q.transpose() * &q).try_inverse().unwrap();
    let gamma = &binv * (q.transpose() * &yv);
    let g = &yv - lam * &q * &gamma;
    let s = lam * &q * &binv * q.transpose();      // hat matrix A = I - S
    let df: f64 = (0..n).map(|i| 1.0 - s[(i, i)]).sum();  // trace of A
    let mut m = vec![0.0];
    m.extend(gamma.iter());
    m.push(0.0);
    Fit { g: g.iter().cloned().collect(), m, df }
}

fn gcv(x: &[f64], y: &[f64], lam: f64) -> f64 {
    let f = smooth_fit(x, y, lam);
    let n = x.len() as f64;
    let rss: f64 = y.iter().zip(&f.g).map(|(a, b)| (a - b).powi(2)).sum();
    n * rss / (n - f.df).powi(2)
}

// minimise a function of log10(lam): coarse grid, then golden section
fn minimise_log(fun: &dyn Fn(f64) -> f64, lo: f64, hi: f64) -> f64 {
    let grid: Vec<f64> = (0..=90).map(|i| lo + (hi - lo) * i as f64 / 90.0).collect();
    let k = (0..grid.len()).min_by(|&a, &b| fun(grid[a]).partial_cmp(&fun(grid[b])).unwrap()).unwrap();
    let (mut a, mut b) = (grid[k.saturating_sub(1)], grid[(k + 1).min(90)]);
    let phi = (5f64.sqrt() - 1.0) / 2.0;
    while b - a > 1e-8 {
        let (c, d) = (b - phi * (b - a), a + phi * (b - a));
        if fun(c) < fun(d) { b = d } else { a = c }
    }
    0.5 * (a + b)
}

use nalgebra::{DMatrix, DVector};

// scientific notation as R and Python print it: 1.114e-04 rather than Rust's 1.114e-4
fn sci(x: f64, digits: usize) -> String {
    let s = format!("{:.*e}", digits, x);
    let (m, e) = s.split_once('e').unwrap();
    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

// value (deriv = 0) or slope (deriv = 1) of the spline at t
fn spline_eval(x: &[f64], y: &[f64], m: &[f64], t: f64, deriv: u8) -> f64 {
    let i = x.partition_point(|&xi| xi <= t).clamp(1, x.len() - 1) - 1;
    let h = x[i + 1] - x[i];
    let (a, b) = ((x[i + 1] - t) / h, (t - x[i]) / h);
    if deriv == 0 {
        a * y[i] + b * y[i + 1] + ((a * a * a - a) * m[i] + (b * b * b - b) * m[i + 1]) * h * h / 6.0
    } else {
        (y[i + 1] - y[i]) / h + (-(3.0 * a * a - 1.0) * m[i] + (3.0 * b * b - 1.0) * m[i + 1]) * h / 6.0
    }
}

// Smoothing spline (Reinsch form): minimise sum (y_i - g_i)^2 + lam * int S''^2.
// With Q (n x n-2) and R (n-2 x n-2, tridiagonal) built from the spacings,
// solve (R + lam Q^T Q) gamma = Q^T y; fitted values g = y - lam Q gamma;
// gamma are the second derivatives at the interior knots (natural spline).
struct Fit { g: Vec<f64>, m: Vec<f64>, hat_diag: Vec<f64>, df: f64 }

fn smooth_fit(x: &[f64], y: &[f64], lam: f64) -> Fit {
    let n = x.len();
    let h: Vec<f64> = (0..n - 1).map(|i| x[i + 1] - x[i]).collect();
    let mut q = DMatrix::<f64>::zeros(n, n - 2);
    let mut r = DMatrix::<f64>::zeros(n - 2, n - 2);
    for j in 0..n - 2 {                            // column j <-> interior knot j+1
        q[(j, j)] = 1.0 / h[j];
        q[(j + 1, j)] = -1.0 / h[j] - 1.0 / h[j + 1];
        q[(j + 2, j)] = 1.0 / h[j + 1];
        r[(j, j)] = (h[j] + h[j + 1]) / 3.0;
        if j + 1 < n - 2 { r[(j, j + 1)] = h[j + 1] / 6.0; r[(j + 1, j)] = h[j + 1] / 6.0; }
    }
    let yv = DVector::from_column_slice(y);
    let binv = (&r + lam * q.transpose() * &q).try_inverse().unwrap();
    let gamma = &binv * (q.transpose() * &yv);
    let g = &yv - lam * &q * &gamma;
    let s = lam * &q * &binv * q.transpose();      // hat matrix A = I - S
    let hat_diag: Vec<f64> = (0..n).map(|i| 1.0 - s[(i, i)]).collect();
    let df = hat_diag.iter().sum();
    let mut m = vec![0.0];
    m.extend(gamma.iter());
    m.push(0.0);
    Fit { g: g.iter().cloned().collect(), m, hat_diag, df }
}

fn gcv(x: &[f64], y: &[f64], lam: f64) -> f64 {
    let f = smooth_fit(x, y, lam);
    let n = x.len() as f64;
    let rss: f64 = y.iter().zip(&f.g).map(|(a, b)| (a - b).powi(2)).sum();
    n * rss / (n - f.df).powi(2)
}

// minimise a function of log10(lam): coarse grid, then golden section
fn minimise_log(fun: &dyn Fn(f64) -> f64, lo: f64, hi: f64) -> f64 {
    let grid: Vec<f64> = (0..=90).map(|i| lo + (hi - lo) * i as f64 / 90.0).collect();
    let k = (0..grid.len()).min_by(|&a, &b| fun(grid[a]).partial_cmp(&fun(grid[b])).unwrap()).unwrap();
    let (mut a, mut b) = (grid[k.saturating_sub(1)], grid[(k + 1).min(90)]);
    let phi = (5f64.sqrt() - 1.0) / 2.0;
    while b - a > 1e-8 {
        let (c, d) = (b - phi * (b - a), a + phi * (b - a));
        if fun(c) < fun(d) { b = d } else { a = c }
    }
    0.5 * (a + b)
}

// leave-one-out CV: for a linear smoother the LOO residual is r_i / (1 - A_ii)
fn loocv(x: &[f64], y: &[f64], lam: f64) -> f64 {
    let f = smooth_fit(x, y, lam);
    let n = x.len() as f64;
    (0..x.len()).map(|i| ((y[i] - f.g[i]) / (1.0 - f.hat_diag[i])).powi(2)).sum::<f64>() / n
}

GCV and leave-one-out CV agree closely (df 9.4 and 9.3) and both put the peak at pseudotime 0.598 with height 2.97, close to the truth (0.6, 3.0). The rough fit (df 22.5) finds a spurious higher, sharper peak (3.22): it follows a few high cells. The stiff fit (df 3.8) flattens the peak to 2.28 and moves it. The residual check flags both: the rough fit has strongly negative lag-1 correlation (\(-0.41\): residuals alternate in sign, the curve chases individual cells), the stiff fit strongly positive (\(+0.52\): long runs of residuals with the same sign, a systematic misfit, i.e. bias). The good fits have \(|r_1| < 0.1\), well inside the \(\pm2/\sqrt{40} = \pm0.32\) expected for independent noise. Python searches a grid with step 0.05 in \(\log_{10}\lambda\) and lands on the same grid point for GCV and CV; R and Rust use a one-dimensional optimiser and agree to 3–4 digits. R’s df for the rough fit differs from Python and Rust in the third decimal: R’s smooth.spline computes it with a slightly different (B-spline) representation.
