Exercise: flow plus diffusion

Goal

By the end of this exercise you should be able to:

  • compute the Péclet number of a microfluidic device and estimate a mixing length \(\approx \bar u w^2/D\),
  • discretise the advection term with central and upwind differences, and predict from the cell Péclet number \(u\Delta x/D\) when central differences wiggle,
  • show that upwind differences add a numerical diffusion \(u\Delta x/2\), and detect it with grid refinement,
  • choose a stable explicit time step from the CFL condition \(C + 2r \le 1\),
  • solve a steady channel problem by marching downstream with a given Poiseuille profile, and check the solver against an exact solution and with flux conservation,
  • use the solver for an H-filter, a Christmas-tree gradient generator, and to fit a diffusion coefficient to a downstream profile with Brent’s method.

The by-hand part needs pen, paper and a calculator. All “measurements” on this page are synthetic: generated from the model plus noise. The device parameters are our own round numbers, typical for microfluidics but not taken from a specific paper.

Background

With a flow of speed \(u\) the flux of a solute is \(J = u\,c - D\,\partial c/\partial x\), and the mass balance gives the advection–diffusion equation

\[\frac{\partial c}{\partial t} + u\,\frac{\partial c}{\partial x} = D\,\frac{\partial^2 c}{\partial x^2}.\]

We work in µm and s: \(D = 1000\) µm²/s is \(10^{-9}\) m²/s (a small molecule), \(D = 100\) µm²/s a protein.

Facts used below:

  1. Péclet number \(\text{Pe} = uL/D\): advection against diffusion over a length \(L\). Across a channel of width \(w\) at mean speed \(\bar u\), streams mix after a mixing length of order \(\bar u w^2/D = \text{Pe}\cdot w\). For two half-streams in plug flow, mixing is complete to 1 % at \(x \approx 0.42\,\bar u w^2/D\).
  2. Back-diffusion test problem. Steady \(u\,c' = D\,c''\) on \([0, L]\) with \(c(0) = 0\), \(c(L) = 1\): \(c(x) = \dfrac{e^{\text{Pe}\,x/L} - 1}{e^{\text{Pe}} - 1}\), a boundary layer of thickness \(D/u\) at \(x = L\). We use \(L = 500\) µm, \(u = 100\) µm/s, \(D = 1000\) µm²/s, so Pe = 50.
  3. Central differences, with the cell Péclet number \(P = u\Delta x/D\): \(\left(1 + \tfrac P2\right)c_{i-1} - 2c_i + \left(1 - \tfrac P2\right)c_{i+1} = 0\). Second order; wiggles if \(P > 2\).
  4. Upwind differences (\(u > 0\)): \((1 + P)\,c_{i-1} - (2 + P)\,c_i + c_{i+1} = 0\). First order, never wiggles, and exactly the central scheme with \(D\) replaced by \(D + u\Delta x/2\) (numerical diffusion).
  5. Explicit upwind in time: \(c_i^{n+1} = (C + r)\,c_{i-1}^n + (1 - C - 2r)\,c_i^n + r\,c_{i+1}^n\) with Courant number \(C = u\Delta t/\Delta x\) and \(r = D\Delta t/\Delta x^2\). Stable (no new extremes) if \(C + 2r \le 1\); for \(D = 0\) this is the CFL condition \(C \le 1\). Numerical diffusion \(u\Delta x(1 - C)/2\).
  6. Marching. Steady flow along a channel, profile \(u(y)\), Pe ≫ 1: drop diffusion along \(x\) and solve \(u(y)\,\partial c/\partial x = D\,\partial^2 c/\partial y^2\) as if \(x\) were time. Grid across the channel: \(M\) cells of width \(\Delta y\), centres \(y_j = (j - \tfrac12)\Delta y\). Backward Euler in \(x\) with \(a_j = D\Delta x/(u_j\Delta y^2)\): \(-a_j c_{j-1}^{k+1} + (1 + 2a_j)\,c_j^{k+1} - a_j c_{j+1}^{k+1} = c_j^k\), with \(1 + a_j\) on the diagonal in the two wall rows (no flux). One tridiagonal solve per step.
  7. Given flow profile (Poiseuille): \(u(y) = 6\bar u\,(y/w)(1 - y/w)\), zero at the walls, \(1.5\bar u\) in the middle. The solute flux \(\sum_j u_j c_j\) is the same at every \(x\).

The basic tool: the steady 1D problem with both schemes. The tridiagonal system is solved with solve (Python: numpy.linalg.solve; the Rust version uses the hand-written Thomas algorithm from Implicit schemes and the method of lines). The exact solution uses expm1 (Python: np.expm1, Rust: f64::exp_m1).

L <- 500; D <- 1000; u <- 100                    # Pe = u L / D = 50
exact <- function(x) expm1(u * x / D) / expm1(u * L / D)
steady <- function(N, scheme, D = 1000) {
  dx <- L / N; P <- u * dx / D; m <- N - 1       # P = cell Peclet number
  if (scheme == "central") { lo <- 1 + P/2; di <- -2;     up <- 1 - P/2 }
  else                     { lo <- 1 + P;   di <- -2 - P; up <- 1 }
  A <- diag(di, m)
  A[cbind(2:m, 1:(m-1))] <- lo; A[cbind(1:(m-1), 2:m)] <- up
  b <- numeric(m); b[m] <- -up                   # c(L) = 1 moves to the right side
  c(0, solve(A, b), 1)
}
x <- seq(0, L, length.out = 11)
cat(sprintf("%6.3f", steady(10, "central")), "\n")
cat(sprintf("%6.3f", steady(10, "upwind")), "\n")
cat(sprintf("%6.3f", exact(x)), "\n")

import numpy as np

L, D, u = 500.0, 1000.0, 100.0                    # Pe = u L / D = 50

def exact(x):
    return np.expm1(u * x / D) / np.expm1(u * L / D)

def steady(N, scheme, D=1000.0):
    dx = L / N; P = u * dx / D; m = N - 1          # P = cell Peclet number
    if scheme == "central":
        lo, di, up = 1 + P / 2, -2.0, 1 - P / 2
    else:
        lo, di, up = 1 + P, -2 - P, 1.0
    A = np.diag(np.full(m, di)) + np.diag(np.full(m - 1, lo), -1) + np.diag(np.full(m - 1, up), 1)
    b = np.zeros(m); b[-1] = -up                   # c(L) = 1 moves to the right side
    return np.concatenate(([0.0], np.linalg.solve(A, b), [1.0]))

print(" ".join(f"{v:6.3f}" for v in steady(10, "upwind")))
print(" ".join(f"{v:6.3f}" for v in exact(x)))

// rust/examples/advection_diffusion_background.rs  —  cargo run --example advection_diffusion_background
// Background: steady advection-diffusion u c' = D c'' on [0, L], c(0) = 0, c(L) = 1,
// with central and upwind differences for c'. The tridiagonal system is solved with the
// Thomas algorithm (R and Python use a dense solve; same numbers).
const L: f64 = 500.0; // um
const U: f64 = 100.0; // um/s, Pe = u L / D = 50

fn exact(x: f64, d: f64) -> f64 {
    (U * x / d).exp_m1() / (U * L / d).exp_m1()
}

// a = sub-, b = main, c = super-diagonal, d = right-hand side
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

fn steady(n: usize, central: bool, d: f64) -> Vec<f64> {
    let dx = L / n as f64;
    let p = U * dx / d; // cell Peclet number
    let m = n - 1;
    let (lo, di, up) = if central { (1.0 + p / 2.0, -2.0, 1.0 - p / 2.0) } else { (1.0 + p, -2.0 - p, 1.0) };
    let mut rhs = vec![0.0; m];
    rhs[m - 1] = -up; // c(L) = 1 moves to the right side
    let inner = thomas(&vec![lo; m], &vec![di; m], &vec![up; m], &rhs);
    let mut c = vec![0.0];
    c.extend(inner);
    c.push(1.0);
    c
}

fn show(v: &[f64]) -> String {
    v.iter().map(|x| format!("{:6.3}", x)).collect::<Vec<_>>().join(" ")
}

fn main() {
    let x: Vec<f64> = (0..=10).map(|i| i as f64 * L / 10.0).collect();
    println!("{}", show(&steady(10, true, 1000.0)));
    println!("{}", show(&steady(10, false, 1000.0)));
    println!("{}", show(&x.iter().map(|&xi| exact(xi, 1000.0)).collect::<Vec<_>>()));
}

By hand

B1. Péclet numbers and mixing lengths. A T-sensor has width \(w = 100\) µm and mean speed \(\bar u = 1000\) µm/s. (a) Compute Pe \(= \bar u w/D\) and the mixing length \(\bar u w^2/D\) for a small molecule (\(D = 1000\) µm²/s), a protein (\(D = 100\)) and a cell (\(D \approx 0.05\) µm²/s). (b) The flow is halved. What happens to Pe, to the mixing length, and to the amount of sample processed per minute? (c) A serpentine in a gradient generator is 50 µm wide and carries \(\bar u = 1000\) µm/s. How long must it be to mix two half-streams to 1 % (Fact 1), for a small molecule and for a protein chemokine (\(D = 100\) µm²/s)? What happens to the outlet gradient if the serpentines are only 3 mm long and the molecule is the protein? (d) Back-diffusion: in the test problem (Fact 2), \(c \approx e^{-us/D}\) at a distance \(s\) upstream of the chamber. For \(D = 1000\) µm²/s and perfusion speeds \(u = 10\), 100 and 1000 µm/s, give the layer thickness \(D/u\) and the distance at which the drug is down to 1 %.

Solution B1
\(D\) (µm²/s) Pe mixing length \(\bar u w^2/D\)
small molecule 1000 100 \(10^3\cdot 10^4/10^3 = 10^4\) µm = 10 mm
protein 100 1000 100 mm
cell 0.05 \(2\times10^6\) \(2\times10^8\) µm = 200 m

  1. Pe and the mixing length both halve: the streams mix in half the distance, because each parcel spends twice as long in every millimetre. Only \(Dx/\bar u\) matters. But half the volume per minute flows through the device: a shorter device at the old speed would do the same separation with the full throughput.

  2. \(0.42\,\bar u w^2/D = 0.42\cdot 1000\cdot 2500/D\): 1.05 mm for the small molecule, 10.5 mm for the protein. With 3 mm serpentines the protein is far from mixed (3 mm is about \(0.12\,\bar u w^2/D\): the first Fourier mode has decayed only to \(e^{-\pi^2\cdot 0.12} \approx 0.3\) of its start value). Each new channel then carries a stream that is still partly two streams side by side, so the next split does not take the intended shares, and the outlet profile is not the designed staircase. Designers lengthen the serpentines or slow the flow.

  3. \(D/u = 100\), 10 and 1 µm. The drug is down to 1 % where \(us/D = \ln 100 = 4.6\), i.e. \(s = 4.6\,D/u\): 461, 46 and 4.6 µm. Even a slow perfusion protects the upstream channel.

B2. Central and upwind on a tiny grid. Take the test problem with only \(N = 4\) intervals and cell Péclet number \(P = 4\) (so Pe = 16). Unknowns \(c_1, c_2, c_3\); \(c_0 = 0\), \(c_4 = 1\). (a) Write down the three central-difference equations (Fact 3) and solve them. (Hint: express \(c_2\) and \(c_3\) in terms of \(c_1\).) Which values are negative? (b) Do the same for upwind (Fact 4). (c) The exact solution is \(c_i = (e^{4i} - 1)/(e^{16} - 1)\). Compute \(c_3\) (use \(e^{-4} \approx 0.0183\)). Compare with (a) and (b). (d) For each scheme, find \(\rho\) such that \(c_i = \rho^i\) solves the difference equation (besides \(\rho = 1\)). Compare with the exact growth factor per cell, \(e^{P}\).

Solution B2

  1. Central with \(P = 4\): \(3c_{i-1} - 2c_i - c_{i+1} = 0\). \(i = 1\): \(-2c_1 - c_2 = 0\), so \(c_2 = -2c_1\). \(i = 2\): \(3c_1 - 2c_2 - c_3 = 0\), so \(c_3 = 3c_1 + 4c_1 = 7c_1\). \(i = 3\): \(3c_2 - 2c_3 - 1 = 0\), so \(-6c_1 - 14c_1 = 1\), \(c_1 = -0.05\). Hence \(c = (0, -0.05, 0.10, -0.35, 1)\): \(c_1\) and \(c_3\) are negative, and the signs alternate.

  2. Upwind with \(P = 4\): \(5c_{i-1} - 6c_i + c_{i+1} = 0\). \(i = 1\): \(c_2 = 6c_1\). \(i = 2\): \(c_3 = 6c_2 - 5c_1 = 31c_1\). \(i = 3\): \(5c_2 - 6c_3 + 1 = 0\), so \(30c_1 - 186c_1 = -1\), \(c_1 = 1/156\). Hence \(c = (0, 0.0064, 0.0385, 0.1987, 1)\): positive and increasing.

  3. \(c_3 = (e^{12} - 1)/(e^{16} - 1) \approx e^{-4} = 0.0183\) (and \(c_1, c_2\) are tiny: \(6\times10^{-6}\), \(3\times10^{-4}\)). Central is wrong in sign and size; upwind has the right shape but is 11 times too large at \(x_3\): the boundary layer is smeared.

  4. Central: \((1 - P/2)\rho^2 - 2\rho + (1 + P/2) = 0\), i.e. \(-\rho^2 - 2\rho + 3 = 0\), roots 1 and \(\rho = -3\). Check: \(c_i = (\,(-3)^i - 1)/((-3)^4 - 1) = ((-3)^i - 1)/80\) gives \(-0.05\), \(0.1\), \(-0.35\). Upwind: \(\rho^2 - 6\rho + 5 = 0\), roots 1 and \(\rho = 5\); \(c_i = (5^i - 1)/624\). Exact: \(e^4 = 54.6\). Neither comes close, because a grid with \(P = 4\) cannot resolve a layer that is a quarter of a cell thick; but a negative \(\rho\) is qualitatively wrong, while \(\rho = 5\) is only too small.

B3. Numerical diffusion. (a) Verify the identity \(\dfrac{c_i - c_{i-1}}{\Delta x} = \dfrac{c_{i+1} - c_{i-1}}{2\Delta x} - \dfrac{\Delta x}{2}\cdot\dfrac{c_{i+1} - 2c_i + c_{i-1}}{\Delta x^2}\) and conclude that upwind with \(D\) is central with \(D + u\Delta x/2\). (b) Check it with B2: the central scheme with \(D_\text{eff} = D + u\Delta x/2\) has cell Péclet number \(P_\text{eff} = u\Delta x/D_\text{eff}\). Compute \(P_\text{eff}\) for \(P = 4\) and the central \(\rho\) for \(P_\text{eff}\). Show in general that \(P_\text{eff} < 2\) always. (c) In the back-diffusion problem (\(u = 100\) µm/s, \(D = 1000\) µm²/s), what is \(D_\text{num}\) for \(\Delta x = 50\), 10 and 1 µm? From what grid spacing is \(D_\text{num}\) less than 10 % of \(D\)? (d) For the stimulus pulse of the lecture (\(u = 200\) µm/s, \(D = 100\) µm²/s, \(C = 0.5\)) the numerical diffusion is \(u\Delta x(1 - C)/2\). Which \(\Delta x\) keeps it below 10 % of \(D\)? How many grid points and time steps does that need for 3 mm and 16 s? (e) At \(C = 1\) the numerical diffusion vanishes. Why can we not simply run at \(C = 1\) here?

Solution B3

  1. Put the right-hand side over the common denominator \(2\Delta x\): \((c_{i+1} - c_{i-1}) - (c_{i+1} - 2c_i + c_{i-1}) = 2c_i - 2c_{i-1}\), divided by \(2\Delta x\) gives the left-hand side. Multiply by \(u\): \(u\cdot\text{upwind} = u\cdot\text{central} - \tfrac{u\Delta x}{2}\cdot\text{second difference}\). Moving the last term to the diffusion side of \(u c' = D c''\) gives \(u\cdot\text{central} = (D + u\Delta x/2)\cdot\text{second difference}\).

  2. \(P_\text{eff} = P/(1 + P/2) = 4/3\), and \(\rho = (1 + 2/3)/(1 - 2/3) = 5\): exactly the upwind \(\rho\). In general \(P/(1 + P/2) = 2P/(2 + P) < 2\) for every \(P > 0\), so the upwind scheme never wiggles.

  3. \(D_\text{num} = 100\,\Delta x/2 = 50\,\Delta x\): 2500, 500 and 50 µm²/s. Below 100 µm²/s needs \(\Delta x < 2\) µm.

  4. \(200\cdot\Delta x\cdot 0.5/2 = 50\,\Delta x \le 10\) gives \(\Delta x \le 0.2\) µm: 15 001 points, \(\Delta t = C\Delta x/u = 0.0005\) s, 32 000 steps. About 5×10⁸ point updates: feasible, but a coarse upwind grid is clearly not.

  5. With \(D > 0\), \(r = D\Delta t/\Delta x^2 > 0\), so \(C = 1\) gives \(C + 2r > 1\): unstable (C2 shows it). Pure advection at \(C = 1\) is the exact shift \(c_i^{n+1} = c_{i-1}^n\), but only without diffusion and only for constant \(u\).

B4. The CFL condition by hand. Pulse problem: \(u = 200\) µm/s, \(D = 100\) µm²/s, \(\Delta x = 10\) µm. (a) Express \(C\) and \(r\) in terms of \(\Delta t\) and find the largest stable \(\Delta t\) from \(C + 2r \le 1\). Which part of the condition dominates? (b) Take \(C = 0.5\), \(r = 0.025\). At step \(n\) the values at \(x = 0, 10, 20, 30, 40\) µm are \((1, 1, 0, 0, 0)\), with \(c_0 = 1\) held by the inlet. Compute \(c_1, c_2, c_3\) at step \(n + 1\). (c) Repeat with \(C = 1.2\), \(r = 0.06\). What goes wrong? (d) T-sensor, explicit marching (Fact 6 with forward Euler in \(x\)): the step must satisfy \(D\Delta x/(u_j\Delta y^2) \le 1/2\) in every row. With \(\Delta y = 2\) µm, \(D = 1000\) µm²/s, \(\bar u = 1000\) µm/s, compute the limit in the middle row (\(u = 1500\) µm/s) and in the first row (\(y = 1\) µm). How many steps for a 20 mm channel?

Solution B4

  2. Weights \((C + r, 1 - C - 2r, r) = (0.525, 0.45, 0.025)\). \(c_1 = 0.525\cdot 1 + 0.45\cdot 1 + 0.025\cdot 0 = 0.975\); \(c_2 = 0.525\cdot 1 + 0.45\cdot 0 + 0.025\cdot 0 = 0.525\); \(c_3 = 0\). The front moves half a cell (and spreads).

  3. Weights \((1.26, -0.32, 0.06)\). \(c_1 = 1.26 - 0.32 + 0 = 0.94\); \(c_2 = 1.26\cdot 1 = 1.26\). A value above 1 appears where there was none: a new maximum, which the next steps amplify into a growing zigzag. One negative weight is enough.

  4. \(\Delta x \le u_j\Delta y^2/(2D) = 4u_j/2000\): 3.0 µm in the middle row; in the first row \(u = 6000\cdot 0.01\cdot 0.99 = 59.4\) µm/s and the limit is 0.119 µm. The slowest row decides: \(20\,000/0.119 \approx 168\,000\) steps. Implicit marching with \(\Delta x = 50\) µm needs 400.

const L: f64 = 500.0;
const U: f64 = 100.0;
const D: f64 = 1000.0;

fn exact(x: f64) -> f64 {
    (U * x / D).exp_m1() / (U * L / D).exp_m1()
}

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

fn steady(n: usize, central: bool, d: f64) -> Vec<f64> {
    let p = U * (L / n as f64) / d;
    let m = n - 1;
    let (lo, di, up) = if central { (1.0 + p / 2.0, -2.0, 1.0 - p / 2.0) } else { (1.0 + p, -2.0 - p, 1.0) };
    let mut rhs = vec![0.0; m];
    rhs[m - 1] = -up;
    let mut c = vec![0.0];
    c.extend(thomas(&vec![lo; m], &vec![di; m], &vec![up; m], &rhs));
    c.push(1.0);
    c
}

fn wiggly(c: &[f64]) -> bool {
    c.windows(2).any(|p| p[1] - p[0] < 0.0) // exact profile only increases
}

    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

const U: f64 = 200.0; // um/s
const D: f64 = 100.0; // um^2/s

struct Run { peak: f64, tpeak: f64, r: f64, maxabs: f64 }

fn pulse(dx: f64, cfl: f64, tend: f64) -> Run {
    let n = (3000.0 / dx).round() as usize + 1;
    let iobs = (2000.0 / dx).round() as usize;
    let dt = cfl * dx / U;
    let r = D * dt / (dx * dx);
    let mut c = vec![0.0; n];
    let mut old = c.clone();
    let nsteps = (tend / dt).round() as usize;
    let (mut peak, mut kpeak, mut big) = (f64::NEG_INFINITY, 0, 0.0f64);
    for k in 1..=nsteps {
        old.copy_from_slice(&c); // previous time level
        for i in 1..n - 1 {
            c[i] = old[i] - cfl * (old[i] - old[i - 1]) + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
        c[n - 1] = c[n - 2]; // outflow
        c[0] = if k as f64 * dt <= 1.0 { 1.0 } else { 0.0 }; // inlet: 1 s pulse
        if c[iobs] > peak { peak = c[iobs]; kpeak = k; }
        big = c.iter().fold(big, |m, v| m.max(v.abs()));
    }
    Run { peak, tpeak: kpeak as f64 * dt, r, maxabs: big }
}

fn step(x: f64, t: f64, d: f64) -> f64 {
    if t > 0.0 { 0.5 * erfc((x - U * t) / (2.0 * (d * t).sqrt())) } else { 0.0 }
}

        if s.contains('.') { s.trim_end_matches('0').trim_end_matches('.').to_string() } else { s }
    }
}

use std::f64::consts::PI;

const W: f64 = 100.0; // channel width, um
const UBAR: f64 = 1000.0; // mean speed, um/s
const D: f64 = 1000.0; // small molecule, um^2/s

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

// backward Euler in x: one tridiagonal solve per step of dx
fn march(c: &[f64], u: &[f64], d: f64, dy: f64, dx: f64, nsteps: usize) -> Vec<f64> {
    let m = c.len();
    let a: Vec<f64> = u.iter().map(|uj| d * dx / (uj * dy * dy)).collect();
    let mut di: Vec<f64> = a.iter().map(|aj| 1.0 + 2.0 * aj).collect();
    di[0] = 1.0 + a[0]; // no-flux walls
    di[m - 1] = 1.0 + a[m - 1];
    let off: Vec<f64> = a.iter().map(|aj| -aj).collect();
    let mut c = c.to_vec();
    for _ in 0..nsteps {
        c = thomas(&off, &di, &off, &c);
    }
    c
}

fn explicit(c: &[f64], u: &[f64], d: f64, dy: f64, dx: f64, nsteps: usize) -> Vec<f64> {
    let m = c.len();
    let mut c = c.to_vec();
    for _ in 0..nsteps {
        let old = c.clone();
        for j in 0..m {
            let left = if j == 0 { old[0] } else { old[j - 1] }; // mirror ghost cells
            let right = if j == m - 1 { old[m - 1] } else { old[j + 1] };
            c[j] = old[j] + d * dx / (u[j] * dy * dy) * (left - 2.0 * old[j] + right);
        }
    }
    c
}

fn plug_exact(y: f64, x: f64, d: f64) -> f64 {
    let mut s = 0.5;
    for n in 1..=2001 {
        let nf = n as f64;
        s += 2.0 / (nf * PI) * (nf * PI / 2.0).sin() * (nf * PI * y / W).cos()
            * (-(nf * PI).powi(2) * d * x / (UBAR * W * W)).exp();
    }
    s
}

}

// n streams -> n + 1 streams: channel k takes k/n of stream k-1 and (n-k)/n of stream k
fn stage(c: &[f64]) -> Vec<f64> {
    let n = c.len();
    (0..=n).map(|k| {
        let left = if k > 0 { c[k - 1] } else { 0.0 };
        let right = if k < n { c[k] } else { 0.0 };
        (k as f64 / n as f64) * left + ((n - k) as f64 / n as f64) * right
    }).collect()
}

fn tree(inlets: &[f64], nout: usize) -> Vec<f64> {
    let mut c = inlets.to_vec();
    while c.len() < nout { c = stage(&c); }
    c
}

fn profile(d: f64, m: usize, dx: f64, ubar: f64) -> Vec<f64> {

    let y: Vec<f64> = (1..=m).map(|j| (j as f64 - 0.5) * dy).collect();

    type Output = f64;

        Ok(profile(*d, self.m, self.dx, self.ubar).iter().zip(COBS.iter()).map(|(p, o)| (o - p).powi(2)).sum())
    }
}

}
