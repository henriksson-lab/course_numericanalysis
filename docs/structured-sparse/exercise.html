Exercise: structure — symmetric, banded, sparse

Goal

By the end of this exercise you should be able to:

  • compute a Cholesky factorisation \(A = LL^T\) of a small symmetric positive definite (SPD) matrix by hand, and use it to solve a system and to get \(\log\det A\),
  • recognise when a covariance or correlation matrix is not positive definite, and what to do about it,
  • solve a tridiagonal system with the Thomas algorithm by hand and in code, check the answer, and say when the algorithm is safe,
  • read and write the three arrays of compressed sparse column (CSC) storage,
  • predict fill-in in elimination, and explain why the inverse of a sparse matrix is dense,
  • run Jacobi and conjugate gradient iterations and tell from the residual whether they converge.

The by-hand part needs pen, paper and a calculator for square roots. The code part checks the hand answers and then goes to sizes where only code works.

Background

Facts used below:

  1. SPD. \(A\) is symmetric positive definite if \(A = A^T\) and \(\mathbf{x}^TA\mathbf{x} > 0\) for every \(\mathbf{x} \ne \mathbf{0}\); equivalently, all eigenvalues are positive. Covariance and kinship matrices are SPD, unless they are estimated from too few observations (then only semidefinite).
  2. Cholesky. Every SPD matrix is \(A = LL^T\) with \(L\) lower triangular and positive diagonal. Column by column: \[\ell_{jj} = \sqrt{a_{jj} - \textstyle\sum_{k<j}\ell_{jk}^2}, \qquad \ell_{ij} = \Big(a_{ij} - \textstyle\sum_{k<j}\ell_{ik}\ell_{jk}\Big)\Big/\ell_{jj}\quad (i>j).\] Cost \(\tfrac13 n^3\), no pivoting. A square root of a number \(\le 0\) means \(A\) is not SPD.
  3. Using \(L\). Solve \(A\mathbf{x} = \mathbf{b}\) by \(L\mathbf{y} = \mathbf{b}\) (forward) then \(L^T\mathbf{x} = \mathbf{y}\) (back). \(\log\det A = 2\sum_i \log\ell_{ii}\). If \(\mathbf{z}\) has independent \(N(0,1)\) entries, \(L\mathbf{z}\) has covariance \(A\).
  4. Thomas algorithm for a tridiagonal system with sub-diagonal \(a_i\), diagonal \(b_i\), super-diagonal \(c_i\), right-hand side \(d_i\): forward sweep \(w = a_i/b_{i-1}\), \(b_i \leftarrow b_i - w c_{i-1}\), \(d_i \leftarrow d_i - w d_{i-1}\) for \(i = 2,\dots,n\); back substitution \(x_n = d_n/b_n\), \(x_i = (d_i - c_i x_{i+1})/b_i\). About \(8n\) operations. No pivoting: safe if \(|b_i| \ge |a_i| + |c_i|\) in every row (strictly in at least one) or if the matrix is SPD.
  5. Morphogen in a row of cells (lecture): \(-D\,c_{i-1} + (2D+k)\,c_i - D\,c_{i+1} = s_i\), with \(D + k\) on the diagonal of the two end cells. We use \(D = 1\), \(k = 0.01\) per minute, production \(s_1 = 1\) in cell 1.
  6. CSC stores the non-zeros column by column: x (values), i (row index, from 0), and p (column pointers, length = columns + 1, from 0): column \(j\) (from 0) owns entries p[j] to p[j+1] - 1. About 12 bytes per non-zero.
  7. Fill-in: zeros of \(A\) that become non-zero in \(L\) (or \(U\)). It depends on the order of the unknowns. The inverse of a sparse matrix is usually completely dense.
  8. Jacobi: \(\mathbf{x} \leftarrow \mathbf{x} + D^{-1}(\mathbf{b} - A\mathbf{x})\), \(D\) = diagonal of \(A\). Converges for diagonally dominant \(A\). Conjugate gradient (CG) needs SPD \(A\). Both need only products \(A\mathbf{x}\).

The basic tools in each language. R’s chol returns the upper factor \(R = L^T\); Python’s np.linalg.cholesky and nalgebra’s Cholesky return the lower factor \(L\).

// Background: Cholesky with nalgebra, and a small sparse matrix with sprs.
use nalgebra::{dmatrix, dvector};
use sprs::TriMat;

fn main() {
    let a = dmatrix![4.0, 2.0; 2.0, 5.0];
    let chol = a.cholesky().expect("not positive definite"); // None if not SPD
    println!("{}", chol.l());          // lower triangular: A = L L^T
    let x = chol.solve(&dvector![2.0, 9.0]);
    println!("{:?}", x.as_slice());

    // sprs builds CSC from triplets (row, column, value), 0-based
    let mut t = TriMat::new((4, 4));
    for (r, c, v) in [(0, 0, 3.0), (2, 0, 1.0), (1, 1, 5.0), (0, 3, 2.0), (3, 3, 7.0)] {
        t.add_triplet(r, c, v);
    }
    let m: sprs::CsMat<f64> = t.to_csc();
    println!("{}", m.nnz());
}

Python indexes from 0, so sparse.csc_matrix((x, (i, j))) takes 0-based rows and columns; R’s sparseMatrix(i, j, x) takes 1-based ones but stores 0-based indices inside. Rust’s sprs uses 0-based triplets.

By hand

B1. Cholesky. (a) Compute the Cholesky factor \(L\) of the covariance matrix of three genes \[\Sigma = \begin{pmatrix} 4 & 2 & -2 \\ 2 & 10 & 2 \\ -2 & 2 & 6 \end{pmatrix}.\] (b) Use \(L\) to solve \(\Sigma\mathbf{x} = (4, 14, 6)^T\): first \(L\mathbf{y} = \mathbf{b}\), then \(L^T\mathbf{x} = \mathbf{y}\). (c) Compute \(\det\Sigma\) from \(L\). Check it with the usual 3 × 3 determinant formula. (d) Three genes have pairwise correlations estimated from different subsets of samples (missing values): \(r_{12} = 0.9\), \(r_{13} = 0.9\), \(r_{23} = -0.9\). Try to compute the Cholesky factor of the correlation matrix. Where does it break? Explain in words why these three correlations cannot all be true at once.

B2. Thomas by hand. Four cells with \(D = 1\), \(k = 1\) and production 1 in cell 1: \[\begin{pmatrix} 2 & -1 & 0 & 0 \\ -1 & 3 & -1 & 0 \\ 0 & -1 & 3 & -1 \\ 0 & 0 & -1 & 2 \end{pmatrix}\mathbf{c} = \begin{pmatrix} 1 \\ 0 \\ 0 \\ 0 \end{pmatrix}.\] (a) Write down the vectors \(a\), \(b\), \(c\), \(d\) (with \(a_1\) and \(c_4\) unused). (b) Run the forward sweep with fractions: give the new \(b_2, b_3, b_4\) and \(d_2, d_3, d_4\). (c) Back-substitute to get \(c_4, c_3, c_2, c_1\). (d) Check mass balance: total degradation \(k\sum_i c_i\) should equal total production. Is it? (e) Is the matrix diagonally dominant? Are all pivots (\(b_1\) and the new \(b_2, b_3, b_4\)) positive?

B3. When Thomas breaks. (a) Run the forward sweep for \(a = (\cdot, 1, 1)\), \(b = (1, 1, 1)\), \(c = (1, 1, \cdot)\). What happens at the second pivot? (b) Is this matrix diagonally dominant? Is it singular? (Compute its determinant.) (c) Which algorithm from Pivoting, norms and conditioning would solve it, and why?

B4. CSC by hand. A count matrix of 3 genes × 5 cells: \[M = \begin{pmatrix} 0 & 1 & 0 & 0 & 3 \\ 4 & 0 & 0 & 6 & 0 \\ 0 & 2 & 0 & 0 & 1 \end{pmatrix}.\] (a) Write down x, i and p (0-based, column by column). (b) Use only x and p to compute the total count (library size) of each cell. (c) Go back: which matrix (3 × 3) has x = (5, 1, 2), i = (2, 0, 1), p = (0, 1, 1, 3)? (d) A 20 000 genes × 100 000 cells matrix has 7 % non-zeros. How much memory does it take dense, and in CSC (8 bytes per value, 4 per row index and per pointer)? Above what fraction of non-zeros is CSC larger than dense?

B5. Fill-in. Use only the pattern: write × for a non-zero and · for a zero. (a) The arrow matrix with the hub first: \[A = \begin{pmatrix} \times & \times & \times & \times \\ \times & \times & \cdot & \cdot \\ \times & \cdot & \times & \cdot \\ \times & \cdot & \cdot & \times \end{pmatrix}.\] Eliminate the first column (subtract multiples of row 1 from rows 2–4). Which zeros become non-zero? What is the pattern of \(L\)? (b) Renumber so the hub is last. Write the new pattern and eliminate. How many fill-ins now? (c) Does elimination of a tridiagonal matrix (Thomas) create any fill-in? (d) Compute the inverse of \(\begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{pmatrix}\) (hint: check that it is \(\tfrac14\begin{pmatrix} 3 & 2 & 1 \\ 2 & 4 & 2 \\ 1 & 2 & 3\end{pmatrix}\)). How many zeros does it have?

B6. Jacobi by hand. (a) Do two Jacobi steps from \(\mathbf{x} = (0, 0)\) for \(\begin{pmatrix} 4 & 1 \\ 1 & 3 \end{pmatrix}\mathbf{x} = \begin{pmatrix} 1 \\ 2 \end{pmatrix}\). Compare with the exact solution \((1/11, 7/11)\). (b) Do three Jacobi steps from \((0, 0)\) for \(\begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}\mathbf{x} = \begin{pmatrix} 3 \\ 3 \end{pmatrix}\) (exact solution \((1, 1)\)). What happens? Which of the two matrices is diagonally dominant?

B7. What structure buys. A computer does \(10^9\) operations per second. (a) For a row of \(n = 10^4\) cells, estimate the time of dense LU (\(\tfrac23 n^3\)), dense Cholesky (\(\tfrac13 n^3\)) and Thomas (\(8n\)). (b) Memory of the dense matrix and of the three diagonals, in bytes. (c) Same for \(n = 10^6\).

In code

C1. Cholesky. Check B1 (a)–(d) in code: the factor, the two triangular solves (R: forwardsolve / backsolve; Python: scipy.linalg.solve_triangular), the log-determinant, and the failure for the correlation matrix of B1(d). Print the eigenvalues of that matrix.

C2. Log-determinant of an LD matrix. The correlation between \(n = 2000\) equally spaced SNP markers is \(\Sigma_{ij} = 0.9^{|i-j|}\). (a) Compute det(S) and the log-determinant from the Cholesky factor. Compare with determinant(S, logarithm = TRUE) (Python: np.linalg.slogdet) and with the exact value \((n-1)\log(1 - 0.9^2)\). (b) The quadratic form of the log-likelihood is \(\mathbf{y}^T\Sigma^{-1}\mathbf{y}\). With \(\mathbf{z} = L^{-1}\mathbf{y}\) it is \(\mathbf{z}^T\mathbf{z}\). Compute it for \(\mathbf{y} = (1, \dots, 1)\) with one triangular solve, and check against a general solve and the exact value \(\big(2 + (n-2)(1+\rho^2) - 2(n-1)\rho\big)/(1-\rho^2)\).

C3. The Thomas algorithm. Write thomas(a, b, c, d) (convention as in the lecture: all four vectors of length \(n\)). (a) Check your answer to B2. (b) Solve the morphogen system for \(n = 100\) cells and check it three ways: the residual \(\max|A\mathbf{x} - \mathbf{s}|\), mass balance \(k\sum x_i = 1\), and \(x_{11}/x_1 \approx e^{-1}\) (decay length 10 cells). (c) Compare with a library solver: R Matrix::bandSparse + solve, Python scipy.linalg.solve_banded.

C4. Timing. Time a dense solve and thomas for \(n = 1000, 2000, 4000\) cells, and thomas alone for \(n = 10^5\) and \(10^6\). By what factor does each time grow when \(n\) doubles? Extrapolate the dense solve to \(10^6\) cells.

C5. Thomas without pivoting. (a) Write diag_dominant(a, b, c). Apply it to the morphogen matrix and to \(a = (\cdot, 1, 1, 1)\), \(b = (10^{-17}, 2, 2, 2)\), \(c = (1, 1, 1, \cdot)\). (b) Solve the second system with d = (1, 1, 1, 1) by thomas and by a general solver. Compute the residual of the Thomas answer. What went wrong?

C6. CSC and the dense inverse. (a) Build \(M\) from B4 from triplets (R sparseMatrix, Python scipy.sparse.csc_matrix, Rust sprs::TriMat) and print its three arrays (R: M@x, M@i, M@p; Python: .data, .indices, .indptr). Compare with B4(a). Compute the library sizes. (b) For the 100-cell morphogen matrix, count the non-zeros of \(A\) and of \(A^{-1}\) (Python: scipy.sparse.linalg.inv). What would \(A^{-1}\) cost in memory for \(10^6\) cells?

C7. Fill-in. Build the 1000 × 1000 arrow matrix (hub gene: diagonal \(n\), row and column of ones; other genes: diagonal 2) with the hub first and with the hub last. Count the non-zeros of the Cholesky factor in both cases. In R, also try Cholesky(A, perm = TRUE). (Python: scipy has no sparse Cholesky; use scipy.sparse.linalg.splu with permc_spec="NATURAL" and "COLAMD".)

C8. Jacobi and conjugate gradient. Write jacobi(A, b, tol, maxit) and cg(A, b, tol, maxit) that stop when \(\|\mathbf{b} - A\mathbf{x}\| <\) tol and report the number of iterations (or that they did not converge). (a) Run both on the morphogen system with \(n = 1000\) cells and tol = 1e-10. How many iterations does each need? How close are they to the direct solution? (Python: compare with scipy.sparse.linalg.cg.) (b) Run Jacobi on the matrix of B6(b) for 50 iterations. What happens?

Explore

The demo below runs Cholesky on the pattern of a sparse symmetric matrix, one column at a time, and only tracks which entries of \(L\) become non-zero (it assumes no lucky cancellation). Panel (a) shows the pattern with rows and columns in elimination order: blue entries are non-zeros of \(A\), vermillion entries are fill-in, and entries outlined in black were created by the last step. The finished rows and columns are faded; the box marks the next pivot. Panel (b) shows the same matrix as a network: one node per unknown (gene or cell), one link per non-zero pair. The number in a node is its place in the elimination order. Eliminating a node links all its remaining neighbours to each other, and every new link is a fill-in entry.

The counters give the non-zeros of \(A\), of \(L\) so far, the fill-in so far, and the operations so far: a column with \(c\) non-zeros below the pivot costs \((c + 1)^2\) (one square root, \(c\) divisions, and \(c(c+1)/2\) multiply-subtract pairs), which gives about \(n^3/3\) for a full matrix. The table compares the five orderings for the current matrix, and for the same kind of matrix with \(n = 1000\) (the 2D grid: \(30 \times 30\)). Min degree always eliminates the node with fewest remaining neighbours next; RCM (reverse Cuthill–McKee) numbers the nodes in breadth-first sweeps, which keeps the non-zeros near the diagonal.

E1. (the hub first) The arrow matrix with \(n = 8\) genes is selected, hub first (natural order). Click step ▶ once. How many neighbours does the pivot have, how many fill-in entries appear, and what does \(L\) look like at the end (click all)? Now choose reversed (hub last) and step through all 8 columns. Compare nnz(\(L\)) and the operations, and the column for \(n = 1000\) with C7.

Answer E1

Hub first: the pivot (the hub) has \(c = 7\) neighbours, all \(7 \cdot 6/2 = 21\) pairs of leaves get linked, and all 21 are new. That single step fills the whole lower right \(7 \times 7\) block; in panel (b) every leaf is now linked to every other. At the end \(L\) has 36 non-zeros, the full lower triangle \(8 \cdot 9/2\), with 21 fill-in, and costs \(1^2 + 2^2 + \dots + 8^2 = 204\) operations. Hub last: each leaf has only the hub as neighbour (\(c = 1\), nothing to link), so no step creates fill-in; \(L\) has \(15 = 2n - 1\) non-zeros (the non-zeros of the lower triangle of \(A\)) and costs 29 operations. For \(n = 1000\) the table gives 500 500 against 1999, the numbers of C7.

E2. (let the ordering choose) Stay with the arrow matrix and try shuffled, min degree and RCM. Where does the hub land in each ordering (look at its number in panel (b)), and how much fill-in does each give? Then set \(n = 30\) and compare natural with min degree.

Answer E2

Shuffled puts the hub 4th: the three leaves before it cost nothing, then the hub still has \(c = 4\) neighbours and links them, \(4 \cdot 3/2 = 6\) fill-ins (nnz(\(L\)) 21 instead of 15). The fill-in only depends on how many neighbours the hub has left when it goes. Min degree eliminates the leaves first (degree 1) and keeps the hub to the end (7th, with only the last leaf left), and RCM numbers the hub 7th too: both give 15 non-zeros, no fill-in, like hub last. At \(n = 30\): natural has 465 non-zeros and 406 fill-ins and costs 9455 operations; min degree 59 non-zeros, no fill-in, 117 operations. This is what Cholesky(A, perm = TRUE) does for you: it finds a fill-reducing ordering before it factorises.

E3. (a row of cells) Choose tridiagonal, \(n = 12\) (the morphogen in a row of cells), natural order, and click play. Does any step create fill-in? Then choose shuffled and step through. What happens in panel (b) when a cell in the middle of the row is eliminated, and how many fill-ins does that give at most? Repeat with band (width 2).

Answer E3

Natural order: each pivot has one remaining neighbour (the next cell), so there is nothing to link; no fill-in, \(L\) has \(2n - 1 = 23\) non-zeros, 45 operations, \(4(n - 1) + 1\): the Thomas algorithm, \(O(n)\). Shuffled: eliminating a cell whose two neighbours are both still there links those two neighbours, one new link that jumps over the eliminated cell. That is at most one fill-in per step, so the fill stays small (5 here, nnz(\(L\)) 28, 70 operations; 2986 instead of 1999 at \(n = 1000\)), but the pattern in panel (a) is scattered, not a band, so Thomas could not be used. The band of width 2 behaves the same: no fill-in in natural order (33 non-zeros, 95 operations), 7 fill-ins shuffled. Elimination never fills outside the band when you go along the row.

E4. (a sheet of cells) Choose 2D grid with side 6 (36 cells, numbered row by row) in natural order. Click step ▶ six times, eliminating the first row of cells. Where does the fill-in go in panel (a)? Click all and read nnz(\(L\)). Then compare min degree and RCM, also for the \(30 \times 30\) grid. Can any ordering avoid fill-in here?

Answer E4

After the first row (6 steps) there are already 25 fill-ins. The first cell links its right neighbour to the cell below it; each later cell of the row links its right neighbour, the cell below it and the cells of the second row that earlier steps had already linked to it. In panel (a) all of this lands inside the band between the diagonal and the neighbour one row down (6 positions away), and the band fills up from the left. In natural order the whole band of width 6 fills in: \(L\) has 221 non-zeros against 96 in the lower triangle of \(A\) (125 fill-in), and costs 1451 operations. Min degree: 167 non-zeros (71 fill-in), 845 operations; RCM: 191 and 1101. For \(30 \times 30\): 27 029 in natural order, the number on the lecture slide; min degree gives 10 351 (the lecture’s AMD gets 10 231), RCM 19 315. No ordering reaches zero: in a sheet, every cell has four neighbours, and eliminating one always links some of them that were not linked before. In 2D (and much more in 3D) some fill-in is unavoidable; that is where iterative solvers come in.

Hints

Hint 1 — Cholesky by hand (B1)

Work column by column. Column 1: \(\ell_{11} = \sqrt{a_{11}}\), then \(\ell_{i1} = a_{i1}/\ell_{11}\). Column 2: \(\ell_{22} = \sqrt{a_{22} - \ell_{21}^2}\), \(\ell_{32} = (a_{32} - \ell_{31}\ell_{21})/\ell_{22}\). Column 3: \(\ell_{33} = \sqrt{a_{33} - \ell_{31}^2 - \ell_{32}^2}\). For (c), \(\det\Sigma = \det L \cdot \det L^T = (\ell_{11}\ell_{22}\ell_{33})^2\).

Hint 2 — Thomas (B2, C3)

Keep fractions: \(b_2 = 3 - \tfrac{-1}{2}(-1) = \tfrac52\). The multiplier \(w\) is \(a_i\) divided by the new \(b_{i-1}\). In Python, copy b and d inside the function (b = np.array(b, dtype=float)), otherwise the caller’s arrays are overwritten. To build the matrix for a check: R bandSparse(n, k = -1:1, diagonals = list(a[-1], b, c[-n])); Python scipy.sparse.diags([a[1:], b, c[:-1]], [-1, 0, 1]). For solve_banded((1, 1), ab, d) the rows of ab are the super-diagonal (shifted right by one), the diagonal and the sub-diagonal (shifted left).

Hint 3 — CSC (B4, C6)

Go down column 1 from top to bottom, then column 2, and so on. p starts at 0 and after each column adds the number of non-zeros in that column; an empty column repeats the previous value. Library size of cell \(j\) = sum of x[p[j]] to x[p[j+1]-1].

Hint 4 — fill-in (B5, C7)

Subtracting a multiple of row 1 from row \(i\) makes row \(i\) non-zero wherever row 1 is non-zero. If row 1 is full, every later row becomes full. In code count non-zeros with nnzero (R), .nnz or np.count_nonzero (Python). Build the arrow matrix with Diagonal(n, 2) and forceSymmetric in R, scipy.sparse.lil_matrix in Python.

Hint 5 — Jacobi and CG (B6, C8)

Jacobi: \(x_1^{\text{new}} = (b_1 - a_{12}x_2)/a_{11}\), \(x_2^{\text{new}} = (b_2 - a_{21}x_1)/a_{22}\), using the old \(x\) on the right. CG, one step: \(\alpha = \mathbf{r}^T\mathbf{r} / \mathbf{p}^TA\mathbf{p}\), \(\mathbf{x} \leftarrow \mathbf{x} + \alpha\mathbf{p}\), \(\mathbf{r} \leftarrow \mathbf{r} - \alpha A\mathbf{p}\), \(\mathbf{p} \leftarrow \mathbf{r} + (\mathbf{r}^T\mathbf{r})_\text{new}/(\mathbf{r}^T\mathbf{r})_\text{old}\,\mathbf{p}\), starting from \(\mathbf{x} = 0\), \(\mathbf{r} = \mathbf{p} = \mathbf{b}\). With a sparse A, A %*% x (R, returns a 1-column matrix: take [, 1]) and A @ x (Python) cost \(O(\text{nnz})\).

B5. // C3: the Thomas algorithm (hand-written) for the morphogen gradient,
// checked by residual, mass balance, decay length and nalgebra's dense LU.
use nalgebra::{DMatrix, DVector};

/// Thomas algorithm: a = below the diagonal (a[0] unused), b = diagonal,
/// c = above the diagonal (c[n-1] unused), d = right-hand side.
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec()); // copies: inputs stay unchanged
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Morphogen in a row of n cells: exchange D, decay k, production 1 in cell 1.
fn morphogen(n: usize, dd: f64, k: f64) -> (Vec<f64>, Vec<f64>, Vec<f64>, Vec<f64>) {
    let mut a = vec![-dd; n];
    a[0] = 0.0;
    let mut c = vec![-dd; n];
    c[n - 1] = 0.0;
    let mut b = vec![2.0 * dd + k; n];
    b[0] = dd + k;
    b[n - 1] = dd + k;
    let mut s = vec![0.0; n];
    s[0] = 1.0;
    (a, b, c, s)
}

/// Thomas algorithm: a = below the diagonal (a[0] unused), b = diagonal,

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec()); // copies: inputs stay unchanged
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

    x = np.zeros(len(b)); dA = A.diagonal()
    for it in range(1, maxit + 1):
        x = x + (b - A @ x) / dA
        if np.linalg.norm(b - A @ x) < tol:
            return x, it
    return x, None                              # not converged

def cg(A, b, tol=1e-10, maxit=20000):
    x = np.zeros(len(b)); r = b.copy(); p = r.copy(); rr = r @ r
    for it in range(1, maxit + 1):
        Ap = A @ p
        alpha = rr / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rr_new = r @ r
        if np.sqrt(rr_new) < tol:
            return x, it
        p = r + (rr_new / rr) * p
        rr = rr_new
    return x, None

// C8: Jacobi and conjugate gradient (hand-written) on the morphogen system,
// with the matrix stored in CSR by sprs and a hand-written matrix-vector product.
use sprs::{CsMat, TriMat};

fn matvec(a: &CsMat<f64>, x: &[f64]) -> Vec<f64> {   // CSR: one row at a time
    a.outer_iterator()
        .map(|row| row.iter().map(|(j, v)| v * x[j]).sum())
        .collect()
}
fn norm(v: &[f64]) -> f64 { v.iter().map(|x| x * x).sum::<f64>().sqrt() }
fn dot(u: &[f64], v: &[f64]) -> f64 { u.iter().zip(v).map(|(p, q)| p * q).sum() }

fn jacobi(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, Option<usize>) {
    let n = b.len();
    let d: Vec<f64> = (0..n).map(|i| *a.get(i, i).unwrap()).collect();
    let mut x = vec![0.0; n];
    for it in 1..=maxit {
        let ax = matvec(a, &x);
        for i in 0..n { x[i] += (b[i] - ax[i]) / d[i]; }
        let ax = matvec(a, &x);
        let r: Vec<f64> = (0..n).map(|i| b[i] - ax[i]).collect();
        if norm(&r) < tol { return (x, Some(it)); }
    }
    (x, None)                                           // not converged
}

fn cg(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, Option<usize>) {
    let n = b.len();
    let (mut x, mut r, mut p) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let mut rr = dot(&r, &r);
    for it in 1..=maxit {
        let ap = matvec(a, &p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n { x[i] += alpha * p[i]; r[i] -= alpha * ap[i]; }
        let rr_new = dot(&r, &r);
        if rr_new.sqrt() < tol { return (x, Some(it)); }
        for i in 0..n { p[i] = r[i] + (rr_new / rr) * p[i]; }
        rr = rr_new;
    }
    (x, None)
}

fn main() {
    let (n, k) = (1000, 0.01);
    let mut t = TriMat::new((n, n));
    for i in 0..n {
        let end = i == 0 || i == n - 1;
        t.add_triplet(i, i, if end { 1.0 + k } else { 2.0 + k });
        if i > 0 { t.add_triplet(i, i - 1, -1.0); }
        if i < n - 1 { t.add_triplet(i, i + 1, -1.0); }
    }
    let a: CsMat<f64> = t.to_csr();

    s[0] = 1.0;

Jacobi needs 4158 iterations, CG 237: both reach the residual \(10^{-10}\), and both are within \(10^{-9}\) of the direct solution (the error is larger than the residual: the matrix has condition number about 400, Pivoting, norms and conditioning). (The Rust version compares Jacobi with CG instead of with a direct solve, since sprs has no sparse direct solver.) Each iteration costs one or two sparse matrix–vector products, \(O(\text{nnz})\); here a direct solve is cheaper, but for a 3D tissue with \(10^8\) grid points it is not. On the matrix of B6(b), Jacobi diverges: the error doubles at every step, so after 50 iterations the entries are about \(2^{50} \approx 10^{15}\). The check that catches it is the residual, which must go down.
