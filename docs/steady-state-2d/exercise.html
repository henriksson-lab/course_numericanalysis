Exercise: steady state in two dimensions

Goal

By the end of this exercise you should be able to:

  • write a steady diffusion problem with uptake as a boundary value problem, discretise it in 1D, and solve the tridiagonal system by hand and in code, with fixed-value and no-flux (ghost point) boundaries,
  • check a BVP solver against an exact solution and by grid refinement (slope 2),
  • number the points of a 2D grid as one vector, and say where a point’s four neighbours are in that vector,
  • assemble the five-point Laplacian with Kronecker products (or from triplets), put the boundary values into the right-hand side, and test the matrix with a manufactured field,
  • recognise the row-major vs column-major ordering bug and the check that exposes it,
  • solve a problem with Michaelis–Menten uptake by Newton, with Jacobian = Laplacian + a diagonal, and detect a physically impossible root,
  • judge whether a diffusion model answers the biological question that was asked.

The by-hand part needs pen, paper and a calculator. The code part uses the same equations at sizes where only code works. Two biological settings: the oxygen chamber of the lecture (2D) and the dead-end trenches of a mother machine (1D).

Background

Facts used below:

  1. Steady state. With \(\partial c/\partial t = 0\), diffusion with uptake \(r(c)\) becomes the boundary value problem \(D\,\nabla^2 c = r(c)\), with \(\nabla^2 c = \partial^2 c/\partial x^2 + \partial^2 c/\partial y^2\). Constant \(r\): Poisson equation; \(r = 0\): Laplace equation. Only boundary conditions, no initial condition.
  2. 1D grid. Nodes \(x_i = i\,h\), \(i = 0, \dots, N\), as in The diffusion (heat) equation by finite differences (\(h\) is its \(\Delta x\)). Two differences from that unit: we write minus the second difference (diagonal \(+2\)), so the matrix is symmetric positive definite and Cholesky and CG apply; and concentrations are in µM (or mM), not scaled to 0..1, because thresholds and \(K_m\) are absolute. Interior equation: \[\frac{D}{h^2}\bigl(-c_{i-1} + 2c_i - c_{i+1}\bigr) + r(c_i) = 0.\] A known boundary value \(c_0\) moves to the right-hand side: \(+\frac{D}{h^2}c_0\) in the first equation.
  3. No flux at a closed end \(x_N\): ghost point \(c_{N+1} = c_{N-1}\), so the last equation is \(\frac{D}{h^2}\bigl(-2c_{N-1} + 2c_N\bigr) + r(c_N) = 0\), and \(c_N\) is an unknown.
  4. Second difference has error \(O(h^2)\), and is exact for parabolas: with constant uptake the grid solution equals the exact one at the grid points.
  5. 2D grid with the same \(h\) in \(x\) and \(y\): five-point stencil \(\frac{D}{h^2}\bigl(4c_{i,j} - c_{i-1,j} - c_{i+1,j} - c_{i,j-1} - c_{i,j+1}\bigr) + r(c_{i,j}) = 0\). Numbering with \(x\) running fastest: \(k = i + (j-1)\,n_x\) (1-based), neighbours at \(k \pm 1\) and \(k \pm n_x\).
  6. Kronecker product: \(A \otimes B\) replaces each \(a_{pq}\) by the block \(a_{pq}B\). With \(T_n = \text{tridiag}(-1, 2, -1)\) of size \(n\) and \(x\) running fastest: \[A = \frac{D}{h^2}\bigl(I_{n_y}\otimes T_{n_x} + T_{n_y}\otimes I_{n_x}\bigr).\] With \(y\) running fastest the factors swap: \(T_{n_x}\otimes I_{n_y} + I_{n_x}\otimes T_{n_y}\).
  7. Storage order. R stores matrices column by column, so as.vector(C) of an \(n_x \times n_y\) matrix C[i, j] puts \(x\) fastest. numpy’s C.ravel() and C.reshape(...) are row-major by default (\(y\) fastest); order="F" gives R’s order. In this exercise every language uses \(x\) fastest.
  8. Michaelis–Menten uptake \(r(c) = R_0\,c/(K_m + c)\), \(r'(c) = R_0K_m/(K_m + c)^2\). Newton for \(\mathbf F(\mathbf c) = A\mathbf c + r(\mathbf c) - \mathbf b = \mathbf 0\): solve \(J\boldsymbol\delta = -\mathbf F\) with \(J = A + \operatorname{diag}(r'(c_k))\), then \(\mathbf c \leftarrow \mathbf c + \boldsymbol\delta\).

Numbers. Oxygen: \(D = 2000\) µm²/s (\(2\times10^{-9}\) m²/s), \(c_0 = 200\) µM, chamber \(4000 \times 2000\) µm, \(R_0 = 0.5\) µM/s per \(10^5\) cells/cm² (an order-of-magnitude assumption: 50 amol/s per cell under a 100 µm lid), \(K_m = 1\) µM, hypoxic below 10 µM. Mother machine: trench \(L = 25\) µm, glucose \(D = 600\) µm²/s, uptake by the packed cells \(V_{\max} = 0.6\) mM/s and \(K_m = 5\) µM \(= 0.005\) mM (both order-of-magnitude assumptions, see C2), rich medium 0.2 % glucose \(= 11.1\) mM.

The basic tools in each language: the 2D matrix for a \(3 \times 2\) grid (\(D = h = 1\)), and flattening a grid with \(x\) fastest. R: Matrix::bandSparse, kronecker, Diagonal. Python: scipy.sparse.diags, scipy.sparse.kron, scipy.sparse.identity. Rust: sprs::TriMat triplets with the index written out.

// rust/examples/steady_state_2d_background.rs  —  cargo run --example steady_state_2d_background
// Background: the 2D five-point matrix for a 3 x 2 grid, built from triplets.
// Unknown k = i + nx * j (0-based), so x (index i) runs fastest, as in R.
use sprs::{CsMat, TriMat};

fn laplacian_2d(nx: usize, ny: usize) -> CsMat<f64> {
    let idx = |i: usize, j: usize| i + nx * j;
    let mut t = TriMat::new((nx * ny, nx * ny));
    for j in 0..ny {
        for i in 0..nx {
            let k = idx(i, j);
            t.add_triplet(k, k, 4.0);
            if i > 0 { t.add_triplet(k, idx(i - 1, j), -1.0); }      // x-neighbours
            if i + 1 < nx { t.add_triplet(k, idx(i + 1, j), -1.0); }
            if j > 0 { t.add_triplet(k, idx(i, j - 1), -1.0); }      // y-neighbours
            if j + 1 < ny { t.add_triplet(k, idx(i, j + 1), -1.0); }
        }
    }
    t.to_csr()
}

fn main() {
    let (nx, ny) = (3, 2);
    let a = laplacian_2d(nx, ny);
    let dense = a.to_dense();
    for r in dense.rows() {
        println!("{:?}", r.iter().map(|v| *v as i32).collect::<Vec<_>>());
    }
    // a grid value c[i][j] at (x_i, y_j) goes to position i + nx * j
    let c = [[1.0, 4.0], [2.0, 5.0], [3.0, 6.0]];          // c[i][j]
    let mut v = vec![0.0; nx * ny];
    for j in 0..ny { for i in 0..nx { v[i + nx * j] = c[i][j]; } }
    println!("{:?}", v);
}

sprs stores and multiplies sparse matrices but has no direct (LU or Cholesky) solver. The Rust solutions use the Thomas algorithm in 1D and a hand-written conjugate gradient (CG) in 2D; CG works here because every matrix in this exercise is symmetric positive definite. It is introduced in Structure: symmetric, banded, sparse and treated fully in Iterative linear solvers in depth.

By hand

B1. A 1D oxygen profile. A long chamber, width \(L = 2000\) µm, open on both long sides (\(c = 200\) µM there), cells at half confluence: \(R_0 = 0.25\) µM/s. Use \(N = 4\) (\(h = 500\) µm), so \(D/h^2 = 0.008\) per s. (a) Write the three equations for \(c_1, c_2, c_3\) with the known values moved to the right-hand side, and solve them (use the symmetry \(c_1 = c_3\)). (b) The exact solution is \(c(y) = c_0 - R_0\,y(L - y)/(2D)\). Compare at the grid points. Why is the agreement exact? (c) At which \(R_0\) does the centre reach 0? Which cell density is that? What does the model predict above it, and why is that wrong?

B2. The mother machine trench with constant uptake. A trench of length \(L = 25\) µm, open at \(x = 0\) to the feeding channel (\(c = c_0\)), closed at \(x = L\). Constant uptake \(V_{\max} = 0.6\) mM/s, \(D = 600\) µm²/s. Use \(N = 2\) (\(h = 12.5\) µm, \(D/h^2 = 3.84\) per s): unknowns \(c_1\) (middle) and \(c_2\) (closed end). (a) Write the two equations, using the ghost point \(c_3 = c_1\) for the closed end. (b) Solve them for \(c_1 - c_0\) and \(c_2 - c_0\). (c) Check against the exact solution \(c(x) = c_0 - \frac{V_{\max}}{D}\bigl(Lx - x^2/2\bigr)\). (d) Below which channel concentration \(c_0\) would the closed end run out under this model? Convert to % glucose (180 g/mol) and compare with the 0.2 % of a rich medium. (e) How long could a trench be before its closed end runs out at \(c_0 = 11.1\) mM?

B3. Numbering a grid. A grid with \(n_x = 4\), \(n_y = 3\) interior points, numbered with \(x\) running fastest, \(k = i + (j-1)n_x\) (1-based). (a) Which \(k\) belong to \((i, j) = (2, 3)\) and \((3, 1)\)? (b) Which \((i, j)\) is \(k = 7\)? Give a general formula for \(i\) and \(j\) from \(k\). (c) A Python user keeps the grid in a numpy array of shape \((n_x, n_y)\) and flattens it with the default ravel(). At which (0-based) position does the value of point \((i, j) = (2, 3)\) (1-based) land? Which point does the R-numbered matrix think lives at that position? (d) In each numbering, how far apart in the vector are \(x\)-neighbours, and \(y\)-neighbours?

B4. The matrix of a small grid. Take \(n_x = 3\), \(n_y = 2\), \(D = h = 1\), and \(c = 1\) on all edges. (a) Write the \(6 \times 6\) matrix \(A\), numbering as in B3. (b) Mark the diagonal blocks and the off-diagonal blocks. Which are copies of \(T_3 + 2I\) and which of \(-I\)? (c) Write the right-hand side \(\mathbf b\) (count each point’s neighbours on the edge). (d) Show that \(\mathbf c = (1, 1, 1, 1, 1, 1)\) solves \(A\mathbf c = \mathbf b\). Why must that be so physically, and why is it a useful test of code?

B5. Kronecker products by hand. \(T_2 = \begin{pmatrix} 2 & -1 \\ -1 & 2\end{pmatrix}\). (a) Write \(I_2 \otimes T_2\) and \(T_2 \otimes I_2\), and their sum. (b) The sum is \(h^2/D\) times the matrix for a \(2\times2\) interior grid. Solve the Poisson problem with \(c_0 = 200\) µM on all edges, \(R_0 = 0.5\) µM/s, \(D = 2000\) µm²/s, \(h = 500\) µm (all four unknowns are equal by symmetry). (c) For a \(2 \times 2\) grid, does the order of the Kronecker factors matter? For a \(3 \times 2\) grid?

B6. Newton with a spurious root. The coarsest possible 1D chamber: \(L = 2000\) µm, \(N = 2\), so one unknown \(c\) at the centre (\(h = 1000\) µm, \(D/h^2 = 0.002\) per s), \(c_0 = 200\) µM, Michaelis–Menten uptake with \(R_0 = 1\) µM/s, \(K_m = 1\) µM. The equation is \[F(c) = 0.002\,(2c - 400) + \frac{c}{1 + c} = 0.004\,(c - 200) + \frac{c}{1 + c} = 0.\] (a) Compute \(F'(c)\). (b) Do two Newton steps from \(c = 200\) (air-saturated start). (c) Do two Newton steps from \(c = 0\). (d) The two runs converge to \(-54.66\) and \(3.66\). Check that both are roots. Which is the oxygen level, and why does the other one exist?

B7. The Jacobian. For the \(2\times2\) grid of B5 with Michaelis–Menten uptake: (a) Write \(J(\mathbf c)\) for a general \(\mathbf c = (c_1, c_2, c_3, c_4)\). (b) Why does uptake add only to the diagonal? Which entries of \(J\) would change if a cell’s uptake also depended on its neighbours’ oxygen? (c) Explain why \(J\) is symmetric positive definite whenever \(A\) is.

B8. Fill-in and cost. In natural order (B3), Cholesky of the 2D matrix fills the whole band between the diagonal and distance \(n_x\). (a) Estimate nnz(\(L\)) \(\approx N n_x\) for the oxygen chamber with \(h = 50\) µm and \(h = 12.5\) µm (\(N\) = number of unknowns), and compare with the lecture table. (b) A banded Cholesky costs about \(N n_x^2\) operations. Estimate it for \(h = 12.5\) µm. (c) A 3D tissue block of \(100 \times 100 \times 100\) points, numbered the same way: what is the bandwidth, nnz(\(L\)) and the memory at 8 bytes per number? What do you conclude?

In code

C1. A 1D BVP with an exact solution. Before trusting a solver, test it. Take the trench of B2 (\(L = 25\) µm, \(D = 600\) µm²/s, open end \(c_0 = 1\), closed end by a ghost point) with linear uptake \(r = kc\), \(k = 6\) per s. The exact solution is \(c(x) = c_0\cosh\bigl((L - x)/\lambda\bigr)/\cosh(L/\lambda)\), \(\lambda = \sqrt{D/k} = 10\) µm. (a) Write trench_matrix(N, h, D) that returns the \(N \times N\) matrix of fact 3 (without uptake). (b) For \(N = 10, 20, 40, 80, 160\), add \(k\) to the diagonal, solve, and compute the maximum error. By what factor does it fall per halving of \(h\)? (c) Compare the value at the closed end with the exact one.

C2. Do cells at the closed end starve? Mother-machine trenches are dead ends: nutrient reaches the cells at the closed end only by diffusion through the medium between the cells in front of them [B1, B2]. Use Michaelis–Menten uptake with \(V_{\max} = 0.6\) mM/s and \(K_m = 0.005\) mM, \(D = 600\) µm²/s, \(N = 100\). (a) Write trench_mm(c0, ...) that solves the problem with Newton (the Jacobian is tridiagonal), starting from \(c = c_0\) everywhere, clipping negative values to 0, and checking that no value is negative at the end. (b) Solve for \(c_0 = 11.1\) (0.2 % glucose), \(1\), \(0.3\), \(0.1\) and \(0.02\) mM. For each, report the number of Newton steps, the concentration at the closed end, and the length of trench where \(c < K_m\) (“starved”). (c) Compare with your threshold from B2(d).

The uptake numbers are an order-of-magnitude estimate, not taken from [B1]: an E. coli cell of about 1 µm³ with 0.3 pg dry mass, doubling once per hour on glucose with a yield of 0.5 g dry mass per g glucose, takes up about \(6\times10^{-19}\) mol/s, or 0.6 mM/s per volume of packed cells. \(K_m\) of glucose uptake is a few µM.

C3. Does the model answer the right question? The cells in the trench are packed tightly, so the effective diffusion coefficient is lower than in free medium (by how much is uncertain). (a) With \(c_0 = 11.1\) mM, compute the concentration at the closed end for \(D = 600\), \(60\) and \(6\) µm²/s, and the trench length \(L_{\max} = \sqrt{2Dc_0/V_{\max}}\) at which constant uptake would exhaust the nutrient. (b) Yang et al. [B1] analysed what limits growth in PDMS mother-machine trenches and concluded that it was not nutrient supply along the trench but mechanical constraints on the cells. Is your model consistent with this? What would it take, in \(D\) or in trench length, for nutrients to become limiting? (c) Which question can this model answer, and which can it not? Write three or four sentences.

C4. Assemble the 2D matrix. (a) Write lap2d(nx, ny, h, D) (Kronecker products; in Rust, triplets) and edge_rhs(nx, ny, h, D, c0), which builds \(\mathbf b\) from a grid-shaped array as on the lecture slide. Check B4: print \(\mathbf b\) and solve for the \(3 \times 2\) grid. (b) Build the oxygen chamber matrix for \(h = 50\) µm. Check its size, non-zeros (compare with the count \(5N\) minus the missing edge neighbours) and symmetry. (c) Manufactured field. \(U(x, y) = \sin(\pi x/L_x)\sin(2\pi y/L_y)\) is zero on all edges and \(-D\nabla^2U = D\pi^2(1/L_x^2 + 4/L_y^2)\,U\). Compute the relative error of \(A\mathbf U\) for \(h = 100, 50, 25\) µm. Is it second order?

C5. The ordering bug. Deliberately mix the two orders and see whether your checks catch it. R: build the matrix with the Kronecker factors in the order that belongs to \(y\) running fastest, but keep as.vector for the vectors. Python: keep the \(x\)-fastest matrix but flatten with numpy’s default ravel() (no order="F"). Rust: keep the matrix, but index the vectors with j + ny * i. (a) Run the C4(c) check and solve the constant-uptake problem (\(R_0 = 0.5\) µM/s), with the correct and with the mixed order. Print the check error and the maximum of \(c\). (b) Repeat the mixed version on a square chamber, \(2000 \times 2000\) µm. What do you see, and what is the lesson?

C6. Oxygen under the lid, with Michaelis–Menten uptake. Use \(h = 50\) µm, \(K_m = 1\) µM. Hints

Hint 1 — 1D equations and boundaries (B1, B2, C1)

Write the stencil at each interior point; any \(c_0\) that appears is a number and goes to the right-hand side with a plus sign. For the closed end, write the ordinary stencil at \(x_N\) and replace \(c_{N+1}\) by \(c_{N-1}\). Divide each equation by \(D/h^2\) first; then the right-hand side contains \(R_0h^2/D\) (B1: \(62.5/2\); B2: \(0.6/3.84 = 0.15625\)). In code: R bandSparse takes the sub-diagonal first in diagonals, so its last entry is the \(-2\) of the ghost-point row; Python scipy.sparse.diags likewise; solve with Matrix::solve or scipy.sparse.linalg.spsolve; in Rust use the Thomas algorithm from Structure: symmetric, banded, sparse.

Hint 2 — numbering and Kronecker products (B3–B5, C4, C5)

Draw the grid with \(i\) to the right and \(j\) upwards and write \(k\) in each point, as in the lecture figure. From \(k\) (1-based): \(i = (k - 1) \bmod n_x + 1\), \(j = \lfloor (k-1)/n_x \rfloor + 1\). For numpy’s row-major order on shape \((n_x, n_y)\), the 0-based position is \(i\,n_y + j\) with 0-based \(i, j\). In \(A\otimes B\), the factor on the right (\(B\)) acts on the index that runs fastest. Check sizes: \(I_{n_y}\otimes T_{n_x}\) and \(T_{n_y}\otimes I_{n_x}\) are both \(n_xn_y \times n_xn_y\), and so are the swapped versions, so a wrong order never gives a size error.

Hint 3 — Newton with uptake (B6, B7, C2, C6)

\(\frac{d}{dc}\frac{c}{K_m + c} = \frac{K_m}{(K_m + c)^2}\). In B6, \(F'(c) = 0.004 + 1/(1+c)^2\). Each uptake term \(r(c_k)\) depends only on \(c_k\), so its derivative lands on the diagonal of \(J\). In code: R J <- A + Diagonal(x = dr), Python J = A + sparse.diags(dr); in Rust add the diagonal to a copy of the triplets, then solve with Thomas (1D) or CG (2D). Stop on the residual \(\|\mathbf F\|\), and clip with pmax(c, 0) / np.maximum(c, 0) / .max(0.0). After the loop, check min(c) >= 0.

Hint 4 — fill-in estimates (B8)

Unknowns: \(n_x = L_x/h - 1\), \(n_y = L_y/h - 1\), \(N = n_xn_y\). For a 3D block numbered with \(x\) fastest, then \(y\), then \(z\), the neighbour in \(z\) is \(n_xn_y\) away: that is the bandwidth. Memory: nnz × 8 bytes (plus indices).

Hint 5 — manufactured field and ordering (C4, C5)

Evaluate \(U\) at the interior points as a grid-shaped array U[i, j] (R outer(sin(pi * x / Lx), sin(2 * pi * y / Ly)); Python np.outer(...)), flatten it with the same order as \(\mathbf b\), multiply by \(A\), and compare with the exact values flattened the same way. // C1: a 1D boundary value problem in a dead-end trench (open end c = c0,
// closed end no flux by a ghost point), linear uptake k c, solved with the
// Thomas algorithm and compared with the exact cosh solution.

// Thomas algorithm (as in Structure: symmetric, banded, sparse):
// a = sub-diagonal (a[0] unused), b = diagonal, c = super-diagonal (c[n-1] unused)
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = b.len();
    let (mut bb, mut dd) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / bb[i - 1];
        bb[i] -= w * c[i - 1];
        dd[i] -= w * dd[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = dd[n - 1] / bb[n - 1];
    for i in (0..n - 1).rev() { x[i] = (dd[i] - c[i] * x[i + 1]) / bb[i]; }
    x
}

fn main() {
    let (l, d, k, c0): (f64, f64, f64, f64) = (25.0, 600.0, 6.0, 1.0);   // µm, µm^2/s, 1/s, relative
    let lam = (d / k).sqrt();                          // 10 µm
    let mut errs = Vec::new();
    let mut last = 0.0;
    for n in [10usize, 20, 40, 80, 160] {
        let h = l / n as f64;
        let s = d / (h * h);
        let mut a = vec![-s; n];
        a[n - 1] = -2.0 * s;                           // ghost point c_{N+1} = c_{N-1}
        let b = vec![2.0 * s + k; n];
        let c = vec![-s; n];
        let mut rhs = vec![0.0; n];
        rhs[0] = s * c0;                               // the open end is known
        let cn = thomas(&a, &b, &c, &rhs);

            let x = h * (i + 1) as f64;
            (cn[i] - c0 * ((l - x) / lam).cosh() / (l / lam).cosh()).abs()
        }).fold(0.0, f64::max);
        errs.push(err);
        last = cn[n - 1];
    }
    println!("{:?}", errs.iter().map(|e| format!("{:.6e}", e)).collect::<Vec<_>>());

// C2: nutrient (glucose) in a dead-end mother-machine trench with
// Michaelis-Menten uptake, solved by Newton. The Jacobian is tridiagonal,

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = b.len();
    let (mut bb, mut dd) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / bb[i - 1];
        bb[i] -= w * c[i - 1];
        dd[i] -= w * dd[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = dd[n - 1] / bb[n - 1];
    for i in (0..n - 1).rev() { x[i] = (dd[i] - c[i] * x[i + 1]) / bb[i]; }
    x
}

// returns (concentrations at x_1..x_N, Newton steps)
fn trench_mm(c0: f64, l: f64, d: f64, vmax: f64, km: f64, n: usize) -> (Vec<f64>, usize) {
    let h = l / n as f64;
    let s = d / (h * h);
    let mut a = vec![-s; n];
    a[n - 1] = -2.0 * s;                                 // ghost point at the closed end
    let sup = vec![-s; n];
    let mut c = vec![c0; n];                             // start: trench = channel
    let mut it = 0;
    loop {
        // residual F = A c + r(c) - b; the known c0 at x_0 is the b part
        let f: Vec<f64> = (0..n).map(|i| {
            let left = if i == 0 { c0 } else { c[i - 1] };
            let right = if i + 1 < n { c[i + 1] } else { c[i - 1] };   // ghost point
            s * (-left + 2.0 * c[i] - right) + vmax * c[i] / (km + c[i])
        }).collect();
        let norm = f.iter().map(|v| v * v).sum::<f64>().sqrt();
        if norm < 1e-10 * (1.0 + s * c0) || it == 50 { break; }
        let diag: Vec<f64> = c.iter().map(|ci| 2.0 * s + vmax * km / ((km + ci) * (km + ci))).collect();
        let minus_f: Vec<f64> = f.iter().map(|v| -v).collect();
        let delta = thomas(&a, &diag, &sup, &minus_f);
        for i in 0..n { c[i] = (c[i] + delta[i]).max(0.0); }  // clip: no negative glucose
        it += 1;
    }
    (c, it)
}

// C4: assemble the 2D five-point matrix from triplets (k = i + nx * j, x fastest),
// put the edge values into the right-hand side, and check the matrix with a
// manufactured field. sprs has no direct solver: we use a hand-written

use sprs::{CsMat, TriMat};

fn lap2d(nx: usize, ny: usize, h: f64, d: f64) -> CsMat<f64> {
    let s = d / (h * h);
    let idx = |i: usize, j: usize| i + nx * j;
    let mut t = TriMat::new((nx * ny, nx * ny));
    for j in 0..ny {
        for i in 0..nx {
            let k = idx(i, j);
            t.add_triplet(k, k, 4.0 * s);
            if i > 0 { t.add_triplet(k, idx(i - 1, j), -s); }
            if i + 1 < nx { t.add_triplet(k, idx(i + 1, j), -s); }
            if j > 0 { t.add_triplet(k, idx(i, j - 1), -s); }
            if j + 1 < ny { t.add_triplet(k, idx(i, j + 1), -s); }
        }
    }
    t.to_csr()
}

fn edge_rhs(nx: usize, ny: usize, h: f64, d: f64, c0: f64) -> Vec<f64> {
    let s = d / (h * h);
    let mut b = vec![0.0; nx * ny];
    for j in 0..ny {
        for i in 0..nx {
            let mut m = 0.0;                       // number of edge neighbours
            if i == 0 { m += 1.0; }
            if i == nx - 1 { m += 1.0; }
            if j == 0 { m += 1.0; }
            if j == ny - 1 { m += 1.0; }
            b[i + nx * j] = s * c0 * m;
        }
    }
    b
}

fn matvec(a: &CsMat<f64>, x: &[f64]) -> Vec<f64> {
    a.outer_iterator().map(|row| row.iter().map(|(j, v)| v * x[j]).sum()).collect()
}
fn dot(u: &[f64], v: &[f64]) -> f64 { u.iter().zip(v).map(|(p, q)| p * q).sum() }

// conjugate gradient for SPD a; stops when ||r|| < tol * ||b||
fn cg(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let n = b.len();
    let (mut x, mut r, mut p) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let mut rr = dot(&r, &r);
    let stop = tol * rr.sqrt();
    for it in 1..=maxit {
        let ap = matvec(a, &p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n { x[i] += alpha * p[i]; r[i] -= alpha * ap[i]; }
        let rr_new = dot(&r, &r);
        if rr_new.sqrt() < stop { return (x, it); }
        for i in 0..n { p[i] = r[i] + (rr_new / rr) * p[i]; }
        rr = rr_new;
    }
    panic!("CG did not converge in {} iterations", maxit);
}

use sprs::{CsMat, TriMat};

fn lap2d(nx: usize, ny: usize, h: f64, d: f64) -> CsMat<f64> {
    let s = d / (h * h);
    let idx = |i: usize, j: usize| i + nx * j;
    let mut t = TriMat::new((nx * ny, nx * ny));
    for j in 0..ny {
        for i in 0..nx {
            let k = idx(i, j);
            t.add_triplet(k, k, 4.0 * s);
            if i > 0 { t.add_triplet(k, idx(i - 1, j), -s); }
            if i + 1 < nx { t.add_triplet(k, idx(i + 1, j), -s); }
            if j > 0 { t.add_triplet(k, idx(i, j - 1), -s); }
            if j + 1 < ny { t.add_triplet(k, idx(i, j + 1), -s); }
        }
    }
    t.to_csr()
}

fn edge_rhs(nx: usize, ny: usize, h: f64, d: f64, c0: f64, wrong: bool) -> Vec<f64> {
    let s = d / (h * h);
    let mut b = vec![0.0; nx * ny];
    for j in 0..ny {
        for i in 0..nx {
            let mut m = 0.0;                       // number of edge neighbours
            if i == 0 { m += 1.0; }
            if i == nx - 1 { m += 1.0; }
            if j == 0 { m += 1.0; }
            if j == ny - 1 { m += 1.0; }
            let k = if wrong { j + ny * i } else { i + nx * j };
            b[k] = s * c0 * m;
        }
    }
    b
}

fn matvec(a: &CsMat<f64>, x: &[f64]) -> Vec<f64> {
    a.outer_iterator().map(|row| row.iter().map(|(j, v)| v * x[j]).sum()).collect()
}
fn dot(u: &[f64], v: &[f64]) -> f64 { u.iter().zip(v).map(|(p, q)| p * q).sum() }

// conjugate gradient for SPD a; stops when ||r|| < tol * ||b||
fn cg(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let n = b.len();
    let (mut x, mut r, mut p) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let mut rr = dot(&r, &r);
    let stop = tol * rr.sqrt();
    for it in 1..=maxit {
        let ap = matvec(a, &p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n { x[i] += alpha * p[i]; r[i] -= alpha * ap[i]; }
        let rr_new = dot(&r, &r);
        if rr_new.sqrt() < stop { return (x, it); }
        for i in 0..n { p[i] = r[i] + (rr_new / rr) * p[i]; }
        rr = rr_new;
    }
    panic!("CG did not converge in {} iterations", maxit);
}

fn edge_rhs(nx: usize, ny: usize, h: f64, d: f64, c0: f64) -> Vec<f64> {

        }
    }

}

// conjugate gradient for SPD a; stops when ||r|| < tol * ||b||
fn cg(a: &CsMat<f64>, b: &[f64], tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let n = b.len();
    let (mut x, mut r, mut p) = (vec![0.0; n], b.to_vec(), b.to_vec());
    let mut rr = dot(&r, &r);
    let stop = tol * rr.sqrt();
    for it in 1..=maxit {
        let ap = matvec(a, &p);
        let alpha = rr / dot(&p, &ap);
        for i in 0..n { x[i] += alpha * p[i]; r[i] -= alpha * ap[i]; }
        let rr_new = dot(&r, &r);
        if rr_new.sqrt() < stop { return (x, it); }
        for i in 0..n { p[i] = r[i] + (rr_new / rr) * p[i]; }
        rr = rr_new;
    }
    panic!("CG did not converge in {} iterations", maxit);
}

// returns (c with k = i + nx * j, Newton steps)
fn oxygen_mm(a: &CsMat<f64>, b: &[f64], r0: f64, km: f64, c0: f64, clip: bool) -> (Vec<f64>, usize) {
    let n = b.len();
    let mut c = vec![c0; n];
    let mut it = 0;
    loop {
        let ac = matvec(a, &c);
        let f: Vec<f64> = (0..n).map(|k| ac[k] + r0 * c[k] / (km + c[k]) - b[k]).collect();
        if dot(&f, &f).sqrt() < 1e-8 || it == 50 { break; }
        // J = A + diag(r'(c)): add the diagonal to a copy of A
        let mut t = TriMat::new((n, n));
        for (v, (i, j)) in a.iter() { t.add_triplet(i, j, *v); }
        for k in 0..n { t.add_triplet(k, k, r0 * km / ((km + c[k]) * (km + c[k]))); }
        let jac: CsMat<f64> = t.to_csr();
        let minus_f: Vec<f64> = f.iter().map(|v| -v).collect();
        let (delta, _) = cg(&jac, &minus_f, 1e-12, 20000);
        for k in 0..n {
            c[k] += delta[k];
            if clip { c[k] = c[k].max(0.0); }
        }
        it += 1;
    }
    (c, it)
}

Where this leads

  • Flow plus diffusion: an advection term makes the matrix non-symmetric; Cholesky and CG no longer apply, and the order of upwind differences matters.
  • Reaction–diffusion and pattern formation: production and decay terms, the length scale \(\sqrt{D/k}\) of C1, and time-dependent 2D problems, where each implicit time step is a linear solve with the five-point Laplacian of this unit (there done with the FFT on a periodic grid, which diagonalises it).
  • Beyond rectangles: finite elements and flow: real chambers with pillars and curved walls, where a rectangular grid no longer fits.
  • Iterative linear solvers in depth: conjugate gradient (used in the Rust solutions here), preconditioning, and why 3D problems (B8(c)) need it.
