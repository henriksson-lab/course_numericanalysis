Exercise: reaction–diffusion and pattern formation

Goal

By the end of this exercise you should be able to:

  • compute the decay length \(\lambda = \sqrt{D/k}\) of a synthesis–diffusion–degradation gradient, and use it to go between \(D\), \(k\), \(\lambda\) and threshold positions,
  • set up the steady gradient on a grid with ghost-point boundaries, solve it with the Thomas algorithm, and check it against the exact solution and the mass balance,
  • take IMEX Euler steps (diffusion implicit, reaction explicit) and say when the explicit reaction makes them unstable,
  • measure the error of Lie and Strang splitting and explain when it vanishes,
  • compute the dispersion relation of a two-species model from 2 × 2 eigenvalues and find the band of growing wavelengths (Turing instability),
  • run a 2D pattern simulation and decide, by refining the grid and the time step, whether a pattern is real or an artefact.

The by-hand part needs pen, paper and a calculator. The code part checks the hand answers and then goes to sizes where only code works. All “data” in this exercise are synthetic: model output plus noise. Literature numbers are approximate.

Background

Facts used below:

  1. Synthesis–diffusion–degradation (units µm and min, as for the morphogen in a row of cells; the earlier Part 10 units used seconds): \(\partial c/\partial t = D\,\partial^2 c/\partial x^2 - k\,c\) on \(0 < x < L\), influx \(j\) at \(x = 0\) (\(-D\,\partial c/\partial x = j\)), wall at \(x = L\) (\(\partial c/\partial x = 0\)). We use \(D = 100\) µm²/min, \(k = 0.01\) per min, \(L = 500\) µm, \(j = D/\lambda = 1\).
  2. Steady state: \(c(x) = \dfrac{j\lambda}{D}\,\dfrac{\cosh\bigl((L - x)/\lambda\bigr)}{\sinh(L/\lambda)}\) with \(\lambda = \sqrt{D/k}\); in a long embryo simply \(c(x) = \tfrac{j\lambda}{D}e^{-x/\lambda}\). Mass balance: \(k\int_0^L c\,dx = j\).
  3. Grid: nodes \(x_i = i\,\Delta x\), \(i = 0, \dots, N\). Ghost points: \(c_{-1} = c_1 + 2\Delta x\,j/D\) and \(c_{N+1} = c_{N-1}\). With \(r = D/\Delta x^2\), the operator \(-D\,c''\) becomes a tridiagonal matrix \(K_D\) with diagonal \(2r\), off-diagonals \(-r\), and \(-2r\) in the first row (above the diagonal) and in the last row (below the diagonal); the influx gives the right-hand side \(2j/\Delta x\) in row 0.
  4. IMEX Euler: \((I + \Delta t\,K_D)\,\mathbf c^{n+1} = \mathbf c^n + \Delta t\,\bigl(\mathbf f(\mathbf c^n) + \mathbf s\bigr)\). On one Fourier mode with \(f = -kc\) it multiplies by \(G = (1 - k\Delta t)/(1 + Dq^2\Delta t)\).
  5. Splitting: Lie does \(\Delta t\) of diffusion, then \(\Delta t\) of reaction; Strang does \(\Delta t/2\) reaction, \(\Delta t\) diffusion, \(\Delta t/2\) reaction. With exact sub-steps the error comes from \(\mathcal{AB} - \mathcal{BA}\): Lie is order 1, Strang order 2.
  6. Schnakenberg model (dimensionless): \(u_t = a - u + u^2 v + \nabla^2 u\), \(v_t = b - u^2 v + d\,\nabla^2 v\), with \(a = 0.1\), \(b = 0.9\). A perturbation \(\boldsymbol\delta\cos(qx)\) of the uniform state grows or decays with the eigenvalues of \(J - q^2\,\mathrm{diag}(1, d)\), \(J\) = Jacobian of the reaction.
  7. Periodic 2D grid (a patch of a large tissue without edges; with walls one would use the sparse Kronecker matrix of Steady state in two dimensions instead): the five-point Laplacian has eigenvalues \(-\kappa_{kl}\) with \(\kappa_{kl} = \frac{4}{\Delta x^2}\bigl(\sin^2\frac{\pi k}{N} + \sin^2\frac{\pi l}{N}\bigr)\) on the 2D Fourier modes, so an implicit diffusion step is: FFT, divide by \(1 + \Delta t\,D\,\kappa\), inverse FFT.
  8. Euler stability for a reaction eigenvalue \(\lambda\): \(|1 + \Delta t\,\lambda| \le 1\).

thomas <- function(a, b, c, d) {               # from Structure: symmetric, banded, sparse
  n <- length(d)
  for (i in 2:n) {
    w <- a[i] / b[i - 1]
    b[i] <- b[i] - w * c[i - 1]
    d[i] <- d[i] - w * d[i - 1]
  }
  x <- numeric(n)
  x[n] <- d[n] / b[n]
  for (i in (n - 1):1) x[i] <- (d[i] - c[i] * x[i + 1]) / b[i]
  x
}

lam <- sqrt(D / k); j <- D / lam               # decay length 100 µm; c(0) close to 1
N <- 50; dx <- L / N; x <- (0:N) * dx; r <- D / dx^2
lo <- c(0, rep(-r, N - 1), -2 * r)             # -D c'' on the grid, ghost points
di <- rep(2 * r, N + 1)
up <- c(-2 * r, rep(-r, N - 1), 0)
src <- c(2 * j / dx, rep(0, N))                # flux j enters at x = 0

import numpy as np

def thomas(a, b, c, d):                        # from Structure: symmetric, banded, sparse
    n = len(d)
    b = np.array(b, dtype=float); d = np.array(d, dtype=float)   # copies
    for i in range(1, n):
        w = a[i] / b[i - 1]
        b[i] -= w * c[i - 1]
        d[i] -= w * d[i - 1]
    x = np.zeros(n)
    x[-1] = d[-1] / b[-1]
    for i in range(n - 2, -1, -1):
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i]
    return x

// rust/examples/reaction_diffusion_background.rs  —  cargo run --example reaction_diffusion_background
// Background: steady synthesis-diffusion-degradation gradient on a grid with
// ghost points, solved by Thomas, checked against the exact cosh formula;
// then one hour of IMEX Euler from c = 0.

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec()); // copies: inputs stay unchanged
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// IMEX Euler: diffusion implicit (one Thomas solve per step), reaction f explicit.
fn imex(c: &[f64], lo: &[f64], di: &[f64], up: &[f64], src: &[f64], dt: f64, nsteps: usize,
        f: &dyn Fn(&[f64]) -> Vec<f64>) -> Vec<f64> {
    let a: Vec<f64> = lo.iter().map(|v| dt * v).collect();
    let b: Vec<f64> = di.iter().map(|v| 1.0 + dt * v).collect();
    let cc: Vec<f64> = up.iter().map(|v| dt * v).collect();
    let mut c = c.to_vec();
    for _ in 0..nsteps {
        let fc = f(&c);
        let rhs: Vec<f64> = (0..c.len()).map(|i| c[i] + dt * (fc[i] + src[i])).collect();
        c = thomas(&a, &b, &cc, &rhs);
    }
    c
}

fn main() {
    let (dd, k, l) = (100.0_f64, 0.01_f64, 500.0_f64); // µm^2/min, 1/min, µm
    let lam = (dd / k).sqrt();
    let j = dd / lam; // decay length 100 µm; c(0) close to 1
    let n = 50;
    let dx = l / n as f64;
    let r = dd / (dx * dx);
    let x: Vec<f64> = (0..=n).map(|i| i as f64 * dx).collect();
    // -D c'' on the grid, ghost points at both ends
    let mut lo = vec![-r; n + 1];
    lo[0] = 0.0;
    lo[n] = -2.0 * r;
    let mut up = vec![-r; n + 1];
    up[0] = -2.0 * r;
    up[n] = 0.0;
    let di: Vec<f64> = vec![2.0 * r; n + 1];
    let di_k: Vec<f64> = di.iter().map(|v| v + k).collect(); // + decay
    let mut src = vec![0.0; n + 1];
    src[0] = 2.0 * j / dx; // flux j enters at x = 0
    let cs = thomas(&lo, &di_k, &up, &src); // steady state: -D c'' + k c = src
    let err = x.iter().zip(&cs)
        .map(|(xi, ci)| (ci - j * lam / dd * ((l - xi) / lam).cosh() / (l / lam).sinh()).abs())
        .fold(0.0, f64::max);
    println!("{}", err);
    let total: f64 = cs.iter().sum::<f64>() - (cs[0] + cs[n]) / 2.0;
    println!("{}", k * dx * total); // total decay (trapezoid) = influx j
    let c60 = imex(&vec![0.0; n + 1], &lo, &di, &up, &src, 1.0, 60,
                   &|c: &[f64]| c.iter().map(|v| -k * v).collect());
    println!("{:.4} {:.4} {:.4}", c60[0], c60[10], c60[20]); // x = 0, 100, 200 µm at t = 60 min
}

By hand

B1. Decay lengths. (a) Our running example has \(D = 100\) µm²/min and \(k = 0.01\) per min. Compute \(\lambda\), and \(D\) in µm²/s. (b) Bicoid (approximate literature values): \(\lambda \approx 100\) µm and a lifetime \(1/k \approx 50\) min. Which \(D\) (in µm²/s) does that require? Which \(\lambda\) would a lifetime of 50 min give with \(D = 0.3\) µm²/s (a FRAP estimate) and with \(D = 7\) µm²/s (an FCS estimate)? (c) Fgf8 [M4] (approximate): \(D \approx 50\) µm²/s and \(\lambda \approx 200\) µm. Infer \(k\) and the lifetime in minutes. (d) In a long embryo, \(c(x) = c_0 e^{-x/\lambda}\) with \(c_0 = j\lambda/D = 1\). Where is \(c = 0.1\)? Now \(k\) doubles everywhere with \(j\) and \(D\) unchanged. What are the new \(\lambda\), \(c_0\) and threshold position? (e) Instead, both \(D\) and \(k\) go up by a factor 1.5 (all rates faster at a higher temperature). What happens to \(\lambda\), to \(c_0\), and to the time the gradient needs to form?

B2. A three-node grid. Take \(L = 200\) µm, \(N = 2\) (\(\Delta x = 100\) µm \(= \lambda\)), \(D = 100\), \(k = 0.01\), \(j = 1\). (a) Write the three equations for the steady state at \(x_0 = 0\), \(x_1 = 100\), \(x_2 = 200\) µm, using the ghost points. (b) Solve them by hand. (c) Compare with the exact values \(c(0) = \coth 2 = 1.0373\), \(c(100) = \cosh 1/\sinh 2 = 0.4255\), \(c(200) = 1/\sinh 2 = 0.2757\). How large is the relative error? (d) Check the mass balance \(k\int c\,dx = j\) with the trapezoid rule on your three values.

B3. IMEX on one mode. Use \(G = (1 - k\Delta t)/(1 + Dq^2\Delta t)\). (a) With \(D = 100\), \(k = 0.01\), a short wave of wavelength 20 µm (\(q = 2\pi/20\)) and \(\Delta t = 10\) min: compute \(G\). What factor would a fully explicit Euler step, \(1 - (Dq^2 + k)\Delta t\), give? (b) For the uniform mode (\(q = 0\)), what is the largest stable \(\Delta t\)? Is \(\Delta t = 150\) min accurate? (Compare \(G\) with \(e^{-k\Delta t}\).) (c) A ligand binds receptors at an effective rate of 1 per s. Which \(\Delta t\) does IMEX need? (d) The Schnakenberg reaction (below) has eigenvalues \(\lambda = -0.1 \pm 0.995i\) at its steady state. For which \(\Delta t\) is \(|1 + \Delta t\lambda| \le 1\)? (Use \(|1 + \Delta t\lambda|^2 = (1 - 0.1\Delta t)^2 + 0.99\,\Delta t^2\).)

B4. When do the parts commute? Two cells exchange morphogen at rate 1 and decay at rates \(k_1\) and \(k_2\): \(\mathbf c' = A\mathbf c - K\mathbf c\) with \(A = \begin{pmatrix} -1 & 1 \\ 1 & -1\end{pmatrix}\), \(K = \begin{pmatrix} k_1 & 0 \\ 0 & k_2\end{pmatrix}\). (a) Compute \(AK - KA\). When is it zero? (b) If \(k_1 = k_2 = k\), show that \(e^{(A - kI)t} = e^{At}e^{-kt}\), so Lie splitting with exact sub-steps has no error at all. (c) Which of these have a splitting error: decay with a temperature step; uniform decay with a source in cell 1; uniform decay without a source?

B5. Turing by hand. Schnakenberg with \(a = 0.1\), \(b = 0.9\). (a) Show that \(u^* = a + b\), \(v^* = b/(a+b)^2\) is a steady state, and compute it. (b) Compute the Jacobian \(J\) of \(f = a - u + u^2v\), \(g = b - u^2 v\) at the steady state, its trace and determinant, and its eigenvalues. Is the uniform state stable without diffusion? What kind of fixed point is it (Equilibria, stability and the phase plane)? (c) With \(d = 20\), write \(\det\bigl(J - q^2\,\mathrm{diag}(1, d)\bigr)\) as a polynomial in \(q^2\). For which \(q\) is it negative? Which wavelengths can grow? (d) Show that the trace of \(J - q^2\,\mathrm{diag}(1, d)\) is negative for every \(q\). What does that imply about how instability can arise? (e) Find the smallest \(d\) for which some \(q\) is unstable. Why can there be no pattern with \(d = 1\)?

B6. Artefact or pattern? (a) The 2D simulation has \(d = 20\) and \(\Delta x = 1\). What is the largest stable step for explicit (FTCS) diffusion of \(v\) in 2D, \(\Delta t \le \Delta x^2/(4d)\)? How many steps to \(t = 200\), compared with IMEX at \(\Delta t = 0.1\)? (b) The fastest-growing wavelength is 12.9 (\(q = 0.487\)). The grid sees \(q^2\) as \(\tfrac{4}{\Delta x^2}\sin^2(q\Delta x/2)\). Compute this for \(\Delta x = 2\), \(1\) and \(0.5\), and the relative error against \(q^2 = 0.237\). How many grid points per wavelength does each grid have? (c) A checkerboard pattern has wavelength \(2\Delta x\). With \(\Delta x = 1\), is that wavelength inside the unstable band of B5(c)? What does it tell you if you see one?

In code

C1. Steady state and its order. Write a function that solves the steady gradient for a given \(N\) and returns the maximum error against the exact solution and the mass balance \(k\int c\,dx\) (trapezoid rule). Use \(N = 5, 10, \dots, 320\). (a) Read the order off the errors. Check B2 with \(N = 2\) and \(L = 200\) if you like. (b) Replace the ghost point at \(x = 0\) by the one-sided condition \((c_1 - c_0)/\Delta x = -j/D\) (row 0 becomes \(c_0 - c_1 = j\Delta x/D\)). What happens to the order, and to the mass balance?

C2. How fast does the gradient form? Start from \(c = 0\) and take IMEX steps with \(\Delta t = 0.5\) min up to \(t = 1000\) min. (a) Compute the local accumulation time \(\tau(x) = \int_0^\infty \bigl(1 - c(x,t)/c_s(x)\bigr)\,dt\) (trapezoid rule over the steps) at \(x = 0\), 100 and 200 µm and compare with \((1 + x/\lambda)/(2k)\). (b) Run IMEX to \(t = 5000\) min with \(\Delta t = 1\), 10 and 50 min and compare with the steady state cs. Why does the step size not matter?

C3. Splitting error. Use the exact solution of the grid ODEs, \(\mathbf c(t) = \mathbf c_s + e^{Mt}(\mathbf c_0 - \mathbf c_s)\) with \(M = -K_D - \mathrm{diag}(k_i)\), as reference. Do the diffusion sub-step exactly with the matrix exponential of the augmented matrix \(\begin{pmatrix} -K_D & \mathbf s \\ 0 & 0\end{pmatrix}\) (it includes the influx), and the decay exactly (\(c_i \to e^{-k_i\Delta t}c_i\)). (a) With the temperature step \(k = 0.01\) for \(x < 250\) µm and \(0.02\) beyond, the influx on and \(\mathbf c_0 = 0\): errors of Lie and Strang at \(t = 60\) min for \(\Delta t = 20, 10, 5, 2.5, 1.25\). Orders? (b) Influx off, uniform \(k\), start from the steady state cs (production has stopped). Error? (c) Influx off, temperature step. Error? Compare with B4.

C4. The temperature step [M1]. Assume that in the warm (27 °C) half of the embryo \(k\) is twice its 20 °C value, with \(D\) and \(j\) unchanged. Hints

Hint 1 — decay lengths (B1)

\(\lambda^2 = D/k\), so \(k = D/\lambda^2\) and \(D = \lambda^2 k\). Keep the units together: µm²/s divided by µm² gives 1/s; 1 µm²/s \(= 60\) µm²/min. A threshold \(c_T\) is crossed where \(c_0 e^{-x/\lambda} = c_T\), i.e. \(x = \lambda\ln(c_0/c_T)\). The formation time scales like \(1/k\).

Hint 2 — the grid and the ghost points (B2, C1)

At node 0: \(D(c_{-1} - 2c_0 + c_1)/\Delta x^2 - k c_0 = 0\) with \(c_{-1} = c_1 + 2\Delta x\,j/D\) gives \((2r + k)c_0 - 2r\,c_1 = 2j/\Delta x\). At the last node use \(c_{N+1} = c_{N-1}\). In B2, \(r = D/\Delta x^2 = 0.01\). Solve the last equation for \(c_2\) in terms of \(c_1\) and work upwards. The trapezoid rule gives the end points half weight.

Hint 3 — IMEX and splitting (B3, B4, C2, C3)

For a mode, diffusion is multiplication by \(-Dq^2\); IMEX treats it implicitly (divide by \(1 + Dq^2\Delta t\)) and the reaction explicitly (multiply by \(1 - k\Delta t\)). For B4(b), \(kI\) commutes with every matrix, and \(e^{X+Y} = e^X e^Y\) when \(XY = YX\). Matrix exponential: R Matrix::expm, Python scipy.linalg.expm, Rust nalgebra’s .exp(). The augmented-matrix trick: the last component stays 1, so \(e^{\Delta t\,\text{Aug}}\) applied to \((\mathbf c, 1)\) gives the solution of \(\mathbf c' = -K_D\mathbf c + \mathbf s\).

Hint 4 — dispersion relation (B5, C6)

\(J = \begin{pmatrix} \partial f/\partial u & \partial f/\partial v \\ \partial g/\partial u & \partial g/\partial v\end{pmatrix}\) with \(\partial f/\partial u = -1 + 2uv\), \(\partial f/\partial v = u^2\), \(\partial g/\partial u = -2uv\), \(\partial g/\partial v = -u^2\). For a 2 × 2 matrix, \(\lambda = \tfrac12\bigl(\tau \pm \sqrt{\tau^2 - 4\Delta}\bigr)\). A quadratic \(d\,Q^2 - \beta Q + \Delta\) in \(Q = q^2\) is negative between its roots, which exist when \(\beta^2 > 4d\Delta\). Code: R eigen and uniroot; Python np.linalg.eigvals and scipy.optimize.brentq.

Hint 5 — the 2D simulation (C7, C8)

R: fft on a matrix is the 2D transform; fft(z, inverse = TRUE) is not normalised, so divide by \(N^2\). outer(s, s, "+") builds \(\kappa_{kl} = s_k + s_l\). Python: np.fft.fft2 and np.fft.ifft2 (normalised), reshape(N, N, order="F") to fill column by column as R does, np.roll for periodic neighbours. Rust: 1D transforms from rustfft along columns, then along rows; build in release mode (cargo run --release).

Hint 6 — fitting the decay length (C5)

\(\log c = \log c_0 - x/\lambda\) is a straight line; its slope is \(-1/\lambda\). R lm(log(c) ~ x), Python np.polyfit(x, np.log(c), 1) (slope first). A constant offset is not a straight line on the log scale: where \(c\) is small, \(\log(c + 0.05)\) flattens out.

Solutions

Solution

B1. (a) \(\lambda = \sqrt{100/0.01} = \sqrt{10^4} = 100\) µm. \(D = 100/60 = 1.67\) µm²/s. (b) \(k = 1/3000\) per s, so \(D = \lambda^2 k = 10^4/3000 = 3.3\) µm²/s. With \(D = 0.3\): \(\lambda = \sqrt{0.3 \cdot 3000} = 30\) µm; with \(D = 7\): \(\lambda = \sqrt{21\,000} = 145\) µm. The two measured \(D\) values bracket the one needed, which is one reason the mechanism of Bicoid gradient formation was debated. (c) \(k = 50/200^2 = 1.25\times10^{-3}\) per s; lifetime \(800\) s \(\approx 13\) min. (d) \(x = 100\ln 10 = 230\) µm. With \(2k\): \(\lambda = 100/\sqrt2 = 70.7\) µm, \(c_0 = j\lambda/D = 0.707\), threshold at \(70.7\ln 7.07 = 138\) µm. Faster decay shortens the gradient and lowers its amplitude (C4 gives 138.3 µm on the finite embryo). (e) \(\lambda = \sqrt{1.5D/1.5k}\) is unchanged, but \(c_0 = j\lambda/D = j/\sqrt{Dk}\) drops by a factor 1.5 (same influx, faster removal), so the threshold moves to \(100\ln(6.67) = 190\) µm. The gradient forms 1.5 times faster (time scale \(1/k\)). If the influx also rose by 1.5, nothing about the steady gradient would change.

B2. (a) With \(r = 0.01\): \(0.03c_0 - 0.02c_1 = 0.02\); \(-0.01c_0 + 0.03c_1 - 0.01c_2 = 0\); \(-0.02c_1 + 0.03c_2 = 0\). (b) Last equation: \(c_2 = \tfrac23 c_1\). Middle: \(0.01c_0 = 0.03c_1 - 0.00667c_1\), so \(c_0 = 2.333c_1\). First: \(0.07c_1 - 0.02c_1 = 0.05c_1 = 0.02\), so \(c_1 = 0.4\), \(c_0 = 0.9333\), \(c_2 = 0.2667\). (c) Relative errors \(10\%\), \(6\%\), \(3\%\): with one grid point per decay length the shape is right, the numbers are not. (d) \(k\Delta x\,(c_0/2 + c_1 + c_2/2) = 0.01 \cdot 100 \cdot (0.4667 + 0.4 + 0.1333) = 1.000 = j\). The ghost-point scheme conserves mass exactly, even on this coarse grid.

B3. (a) \(q = 0.314\), \(Dq^2 = 9.87\) per min. \(G = 0.9/(1 + 98.7) = 0.0090\): the short wave is damped, as it should be (exactly: \(e^{-98.8} \approx 0\)). Explicit Euler: \(1 - 98.8 = -97.8\), an explosion. (b) \(|1 - k\Delta t| \le 1\) gives \(\Delta t \le 2/k = 200\) min. At \(\Delta t = 150\): \(G = 1 - 1.5 = -0.5\) against \(e^{-1.5} = 0.22\): stable, but the uniform part flips sign each step. Not accurate. (c) \(k = 60\) per min: \(\Delta t \le 2/60\) min \(= 2\) s. (d) \(1 - 0.2\Delta t + \Delta t^2 \le 1\) gives \(\Delta t \le 0.2\).

B4. (a) \(AK = \begin{pmatrix} -k_1 & k_2 \\ k_1 & -k_2\end{pmatrix}\), \(KA = \begin{pmatrix} -k_1 & k_1 \\ k_2 & -k_2\end{pmatrix}\), so \(AK - KA = (k_2 - k_1)\begin{pmatrix} 0 & 1 \\ -1 & 0\end{pmatrix}\): zero only if \(k_1 = k_2\). (b) \(kI\) commutes with \(A\), so \(e^{(A - kI)t} = e^{At}e^{-kIt} = e^{At}e^{-kt}\): diffusing and then decaying is exactly the same as doing both at once. (c) A temperature step (\(k_1 \ne k_2\)) and a localised source both give a splitting error; uniform decay without a source does not. (For the source: the reaction step adds the influx and decays only what is present at that moment, so the order matters.) C3 confirms all three.

B5. (a) \(g = 0\): \(u^2 v = b\). \(f = 0\): \(a - u + b = 0\), so \(u^* = a + b = 1\), \(v^* = b/u^{*2} = 0.9\). (b) \(J = \begin{pmatrix} -1 + 2u^*v^* & u^{*2} \\ -2u^*v^* & -u^{*2}\end{pmatrix} = \begin{pmatrix} 0.8 & 1 \\ -1.8 & -1\end{pmatrix}\). \(\tau = -0.2\), \(\Delta = -0.8 + 1.8 = 1\). \(\lambda = -0.1 \pm \sqrt{0.01 - 1} = -0.1 \pm 0.995i\): a stable spiral. Without diffusion, small perturbations die out in damped oscillations. (c) \(\det = (0.8 - q^2)(-1 - 20q^2) + 1.8 = 20q^4 - 15q^2 + 1\). Roots in \(Q = q^2\): \((15 \pm \sqrt{225 - 80})/40 = 0.0740\) and \(0.6760\). Negative for \(0.272 < q < 0.822\), i.e. wavelengths \(2\pi/q\) between \(7.6\) and \(23.1\). (d) \(\tau_q = 0.8 - 1 - q^2(1 + d) < 0\). With a negative trace, an eigenvalue with positive real part needs \(\Delta_q < 0\), which makes both eigenvalues real: the growing mode does not oscillate, the pattern stands still. (e) \(\det = d\,Q^2 - (0.8d - 1)Q + 1\) has real positive roots when \(0.8d - 1 > 0\) and \((0.8d - 1)^2 > 4d\), i.e. \(0.64d^2 - 5.6d + 1 > 0\), \(d > (5.6 + \sqrt{28.8})/1.28 = 8.57\). With \(d = 1\), \(0.8d - 1 < 0\): the determinant is positive for every \(q\). The substrate must diffuse much faster than the activator.

B6. (a) \(\Delta t \le 1/80 = 0.0125\): 16 000 steps, against 2000 for IMEX. (b) \(\Delta x = 2\): \(\sin^2(0.487) = 0.2190\), so the grid sees \(q^2 = 0.219\), 7.7 % low; 6.5 points per wavelength. \(\Delta x = 1\): \(0.2325\), 2.0 % low; 13 points. \(\Delta x = 0.5\): \(0.2360\), 0.5 % low; 26 points. The error is second order (\(\propto\Delta x^2\)) but large on the coarse grid: the grid makes waves look longer than they are, so the fastest-growing grid mode is shorter than the true one. (c) Wavelength 2 is far outside \([7.6, 23.1]\): no Turing mode can be that short. A checkerboard is an unstable explicit step or a bug, never the model’s pattern.

// C1: steady gradient, ghost-point vs one-sided boundary: error and mass balance.

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

const DD: f64 = 100.0;
const K: f64 = 0.01;
const L: f64 = 500.0;

fn steady(n: usize, onesided: bool) -> (f64, f64) {
    let lam = (DD / K).sqrt();
    let j = DD / lam;
    let dx = L / n as f64;
    let r = DD / (dx * dx);
    let mut lo = vec![-r; n + 1];
    lo[0] = 0.0;
    lo[n] = -2.0 * r;
    let mut up = vec![-r; n + 1];
    up[0] = -2.0 * r;
    up[n] = 0.0;
    let mut di = vec![2.0 * r + K; n + 1];
    let mut rhs = vec![0.0; n + 1];
    rhs[0] = 2.0 * j / dx;
    if onesided { // (c1 - c0)/dx = -j/D
        di[0] = 1.0;
        up[0] = -1.0;
        rhs[0] = j * dx / DD;
    }
    let c = thomas(&lo, &di, &up, &rhs);
    let err = (0..=n)
        .map(|i| {
            let x = i as f64 * dx;
            (c[i] - j * lam / DD * ((L - x) / lam).cosh() / (L / lam).sinh()).abs()
        })
        .fold(0.0, f64::max);
    let mass = K * dx * (c.iter().sum::<f64>() - (c[0] + c[n]) / 2.0);
    (err, mass)
}

// steady state does not depend on dt.

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// The grid of the lecture: N = 50 intervals of 10 µm, ghost points at both ends.
/// lo, di, up = the three diagonals of -D d2/dx2; src = influx j at x = 0.
#[allow(dead_code)]
struct Grid { n: usize, dx: f64, x: Vec<f64>, lo: Vec<f64>, di: Vec<f64>, up: Vec<f64>, src: Vec<f64> }

fn grid(n: usize, dd: f64, l: f64, j: f64) -> Grid {
    let dx = l / n as f64;
    let r = dd / (dx * dx);
    let mut lo = vec![-r; n + 1];
    lo[0] = 0.0;
    lo[n] = -2.0 * r;
    let mut up = vec![-r; n + 1];
    up[0] = -2.0 * r;
    up[n] = 0.0;
    let mut src = vec![0.0; n + 1];
    src[0] = 2.0 * j / dx;
    Grid { n, dx, x: (0..=n).map(|i| i as f64 * dx).collect(), lo, di: vec![2.0 * r; n + 1], up, src }
}

/// IMEX Euler: diffusion implicit (one Thomas solve), reaction f explicit.
fn imex(c: &[f64], g: &Grid, dt: f64, nsteps: usize, f: &dyn Fn(&[f64]) -> Vec<f64>) -> Vec<f64> {
    let a: Vec<f64> = g.lo.iter().map(|v| dt * v).collect();
    let b: Vec<f64> = g.di.iter().map(|v| 1.0 + dt * v).collect();
    let cc: Vec<f64> = g.up.iter().map(|v| dt * v).collect();
    let mut c = c.to_vec();
    for _ in 0..nsteps {
        let fc = f(&c);
        let rhs: Vec<f64> = (0..c.len()).map(|i| c[i] + dt * (fc[i] + g.src[i])).collect();
        c = thomas(&a, &b, &cc, &rhs);
    }
    c
}

fn split_err(g: &Grid, kx: &[f64], b: &[f64], c0: &[f64], hs: &[f64]) {
    let m = g.n + 1;
    let tend = 60.0;
    // A = D d2/dx2 with ghost points (minus the positive operator)
    let a = DMatrix::from_fn(m, m, |i, j| {
        if i == j { -g.di[i] } else if i == j + 1 { -g.lo[i] } else if j == i + 1 { -g.up[i] } else { 0.0 }
    });
    let mm = &a - DMatrix::from_diagonal(&DVector::from_column_slice(kx));
    let bv = DVector::from_column_slice(b);
    let cst = -mm.clone().lu().solve(&bv).unwrap();
    let cref = &cst + (&mm * tend).exp() * (DVector::from_column_slice(c0) - &cst); // exact
    let mut aug = DMatrix::zeros(m + 1, m + 1); // diffusion + influx, done exactly
    aug.view_mut((0, 0), (m, m)).copy_from(&a);
    aug.view_mut((0, m), (m, 1)).copy_from(&bv);
    for &h in hs {
        let e = (&aug * h).exp();
        let dif = |c: &DVector<f64>| -> DVector<f64> {
            let mut ce = DVector::from_element(m + 1, 1.0);
            ce.rows_mut(0, m).copy_from(c);
            (&e * ce).rows(0, m).into_owned()
        };
        let decay = |c: &DVector<f64>, t: f64| -> DVector<f64> {
            DVector::from_fn(m, |i, _| (-kx[i] * t).exp() * c[i])
        };
        let mut lie = DVector::from_column_slice(c0);
        let mut strang = lie.clone();
        for _ in 0..(tend / h).round() as usize {
            lie = decay(&dif(&lie), h);
            strang = decay(&dif(&decay(&strang, h / 2.0)), h / 2.0);

fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

fn slope(x: &[f64], y: &[f64]) -> f64 {
    let n = x.len() as f64;
    let (mx, my) = (x.iter().sum::<f64>() / n, y.iter().sum::<f64>() / n);

}

/// 2D FFT of an N x N grid stored column by column (w[i + n*j]): rows, then columns.
fn fft2(w: &mut [Complex<f64>], n: usize, planner: &mut FftPlanner<f64>, inverse: bool) {
    let fft = if inverse { planner.plan_fft_inverse(n) } else { planner.plan_fft_forward(n) };
    for col in w.chunks_mut(n) { fft.process(col); } // along i, for each j
    let mut tmp = vec![Complex::new(0.0, 0.0); n];
    for i in 0..n { // along j, for each i
        for j in 0..n { tmp[j] = w[i + n * j]; }
        fft.process(&mut tmp);
        for j in 0..n { w[i + n * j] = tmp[j]; }
    }
}

/// Schnakenberg on an N x N periodic grid of side 80: IMEX Euler, the implicit
/// five-point diffusion solved by FFT. Returns u (column by column).
fn schnak(n: usize, dt: f64, tend: f64, d: f64) -> Vec<f64> {
    let (a, b, lbox) = (0.1, 0.9, 80.0);
    let dx = lbox / n as f64;
    let s: Vec<f64> = (0..n)
        .map(|i| 4.0 / (dx * dx) * (std::f64::consts::PI * i as f64 / n as f64).sin().powi(2))
        .collect();
    let kap: Vec<f64> = (0..n * n).map(|idx| s[idx % n] + s[idx / n]).collect();
    let z = lcg(2 * n * n, 1);
    let mut u: Vec<f64> = (0..n * n).map(|i| 1.0 + 0.02 * (z[i] - 0.5)).collect();
    let mut v: Vec<f64> = (0..n * n).map(|i| 0.9 + 0.02 * (z[n * n + i] - 0.5)).collect();
    let mut planner = FftPlanner::new();
    let mut solve_diff = |w: &[f64], dw: f64| -> Vec<f64> {
        let mut c: Vec<Complex<f64>> = w.iter().map(|&x| Complex::new(x, 0.0)).collect();
        fft2(&mut c, n, &mut planner, false);
        for (ci, k) in c.iter_mut().zip(&kap) { *ci /= 1.0 + dt * dw * k; }
        fft2(&mut c, n, &mut planner, true);
        c.iter().map(|x| x.re / (n * n) as f64).collect()
    };
    for _ in 0..(tend / dt).round() as usize {
        let mut ru = vec![0.0; n * n];
        let mut rv = vec![0.0; n * n];
        for i in 0..n * n {
            let uuv = u[i] * u[i] * v[i];
            ru[i] = u[i] + dt * (a - u[i] + uuv); // reaction: explicit
            rv[i] = v[i] + dt * (b - uuv);
        }
        u = solve_diff(&ru, 1.0); // diffusion: implicit
        v = solve_diff(&rv, d);
    }
    u
}

fn spots(u: &[f64], n: usize) -> usize {

            let mut ismax = c > mean;

                }
            }
            if ismax { count += 1; }
        }
    }
    count
}

use rustfft::{num_complex::Complex, FftPlanner};

/// Park-Miller generator, the same numbers as in R and Python.
fn lcg(n: usize, seed: u64) -> Vec<f64> {
    let mut s = seed;
    (0..n).map(|_| { s = (16807 * s) % 2147483647; s as f64 / 2147483647.0 }).collect()
}

/// 2D FFT of an N x N grid stored column by column (w[i + n*j]): rows, then columns.
fn fft2(w: &mut [Complex<f64>], n: usize, planner: &mut FftPlanner<f64>, inverse: bool) {
    let fft = if inverse { planner.plan_fft_inverse(n) } else { planner.plan_fft_forward(n) };
    for col in w.chunks_mut(n) { fft.process(col); } // along i, for each j
    let mut tmp = vec![Complex::new(0.0, 0.0); n];
    for i in 0..n { // along j, for each i
        for j in 0..n { tmp[j] = w[i + n * j]; }
        fft.process(&mut tmp);
        for j in 0..n { w[i + n * j] = tmp[j]; }
    }
}

/// Schnakenberg on an N x N periodic grid of side 80: IMEX Euler, the implicit
/// five-point diffusion solved by FFT. Returns u (column by column).
fn schnak(n: usize, dt: f64, tend: f64, d: f64) -> Vec<f64> {
    let (a, b, lbox) = (0.1, 0.9, 80.0);
    let dx = lbox / n as f64;
    let s: Vec<f64> = (0..n)
        .map(|i| 4.0 / (dx * dx) * (std::f64::consts::PI * i as f64 / n as f64).sin().powi(2))
        .collect();
    let kap: Vec<f64> = (0..n * n).map(|idx| s[idx % n] + s[idx / n]).collect();
    let z = lcg(2 * n * n, 1);
    let mut u: Vec<f64> = (0..n * n).map(|i| 1.0 + 0.02 * (z[i] - 0.5)).collect();
    let mut v: Vec<f64> = (0..n * n).map(|i| 0.9 + 0.02 * (z[n * n + i] - 0.5)).collect();
    let mut planner = FftPlanner::new();
    let mut solve_diff = |w: &[f64], dw: f64| -> Vec<f64> {
        let mut c: Vec<Complex<f64>> = w.iter().map(|&x| Complex::new(x, 0.0)).collect();
        fft2(&mut c, n, &mut planner, false);
        for (ci, k) in c.iter_mut().zip(&kap) { *ci /= 1.0 + dt * dw * k; }
        fft2(&mut c, n, &mut planner, true);
        c.iter().map(|x| x.re / (n * n) as f64).collect()
    };
    for _ in 0..(tend / dt).round() as usize {
        let mut ru = vec![0.0; n * n];
        let mut rv = vec![0.0; n * n];
        for i in 0..n * n {
            let uuv = u[i] * u[i] * v[i];
            ru[i] = u[i] + dt * (a - u[i] + uuv); // reaction: explicit
            rv[i] = v[i] + dt * (b - uuv);
        }
        u = solve_diff(&ru, 1.0); // diffusion: implicit
        v = solve_diff(&rv, d);
    }
    u
}

/// Number of local maxima (8 neighbours, periodic) above the mean.
fn spots(u: &[f64], n: usize) -> usize {
    let mean = u.iter().sum::<f64>() / (n * n) as f64;
    let mut count = 0;
    for j in 0..n {
        for i in 0..n {
            let c = u[i + n * j];
            let mut ismax = c > mean;
            for di in [n - 1, 0, 1] {
                for dj in [n - 1, 0, 1] {
                    if di == 0 && dj == 0 { continue; }
                    if !(c > u[(i + di) % n + n * ((j + dj) % n)]) { ismax = false; }
                }
            }
            if ismax { count += 1; }
        }
    }
    count
}

    for n in [40, 80, 160] { // (a) grid: dx = 2, 1, 0.5

        println!("dx = {:.1}, dt = 0.1:  {} spots, max u {:.3}", 80.0 / n as f64, spots(&u, n), umax);

    for dt in [0.4, 0.2, 0.05] { // (b) time step

        println!("dx = 1.0, dt = {:.2}: {} spots, max u {:.3}", dt, spots(&u, 80), umax);

(c) With \(d = 5\) there is no Turing instability, and \(\Delta t = 0.1\) correctly stays uniform. \(\Delta t = 0.4\) makes \(|1 + \Delta t\lambda| = 1.039 > 1\): Euler on the reaction amplifies the long waves (which implicit diffusion hardly damps) by 4 % per step, and a large, oscillating “pattern” appears. A pattern that exists only for some \(\Delta t\), or whose spacing follows \(\Delta x\), is a numerical artefact.
