Exercise: least squares, normal equations vs QR

Goal

By the end of this exercise you should be able to:

  • write a calibration (standard) curve as an overdetermined system \(A\mathbf x \approx \mathbf b\) and say what the residuals are,
  • solve a small least-squares problem by hand with the normal equations \(A^TA\mathbf x = A^T\mathbf b\), and check that \(A^T\mathbf r = \mathbf 0\),
  • explain why the normal equations square the condition number, and show a case where that destroys the answer,
  • compute a QR factorisation of a small matrix by Gram–Schmidt and apply one Householder reflection by hand,
  • compare classical and modified Gram–Schmidt and Householder QR in code, and read off the digits lost against \(\kappa\),
  • recognise a badly conditioned polynomial (Vandermonde) calibration and fix it by rescaling or poly(),
  • say what lm, qr.solve, numpy.linalg.lstsq and nalgebra’s QR do, and how each reports dependent columns.

The by-hand part needs pen, paper and a calculator for square roots. The code part checks your hand answers and then works at sizes where only code works.

Background

A standard curve relates a known amount (copies of a qPCR standard, µg/mL of BSA) to a reading (Cq, absorbance). With \(m\) standards and a model with \(n\) parameters, \(m > n\), we get an overdetermined system

\[A\mathbf x \approx \mathbf b, \qquad A: m\times n \text{ (design matrix)}, \quad \mathbf b: \text{the readings}.\]

Facts used below:

  1. Residual and least squares. \(\mathbf r = \mathbf b - A\mathbf x\). Least squares minimises \(\|\mathbf r\|^2 = \sum_i r_i^2\). At the minimum the residual is perpendicular to every column of \(A\): \(A^T\mathbf r = \mathbf 0\).
  2. Normal equations. \(A^TA\,\mathbf x = A^T\mathbf b\), an \(n\times n\) symmetric positive definite system. For a straight line \(b \approx x_1 + x_2 t\): \[A^TA = \begin{pmatrix} m & \sum t_i \\ \sum t_i & \sum t_i^2\end{pmatrix}, \qquad A^T\mathbf b = \begin{pmatrix}\sum b_i \\ \sum t_i b_i\end{pmatrix}.\]
  3. Condition number. \(\kappa(A)\) = largest stretch / smallest stretch of \(A\) over unit vectors (kappa(A, exact = TRUE), np.linalg.cond(A)). A good method loses about \(\log_{10}\kappa(A)\) digits. Since \(\|A\mathbf v\|^2 = \mathbf v^TA^TA\mathbf v\), \(\kappa(A^TA) = \kappa(A)^2\): the normal equations lose about twice as many.
  4. QR. \(A = QR\) with \(Q^TQ = I\) (\(m\times n\), orthonormal columns) and \(R\) upper triangular (\(n\times n\)). Least squares becomes \(R\mathbf x = Q^T\mathbf b\) (back substitution), and \(\kappa(R) = \kappa(A)\).
  5. Gram–Schmidt. For \(j = 1, \dots, n\): \(\mathbf v = \mathbf a_j\); for each earlier \(i\): \(r_{ij} = \mathbf q_i^T\mathbf a_j\) (classical) or \(\mathbf q_i^T\mathbf v\) (modified), \(\mathbf v \leftarrow \mathbf v - r_{ij}\mathbf q_i\); then \(r_{jj} = \|\mathbf v\|\), \(\mathbf q_j = \mathbf v / r_{jj}\).
  6. Householder reflection. \(H = I - 2\mathbf v\mathbf v^T/(\mathbf v^T\mathbf v)\) with \(\mathbf v = \mathbf a + \text{sign}(a_1)\|\mathbf a\|\mathbf e_1\) maps \(\mathbf a\) to \(-\text{sign}(a_1)\|\mathbf a\|\mathbf e_1\). Useful form: \(H\mathbf a = \mathbf a - 2\dfrac{\mathbf v^T\mathbf a}{\mathbf v^T\mathbf v}\mathbf v\).
  7. qPCR. \(\text{Cq} = x_1 + x_2\log_{10}N\); efficiency \(E = 10^{-1/x_2} - 1\) (slope \(-3.32\) gives 100 %).

The two data sets used throughout and the basic calls in each language: qPCR standards (\(10^1\) to \(10^7\) copies, triplicates) and BCA protein standards (BSA 0–2000 µg/mL, duplicates, absorbance at 562 nm).

// Background: a straight-line fit by the normal equations and by QR (nalgebra).
use nalgebra::{DMatrix, DVector};

fn main() {
    let log_n: Vec<f64> = (1..=7).flat_map(|k| [k as f64; 3]).collect();
    let cq = DVector::from_vec(vec![
        34.52, 34.69, 34.48, 31.62, 31.37, 31.14, 28.05, 28.10, 28.07,
        24.54, 24.90, 24.68, 21.13, 20.81, 21.47, 17.89, 17.90, 18.09,
        14.71, 14.67, 14.73]);
    // design matrix, 21 x 2: a column of ones and log10 N
    let a = DMatrix::from_fn(log_n.len(), 2, |i, j| if j == 0 { 1.0 } else { log_n[i] });

    // normal equations (A^T A) x = A^T b, solved by Cholesky
    let x_ne = (a.transpose() * &a).cholesky().unwrap().solve(&(a.transpose() * &cq));
    println!("{:.6} {:.6}", x_ne[0], x_ne[1]);

    // Householder QR: R x = Q^T b; Q is never formed
    let qr = a.clone().qr();
    let mut qtb = cq.clone();
    qr.q_tr_mul(&mut qtb);                                    // qtb <- Q^T b
    let x_qr = qr.r().solve_upper_triangular(&qtb.rows(0, 2).into_owned()).unwrap();
    println!("{:.6} {:.6}", x_qr[0], x_qr[1]);

    // 2-norm condition number = largest / smallest singular value
    let sv = a.singular_values();
    println!("{}", sv.max() / sv.min());

    // BCA standards: BSA in ug/mL (duplicates) and absorbance at 562 nm
    let conc: Vec<f64> = [0., 25., 125., 250., 500., 750., 1000., 1500., 2000.]
        .iter().flat_map(|&c| [c; 2]).collect();
    let a562 = DVector::from_vec(vec![0.087, 0.103, 0.150, 0.109, 0.226, 0.229, 0.358,
        0.344, 0.601, 0.569, 0.780, 0.789, 0.951, 0.942, 1.300, 1.238, 1.545, 1.532]);
    println!("{} {}", conc.len(), a562.len());
}

In R, lm and qr.solve use Householder QR. In Python, np.linalg.qr is Householder QR and np.linalg.lstsq uses the SVD. In Rust, nalgebra’s QR is Householder QR: q_tr_mul applies \(Q^T\) to a vector without forming \(Q\), and solve_upper_triangular does the back substitution. nalgebra’s QR::solve only accepts square matrices, so the least-squares solve is written out in two lines.

By hand

B1. A four-point standard curve. A qPCR dilution series gives

\(\log_{10} N\) 1 2 3 4
Cq 34.6 31.2 28.0 24.6
  1. Write down \(A\) (4×2) and \(\mathbf b\) for the model \(\text{Cq} = x_1 + x_2\log_{10}N\).
  2. Compute \(A^TA\) and \(A^T\mathbf b\).
  3. Solve the 2×2 normal equations for \(x_1\) and \(x_2\).
  4. Compute the four residuals and their sum of squares. Check that \(A^T\mathbf r = \mathbf 0\) (two numbers).
  5. What is the amplification efficiency?

B2. Squaring the condition number. (a) Let \(A = \begin{pmatrix} 1 & 0 \\ 0 & \delta \\ 0 & 0\end{pmatrix}\) with \(\delta = 10^{-3}\). What are the largest and smallest stretches \(\|A\mathbf v\|\) over unit vectors \(\mathbf v\)? What is \(\kappa(A)\)? Compute \(A^TA\) and \(\kappa(A^TA)\). (b) Now take \(A = \begin{pmatrix} 1 & 1 \\ \delta & 0 \\ 0 & \delta\end{pmatrix}\) (Läuchli’s example: two predictors that are nearly the same). Compute \(A^TA\). (c) With \(\delta = 10^{-8}\): what is \(1 + \delta^2\) in double precision (\(\varepsilon/2 \approx 1.1\times10^{-16}\))? What happens to the computed \(A^TA\)? Does \(A\) itself have rank 2? (d) For \(\delta = 10^{-8}\), \(\kappa(A) \approx 1.4\times10^{8}\). How many correct digits can a good method deliver? And the normal equations?

B3. Gram–Schmidt by hand. Three standards at \(\log_{10}N = 1, 3, 5\) give Cq \(= 35.0, 28.4, 21.6\). (a) Run Gram–Schmidt on the columns \(\mathbf a_1 = (1, 1, 1)\) and \(\mathbf a_2 = (1, 3, 5)\): find \(r_{11}, \mathbf q_1, r_{12}, \mathbf v, r_{22}, \mathbf q_2\). Write down \(R\). (b) Check that \(\mathbf q_1^T\mathbf q_2 = 0\) and that \(\mathbf a_2 = r_{12}\mathbf q_1 + r_{22}\mathbf q_2\). (c) Compute \(Q^T\mathbf b\) and solve \(R\mathbf x = Q^T\mathbf b\) by back substitution. (d) What is \(\mathbf v\) in words, in terms of \(\mathbf a_2\)? Use that to write the slope \(x_2\) as a formula in the centred \(\log_{10}N\).

B4. One Householder reflection. (a) For \(\mathbf a = (2, 1, 2)\), compute \(\|\mathbf a\|\), \(\mathbf v = \mathbf a + \|\mathbf a\|\mathbf e_1\), \(\mathbf v^T\mathbf v\), \(\mathbf v^T\mathbf a\) and \(H\mathbf a\). (b) Why is \(\|H\mathbf a\| = \|\mathbf a\|\) a good sign? What would \(\|H\mathbf a\|\) be if \(H\) were not orthogonal? (c) Take \(\mathbf a = (1, 10^{-5}, 0)\), a column that is almost along \(\mathbf e_1\). Compute \(\|\mathbf a\|\) to 12 significant digits (\(\sqrt{1 + x} \approx 1 + x/2\)). Compare the first component of \(\mathbf v\) for the two sign choices, \(a_1 + \|\mathbf a\|\) and \(a_1 - \|\mathbf a\|\). Which one suffers from cancellation, and roughly how many digits does it lose in double precision?

B5. A Vandermonde matrix in the wrong units. A quadratic BCA calibration \(a = c_0 + c_1 x + c_2 x^2\) with standards at \(x = 0, 1000, 2000\) µg/mL. (a) Write down the 3×3 matrix \(A\) with \(x\) in µg/mL, and again with \(x\) in mg/mL. (b) The stretch of a column \(\|A\mathbf e_j\|\) lies between the smallest and the largest stretch of \(A\). Use the column lengths to give a lower bound for \(\kappa(A)\) in µg/mL. What does that imply for \(\kappa(A^TA)\)? (c) Do the same in mg/mL. Is the bound useful there? (d) If the mg/mL fit gives \((c_0, c_1, c_2)\), what are the coefficients in µg/mL? Do the fitted curves differ?

B6. A column that adds nothing. Someone enters the concentration twice, in µg/mL and in mg/mL. With standards at \(0, 1000, 2000\) µg/mL, the columns are \(\mathbf a_1 = (1, 1, 1)\), \(\mathbf a_2 = (0, 1000, 2000)\), \(\mathbf a_3 = (0, 1, 2)\). (a) Run Gram–Schmidt: find \(\mathbf q_1, \mathbf q_2\) and show that for column 3 you get \(\mathbf v = \mathbf 0\). What is \(r_{33}\), and what goes wrong in the next step? (b) In floating point, \(r_{33}\) comes out as something like \(10^{-16}\) rather than exactly 0. Why does software need a tolerance here? What does lm report for the third coefficient?

In code

C1. The qPCR standard curve. Use the 21 qPCR standards from the Background. (a) Solve the normal equations with crossprod and solve (Python: A.T @ A and np.linalg.solve). Compare with lm (Python: np.linalg.lstsq). (b) Compute the residuals, check \(A^T\mathbf r \approx \mathbf 0\), and the residual sum of squares. (c) Compute the efficiency and the copy number of two unknowns with Cq 24.0 and 30.5. Is either outside the range of the standards?

C2. \(\kappa(A^TA) = \kappa(A)^2\). (a) For the qPCR design matrix, compute \(\kappa(A)\), \(\kappa(A^TA)\) and \(\kappa(A)^2\) with kappa(..., exact = TRUE) (Python: np.linalg.cond). (b) For the BCA standards, build the Vandermonde matrix with columns \(1, x, \dots, x^d\) for \(d = 1, \dots, 4\) (R: outer(conc, 0:d, "^"); Python: np.vander(conc, d + 1, increasing=True)). Print \(\kappa(A)\) and \(\kappa(A)^2\) in µg/mL, and \(\kappa(A)\) with \(x\) in mg/mL. From which degree is \(\kappa(A^TA)\) above \(1/\varepsilon \approx 4.5\times10^{15}\)? Compare with B5.

C3. Läuchli’s example in code. Check B2: for \(\delta = 10^{-6}\) and \(10^{-8}\), solve with the normal equations and with QR, \(\mathbf b = (2, \delta, \delta)\) (exact solution \((1, 1)\)). Print 15 decimals. In R use qr.solve(A, b, tol = 1e-12); what happens with the default tol?

C4. Gram–Schmidt, classical and modified. (a) Write gs(A, modified) returning \(Q\) and \(R\) (fact 5). Check B3: \(R\) and the solution of \(R\mathbf x = Q^T\mathbf b\) (R: backsolve; Python: scipy.linalg.solve_triangular). (b) For Vandermonde matrices on 50 equally spaced points in \([0, 1]\), degrees \(d = 2, 4, \dots, 12\), print \(\kappa(A)\) and the loss of orthogonality \(\|Q^TQ - I\|_2\) for classical GS, modified GS and the library’s Householder QR (R: qr.Q(qr(A)); Python: np.linalg.qr(A)[0]). C5. Digits lost: normal equations vs QR. Same Vandermonde matrices, degrees \(d = 1, \dots, 12\). Make data with known coefficients, \(\mathbf x_\text{true} = (1, \dots, 1)\) and \(\mathbf b = A\mathbf x_\text{true}\). Solve by the normal equations and by QR, and print \(\kappa(A)\) and the relative error \(\|\mathbf x - \mathbf x_\text{true}\| / \|\mathbf x_\text{true}\|\) of each. Compare with \(\kappa^2\varepsilon\) and \(\kappa\varepsilon\). (If solve stops with an error, record NA.)

C6. The BCA calibration. (a) Fit a cubic in µg/mL by the normal equations and by QR. What does each language do? (b) Repeat in mg/mL. (c) Fit degrees 1, 2 and 3 (mg/mL, by QR). For each print the residual sum of squares and the signs of the residuals in order of concentration. Which degree would you use? (d) An unknown sample reads 0.70. Read off its concentration from the quadratic (solve \(c_2 s^2 + c_1 s + c_0 = 0.70\) with the quadratic formula, taking the root inside the standard range).

C7. Dependent columns. Fit \(a_{562}\) on an intercept, conc (µg/mL) and mgml = conc / 1000, as in B6. What do lm, qr()$rank and solve on the normal equations report? Python: np.linalg.lstsq (look at the returned rank and coefficients) and np.linalg.matrix_rank. Rust: the diagonal of \(R\) and nalgebra’s rank.

Explore

The demo below fits a polynomial of degree \(d\) to the standards of the BCA assay or the qPCR curve, in your browser, by both routes: the normal equations (form \(A^TA\) and \(A^T\mathbf b\) in doubles, then Gaussian elimination with pivoting, as solve does) and Householder QR (\(R\mathbf x = Q^T\mathbf b\)). Panel (a) shows the standards, the QR fit (solid), the normal-equations fit (dashed) and the residuals as vertical segments, with a magnified residual strip below. You can drag any standard up or down. Panel (b) shows, for every degree, the relative error \(\|\mathbf x - \mathbf x_\text{exact}\| / \|\mathbf x_\text{exact}\|\) of the coefficients from each route, with the lines \(\kappa^2\varepsilon\) and \(\kappa\varepsilon\) for \(\kappa = \kappa(A)\) in the chosen units. The right-hand axis turns the error into correct digits. The exact least-squares solution is computed in exact fractions (big-integer arithmetic), so the error you see is the rounding error of the route itself. Degrees where \(\kappa(A^TA) = \kappa(A)^2 > 1/\varepsilon\) are shaded: at those degrees R’s solve stops with “computationally singular”. Click a degree in panel (b) to select it.

The browser computes in the same IEEE doubles as R and Python, so \(\kappa\), the coefficients and the RSS agree with the lecture. The last digits of the errors depend on the order of the additions, so your own C5 errors will differ somewhat from the ones shown here, but their size will not.

The quadratic removes the systematic error; the cubic only fits noise a little better. Use \(d = 2\), as in C6.

Hints

Hint 1 — normal equations by hand (B1)

\(\sum t_i = 10\), \(\sum t_i^2 = 30\). For a 2×2 system \(\begin{pmatrix} p & q\\ q & s\end{pmatrix}\mathbf x = \begin{pmatrix} u\\ w\end{pmatrix}\): \(x_1 = (su - qw)/D\), \(x_2 = (pw - qu)/D\) with \(D = ps - q^2\). \(A^T\mathbf r = \mathbf 0\) means \(\sum r_i = 0\) and \(\sum t_i r_i = 0\). For the efficiency, \(10^{0.3012} \approx 2.001\).

Hint 2 — stretches and conditioning (B2, B5)

For a matrix whose columns are perpendicular, the stretches are the column lengths. In general, $|Ae_j| = $ length of column \(j\), so \(\kappa(A) \ge \max_j\|\mathbf a_j\| / \min_j\|\mathbf a_j\|\). A number \(1 + y\) with \(|y| < \varepsilon/2\) is stored as exactly 1.

Hint 3 — Gram–Schmidt (B3, B6, C4)

\(\mathbf q_1\) is \(\mathbf a_1\) divided by its length. \(r_{12} = \mathbf q_1^T\mathbf a_2\); subtracting \(r_{12}\mathbf q_1\) when \(\mathbf q_1\) is the normalised column of ones subtracts the mean. In code, loop over columns \(j\) and earlier columns \(i < j\); the only difference between classical and modified is whether the inner product uses the original column or the current \(\mathbf v\). The 2-norm of a matrix: R norm(M, "2"); Python np.linalg.norm(M, 2); Rust the largest singular value.

Hint 4 — Householder (B4)

Use the form \(H\mathbf a = \mathbf a - 2\frac{\mathbf v^T\mathbf a}{\mathbf v^T\mathbf v}\mathbf v\); there is no need to build \(H\). For (c): \(\|\mathbf a\| = \sqrt{1 + 10^{-10}} \approx 1 + 5\times10^{-11}\), stored with an absolute error up to about \(10^{-16}\).

Hint 5 — QR in each language (C1, C3–C6)

R: qr.solve(A, b), or f <- qr(A); backsolve(qr.R(f), crossprod(qr.Q(f), b)); lm for formulas. Python: Q, R = np.linalg.qr(A) (reduced: \(Q\) is \(m\times n\)), then solve_triangular(R, Q.T @ b); or np.linalg.lstsq(A, b, rcond=None) (SVD). Rust: let qr = a.clone().qr(); qr.q_tr_mul(&mut b) overwrites b with \(Q^T\mathbf b\); then qr.r().solve_upper_triangular(&b.rows(0, n).into_owned()). Condition numbers in Rust: a.singular_values(), largest over smallest.

Hint 6 — polynomial calibration (C2, C6)

R: outer(x, 0:d, "^") gives columns \(x^0, \dots, x^d\); poly(x, d) gives orthogonal columns. Python: np.vander(x, d + 1, increasing=True). Residual signs: paste(ifelse(r > 0, "+", "-"), collapse = "") in R, "".join("+" if v > 0 else "-" for v in r) in Python. In (d), \(c_2 < 0\); check that your root lies between 0 and 2 mg/mL.

Hint 7 — rank (C7)

R: qr() returns $rank, decided with tol = 1e-7; diag(qr.R(f)) shows the diagonal. Python: x, res, rank, sv = np.linalg.lstsq(X, b, rcond=None). Rust: qr.r().diagonal(), and X.rank(eps) (from the SVD) counts singular values above eps.

B2. (a) \(\|A\mathbf v\|^2 = v_1^2 + \delta^2v_2^2\), largest 1 (at \(\mathbf v = \mathbf e_1\)), smallest \(\delta\) (at \(\mathbf e_2\)). \(\kappa(A) = 1/\delta = 10^3\). \(A^TA = \begin{pmatrix}1 & 0\\ 0 & \delta^2\end{pmatrix}\), \(\kappa(A^TA) = 1/\delta^2 = 10^6\): the square. (b) \(A^TA = \begin{pmatrix} 1 + \delta^2 & 1\\ 1 & 1 + \delta^2\end{pmatrix}\). (c) \(\delta^2 = 10^{-16} < \varepsilon/2\), so \(1 + \delta^2\) is stored as exactly \(1\). The computed \(A^TA = \begin{pmatrix}1 & 1\\1 & 1\end{pmatrix}\) is singular. But \(A\) has rank 2: rows 2 and 3, \((\delta, 0)\) and \((0, \delta)\), are independent. All the information that separates the two predictors was in \(\delta^2\), and it was rounded away when \(A^TA\) was formed. (d) A good method loses about \(\log_{10}(1.4\times10^8) \approx 8\) digits, so about 8 of 16 remain. The normal equations would lose about 16, i.e. all of them; here they do not even get an answer.

B3. (a) \(r_{11} = \sqrt3\), \(\mathbf q_1 = (1,1,1)/\sqrt3\). \(r_{12} = \mathbf q_1^T\mathbf a_2 = 9/\sqrt3 = 3\sqrt3 \approx 5.196\). \(\mathbf v = \mathbf a_2 - 3\sqrt3\,\mathbf q_1 = (1,3,5) - (3,3,3) = (-2, 0, 2)\). \(r_{22} = \sqrt8 = 2\sqrt2 \approx 2.828\), \(\mathbf q_2 = (-1, 0, 1)/\sqrt2\). \[R = \begin{pmatrix}\sqrt3 & 3\sqrt3\\ 0 & 2\sqrt2\end{pmatrix} \approx \begin{pmatrix} 1.732 & 5.196\\ 0 & 2.828\end{pmatrix}\] (b) \(\mathbf q_1^T\mathbf q_2 = (-1 + 0 + 1)/\sqrt6 = 0\). \(3\sqrt3\,\mathbf q_1 + 2\sqrt2\,\mathbf q_2 = (3,3,3) + (-2, 0, 2) = (1, 3, 5)\). B4. (a) \(\|\mathbf a\| = \sqrt{4 + 1 + 4} = 3\). \(\mathbf v = (2 + 3, 1, 2) = (5, 1, 2)\), \(\mathbf v^T\mathbf v = 30\), \(\mathbf v^T\mathbf a = 10 + 1 + 4 = 15\). \(H\mathbf a = \mathbf a - 2\cdot\tfrac{15}{30}\mathbf v = \mathbf a - \mathbf v = (-3, 0, 0)\). (b) An orthogonal \(H\) keeps lengths, so the result has length 3 and all of it is in the first component: two zeros were created without changing the size of anything. A non-orthogonal transformation (like an elimination step) can change lengths, and with them the size of the rounding errors already present. (c) \(\|\mathbf a\| = \sqrt{1 + 10^{-10}} = 1.00000000005\). With the sign in fact 6, \(a_1 + \|\mathbf a\| = 2.00000000005\): no cancellation. With the other sign, \(a_1 - \|\mathbf a\| = -5\times10^{-11}\): the difference of two numbers that agree in 10 digits. The stored \(\|\mathbf a\|\) has an absolute error up to about \(10^{-16}\), which relative to \(5\times10^{-11}\) is about \(2\times10^{-6}\): some 10 of the 16 digits of \(v_1\) are lost (catastrophic cancellation, as in Error, conditioning and stability).

B5. (a) µg/mL: \(A = \begin{pmatrix}1 & 0 & 0\\ 1 & 1000 & 10^6\\ 1 & 2000 & 4\times10^6\end{pmatrix}\). mg/mL: \(A = \begin{pmatrix}1 & 0 & 0\\ 1 & 1 & 1\\ 1 & 2 & 4\end{pmatrix}\). (c) mg/mL: \(1.73\), \(2.24\), \(4.12\), bound \(\kappa \ge 2.4\). fn kappa(a: &DMatrix<f64>) -> f64 {
    let sv = a.clone().singular_values();
    sv.max() / sv.min()
}

// columns 1, x, x^2, ..., x^d

}

fn sci(x: f64, digits: usize) -> String {
    let s = format!("{:.*e}", digits, x);
    let (m, e) = s.split_once('e').unwrap();
    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

fn gs(a: &DMatrix<f64>, modified: bool) -> (DMatrix<f64>, DMatrix<f64>) {
    let n = a.ncols();
    let mut q = a.clone();
    let mut r = DMatrix::zeros(n, n);
    for j in 0..n {
        let mut v: DVector<f64> = a.column(j).into_owned();
        for i in 0..j {
            r[(i, j)] = if modified { q.column(i).dot(&v) } else { q.column(i).dot(&a.column(j)) };
            v -= r[(i, j)] * q.column(i);
        }
        r[(j, j)] = v.norm();
        q.set_column(j, &(v / r[(j, j)]));
    }
    (q, r)
}

fn orth(q: &DMatrix<f64>) -> f64 {
    // 2-norm of Q^T Q - I = its largest singular value
    let e = q.transpose() * q - DMatrix::identity(q.ncols(), q.ncols());
    e.singular_values().max()
}

fn kappa(a: &DMatrix<f64>) -> f64 {
    let sv = a.clone().singular_values();
    sv.max() / sv.min()
}

use nalgebra::DMatrix;

// scientific notation as R and Python print it: 2.2e+01 rather than Rust's 2.2e1
fn sci(x: f64, digits: usize) -> String {
    let s = format!("{:.*e}", digits, x);
    let (m, e) = s.split_once('e').unwrap();
    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

fn main() {
    let conc: Vec<f64> = [0., 25., 125., 250., 500., 750., 1000., 1500., 2000.]
        .iter().flat_map(|&c| [c; 2]).collect();
    let x = DMatrix::from_fn(conc.len(), 3, |i, j| match j {
        0 => 1.0,
        1 => conc[i],
        _ => conc[i] / 1000.0,
    });
    let r = x.clone().qr().r();
    let diag: Vec<String> = r.diagonal().iter().map(|&d| sci(d, 6)).collect();
    println!("{}", diag.join(" "));
    // numerical rank: diagonal entries above a relative tolerance (as R's tol = 1e-7)
    let rmax = r.diagonal().amax();
    let rank = r.diagonal().iter().filter(|d| d.abs() > 1e-7 * rmax).count();
    println!("{}", rank);
    println!("{}", x.rank(1e-7 * x.singular_values().max()));    // via the SVD
}
