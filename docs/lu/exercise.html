Exercise: Gaussian elimination as LU

Goal

By the end of this exercise you should be able to:

  • run Gaussian elimination on a 3×3 matrix by hand and record the multipliers,
  • write the result as an LU factorisation \(A = LU\) and check it by multiplying out,
  • solve \(A\mathbf x = \mathbf b\) for a new \(\mathbf b\) by forward and back substitution alone,
  • count the operations: about \(\tfrac23 n^3\) to factorise, \(2n^2\) per solve, and use that to choose between factor once, solve many and refactorising,
  • explain why solve(A) %*% b is slower and less accurate than solve(A, b),
  • recognise a zero or tiny pivot, and run the checks (is.finite, the residual) that catch it.

The biology throughout is the isotope mixing model: which fraction of a consumer’s diet came from each source. The by-hand part uses pen and paper only.

Background

A consumer’s isotope signature is a weighted average of its diet sources (after correcting for trophic enrichment). With \(k\) isotopes and \(k+1\) sources, the mass balance for each isotope plus “fractions sum to 1” gives a square system \(A\mathbf f = \mathbf b\): the columns of \(A\) are the sources, \(\mathbf b\) is the consumer.

Facts used below:

  1. Elimination. At step \(k\), the pivot is \(u_{kk}\); row \(i > k\) gets row \(k\) times the multiplier \(\ell_{ik} = u_{ik}/u_{kk}\) subtracted from it. After \(n-1\) steps the matrix is upper triangular, \(U\).
  2. LU. Put the multipliers below the diagonal of a unit lower triangular \(L\) (1s on the diagonal). Then \(A = LU\).
  3. Solving with the factors. \(L\mathbf y = \mathbf b\) by forward substitution (top to bottom), then \(U\mathbf x = \mathbf y\) by back substitution (bottom to top).
  4. Cost. Factorising \(\approx \tfrac23 n^3\) operations; each forward + back substitution \(\approx 2n^2\). A computer does roughly \(10^9\) simple operations per second per core.
  5. Inverse. Computing \(A^{-1}\) costs \(\approx 2n^3\), and multiplying by it is less accurate than substituting.
  6. Pivots. A zero pivot stops elimination (division by zero); a tiny one gives huge multipliers and a wrong answer. Libraries reorder rows (partial pivoting): \(A = PLU\). Pivoting is the topic of Pivoting, norms and conditioning.
  7. Residual \(\mathbf r = \mathbf b - A\mathbf x\). A good solver gives \(\max|r_i|\) near \(\varepsilon\cdot\max|a_{ij}|\cdot\max|x_j|\).

A salt-marsh example: a ribbed mussel feeds on Spartina (marsh grass, \(\delta^{13}\)C \(= -13\) ‰, \(\delta^{34}\)S \(= +6\) ‰), phytoplankton (\(-21\), \(+18\)) and upland C3 plant detritus (\(-27\), \(+2\)). The basic tools in each language:

  • Python
  • Rust
library(Matrix)
A <- rbind(c(  1,   1,   1),      # fractions sum to 1
           c(-13, -21, -27),      # d13C: Spartina, phytoplankton, upland C3
           c(  6,  18,   2))      # d34S
b <- c(1, -18.4, 11.6)            # one ribbed mussel
solve(A, b)                       # factorise + substitute, in one call
# [1] 0.4 0.5 0.1
F <- lu(A)                        # factorise once ...
solve(F, b)                       # ... substitute as often as needed
# [1] 0.4 0.5 0.1

use nalgebra::{dmatrix, dvector};

fn main() {
    let a = dmatrix![  1.0,   1.0,   1.0;      // fractions sum to 1
                     -13.0, -21.0, -27.0;      // d13C: Spartina, phytoplankton, upland C3
                       6.0,  18.0,   2.0];     // d34S
    let b = dvector![1.0, -18.4, 11.6];        // one ribbed mussel
    let f = a.clone().lu();                    // factorise once ...
    let x = f.solve(&b).expect("singular");    // ... substitute as often as needed
    println!("{:?}", x.as_slice());
}

// Output:
// [0.39999999999999997, 0.5, 0.1]

R prints 7 significant digits, numpy 8, and Rust’s {:?} prints every digit needed to identify the double, so Rust shows 0.39999999999999997 where R shows 0.4. They are the same number up to the last bit or two. Python’s library calls are numpy.linalg.solve, scipy.linalg.lu_factor and scipy.linalg.lu_solve; Rust uses nalgebra’s LU (.lu(), .solve()).

By hand

B1. Elimination, as in your first course. The mussel above has signature \(\delta^{13}\)C \(= -18.4\) ‰, \(\delta^{34}\)S \(= 11.6\) ‰. (a) Write the system \(A\mathbf f = \mathbf b\) as an augmented matrix \([A \mid \mathbf b]\). (b) Eliminate below the diagonal. Write down each multiplier \(\ell_{ik}\) as you use it. (c) Back-substitute for \(f_1, f_2, f_3\). What fraction of the mussel’s diet is phytoplankton?

B2. The multipliers make \(L\). (a) From B1, write \(L\) (multipliers below the diagonal, 1s on it) and \(U\) (the eliminated \(A\), without the \(\mathbf b\) column). (b) Multiply out \(LU\) and check that you get \(A\). (c) Look at the \(\mathbf b\) column at the end of B1(b). Which triangular system with \(L\) does that column solve?

B3. A second mussel, without eliminating again. A second mussel has \(\delta^{13}\)C \(= -22.4\) ‰, \(\delta^{34}\)S \(= 7.6\) ‰. (a) Solve \(L\mathbf y = \mathbf b\) by forward substitution, then \(U\mathbf f = \mathbf y\) by back substitution. (b) Count the multiplications, additions/subtractions and divisions in (a). Then count those that eliminating \(A\) itself took in B1(b) (ignore the \(\mathbf b\) column). Which part would you redo for a third mussel?

B4. An LU with no biology. Factorise \[A = \begin{pmatrix} 2 & 1 & 1 \\ 4 & 3 & 3 \\ 8 & 7 & 9 \end{pmatrix}.\] (a) Give \(L\) and \(U\). (b) The determinant of a triangular matrix is the product of its diagonal, and \(\det(LU) = \det L \cdot \det U\). What is \(\det A\)? (c) Solve \(A\mathbf x = (4, 10, 24)^T\) with your factors.

B5. A zero pivot. Three diet sources: C3 plants (\(\delta^{13}\)C \(= -26\), \(\delta^{15}\)N \(= 2\)), freshwater fish (\(-26\), \(10\)) and maize (\(-10\), \(6\)). Rows: sum to 1, \(\delta^{13}\)C, \(\delta^{15}\)N. (a) Write \(A\) and do the first elimination step. What goes wrong at step 2? (b) Swap rows 2 and 3 of \(A\) (and of \(\mathbf b\)), and factorise again. Give \(L\) and \(U\). (c) Solve for a consumer with \(\delta^{13}\)C \(= -20\), \(\delta^{15}\)N \(= 6.5\). (d) Now suppose the fish had \(\delta^{15}\)N \(= 2\) as well (the same signature as the C3 plants in both isotopes). Eliminate. Does any row swap help? What does that mean for the diet estimate?

B6. Counting the cost. (a) Use B3(b) to give the exact operation counts for \(n = 3\). Compare with \(\tfrac23 n^3\) and \(2n^2\). (b) For \(n = 1000\), how many operations are one factorisation and one solve? Roughly how many seconds at \(10^9\) operations per second? (c) An implicit model of tracer diffusion in tissue (Part 11) solves a system with the same \(5000 \times 5000\) matrix at each of 1000 time steps. Estimate the time if you factorise at every step, and if you factorise once. (Treat the matrix as dense.) (d) A study has 10 000 consumers and a 3×3 mixing matrix. Does the choice between refactorising and factor-once matter for the operation count?

B7. Why not the inverse. (a) Accuracy, \(1 \times 1\). Work in decimal arithmetic with 3 significant digits (round after every operation). Solve \(7x = 63\) (i) by division, \(x = 63/7\), and (ii) via the inverse, \(x = (1/7) \cdot 63\). (b) Cost. Computing \(A^{-1}\) means solving \(A\mathbf x_j = \mathbf e_j\) for \(j = 1, \dots, n\). With the counts from the lecture, what does that cost, compared with one factorisation? (Use \(2n^2\) per column, ignoring that the \(\mathbf e_j\) are mostly zeros.) (c) For \(m\) right-hand sides, write the total cost of the inverse route and of the factor-once route. Does the inverse ever win?

In code

C1. Write it yourself. Write lu_nopivot(A), forward_sub(L, b) and back_sub(U, y) (the lecture has the R versions). (a) Check your B1–B3 answers: print \(L\), \(U\), \(\max|LU - A|\), and \(\mathbf y\) and \(\mathbf f\) for both mussels. (b) Check B4: \(L\), \(U\), and \(\det A\) from the diagonal of \(U\); compare with the built-in determinant.

C2. The library LU. Factorise the salt-marsh \(A\) with Matrix::lu (Python: scipy.linalg.lu for \(P, L, U\) and lu_factor for solving; Rust: a.lu()). (a) Print \(L\) and \(U\). Why are they different from yours? Which row became the first pivot row, and why that one? (b) Check that \(PLU\) (or \(P^TLU\), depending on the convention) gives back \(A\). (c) Solve for both mussels with one call, putting the two right-hand sides as columns of a matrix.

phytoplankton \(-21\) 8 18

Build all 286 diets whose fractions are multiples of 0.1 and sum to 1 (loop \(i, j, k\) from 0 with \(i + j + k \le 10\), fractions \((i, j, k, 10 - i - j - k)/10\), in that loop order), compute each consumer’s signature, and add the deterministic “measurement noise” \(0.2\sin t\), \(0.2\cos t\), \(0.2\sin 2t\) to the three isotopes of consumer \(t = 1, \dots, 286\).

C4. Cost of factorising vs substituting. For random \(n \times n\) matrices with \(n = 250, 500, 1000, 2000\), time one factorisation and one solve with the factors (repeat each several times and average). Print the times and their ratio. Compare the doubling ratios with 8 and 4. (Optional: start R or Python with the environment variable OPENBLAS_NUM_THREADS=1 to time on one core; in Rust use --release.)

C5. Factor once, solve many. For a random \(1000 \times 1000\) matrix and 200 right-hand sides used one at a time (in a loop), time three strategies: (i) solve(A, b) for each \(\mathbf b\), (ii) factorise once, then solve with the factors for each \(\mathbf b\), (iii) invert once, then multiply each \(\mathbf b\) by the inverse. Predict the ratio of (i) to (ii) from C4 first.

C6. The inverse is less accurate. The four-source matrix from the lecture has sources 1 and 2 that differ by \(d\) in every isotope: \[A_4 = \begin{pmatrix} 1 & 1 & 1 & 1 \\ -26 & -26 + d & -10 & -18 \\ 2 & 2 + d & 6 & 14 \\ 4 & 4 + 2d & 3 & 19 \end{pmatrix}, \qquad \mathbf f = (0.3, 0.2, 0.4, 0.1)^T.\] For \(d = 1, 10^{-1}, \dots, 10^{-6}\), compute \(\mathbf b = A_4\mathbf f\), then \(\mathbf x\) both with solve(A4, b) and with solve(A4) %*% b (Python: np.linalg.inv). Print the maximum residual and the maximum error of each. Which of the two is consistently better, and in which quantity?

C7. Zero and tiny pivots. (a) Run your lu_nopivot on the matrix from B5. Write a one-line check that detects the failure. Then swap rows 2 and 3, factorise, and solve for the consumer in B5(c). (b) Run lu_nopivot with forward and back substitution on \(\begin{pmatrix} 10^{-20} & 1 \\ 1 & 1\end{pmatrix}\mathbf x = \begin{pmatrix} 1 \\ 2\end{pmatrix}\). Does your check from (a) catch this? Compute the residual of your answer and of the library’s.

E1. (the multipliers fill \(L\)) Before you start, write down your operation count for eliminating a \(3\times3\) matrix from B3(b). In tab 1, click next ▶ through the elimination. For each step write down the multiplier, where it lands in \(L\) and the new row of \(U\), and check the running operation count against your own. Look at the check panel at every step, including the middle ones where \(L\) still has grey zeros. What does it show, and why does it hold even halfway?

Answer E1

Step 1: \(\ell_{21} = -26 \div 1 = -26\), row 2 of \(U\) becomes \((0, 16, 8)\), 5 operations. Step 2: \(\ell_{31} = 2 \div 1 = 2\), row 3 becomes \((0, 4, 12)\), 10 so far. Step 3: \(\ell_{32} = 4 \div 16 = \tfrac14\), row 3 becomes \((0, 0, 10)\), 13 in total. These are the \(L\) and \(U\) of the lecture. The check panel shows \(L\cdot U = A\) ✓ at every step. Each step subtracts \(\ell_{ik}\) times row \(k\) from row \(i\) of \(U\) and at the same time writes \(\ell_{ik}\) into \(L\), and multiplying by \(L\) adds that multiple back. The two changes cancel in the product, so no information is lost at any point. The grey zeros are multipliers not computed yet; those rows have not been touched.

E2. (forward substitution replays elimination) Switch to tab 2. Consumer #1 is solved. Read off \(\mathbf y\) and compare it with the slide “Why triangular is good”. Then click consumers #2 and #3. Write down \(\mathbf y\) and the diet for each. Does the operation count per sample agree with your count for one forward + back substitution in B3(b)? Which numbers stay the same from one consumer to the next?

Answer E2

Consumer #1: \(\mathbf y = (1, 6.4, 2)\), \(\mathbf f = (0.5, 0.3, 0.2)\), as on the slide. Consumer #2: \(\mathbf y = (1, 11.2, 2)\), \(\mathbf f = (0.2, 0.6, 0.2)\). E3. (a consumer outside the triangle) Click consumer #4. Which fraction is negative? Where is the consumer in the isotope plot? Did anything go wrong numerically?

Answer E3

\(\mathbf y = (1, 2, 6.5)\) and \(\mathbf f = (0.55, -0.20, 0.65)\): maize gets \(-20\) %. The point \((-24, 9)\) lies outside the source triangle (red dot), to the upper left of the C3–fish edge. E4. (when does factor once pay?) Click reset count, then solve another sample ▶ ten times. Read both totals and the ratio for \(n = 3\). Then click \(n = 1000\) (the same counts for a \(1000\times1000\) matrix). Why does keeping \(L\) and \(U\) gain so little for the \(3 \times 3\) mixing model and so much for \(n = 1000\)? What does the ratio approach for very many samples in each case?

Answer E4

After 10 samples with \(n = 3\): re-eliminating costs \(10 \cdot 28 = 280\) operations, factor once \(13 + 10\cdot 15 = 163\), 1.72 times fewer. With \(n = 1000\): \(6.7\cdot10^9\) against \(6.9\cdot10^8\), 9.74 times fewer. For \(n = 3\) the factorisation (13) costs about as much as one solve (15), so skipping it saves at most a factor \(28/15 = 1.87\). For \(n = 1000\) one factorisation (\(\approx \tfrac23 n^3 = 6.7\cdot10^8\)) costs as much as 333 solves (\(2n^2 = 2\cdot10^6\)). For \(m \ll 333\) the saving is about \(m\), and for very many samples it approaches \((F + S)/S \approx 334\). This is the \(n/3\) ratio from the lecture’s cost table. A 10 000-consumer study with a \(3\times3\) matrix does not care (B6(d)). A \(1000\times1000\) implicit time step does.

E5. (a zero pivot) Do B5(a)–(c) by hand first. Then click zero pivot (two sources at −26 ‰) and run to end in tab 1. Does elimination stop where you found in B5(a), and what would lu_nopivot store in row 3? Try tab 2. Then go back, click the swap button, and step through again. Do \(L\), \(U\) and the diet of consumer #1 in tab 2 agree with your B5(b) and (c)? If not, find the first step where they differ.

Answer E5

After step 1, \(U\) has rows \((1, 1, 1)\), \((0, 0, 16)\), \((0, 8, 4)\): the pivot \(u_{22}\) is 0, and \(\ell_{32} = 8 \div 0\) is impossible. In doubles, \(\ell_{32} = \text{Inf}\) and row 3 becomes \((0, \text{NaN}, -\text{Inf})\), as on the lecture slide, with no error message. Tab 2 has no factors to reuse. After swapping rows 2 and 3: \(\ell_{21} = 2\), \(\ell_{31} = -26\), \(\ell_{32} = 0 \div 8 = 0\), so \(L = \begin{pmatrix} 1&0&0\\2&1&0\\-26&0&1\end{pmatrix}\) and \(U = \begin{pmatrix} 1&1&1\\0&8&4\\0&0&16\end{pmatrix}\), again 13 operations and \(L\cdot U\) equal to the reordered \(A\). Consumer #1, reordered to \(P\mathbf b = (1, 6.5, -20)\), gives \(\mathbf y = (1, 4.5, 6)\) and \(\mathbf f = (0.25, 0.375, 0.375)\), the answer of B5(c). (The usual slip: forgetting to swap the entries of \(\mathbf b\) along with the rows of \(A\).) The matrix was never singular; the rows were only in an unlucky order. Choosing that order automatically is partial pivoting, in the next unit.

Hints

Hint 1 — elimination and multipliers (B1, B2, B4)

The multiplier is (entry to be zeroed) / (pivot), and you subtract multiplier × pivot row. With a negative entry below a pivot of 1, the multiplier is negative and you end up adding a multiple. Keep each multiplier in the position of the zero it created: that is \(L\). To check \(LU = A\), row \(i\) of \(LU\) is \(\sum_k \ell_{ik} \times\) (row \(k\) of \(U\)).

Hint 2 — forward and back substitution (B3)

Forward: \(y_1 = b_1\) (the diagonal of \(L\) is 1), then \(y_2 = b_2 - \ell_{21}y_1\), \(y_3 = b_3 - \ell_{31}y_1 - \ell_{32}y_2\). Back: \(x_3 = y_3/u_{33}\), then \(x_2 = (y_2 - u_{23}x_3)/u_{22}\), \(x_1 = (y_1 - u_{12}x_2 - u_{13}x_3)/u_{11}\). Count one multiplication and one subtraction for each off-diagonal term.

Hint 3 — zero pivots (B5, C7)

A zero pivot means you cannot divide. Look below it in the same column: if there is a nonzero entry, swapping that row up fixes the problem; if the whole column below (and including) the pivot is zero, the matrix is singular. In code, a division by zero gives Inf or NaN without an error: test with is.finite (Python np.isfinite, Rust f64::is_finite).

Hint 4 — costs (B6, B7)

\(\tfrac23 \cdot 1000^3 \approx 6.7\times10^8\); \(\tfrac23 \cdot 5000^3 \approx 8.3\times10^{10}\); \(2 \cdot 5000^2 = 5\times10^7\). One day is \(8.64\times10^4\) s. For the inverse: one factorisation plus \(n\) solves.

Hint 5 — library functions (C2, C3, C5)

R: lu() in the Matrix package, expand2() to get \(P\), \(L\), \(U\) with \(A = P_1 L U\), and solve(F, b) on the lu object; solve(A, B) with a matrix B solves for every column with one factorisation. Base R also has forwardsolve and backsolve. Python: scipy.linalg.lu returns P, L, U with A = P @ L @ U; lu_factor / lu_solve keep the factors compactly; solve_triangular does one substitution. Rust: nalgebra::linalg::LU has .l(), .u(), .p() (with \(PA = LU\)), .solve() and .try_inverse().

Hint 6 — timing (C4, C5)

R: system.time(for (k in 1:5) F <- lu(A))["elapsed"] / 5. Python: time.perf_counter() before and after a loop. Rust: std::time::Instant::now() and .elapsed().as_secs_f64(), built with --release. A single solve takes well under a millisecond, so repeat it 100 times inside one timing.

lu_nopivot <- function(A) {
  n <- nrow(A); L <- diag(n); U <- A
  for (k in 1:(n - 1)) {
    for (i in (k + 1):n) {
      L[i, k] <- U[i, k] / U[k, k]                       # multiplier l_ik
      U[i, k:n] <- U[i, k:n] - L[i, k] * U[k, k:n]       # row i minus l_ik * row k
    }
  }
  list(L = L, U = U)
}
forward_sub <- function(L, b) {          # solve L y = b, top to bottom
  n <- length(b); y <- numeric(n)
  for (i in 1:n) {
    j <- seq_len(i - 1)                  # columns 1..i-1
    y[i] <- (b[i] - sum(L[i, j] * y[j])) / L[i, i]
  }
  y
}
back_sub <- function(U, y) {             # solve U x = y, bottom to top
  n <- length(y); x <- numeric(n)
  for (i in n:1) {
    j <- seq_len(n - i) + i              # columns i+1..n
    x[i] <- (y[i] - sum(U[i, j] * x[j])) / U[i, i]
  }
  x
}

import numpy as np

def lu_nopivot(A):
    n = A.shape[0]
    L = np.eye(n)
    U = A.astype(float).copy()
    for k in range(n - 1):                       # pivot column k
        for i in range(k + 1, n):                # rows below the pivot
            L[i, k] = U[i, k] / U[k, k]          # multiplier l_ik
            U[i, k:] = U[i, k:] - L[i, k] * U[k, k:]   # row i - l_ik * row k
    return L, U

def forward_sub(L, b):                           # solve L y = b, top to bottom
    n = len(b)
    y = np.zeros(n)
    for i in range(n):
        y[i] = (b[i] - L[i, :i] @ y[:i]) / L[i, i]
    return y

def back_sub(U, y):                              # solve U x = y, bottom to top
    n = len(y)
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (y[i] - U[i, i + 1:] @ x[i + 1:]) / U[i, i]
    return x

use nalgebra::{dmatrix, dvector, DMatrix, DVector};

fn lu_nopivot(a: &DMatrix<f64>) -> (DMatrix<f64>, DMatrix<f64>) {
    let n = a.nrows();
    let mut l = DMatrix::<f64>::identity(n, n);
    let mut u = a.clone();
    for k in 0..n - 1 {                           // pivot column k
        for i in k + 1..n {                       // rows below the pivot
            l[(i, k)] = u[(i, k)] / u[(k, k)];    // multiplier l_ik
            for j in k..n {                       // row i - l_ik * row k
                u[(i, j)] -= l[(i, k)] * u[(k, j)];
            }
        }
    }
    (l, u)
}

fn forward_sub(l: &DMatrix<f64>, b: &DVector<f64>) -> DVector<f64> {
    let n = b.len();
    let mut y = DVector::<f64>::zeros(n);
    for i in 0..n {                               // top to bottom
        let s: f64 = (0..i).map(|j| l[(i, j)] * y[j]).sum();
        y[i] = (b[i] - s) / l[(i, i)];
    }
    y
}

fn back_sub(u: &DMatrix<f64>, y: &DVector<f64>) -> DVector<f64> {
    let n = y.len();
    let mut x = DVector::<f64>::zeros(n);
    for i in (0..n).rev() {                       // bottom to top
        let s: f64 = (i + 1..n).map(|j| u[(i, j)] * x[j]).sum();
        x[i] = (y[i] - s) / u[(i, i)];
    }
    x
}

}

use nalgebra::{dmatrix, dvector, DMatrix, DVector};

fn lu_nopivot(a: &DMatrix<f64>) -> (DMatrix<f64>, DMatrix<f64>) {
    let n = a.nrows();
    let mut l = DMatrix::<f64>::identity(n, n);
    let mut u = a.clone();
    for k in 0..n - 1 {
        for i in k + 1..n {
            l[(i, k)] = u[(i, k)] / u[(k, k)];
            for j in k..n {
                u[(i, j)] -= l[(i, k)] * u[(k, j)];
            }
        }
    }
    (l, u)
}

fn forward_sub(l: &DMatrix<f64>, b: &DVector<f64>) -> DVector<f64> {
    let n = b.len();
    let mut y = DVector::<f64>::zeros(n);
    for i in 0..n {
        let s: f64 = (0..i).map(|j| l[(i, j)] * y[j]).sum();
        y[i] = (b[i] - s) / l[(i, i)];
    }
    y
}

fn back_sub(u: &DMatrix<f64>, y: &DVector<f64>) -> DVector<f64> {
    let n = y.len();
    let mut x = DVector::<f64>::zeros(n);
    for i in (0..n).rev() {
        let s: f64 = (i + 1..n).map(|j| u[(i, j)] * x[j]).sum();
        x[i] = (y[i] - s) / u[(i, i)];
    }
    x
}

fn show(m: &DMatrix<f64>) {
    for r in m.row_iter() {
        println!("{:?}", r.iter().collect::<Vec<_>>());
    }
}
