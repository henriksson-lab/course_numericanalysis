Exercise: Newton and secant methods

Goal

By the end of this exercise you should be able to:

  • derive and carry out Newton steps and secant steps by hand,
  • write a short Newton and secant function with a sensible stopping rule and an iteration cap,
  • read the order of convergence off a sequence of errors (digits per step), and tell quadratic, superlinear and linear convergence apart,
  • find a maximum-likelihood estimate as the root of the score function, and get its standard error from the same computation,
  • recognise the failure modes (flat derivative, bad start, cycling, wrong derivative) and the check that detects each,
  • explain what a safeguarded method (Brent: uniroot, brentq) adds, and set its tolerance.

The by-hand part uses pen, paper and a pocket calculator. The code part checks your hand answers and then works at sizes where only code works.

Background

To solve \(f(x) = 0\):

  1. Newton. Replace \(f\) near \(x_k\) by its tangent line and solve: \(x_{k+1} = x_k - f(x_k)/f'(x_k)\). Near a simple root (\(f'(x^*) \neq 0\)) the error is squared each step, \(e_{k+1} \approx \dfrac{f''(x^*)}{2f'(x^*)}\,e_k^2\): the number of correct digits doubles (order 2).
  2. Secant. Replace \(f'(x_k)\) by the slope of the chord through the last two points: \(x_{k+1} = x_k - f(x_k)\,\dfrac{x_k - x_{k-1}}{f(x_k) - f(x_{k-1})}\). One function evaluation per step, no derivative, order \(\tfrac{1+\sqrt5}{2} \approx 1.618\).
  3. Order from errors. If \(e_{k+1} \approx C e_k^p\), then \(p \approx \dfrac{\log(e_{k+1}/e_k)}{\log(e_k/e_{k-1})}\). Equivalently, the number of correct digits is multiplied by about \(p\) each step. Linear convergence (\(p = 1\), \(e_{k+1} \approx c\,e_k\)) adds a fixed number of digits per step.
  4. Stopping. Stop when \(|x_{k+1} - x_k| \le \text{tol}\cdot|x_{k+1}|\), and always cap the number of steps. Afterwards check that \(|f|\) is small and that the root is in the meaningful range.
  5. Failure. Newton and secant converge only from close enough. A small \(f'\) gives a huge step; a bad start can run off or reach a root that makes no sense (negative dose); some starts cycle. A wrong derivative or a double root (\(f'(x^*) = 0\)) makes Newton linear.
  6. Safeguarding. Brent’s method keeps a sign-change bracket \([a, b]\), takes fast steps (secant, inverse quadratic interpolation) when they stay inside, and bisects otherwise. R: uniroot (default tol \(\approx 1.2\times10^{-4}\), absolute!). Python: scipy.optimize.brentq. Rust: argmin’s BrentRoot.

The two running examples of the lecture:

  • Two-site dose–response. \(R(c) = 0.3\,\dfrac{c}{0.1 + c} + 0.7\,\dfrac{c^2}{25 + c^2}\) (dose \(c\) in µM). The dose \(c_{50}\) with \(R = 0.5\) is the root of \(f(c) = R(c) - 0.5\); \(c_{50} = 3.261305265055212\).
  • Zero-truncated Poisson. UMI counts of a gene in the 100 cells where it was detected: 52 cells with 1 UMI, 30 with 2, 12 with 3, 5 with 4, 1 with 5. The score is \(S(\lambda) = \sum_i x_i/\lambda - n/(1 - e^{-\lambda})\), with \(n = 100\), \(\sum_i x_i = 173\); the MLE is \(\hat\lambda = 1.2184695258\).

// rust/examples/newton_background.rs  —  cargo run --example newton_background
// Background: the two-site dose-response curve, a hand-written Newton, and a
// bracketing check with argmin's BrentRoot (Brent's method, as in uniroot/brentq).
use argmin::core::{CostFunction, Error, Executor};
use argmin::solver::brent::BrentRoot;

fn r(c: f64) -> f64 {
    0.3 * c / (0.1 + c) + 0.7 * c.powi(2) / (25.0 + c.powi(2))
}
fn f(c: f64) -> f64 {
    r(c) - 0.5
}
fn df(c: f64) -> f64 {
    0.03 / (0.1 + c).powi(2) + 35.0 * c / (25.0 + c.powi(2)).powi(2)
}

// returns (root, iterations); `impl Fn(f64) -> f64` accepts any function of one f64
fn newton(f: impl Fn(f64) -> f64, df: impl Fn(f64) -> f64, x0: f64, tol: f64, maxit: usize) -> (f64, usize) {
    let mut x = x0;
    for k in 1..=maxit {
        let step = f(x) / df(x);
        x -= step;
        if step.abs() <= tol * x.abs() {
            return (x, k);
        }
    }
    eprintln!("warning: no convergence after {maxit} steps");
    (x, maxit)
}

// argmin wants the function as a struct with a `cost` method
struct TwoSite;
impl CostFunction for TwoSite {
    type Param = f64;
    type Output = f64;
    fn cost(&self, c: &f64) -> Result<f64, Error> {
        Ok(f(*c))
    }
}

fn main() {
    let (root, it) = newton(f, df, 1.0, 1e-12, 50);
    println!("{}", root);
    println!("{}", it);
    let solver = BrentRoot::new(0.01, 100.0, 1e-12);
    let res = Executor::new(TwoSite, solver).configure(|s| s.max_iters(100)).run().unwrap();
    println!("{}", res.state.best_param.unwrap());
}

// 5

By hand

B1. Newton on a Hill curve. A Hill curve with \(K = 2\) µM and Hill coefficient 2 gives the equation \(f(c) = \dfrac{c^2}{4 + c^2} - \dfrac12 = 0\), with root \(c^* = K = 2\). (a) Show that \(f'(c) = \dfrac{8c}{(4 + c^2)^2}\). (b) Do two Newton steps from \(c_0 = 1\). Give the errors \(e_0, e_1, e_2\). (c) Compute \(e_1/e_0^2\) and \(e_2/e_1^2\). Compare with \(|f''(2)/(2f'(2))| = 0.25\). (d) The same root solves \(g(c) = c^2 - 4 = 0\). Show that Newton on \(g\) is \(c_{k+1} = \tfrac12(c_k + 4/c_k)\) and do three steps from \(c_0 = 1\). (This is the square-root iteration of Convergence and cost, with 4 in place of 2.) (e) Now start Newton on \(f\) at \(c_0 = 5\). Compute \(c_1\). What is wrong with it, and where do you expect the iteration to end up?

B2. Secant by hand. Use \(g(c) = c^2 - 4\). (a) Do two secant steps from \(c_0 = 1\), \(c_1 = 3\). (b) How many evaluations of \(g\) did that take? How many evaluations (\(g\) and \(g'\) counted separately) do two Newton steps take?

B3. Newton for a reciprocal. Take \(f(x) = 1/x - a\) with \(a > 0\) (root \(x^* = 1/a\)). (a) Show that Newton’s step is \(x_{k+1} = x_k(2 - a x_k)\) (no division!). (b) Write \(x_k = 1/a + e_k\) and show that \(e_{k+1} = -a\,e_k^2\) exactly. (c) With \(a = 0.5\): do three steps from \(x_0 = 1\), and two from \(x_0 = 5\). (d) From (a), for which starting values does Newton converge? (Hint: what happens if \(x_1 \le 0\)?)

B4. Reading the order. Each sequence lists errors \(e_1, e_2, \ldots\) of an iteration. (i) \(10^{-1},\ 5\times10^{-2},\ 2.5\times10^{-2},\ 1.25\times10^{-2}\) (ii) \(10^{-1},\ 10^{-2},\ 10^{-4},\ 10^{-8}\) (iii) \(10^{-1},\ 2.5\times10^{-2},\ 2.5\times10^{-3},\ 6\times10^{-5},\ 1.6\times10^{-7}\) (a) For each, give the number of correct digits (\(-\log_{10} e\)) per step, and estimate the order \(p\). (b) Starting from an error of \(10^{-2}\), how many more steps does each method need to reach \(10^{-16}\)? (For (i), assume the ratio stays \(\tfrac12\); for (ii) and (iii), assume the digit count keeps being multiplied by \(p\).)

B5. The score of a zero-truncated Poisson. (a) For a plain Poisson sample \(x_1, \ldots, x_n\), the log-likelihood is \(\ell(\lambda) = \sum_i x_i \log\lambda - n\lambda + \text{const}\). Find the score \(S(\lambda) = \ell'(\lambda)\) and solve \(S(\lambda) = 0\). (b) With zero-truncation, \(P(X = x \mid X \ge 1) = \dfrac{e^{-\lambda}\lambda^x}{x!\,(1 - e^{-\lambda})}\). Write down \(\ell(\lambda)\) and show that \(S(\lambda) = \dfrac{\sum_i x_i}{\lambda} - \dfrac{n}{1 - e^{-\lambda}}\). (c) For large \(\lambda\), \(e^{-\lambda} \approx 0\). What does \(S\) look like then? Use B3 to predict from which starting values Newton on the score fails, for our data (\(\bar x = 1.73\)). (d) One Newton step from \(\lambda_0 = \bar x = 1.73\) for our data (\(n = 100\), \(\sum x_i = 173\)). Use \(e^{-1.73} = 0.17728\) and \(S'(\lambda) = -\dfrac{\sum_i x_i}{\lambda^2} + \dfrac{n\,e^{-\lambda}}{(1 - e^{-\lambda})^2}\).

B6. Newton cycles on a Michaelis–Menten curve. In log substrate \(u = \ln(S/K_m)\) the Michaelis–Menten curve is \(v/V_{\max} = \sigma(u) = 1/(1 + e^{-u})\), and \(S = K_m\) (that is, \(u = 0\)) gives half the maximal rate. (a) Show that \(\sigma'(u) = \sigma(u)\,(1 - \sigma(u))\). (b) Show that Newton on \(\sigma(u) - \tfrac12 = 0\) is \(u_{k+1} = u_k - \sinh u_k\), with \(\sinh u = (e^u - e^{-u})/2\). (c) Do two steps from \(u_0 = 1\) (that is \(S_0 = e\,K_m\)). Use \(\sinh 1 = 1.1752\) and \(\sinh(0.1752) = 0.1761\). (d) Newton cycles between \(u^*\) and \(-u^*\) if \(u^* - \sinh u^* = -u^*\). Check that \(u^* = 2.177\) (very nearly) satisfies this, using \(e^{2.177} = 8.82\). Which substrate concentrations are these?

B7. A safeguarded step. For the two-site curve, \(f(3) = -0.0244\) and \(f(10) = 0.3570\), so \([3, 10]\) is a bracket. The rule: take the Newton step if it lands inside the current bracket, otherwise take the midpoint; then keep the half-interval with the sign change. (a) Newton from \(c = 10\) (\(f'(10) = 0.02269\)) proposes \(c = -5.73\). What does the safeguarded method do, and what is the new bracket? (\(f(6.5) = 0.2352\).) (b) From \(c = 6.5\), Newton proposes \(1.887\). What now? (\(f(4.75) = 0.1259\).) (c) From \(c = 4.75\) (\(f'(4.75) = 0.07477\)): compute the Newton proposal. Is it accepted? (d) Why can no bracketing method find the root of \((x - 1)^2\)?

In code

C1. Check the derivative, then watch Newton. (a) Compare df(c) with the forward difference \(\bigl(f(c + h) - f(c)\bigr)/h\), \(h = 10^{-6}\), at \(c = 1, 3, 10\). What relative difference do you expect (see Convergence and cost)? (b) Run Newton from \(c_0 = 1\) and from \(c_0 = 5\), printing \(k\), \(c_k\) and \(|c_k - c_{k-1}|\) (the step). How many steps does each take to stop with tol = 1e-12? Is the step a good estimate of the error of the previous iterate? (Compare with \(c_{50}\) given above.)

C2. A maximum-likelihood rate. For the zero-truncated Poisson data: (a) Write S and dS (use expm1 for \(1 - e^{-\lambda}\)), run Newton from \(\bar x\), and compute the standard error \(1/\sqrt{-S'(\hat\lambda)}\). (b) Run 50 Newton steps from each of \(\lambda_0 = 0.2, 0.5, 1, 2, 2.5, 2.7, 2.8, 3, 4\). Which starts fail? Compare with your prediction in B5(c). (c) Solve the same equation with uniroot (Python: brentq) on the bracket \([0.01, 10]\).

C3. The secant method and the order of convergence. (a) Write secant(f, x0, x1) (stop if \(f(x_1) = f(x_0)\)). Solve for \(c_{50}\) from \((1, 2)\) and for \(\hat\lambda\) from \((2, 2.5)\). (b) For the score, record the secant iterates from \((2, 2.5)\) and the Newton iterates from 2. Compute the errors (against \(\hat\lambda\) from uniroot(..., tol = 1e-15) / brentq(..., xtol=1e-15)), drop errors below \(10^{-14}\) (rounding level), and estimate the order \(p\) from every three consecutive errors. What values do you get, and why are the first few estimates useless?

C4. A wrong derivative. Suppose you forgot the weight 0.7 when differentiating the second term, so your derivative is df_bad(c) = 0.03/(0.1 + c)^2 + 50*c/(25 + c^2)^2. (a) Run 30 Newton steps from \(c_0 = 1\) with df_bad. Does it converge? Print the errors and the ratios \(e_{k+1}/e_k\). (b) What order is this? Explain the ratio: Newton with a wrong derivative \(d(x)\) is fixed-point iteration with \(g(x) = x - f(x)/d(x)\), so the ratio is \(|g'(c_{50})| = |1 - f'(c_{50})/d(c_{50})|\). Compute it. (c) How would you notice this bug if you did not know the answer?

C5. A safeguarded Newton. Write newton_safe(f, df, a, b, x0) that keeps a sign-change bracket \([a, b]\): at each step evaluate \(f(x)\), replace the endpoint with the same sign, propose a Newton step, and take the midpoint instead if the proposal is not finite, lies outside \((a, b)\), or is more than half as long as the previous step. Count the bisection steps. (a) Solve for \(c_{50}\) on \([0.01, 100]\) from \(x_0 = 10\), where plain Newton went to \(-3.05\). (b) Solve the Michaelis–Menten problem of B6 (g(u) = 1/(1 + exp(-u)) - 0.5) on \([-5, 5]\) from \(u_0 = 2.3\) (plain Newton: Inf, then NaN) and from \(u_0 = 2.1773189849653\) (plain Newton: cycles).

C6. Count function evaluations. Wrap \(f\) (and \(f'\)) so that each call increments a counter. Count the evaluations used to find \(c_{50}\) by: uniroot with the default tol and with tol = 1e-12 (Python: brentq with its default; Rust: BrentRoot with tol \(10^{-4}\) and \(10^{-12}\)), your Newton from 1 (count \(f\) and \(f'\)), and your secant from (1, 2). Print each error. Which is cheapest? Which is safest? (Python: also try scipy.optimize.newton with and without fprime, whose full_output reports function_calls.)

Explore

The demo below runs Newton, secant or bisection in your browser on the three equations of the lecture: the two-site dose–response \(f(c) = R(c) - 0.5\), the score \(S(\lambda)\) of the zero-truncated Poisson counts, and Michaelis–Menten in log substrate, \(\sigma(u) - \tfrac12\) (Newton step \(u - \sinh u\)). Drag or click in the plot to move the start value (two start values for secant, the bracket \([a, b]\) for bisection). Step takes one step and draws the tangent (Newton), the chord through the last two points (secant) or the halved bracket (bisection), and where it meets zero; Run keeps stepping, Back undoes a step. The table lists each iterate, \(f\) there, the error against the wanted root (\(c_{50}\), \(\hat\lambda\) or \(u^* = 0\)), the number of correct digits \(-\log_{10}\big(|e|/\max(|x^*|, 1)\big)\), and how the digit count changed from the previous step (column ×: the factor, for Newton and secant; column +: the digits added, for bisection). The digits of \(x_k\) that agree with the root are in bold. The demo stops like the lecture’s newton() and secant(): when a step is below \(10^{-12}\,|x|\), or after 60 steps.

The browser computes in the same IEEE doubles as R and Python, but exp and log may round differently in the last bit, so the last digit of an iterate can differ from the lecture.

Hints

Hint 1 — Newton by hand (B1, B3)

Compute \(f(x_k)\) and \(f'(x_k)\) first, then the step \(f/f'\), then subtract. Keep 5–6 significant digits. For B1(a) use the quotient rule: \(\dfrac{d}{dc}\dfrac{c^2}{4 + c^2} = \dfrac{2c(4 + c^2) - c^2\cdot 2c}{(4 + c^2)^2}\). For B3(b), expand \((1/a + e)(2 - a(1/a + e)) = (1/a + e)(1 - ae)\).

Hint 2 — digits and order (B4, C3)

Correct digits \(d_k = -\log_{10} e_k\). Order \(p\): \(d_{k+1} \approx p\,d_k\) (plus a constant). The three-point formula \(p \approx \log(e_{k+1}/e_k)/\log(e_k/e_{k-1})\) only works once the iteration is close to the root; far from it the errors are not yet governed by the local behaviour. In R, log(e[3:m] / e[2:(m-1)]) / log(e[2:(m-1)] / e[1:(m-2)]); in Python, np.log(e[2:] / e[1:-1]) / np.log(e[1:-1] / e[:-2]).

Hint 3 — the score (B5, C2)

\(\log P(X = x \mid X \ge 1) = -\lambda + x\log\lambda - \log x! - \log(1 - e^{-\lambda})\). Sum over the \(n\) observations. The derivative of \(\log(1 - e^{-\lambda})\) is \(e^{-\lambda}/(1 - e^{-\lambda})\); then use \(1 + \dfrac{e^{-\lambda}}{1 - e^{-\lambda}} = \dfrac{1}{1 - e^{-\lambda}}\). In code, \(1 - e^{-\lambda}\) is -expm1(-l) (R), -np.expm1(-l) (Python), -(-l).exp_m1() (Rust). Build the data with rep(1:5, times = c(52, 30, 12, 5, 1)) or np.repeat.

Hint 4 — the sigmoid in log dose (B6)

\(\sigma(u) - \tfrac12 = \dfrac{1 - e^{-u}}{2(1 + e^{-u})}\) and \(\sigma(1 - \sigma) = \dfrac{e^{-u}}{(1 + e^{-u})^2}\). Divide, and multiply top and bottom by \(e^{u}\).

Hint 5 — library root finders (C2, C6)

R: uniroot(f, interval = c(a, b), tol = 1e-12) returns a list with root, f.root, iter and estim.prec; extendInt = "yes" widens an interval without a sign change. Python: brentq(f, a, b, xtol=..., full_output=True) returns (root, info) with info.iterations and info.function_calls; scipy.optimize.root_scalar is a common front end to all of these. Rust: argmin::solver::brent::BrentRoot::new(a, b, tol), run with an Executor; the function must implement CostFunction.

Hint 6 — counting calls (C6)

R: a counter outside the function, updated with <<-: fc <- function(c) { count <<- count + 1; f(c) }. Python: a global count inside the wrapper, or a list count = [0] that the wrapper changes. Rust: a Cell captured by a closure, or an AtomicU64 when a library takes ownership of the function.

B1. (a) Quotient rule: \(\dfrac{2c(4 + c^2) - 2c^3}{(4 + c^2)^2} = \dfrac{8c}{(4 + c^2)^2}\). (b) \(c_0 = 1\): \(f = \tfrac15 - \tfrac12 = -0.3\), \(f' = 8/25 = 0.32\), \(c_1 = 1 + 0.3/0.32 = 1.9375\). \(c_1 = 1.9375\): \(f = 3.75391/7.75391 - 0.5 = -0.015869\), \(f' = 15.5/60.123 = 0.257805\), \(c_2 = 1.9375 + 0.061554 = 1.999054\). The next one (in code) is \(2.2\times10^{-7}/(9.46\times10^{-4})^2 = 0.250\). The ratio approaches \(|f''/(2f')| = 0.25\) as the iterates approach the root: quadratic convergence. (d) \(g' = 2c\), so \(c - (c^2 - 4)/(2c) = \tfrac12(c + 4/c)\). From \(c_0 = 1\): \(2.5\), \(2.05\), \(2.000610\). B3. (a) \(f' = -1/x^2\), so \(x - \dfrac{1/x - a}{-1/x^2} = x + x - a x^2 = x(2 - a x)\). (Early computers divided this way: a division turned into multiplications.) fn score(l: f64) -> f64 {
    SX / l - N / (-(-l).exp_m1()) // -expm1(-l) = 1 - exp(-l)
}
fn dscore(l: f64) -> f64 {
    -SX / l.powi(2) + N * (-l).exp() / (-l).exp_m1().powi(2)
}

fn newton(f: impl Fn(f64) -> f64, df: impl Fn(f64) -> f64, x0: f64, tol: f64, maxit: usize) -> (f64, usize) {
    let mut x = x0;
    for k in 1..=maxit {
        let step = f(x) / df(x);
        x -= step;
        if step.abs() <= tol * x.abs() {
            return (x, k);
        }
    }
    eprintln!("warning: no convergence after {maxit} steps");
    (x, maxit)
}

    type Param = f64;
    type Output = f64;
    fn cost(&self, l: &f64) -> Result<f64, Error> {
        Ok(score(*l))
    }
}

// rust/examples/newton_c6.rs  —  cargo run --example newton_c6
// C6: count function evaluations: Brent (argmin's BrentRoot), Newton, secant.
use argmin::core::{CostFunction, Error, Executor};
use argmin::solver::brent::BrentRoot;
use std::cell::Cell;
use std::sync::atomic::{AtomicU64, Ordering};

// global evaluation counter for the argmin run (argmin owns the function object)
static BRENT_EVALS: AtomicU64 = AtomicU64::new(0);

fn f(c: f64) -> f64 {
    0.3 * c / (0.1 + c) + 0.7 * c.powi(2) / (25.0 + c.powi(2)) - 0.5
}
fn df(c: f64) -> f64 {
    0.03 / (0.1 + c).powi(2) + 35.0 * c / (25.0 + c.powi(2)).powi(2)
}

fn newton(f: impl Fn(f64) -> f64, df: impl Fn(f64) -> f64, x0: f64, tol: f64, maxit: usize) -> f64 {
    let mut x = x0;
    for _ in 0..maxit {
        let step = f(x) / df(x);
        x -= step;
        if step.abs() <= tol * x.abs() {
            break;
        }
    }
    x
}

fn secant(f: impl Fn(f64) -> f64, mut x0: f64, mut x1: f64, tol: f64, maxit: usize) -> f64 {
    let (mut f0, mut f1) = (f(x0), f(x1));
    for _ in 0..maxit {
        if f1 == f0 {
            break;
        }
        let step = f1 * (x1 - x0) / (f1 - f0);
        x0 = x1;
        f0 = f1;
        x1 -= step;
        f1 = f(x1);
        if step.abs() <= tol * x1.abs() {
            break;
        }
    }
    x1
}

struct TwoSite;
impl CostFunction for TwoSite {
    type Param = f64;
    type Output = f64;
    fn cost(&self, c: &f64) -> Result<f64, Error> {
        BRENT_EVALS.fetch_add(1, Ordering::Relaxed);
        Ok(f(*c))
    }
}

fn main() {
    let c50 = 3.261305265055212;
    let report = |name: &str, evals: u64, root: f64| {
        println!("{:<22} evals {:3}   error {:.1e}", name, evals, (root - c50).abs());
    };
    for tol in [1e-4, 1e-12] {
        let res = Executor::new(TwoSite, BrentRoot::new(0.01, 100.0, tol))
            .configure(|s| s.max_iters(100))
            .run()
            .unwrap();
        let evals = BRENT_EVALS.swap(0, Ordering::Relaxed);
        report(&format!("BrentRoot, tol = {:.0e}", tol), evals, res.state.best_param.unwrap());
    }
    // a Cell is a counter that closures may change without `mut`
    let count = Cell::new(0u64);
    let fc = |c: f64| { count.set(count.get() + 1); f(c) };
    let dfc = |c: f64| { count.set(count.get() + 1); df(c) };
    let r = newton(fc, dfc, 1.0, 1e-12, 50);
    report("Newton from 1", count.replace(0), r);
    let r = secant(fc, 1.0, 2.0, 1e-12, 50);
    report("secant from 1, 2", count.replace(0), r);
}

All reach \(c_{50}\) with 7–13 evaluations from a bracket 10 000 times wider than the answer; bisection would need about 58. With the default tol, uniroot stops at an error of \(1.4\times10^{-7}\) (brentq’s default xtol is \(2\times10^{-12}\), much tighter). The secant method is cheapest (8 evaluations, 7 in scipy.optimize.newton, which picks its own second point), then Newton (10: five steps of \(f\) and \(f'\)). Brent’s method costs a few evaluations more but is the only one that cannot fail: it never leaves the bracket. That is why the libraries use it by default, and why our hand-written methods need a good start.

Where this leads

  • Newton for systems of equations (next unit): with several unknowns, \(f'\) becomes the Jacobian matrix, and the division \(f/f'\) becomes a linear solve. The secant idea generalises too (Broyden’s method). The failure modes and the safeguards (damping, line search) carry over.
  • Numerical differentiation (Part 7): when \(f'\) is not available in closed form, a finite-difference derivative can replace it; how to choose the step \(h\) is the topic there.
  • Gradient descent, Newton and quasi-Newton (Part 9): maximising a log-likelihood is solving score \(= 0\). Newton on the score is Newton’s method for optimisation, and the safeguards become line searches and trust regions. The standard error from \(-S'(\hat\lambda)\) returns in Identifiability and uncertainty of fitted parameters.
  • Optimisation in one dimension (Part 9): Brent’s other method (optimize, minimize_scalar) minimises a function of one variable with the same “fast step on a leash” idea.
