Exercise: optimisation in one dimension

Goal

By the end of this exercise you should be able to:

  • tell a minimum from a root of \(f'\), and say what each search can and cannot confuse,
  • find a bracket for a minimum (three points, a low one in the middle) from a table of values,
  • carry out golden-section steps and parabolic-interpolation steps by hand, and predict how many evaluations golden section needs,
  • write a golden-section search and read off its linear convergence (0.618 per evaluation),
  • use Brent’s method (optimize, minimize_scalar, BrentOpt) with a sensible tolerance,
  • explain why a minimum can only be located to about \(\sqrt{\varepsilon}\), and show it,
  • run Newton for minimisation with the checks that catch its failures,
  • recognise a function with several local minima and find the global one with a grid and a refinement.

The by-hand part uses pen, paper and a pocket calculator. The code part checks your hand answers and then works at sizes where only code works.

Background

To minimise a function \(f\) of one variable on an interval:

  1. Minimum and root. At a smooth minimum \(x^*\), \(f'(x^*) = 0\) and \(f''(x^*) \ge 0\). A root of \(f'\) can also be a maximum (\(f'' < 0\)). Maximising a log-likelihood \(\ell\) is minimising \(f = -\ell\).
  2. Bracket. Three points \(a < c < b\) with \(f(c) < f(a)\) and \(f(c) < f(b)\) enclose a (local) minimum. \(f\) is unimodal on \([a, b]\) if it has a single minimum there and no other dips.
  3. Golden section. With \(g = (\sqrt5 - 1)/2 = 0.6180\), evaluate \(x_1 = b - g(b - a)\) and \(x_2 = a + g(b - a)\). If \(f(x_1) < f(x_2)\) keep \([a, x_2]\), otherwise keep \([x_1, b]\). One of the two points is reused, so each step costs one evaluation and shrinks the bracket by \(g\): after \(m \ge 2\) evaluations the width is \(g^{m-1}(b - a)\). Linear convergence.
  4. Parabolic interpolation. The vertex of the parabola through \((a, f_a)\), \((b, f_b)\), \((c, f_c)\) is \[x_\text{new} = b - \frac12\,\frac{(b-a)^2(f_b - f_c) - (b-c)^2(f_b - f_a)}{(b-a)(f_b - f_c) - (b-c)(f_b - f_a)} .\] Superlinear (order about 1.32) near the minimum; can go anywhere far from it.
  5. Brent’s method combines the two: parabolic steps while they behave, golden-section steps otherwise. R: optimize (default tol \(=\varepsilon^{1/4} \approx 1.2\times10^{-4}\), absolute). Python: scipy.optimize.minimize_scalar with bounds and method="bounded" (default xatol \(= 10^{-5}\)). Rust: argmin’s BrentOpt (default absolute part \(10^{-5}\)).
  6. Newton for minimisation. \(x_{k+1} = x_k - f'(x_k)/f''(x_k)\): the vertex of the local parabola, which is Newton’s method on \(f'\). Quadratic near a minimum; if \(f''(x_k) < 0\) the local parabola opens downwards and the step heads for a maximum.
  7. The flat bottom. Near a minimum \(f(x^* + \delta) \approx f(x^*) + \tfrac12 f''(x^*)\delta^2\). The change is lost in rounding when \(\tfrac12 f''\delta^2 < \varepsilon|f(x^*)|\), so a method that compares values of \(f\) can locate \(x^*\) only to about \(|\delta| \approx \sqrt{\varepsilon}\sqrt{2|f(x^*)|/f''(x^*)}\), with \(\sqrt\varepsilon = 1.49\times10^{-8}\). A root of \(f'\) can be found to about \(\varepsilon\).
  8. Convexity. If \(f'' \ge 0\) on the whole interval, \(f\) is convex: a local minimum is the global minimum. Otherwise a local method can return a local minimum without any warning.

The running examples of the lecture:

  • mRNA decay. Fraction of an mRNA left after transcription stops: \(t = 0, 0.5, 1, 2, 4, 6, 8\) h, \(y = 1.000, 0.804, 0.684, 0.484, 0.217, 0.094, 0.083\). Model \(e^{-kt}\); the least-squares (Gaussian maximum-likelihood) rate minimises \(\text{SSE}(k) = \sum_i (y_i - e^{-kt_i})^2\); \(\hat k = 0.3753873095\) per hour.
  • Zero-truncated Poisson (from Newton and secant methods). UMI counts 1, 2, 3, 4, 5 in 52, 30, 12, 5, 1 cells; \(n = 100\), \(\sum x_i = 173\). Minus the log-likelihood is \(f(\lambda) = -173\log\lambda + 100\lambda + 100\log(1 - e^{-\lambda})\); the MLE is \(\hat\lambda = 1.2184695258\).
  • Circadian period. A simulated bioluminescence recording every 4 h for 6 days (36 values, given in C5). \(\text{RSS}(T)\) is the residual sum of squares of the best sine wave with period \(T\); the global minimum is at \(T = 24.63\) h.

import numpy as np
from scipy.optimize import minimize_scalar

t = np.array([0, 0.5, 1, 2, 4, 6, 8])                              # hours

// rust/examples/optimisation_1d_background.rs  —  cargo run --example optimisation_1d_background
// Background: minimise the decay-rate SSE with Brent's method (argmin's BrentOpt,
// Rust's counterpart of R's optimize and scipy's minimize_scalar).
use argmin::core::{CostFunction, Error, Executor, State};
use argmin::solver::brent::BrentOpt;

const T: [f64; 7] = [0.0, 0.5, 1.0, 2.0, 4.0, 6.0, 8.0]; // hours
const Y: [f64; 7] = [1.000, 0.804, 0.684, 0.484, 0.217, 0.094, 0.083]; // fraction left

// argmin wants the objective as a type with a `cost` method
struct Sse;
impl CostFunction for Sse {
    type Param = f64;
    type Output = f64;
    fn cost(&self, k: &f64) -> Result<f64, Error> {
        Ok(T.iter().zip(Y.iter()).map(|(t, y)| (y - (-k * t).exp()).powi(2)).sum())
    }
}

fn main() -> Result<(), Error> {
    // BrentOpt stops when the bracket is below eps*|x| + t: here eps = sqrt(machine eps), t = 1e-10
    let solver = BrentOpt::new(0.0, 1.0).set_tolerance(f64::EPSILON.sqrt(), 1e-10);
    let res = Executor::new(Sse, solver).configure(|s| s.max_iters(100)).run()?;
    let k = *res.state().get_best_param().unwrap();
    println!("{:.7}", k);                          // decay rate (per hour)
    println!("{:.9}", res.state().get_best_cost()); // SSE at the minimum
    println!("{:.6}", 2f64.ln() / k);               // half-life (hours)
    Ok(())
}
// Output:
// 0.3753873
// 0.002042809
// 1.846485

Rust prints numbers in its own format (e.g. 1e-8 rather than 1e-08); the values are the same unless the text says otherwise. The minimisers do not all take the same steps, so the last digits of a result computed with a loose tolerance can differ between languages.

By hand

B1. Minimum, maximum or neither? Take \(f(x) = \tfrac13 x^3 - x\). (a) Find all roots of \(f'\) and classify each with \(f''\). (b) Run two steps of Newton’s method on \(f'(x) = 0\) from \(x_0 = -0.5\), and two from \(x_0 = 2\). Where does each sequence go? Which one has found a minimum? (c) Is \((0, 1, 3)\) a bracket for a minimum? Is \((-3, -1, 0)\)? (d) On the interval \([-3, 3]\), where is the smallest value of \(f\)? Would a local method started near 1 find it?

B2. Golden section by hand. Take \(f(x) = x - 2\ln x\) on \([1, 4]\) (its minimum is at \(x^* = 2\), \(f(2) = 0.6137\)). (a) Compute \(x_1\), \(x_2\), \(f(x_1)\), \(f(x_2)\) and decide which part of the interval to keep. (b) Do a second step. Which point is reused? Which point is new? (c) Compute the widths of the three brackets. What is the ratio of consecutive widths? (d) How many evaluations of \(f\) does golden section need to shrink \([1, 4]\) to a width of \(10^{-6}\)? How many evaluations of \(f'\) would bisection on \(f'\) need?

B3. Parabolic interpolation. (a) For \(g(x) = (x - 2)^2 + 1\), use the vertex formula with the points \(0, 1, 3\). Explain the result. (b) For \(f(x) = x - 2\ln x\), use the points \(1, 1.5, 3\) (values \(1\), \(0.68907\), \(0.80278\)). How far is the vertex from \(x^* = 2\)? Compare with the bracket after the two golden-section steps of B2. (c) What happens if the middle value is the largest of the three, for example \(h(x) = -(x - 2)^2\) at \(1, 2, 3\)?

B4. Newton for minimisation can leave the domain. Again \(f(x) = x - 2\ln x\), \(x > 0\). (a) Compute \(f'\) and \(f''\). Is \(f\) convex? (b) Show that the Newton step is \(x_{k+1} = 2x_k - x_k^2/2\), and that the error \(e_k = x_k - 2\) satisfies \(e_{k+1} = -e_k^2/2\). (c) Run three steps from \(x_0 = 1\). How many correct digits does each step have? (d) What happens from \(x_0 = 3\), \(x_0 = 4\) and \(x_0 = 5\)? For which \(x_0\) does Newton converge? (e) Which check from the lecture would have stopped the iteration from \(x_0 = 4\) and \(x_0 = 5\)?

B5. How flat is the bottom? Use \(\varepsilon = 2.2\times10^{-16}\); a double near 1 has neighbours \(\varepsilon\) apart, near 1000 they are \(1.1\times10^{-13}\) apart. (a) For \(f(x) = 1 + (x - 1)^2\): for which \(\delta\) does the computed \(f(1 + \delta)\) equal \(f(1) = 1\) exactly? (b) The same for \(f(x) = 1 + 100(x - 1)^2\) and for \(f(x) = 1000 + (x - 1)^2\). What makes the flat bottom wider, what makes it narrower? (c) For the zero-truncated Poisson, \(f(\hat\lambda) = 52.61\) and \(f''(\hat\lambda) = 56.92\). How many digits of \(\hat\lambda = 1.218\ldots\) can a minimiser find? (d) The score \(S(\lambda) = -f'(\lambda)\) near \(\hat\lambda\) is about \(-56.92\,(\lambda - \hat\lambda)\). Why can a root finder locate \(\hat\lambda\) much more precisely?

B6. Brackets from a table: the circadian period. \(\text{RSS}(T)\) for the circadian data at a grid with spacing 4 h:

\(T\) (h) 10 14 18 22 26 30 34 38
RSS 10.55 10.50 10.33 9.31 4.45 10.66 10.40 10.66
  1. Find every bracket for a minimum in this table. Which one would you refine?
  2. A colleague uses the grid \(10, 20, 30, 40\) and gets \(10.55, 10.48, 10.66, 10.45\). What does she conclude?
  3. optimize on \([10, 40]\) first evaluates \(T = 21.46\) (RSS \(10.361\)) and \(T = 28.54\) (RSS \(10.311\)), then \(T = 32.92\) (RSS \(10.249\)). Follow the golden-section logic: which brackets does it keep? Can it still find the minimum near 24.6?
  4. The dip around the true period is about 3 h wide. What grid spacing would you use?

(b) Evaluate rss on a grid from 10 to 40 h with spacing 0.25 h, take the best grid point \(T_0\), and refine with Brent on \([T_0 - 0.5, T_0 + 0.5]\). Plot \(\text{RSS}(T)\) and compare RSS at the two candidates. (c) Check your answer to B6(b) with the grid \(10, 20, 30, 40\).

C6. The growth rate of the OD curve. The logistic OD curve of Convergence and cost, \(N(t) = K/(1 + (K/N_0 - 1)e^{-rt})\), with \(K = 1.2\) and \(N_0 = 0.05\) known, measured every 10 min for 10 h with noise (the 61 values of Numerical differentiation, in the solution code). (c) Estimate the noise standard deviation as \(\sqrt{\text{SSE}(\hat r)/(n - 1)}\). The simulation used 0.005.

Answer E1

The first step evaluates \(x_1 = 0.3820\) and \(x_2 = 0.6180\); then \(0.2361\), \(0.4721\) and \(0.3262\), with widths \(1, 0.618, 0.382, 0.236\): the same points as the table by hand, and a ratio of \(0.618\) per evaluation. With the default tolerance (\(1.2\times10^{-4}\)) golden section stops after 21 evaluations at \(0.37537\) with error \(2.0\times10^{-5}\); with tol \(10^{-10}\) after 50 evaluations (as in C2) with error \(2.4\times10^{-10}\). The width lies exactly on the dashed \(0.618^n\) line. The error falls with it down to \(2.4\times10^{-10}\) (after 43 evaluations, near the flat-bottom line at \(4\times10^{-10}\)) and then stops, while the width keeps shrinking: the last rows all show \(f = 0.002042809\), and the comparisons are decided by rounding. The final bracket, \(9.3\times10^{-11}\) wide, does not even contain \(\hat k\) any more. With tol \(10^{-15}\) the width keeps shrinking to \(10^{-15}\) (74 evaluations) and the error stays at \(2.4\times10^{-10}\).

E2. (parabolic steps and Brent) Switch to parabolic and press Step three times from \([0, 1]\). Where do the vertices land, and what happens if you press To end? Now switch to Brent, tol \(10^{-10}\), and press Step repeatedly. Which steps are golden and which are parabolic? How many evaluations does Brent need, and how does that compare with E1? Finally drag b to about \(0.6\) and run Brent again.

Answer E2

Parabolic interpolation from \(0, 0.5, 1\) jumps to \(0.7018\), already worse than \(0.5\), and then to \(-1.509\), where \(\text{SSE} = 3\times10^{10}\): the parabola through those points opens so steeply that its vertex is far outside. To end shows it wandering off to \(k \approx 72\), out on the flat plateau, where the points end up on a line and some parabolas open downwards (the table notes “a maximum”). There is no bracket to stop it. Brent starts at \(0.382\), takes two golden steps (\(0.618\), \(0.236\)) and then only parabolic steps (\(0.428\), \(0.347\), \(0.3775\), …); the error drops by several digits per step and it stops after 13 evaluations with error \(4.9\times10^{-11}\), against 50 for golden section (R reports 14). Hints

Hint 1 — stationary points and brackets (B1, B6)

Solve \(f'(x) = 0\); then \(f'' > 0\) means minimum, \(f'' < 0\) maximum. Newton on \(f'\) is \(x_{k+1} = x_k - f'(x_k)/f''(x_k)\). A bracket needs the middle value lower than both neighbours. A minimum of \(f\) on a closed interval can also sit at an end point.

Hint 2 — golden section (B2, C1)

\(g = 0.6180\), \(1 - g = 0.3820\). Start: \(x_1 = a + 0.382(b - a)\), \(x_2 = a + 0.618(b - a)\). If you keep \([a, x_2]\), the old \(x_1\) becomes the new \(x_2\) and only the new \(x_1 = b - g(b - a)\) (with the new \(b\)) is evaluated. Number of evaluations: solve \(g^{m-1}(b - a) \le \text{tol}\) for \(m\), i.e. \(m - 1 \ge \ln(\text{tol}/(b-a))/\ln g\). Bisection: \(0.5^m (b-a) \le \text{tol}\).

Hint 3 — the vertex formula (B3)

Compute the four differences \(b - a\), \(b - c\), \(f_b - f_c\), \(f_b - f_a\) first, then the numerator and the denominator. For a quadratic the parabola through three of its points is the function itself.

Hint 4 — Newton on x - 2 ln x (B4)

\(f'(x) = 1 - 2/x\), \(f''(x) = 2/x^2\). Then \(f'/f'' = (x - 2)x/2\). For the error, write \(x_{k+1} - 2 = -\tfrac12(x_k^2 - 4x_k + 4)\).

Hint 5 — the flat bottom (B5, C3)

A sum \(F + s\) with \(|s|\) less than half the gap between doubles near \(F\) rounds back to \(F\). The gap near \(F\) is about \(\varepsilon|F|\) (exactly a power of 2: \(2^{-52}\) near 1, \(2^{-43}\) near 1000, \(2^{-47} = 7.1\times10^{-15}\) near 52.6). In code: R uniroot(S, c(0.01, 10), tol = 1e-15) and optimize(nll, c(0.01, 10), tol = 1e-15); Python brentq(S, 0.01, 10, xtol=1e-15, rtol=1e-15) and minimize_scalar(nll, bounds=(0.01, 10), method="bounded", options={"xatol": 1e-15}); Rust BrentRoot::new(0.01, 10.0, 1e-15) and BrentOpt::new(0.01, 10.0).set_tolerance(1e-15, 1e-15). Use -expm1(-l) for \(1 - e^{-\lambda}\).

Hint 6 — library minimisers and counting (C2, C5, C6)

R: optimize(f, interval = c(a, b), tol = ...) returns a list with minimum and objective; count calls with a wrapper fc <- function(k) { count <<- count + 1; f(k) }. Python: res = minimize_scalar(f, bounds=(a, b), method="bounded", options={"xatol": ...}) returns res.x, res.fun and res.nfev; method="brent" with bracket=(a, c, b) is the unbounded version. Rust: Executor::new(problem, BrentOpt::new(a, b).set_tolerance(f64::EPSILON.sqrt(), t)).run()?, then res.state().get_best_param(); count evaluations with an AtomicU64 inside cost, as in the Newton exercise. A minimum returned at an end of the interval means the interval was wrong.

Hint 7 — checks for Newton (C4)

Central difference: \(f'(x) \approx (f(x + h) - f(x - h))/(2h)\) with \(h = 10^{-5}\). In the loop: (1) if d2(x) <= 0, stop; (2) compute the step; (3) if the step is tiny, return; (4) if f(x_new) is not finite or larger than f(x), stop. Near the minimum \(f\) is flat to rounding level, so (4) can fire on a step of size \(10^{-16}\) if it comes before (3).

Hint 8 — the sine-wave fit (C5)

For fixed \(T\), the design matrix has the columns \(1\), \(\cos(2\pi t/T)\), \(\sin(2\pi t/T)\). R: X <- cbind(1, cos(2*pi*t/T), sin(2*pi*t/T)); sum(lm.fit(X, y)$residuals^2). Python: coef = np.linalg.lstsq(X, y, rcond=None)[0]; np.sum((y - X @ coef)**2). Grid: sapply(Tg, rss) and which.min (R), a list comprehension and np.argmin (Python).

B2. (a) \(x_1 = 4 - 0.618\cdot3 = 2.1459\), \(f(x_1) = 2.1459 - 2\ln 2.1459 = 0.6188\). \(x_2 = 1 + 0.618\cdot3 = 2.8541\), \(f(x_2) = 0.7566\). \(f(x_1) < f(x_2)\): keep \([1, 2.8541]\). Parabolic interpolation only makes sense when the middle value is the lowest (a bracket); Brent’s method checks that.

B4. (a) \(f'(x) = 1 - 2/x\), \(f''(x) = 2/x^2 > 0\) for every \(x > 0\): \(f\) is convex on its whole domain. (b) \(x - f'/f'' = x - (1 - 2/x)x^2/2 = x - (x^2 - 2x)/2 = 2x - x^2/2\). Then \(x_{k+1} - 2 = -\tfrac12(x_k - 2)^2\), so \(e_{k+1} = -e_k^2/2\): quadratic convergence. (c) \(1 \to 1.5 \to 1.875 \to 1.9921875\); errors \(0.5, 0.125, 0.0078\) (then \(3.1\times10^{-5}\)): correct digits roughly double each step. (d) From 3: \(e_0 = 1\), \(x_1 = 1.5\), then as in (c): converges. From 4: \(x_1 = 8 - 8 = 0\), where \(\ln 0 = -\infty\) and \(f = +\infty\). (e) “\(f(x_{k+1}) < f(x_k)\), and finite”: \(f(0) = \infty\) and $f(-2.5) = $ NaN both fail it. // rust/examples/optimisation_1d_c2.rs  —  cargo run --example optimisation_1d_c2
// C2: Brent's minimiser (argmin's BrentOpt) with its default and a tight tolerance,
// counting function evaluations.
use argmin::core::{CostFunction, Error, Executor, State};
use argmin::solver::brent::BrentOpt;
use std::sync::atomic::{AtomicU64, Ordering};

// evaluation counter (argmin owns the objective, so we count in a global)
static EVALS: AtomicU64 = AtomicU64::new(0);

const T: [f64; 7] = [0.0, 0.5, 1.0, 2.0, 4.0, 6.0, 8.0];
const Y: [f64; 7] = [1.000, 0.804, 0.684, 0.484, 0.217, 0.094, 0.083];

struct Sse;
impl CostFunction for Sse {
    type Param = f64;
    type Output = f64;
    fn cost(&self, k: &f64) -> Result<f64, Error> {
        EVALS.fetch_add(1, Ordering::Relaxed);
        Ok(T.iter().zip(Y.iter()).map(|(t, y)| (y - (-k * t).exp()).powi(2)).sum())
    }
}

// minimise on [a, b]; tol = None keeps argmin's default (eps = sqrt(machine eps), t = 1e-5)
fn brent(a: f64, b: f64, tol: Option<f64>) -> Result<(f64, u64), Error> {
    EVALS.store(0, Ordering::Relaxed);
    let mut solver = BrentOpt::new(a, b);
    if let Some(t) = tol {
        solver = solver.set_tolerance(f64::EPSILON.sqrt(), t);
    }
    let res = Executor::new(Sse, solver).configure(|s| s.max_iters(100)).run()?;
    let st = res.state();
    let nev = EVALS.load(Ordering::Relaxed);
    Ok((*st.get_best_param().unwrap(), nev))
}

fn main() -> Result<(), Error> {
    let (k1, n1) = brent(0.0, 1.0, None)?;
    let (k2, n2) = brent(0.0, 1.0, Some(1e-10))?;

use argmin::core::{CostFunction, Error, Executor, State};
use argmin::solver::brent::BrentOpt;

const K: f64 = 1.2;
const N0: f64 = 0.05;
const Y: [f64; 61] = [0.047, 0.058, 0.060, 0.081, 0.084, 0.090, 0.108, 0.123, 0.137, 0.150, 0.177,
    0.192, 0.210, 0.226, 0.269, 0.292, 0.322, 0.359, 0.393, 0.428, 0.466, 0.504,
    0.540, 0.569, 0.622, 0.659, 0.698, 0.730, 0.772, 0.812, 0.851, 0.876, 0.909,
    0.935, 0.955, 0.985, 1.007, 1.029, 1.054, 1.069, 1.079, 1.092, 1.109, 1.120,
    1.123, 1.132, 1.145, 1.154, 1.155, 1.166, 1.168, 1.167, 1.175, 1.171, 1.187,
    1.192, 1.183, 1.181, 1.191, 1.189, 1.203];

fn od(t: f64, r: f64) -> f64 { K / (1.0 + (K / N0 - 1.0) * (-r * t).exp()) }
fn sse(r: f64) -> f64 {
    Y.iter().enumerate().map(|(i, y)| (y - od(i as f64 / 6.0, r)).powi(2)).sum() // t = i/6 h
}

struct Sse;
impl CostFunction for Sse {
    type Param = f64;
    type Output = f64;
    fn cost(&self, r: &f64) -> Result<f64, Error> { Ok(sse(*r)) }
}

fn main() -> Result<(), Error> {
    let look: Vec<String> = [0.1, 0.4, 0.8, 1.2, 2.0, 3.0].iter().map(|&r| format!("{:.3}", sse(r))).collect();
    println!("{}", look.join(" ")); // (a) look first
    let solver = BrentOpt::new(0.1, 3.0).set_tolerance(f64::EPSILON.sqrt(), 1e-10); // (b)
    let res = Executor::new(Sse, solver).configure(|s| s.max_iters(200)).run()?;
    let r = *res.state().get_best_param().unwrap();
    println!("{:.9} {:.9}", r, sse(r));
    println!("{:.9}", (sse(r) / 60.0).sqrt()); // (c) residual sd
    Ok(())
}

Where this leads

  • Gradient descent, Newton and quasi-Newton (next unit): with several parameters, \(f'\) becomes the gradient and \(f''\) the Hessian matrix. Every multivariate method chooses a direction and then does a one-dimensional search along it (a line search): the methods of this exercise reappear inside. The checks of C4 become the line-search and trust-region safeguards.
  • Nonlinear least squares and ODE fitting: least squares with several parameters (a pharmacokinetic absorption–elimination curve with three) and fits of ODE models, where multistart replaces the grid of C5.
  • Identifiability and uncertainty of fitted parameters: the curvature \(f''(\hat x)\) at the minimum gives the standard error; a flat valley in \(f\) means a parameter the data cannot pin down.
  • Fourier series and the FFT: the periodogram computes something very close to \(\text{RSS}(T)\) on a whole grid of periods at once.
