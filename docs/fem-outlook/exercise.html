Exercise: beyond rectangles: finite elements and flow

Goal

This is an optional further-reading exercise. By the end of it you should be able to:

  • write a piecewise linear function as a sum of hat functions, and evaluate and integrate it,
  • compute the 2 × 2 element matrices for \(-(D u')' + k u = f\) and assemble them into the tridiagonal system,
  • show that on a uniform mesh the finite element matrix is the finite-difference matrix, and on a non-uniform mesh it is the non-uniform difference formula,
  • solve a 1D finite element problem on a graded mesh and see why putting nodes where the solution changes pays off,
  • recognise the failure (negative concentrations from elements that are too long) and the checks that detect it.

The by-hand part uses pen, paper and a pocket calculator. The code part runs the same 15-line solver on meshes of up to 200 elements.

Background

The model. A hydrogel slab, \(L = 1000\) µm thick, sits on a glass bottom with cells embedded in it. A drug in the medium above diffuses in (\(D = 100\) µm²/s) and the cells take it up (\(k = 0.04\) s⁻¹). The steady concentration (relative to the bath) solves \[-(D\,u')' + k\,u = f, \qquad u(0) = 1, \qquad u'(L) = 0,\] with \(f = 0\). The exact solution is \(u(x) = \cosh\big((L-x)/\lambda\big)/\cosh(L/\lambda)\), \(\lambda = \sqrt{D/k} = 50\) µm.

Facts used below:

  1. Hat functions. On nodes \(x_0 < x_1 < \dots < x_N\) (any spacing), \(\varphi_j\) is 1 at \(x_j\), 0 at all other nodes and linear in between. \(u_h(x) = \sum_j u_j\varphi_j(x)\) is the piecewise linear function through the points \((x_j, u_j)\); its integral is exactly the trapezoid sum.
  2. Weak form. Multiply by \(\varphi_i\), integrate, integrate by parts. The boundary term is the flux and vanishes at a no-flux end (natural boundary condition: nothing to do). At \(x = 0\) the value is known, so there is no equation for \(u_0\). Result: \(K\mathbf u = \mathbf b\) with \(K_{ij} = \int D\varphi_i'\varphi_j' + k\varphi_i\varphi_j\,dx\), \(b_i = \int f\varphi_i\,dx\).
  3. Element matrices for an element of length \(h_e\) (constant \(D\), \(k\), \(f\) on it): \[\frac{D}{h_e}\begin{pmatrix} 1 & -1\\ -1 & 1\end{pmatrix} + \frac{k h_e}{6}\begin{pmatrix} 2 & 1\\ 1 & 2\end{pmatrix}, \qquad \frac{f h_e}{2}\begin{pmatrix}1\\1\end{pmatrix}.\] Lumped version: replace the uptake block by \(\frac{k h_e}{2}\begin{pmatrix}1&0\\0&1\end{pmatrix}\).
  4. Assembly. Add the block of element \(e\) into rows and columns \(e, e+1\). Then move the column of the known \(u_0\) to the right-hand side and drop row 0. The result is tridiagonal and symmetric: solve with the Thomas algorithm (from Structure: symmetric, banded, sparse).
  5. Graded mesh. \(x_i = L\,(i/N)^2\) puts short elements near \(x = 0\) (first one \(L/N^2\)) and long ones at depth.

The solver in each language. R and Rust use the Thomas algorithm; Python uses scipy.linalg.solve_banded, which takes the three diagonals in a 3-row array. D, k and f may be single numbers or one value per element.

thomas <- function(a, b, c, d) {             # Structure: symmetric, banded, sparse
  n <- length(d)
  for (i in 2:n) { w <- a[i] / b[i - 1]; b[i] <- b[i] - w * c[i - 1]; d[i] <- d[i] - w * d[i - 1] }
  x <- numeric(n); x[n] <- d[n] / b[n]
  for (i in (n - 1):1) x[i] <- (d[i] - c[i] * x[i + 1]) / b[i]
  x
}
assemble <- function(x, D, k, f = 0, lumped = FALSE) {
  n <- length(x); h <- diff(x)
  D <- rep_len(D, n - 1); k <- rep_len(k, n - 1); f <- rep_len(f, n - 1)
  wd <- if (lumped) 1 / 2 else 1 / 3         # weight of k h on the diagonal
  wo <- if (lumped) 0 else 1 / 6             # ... and off the diagonal
  di <- numeric(n); off <- numeric(n - 1); b <- numeric(n)
  for (e in 1:(n - 1)) {                     # element e: nodes e and e + 1
    kd <- D[e] / h[e] + k[e] * h[e] * wd
    ko <- -D[e] / h[e] + k[e] * h[e] * wo
    di[e:(e + 1)] <- di[e:(e + 1)] + kd
    off[e] <- off[e] + ko
    b[e:(e + 1)] <- b[e:(e + 1)] + f[e] * h[e] / 2
  }
  list(di = di, off = off, b = b)
}
fem1d <- function(x, D, k, f = 0, u0 = 1, lumped = FALSE) {
  S <- assemble(x, D, k, f, lumped); off <- S$off
  rhs <- S$b[-1]; rhs[1] <- rhs[1] - off[1] * u0   # u(x[1]) = u0 is known
  c(u0, thomas(off, S$di[-1], c(off[-1], 0), rhs))
}

import numpy as np
from scipy.linalg import solve_banded

def assemble(x, D, k, f=0.0, lumped=False):
    n = len(x); h = np.diff(x)
    D, k, f = (np.broadcast_to(v, n - 1) for v in (D, k, f))
    wd, wo = (1 / 2, 0.0) if lumped else (1 / 3, 1 / 6)
    di = np.zeros(n); off = np.zeros(n - 1); b = np.zeros(n)
    for e in range(n - 1):                    # element e: nodes e and e + 1
        kd = D[e] / h[e] + k[e] * h[e] * wd
        ko = -D[e] / h[e] + k[e] * h[e] * wo
        di[e:e + 2] += kd
        off[e] += ko
        b[e:e + 2] += f[e] * h[e] / 2
    return di, off, b

def fem1d(x, D, k, f=0.0, u0=1.0, lumped=False):
    di, off, b = assemble(x, D, k, f, lumped)
    rhs = b[1:].copy(); rhs[0] -= off[0] * u0  # u(x[0]) = u0 is known
    m = len(rhs)
    ab = np.zeros((3, m))                      # banded storage for solve_banded
    ab[0, 1:] = off[1:]                        # above the diagonal
    ab[1] = di[1:]                             # diagonal
    ab[2, :-1] = off[1:]                       # below the diagonal
    return np.concatenate([[u0], solve_banded((1, 1), ab, rhs)])

// rust/examples/fem_outlook_background.rs  —  cargo run --example fem_outlook_background
// Background: a 1D finite element solver for -(D u')' + k u = f with linear
// elements on any mesh, hand-written (assembly loop + Thomas algorithm).
// Model: drug diffusing into a 1 mm hydrogel slab with uptake by cells.

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Assemble the tridiagonal matrix (diagonal, off-diagonal) and load vector.
/// d, k, f hold one value per element.
fn assemble(x: &[f64], d: &[f64], k: &[f64], f: &[f64], lumped: bool) -> (Vec<f64>, Vec<f64>, Vec<f64>) {
    let n = x.len();
    let (wd, wo) = if lumped { (0.5, 0.0) } else { (1.0 / 3.0, 1.0 / 6.0) };
    let (mut di, mut off, mut b) = (vec![0.0; n], vec![0.0; n - 1], vec![0.0; n]);
    for e in 0..n - 1 {                         // element e: nodes e and e + 1
        let h = x[e + 1] - x[e];
        let kd = d[e] / h + k[e] * h * wd;
        let ko = -d[e] / h + k[e] * h * wo;
        di[e] += kd;
        di[e + 1] += kd;
        off[e] += ko;
        b[e] += f[e] * h / 2.0;
        b[e + 1] += f[e] * h / 2.0;
    }
    (di, off, b)
}

/// Solve with u(x[0]) = u0 and no flux at the last node.
fn fem1d(x: &[f64], d: &[f64], k: &[f64], f: &[f64], u0: f64, lumped: bool) -> Vec<f64> {
    let (di, off, b) = assemble(x, d, k, f, lumped);
    let mut rhs = b[1..].to_vec();
    rhs[0] -= off[0] * u0;                     // move the known u0 to the right
    let mut c = off[1..].to_vec();
    c.push(0.0);
    let mut u = vec![u0];
    u.extend(thomas(&off, &di[1..], &c, &rhs));
    u
}

fn main() {
    let (l, dd, k) = (1000.0, 100.0, 0.04);
    let lam = f64::sqrt(dd / k);
    let exact = |x: f64| ((l - x) / lam).cosh() / (l / lam).cosh();
    let n = 10;                                // elements
    let x: Vec<f64> = (0..=n).map(|i| l * i as f64 / n as f64).collect();
    let u = fem1d(&x, &vec![dd; n], &vec![k; n], &vec![0.0; n], 1.0, false);
    println!("    x    fem  exact");
    for i in 0..5 {
        println!("{:5.0} {:6.4} {:6.4}", x[i], u[i], exact(x[i]));
    }
    let err = x.iter().zip(&u).map(|(xi, ui)| (ui - exact(*xi)).abs()).fold(0.0, f64::max);
    println!("{}", err);
}

By hand

B1. Hat functions. Take the nodes \(x = 0, 1, 3, 4\) (a non-uniform mesh). (a) Write \(\varphi_1(x)\) (the hat at \(x_1 = 1\)) as a formula on each element. (b) With nodal values \(u = (1, 0.5, 0.2, 0.1)\), evaluate \(u_h(0.5)\) and \(u_h(2)\). (c) What is the slope \(u_h'\) on each element? (d) Compute \(\int_0^4 u_h\,dx\).

B2. Assemble by hand. Take \(D = 1\), \(k = 0\) (pure diffusion, \(-u'' = f\)). (a) Uniform mesh \(0, 1, 2, 3\) (\(h = 1\)). Write the three element matrices and assemble the full 4 × 4 matrix \(K\). Compare its interior rows with the second difference \((-1, 2, -1)/h^2\). (b) Two elements of lengths \(h_1\) and \(h_2\) meeting at node 1, constant \(f\). Write the assembled equation of row 1. Show that dividing it by \((h_1 + h_2)/2\) gives the non-uniform difference formula \[-\frac{2}{h_1 + h_2}\left(\frac{u_2 - u_1}{h_2} - \frac{u_1 - u_0}{h_1}\right) = f.\] (c) Check (b) with \(u = x^2\) (so \(f = -u'' = -2\)) on nodes \(0, 1, 3\).

B3. Elements that are too long. A thinner slab, \(L = 500\) µm, with the same \(D = 100\) µm²/s and \(k = 0.04\) s⁻¹, cut into 2 elements of \(h = 250\) µm. \(u_0 = 1\), no flux at 500 µm. (a) Compute the diagonal entry \(D/h + kh/3\) and the off-diagonal entry \(-D/h + kh/6\) of each element matrix. What sign has the off-diagonal? (b) Assemble the 2 × 2 system for \(u_1, u_2\) (row 1 gets contributions from both elements) and solve it. (c) The exact values are \(u(250) = 0.0067\) and \(u(500) = 0.00009\). What is wrong with your answer? (d) For which \(h\) is the off-diagonal entry negative? Express the limit in terms of \(\lambda\). (e) Repeat (b) with the lumped matrix. Is the answer positive? Is it accurate?

In code

C1. The same matrix as finite differences. Use assemble from the Background. (a) For 5 uniform elements on \([0, 500]\) µm with \(D = 100\) and \(k = 0\), print the diagonal and off-diagonal times \(h/D\). Compare with B2(a). (b) Now with \(k = 0.04\): print the diagonal and off-diagonal of the consistent and the lumped matrix, and of the finite-difference matrix \(\frac{D}{h}(-1, 2, -1) + k h\) on the diagonal, with the no-flux last row (from the ghost point) divided by 2 to match. Which one is the finite-difference matrix? (c) Solve the 1 mm slab with 10 uniform elements, consistent and lumped. Which has the smaller maximum nodal error?

C2. Refine where the solution changes. For \(N = 5, 10, 20, 40, 80, 160\) elements, solve the slab on the uniform mesh and on the graded mesh \(x_i = L(i/N)^2\). Print the maximum nodal error of each and their ratio; plot both against \(N\) on log–log axes and read off the order. Then compute the amount of drug in the gel, \(\int_0^L u_h\,dx\) (in µm × bath concentration), for \(N = 10\) on both meshes, and compare with the exact \(\lambda\tanh(L/\lambda)\).

C3. Failure, and a two-layer gel. (a) For \(N = 2, 4, 6, 8, 10\) uniform elements, print \(h/\lambda\), the smallest \(u_j\) for the consistent and for the lumped matrix. Compare with B3(d). (b) Now the top 100 µm of the gel is a cell-free coating (\(k = 0\) there), cells only below. Give each element the \(k\) of its midpoint. The exact drug level at the interface is \(u(100) = 1/\big(1 + (100/\lambda)\tanh(900/\lambda)\big)\). Compare the FEM value at \(x = 100\) (interpolated if there is no node there) for \(N = 50, 49, 100, 99, 200, 199\) uniform elements. Which meshes have a node at the interface, and what does that do to the error and its order?

Hints

Hint 1 — hats and integrals (B1)

On an element \([x_j, x_{j+1}]\) only \(\varphi_j\) and \(\varphi_{j+1}\) are non-zero, so \(u_h\) is the straight line between \((x_j, u_j)\) and \((x_{j+1}, u_{j+1})\). The integral of a straight line over an element is its length times the mean of the end values (the trapezoid rule of Numerical integration, here exact).

Hint 2 — assembly (B2, B3)

Write each element matrix in its own 2 × 2, then add: node \(i\) gets the bottom-right entry of element \(i\) (on its left) and the top-left entry of element \(i+1\) (on its right). The last node belongs to one element only. In B3, row 1 has \(-\)(off-diagonal)\(\times u_0\) moved to the right-hand side, with \(u_0 = 1\). Useful values: \(D/h = 0.4\), \(kh/3 = 10/3\), \(kh/6 = 5/3\), \(kh/2 = 5\).

Hint 3 — the solver (C1–C3)

The Thomas convention is the one from Implicit schemes and the method of lines: all four vectors of length \(m\), a[1] and c[m] unused. Python’s solve_banded((1, 1), ab, rhs) wants the superdiagonal in row 0 (first entry unused), the diagonal in row 1 and the subdiagonal in row 2 (last entry unused). For the slab use cosh and tanh (Python: np.cosh).

Hint 4 — order and interpolation (C2, C3)

If the error is \(\approx C N^{-p}\), then \(p = \log_2(e_N/e_{2N})\). Plot with matplot(..., log = "xy") (Python: plt.loglog). To read \(u_h\) between nodes use approx (Python: np.interp): linear interpolation is exactly \(u_h\). A per-element vector: the midpoints are head(x, -1) + diff(x) / 2 (Python: x[:-1] + np.diff(x) / 2). Test “is there a node at 100” with a tolerance, not == (How computers store numbers).

Solutions

Solution — by hand

B1. (a) \(\varphi_1(x) = x\) on \([0, 1]\), \(\varphi_1(x) = (3 - x)/2\) on \([1, 3]\), and \(0\) on \([3, 4]\). (b) \(u_h(0.5) = (1 + 0.5)/2 = 0.75\). \(u_h(2) = 0.5\,\varphi_1(2) + 0.2\,\varphi_2(2) = 0.5 \cdot 0.5 + 0.2 \cdot 0.5 = 0.35\). (c) \(-0.5\) on \([0, 1]\), \((0.2 - 0.5)/2 = -0.15\) on \([1, 3]\), \(-0.1\) on \([3, 4]\). The slope jumps at the nodes: \(u_h\) has no second derivative there, which is why the weak form (only first derivatives) is needed. (d) \(1 \cdot 0.75 + 2 \cdot 0.35 + 1 \cdot 0.15 = 1.6\).

B2. (a) Each element gives \(\begin{pmatrix}1 & -1\\-1 & 1\end{pmatrix}\). Assembled: \[K = \begin{pmatrix} 1 & -1 & 0 & 0\\ -1 & 2 & -1 & 0\\ 0 & -1 & 2 & -1\\ 0 & 0 & -1 & 1\end{pmatrix}.\] The interior rows are \((-1, 2, -1)\), the second difference times \(h^2 = 1\) (in general \(K = \frac{1}{h}\times\) the difference matrix \(\times h^2\), so a factor \(h\) apart, with \(b_i = fh\) on the right). The end rows have half weight: the no-flux row of a ghost-point scheme divided by 2. (b) Row 1 collects \(\frac{1}{h_1}(-u_0 + u_1)\) from element 1 and \(\frac{1}{h_2}(u_1 - u_2)\) from element 2, and \(b_1 = f h_1/2 + f h_2/2\): \[-\frac{u_0}{h_1} + \Big(\frac{1}{h_1} + \frac{1}{h_2}\Big)u_1 - \frac{u_2}{h_2} = f\,\frac{h_1 + h_2}{2}.\] The left side is \(-\big(\frac{u_2 - u_1}{h_2} - \frac{u_1 - u_0}{h_1}\big)\); divide by \((h_1 + h_2)/2\). So in 1D the finite element method on any mesh gives the non-uniform finite-difference formula: the difference of two slopes divided by the distance between the midpoints. (c) \(h_1 = 1\), \(h_2 = 2\), \(u = (0, 1, 9)\): left side \(-0 + 1.5 \cdot 1 - 9/2 = -3\); right side \(-2 \cdot 3/2 = -3\). Exact, as it should be for a quadratic.

// C1: the FEM matrix against the finite-difference matrix, and consistent vs lumped uptake.

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Assemble the tridiagonal matrix (diagonal, off-diagonal) and load vector.
/// d, k, f hold one value per element.
fn assemble(x: &[f64], d: &[f64], k: &[f64], f: &[f64], lumped: bool) -> (Vec<f64>, Vec<f64>, Vec<f64>) {
    let n = x.len();
    let (wd, wo) = if lumped { (0.5, 0.0) } else { (1.0 / 3.0, 1.0 / 6.0) };
    let (mut di, mut off, mut b) = (vec![0.0; n], vec![0.0; n - 1], vec![0.0; n]);
    for e in 0..n - 1 {                         // element e: nodes e and e + 1
        let h = x[e + 1] - x[e];
        let kd = d[e] / h + k[e] * h * wd;
        let ko = -d[e] / h + k[e] * h * wo;
        di[e] += kd;
        di[e + 1] += kd;
        off[e] += ko;
        b[e] += f[e] * h / 2.0;
        b[e + 1] += f[e] * h / 2.0;
    }
    (di, off, b)
}

/// Solve with u(x[0]) = u0 and no flux at the last node.
fn fem1d(x: &[f64], d: &[f64], k: &[f64], f: &[f64], u0: f64, lumped: bool) -> Vec<f64> {
    let (di, off, b) = assemble(x, d, k, f, lumped);
    let mut rhs = b[1..].to_vec();
    rhs[0] -= off[0] * u0;                     // move the known u0 to the right
    let mut c = off[1..].to_vec();
    c.push(0.0);
    let mut u = vec![u0];
    u.extend(thomas(&off, &di[1..], &c, &rhs));
    u
}

// C2: uniform vs graded mesh for the hydrogel slab; error table and order.

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Assemble the tridiagonal matrix (diagonal, off-diagonal) and load vector.
/// d, k, f hold one value per element.
fn assemble(x: &[f64], d: &[f64], k: &[f64], f: &[f64], lumped: bool) -> (Vec<f64>, Vec<f64>, Vec<f64>) {
    let n = x.len();
    let (wd, wo) = if lumped { (0.5, 0.0) } else { (1.0 / 3.0, 1.0 / 6.0) };
    let (mut di, mut off, mut b) = (vec![0.0; n], vec![0.0; n - 1], vec![0.0; n]);
    for e in 0..n - 1 {                         // element e: nodes e and e + 1
        let h = x[e + 1] - x[e];
        let kd = d[e] / h + k[e] * h * wd;
        let ko = -d[e] / h + k[e] * h * wo;
        di[e] += kd;
        di[e + 1] += kd;
        off[e] += ko;
        b[e] += f[e] * h / 2.0;
        b[e + 1] += f[e] * h / 2.0;
    }
    (di, off, b)
}

fn fem1d(x: &[f64], d: &[f64], k: &[f64], f: &[f64], u0: f64, lumped: bool) -> Vec<f64> {

// C3: too-long elements give negative concentrations; a two-layer gel with and
// without a node at the layer interface.

// Thomas algorithm (Structure: symmetric, banded, sparse); a[0] and c[n-1] unused
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Assemble the tridiagonal matrix (diagonal, off-diagonal) and load vector.
/// d, k, f hold one value per element.
fn assemble(x: &[f64], d: &[f64], k: &[f64], f: &[f64], lumped: bool) -> (Vec<f64>, Vec<f64>, Vec<f64>) {
    let n = x.len();
    let (wd, wo) = if lumped { (0.5, 0.0) } else { (1.0 / 3.0, 1.0 / 6.0) };
    let (mut di, mut off, mut b) = (vec![0.0; n], vec![0.0; n - 1], vec![0.0; n]);
    for e in 0..n - 1 {                         // element e: nodes e and e + 1
        let h = x[e + 1] - x[e];
        let kd = d[e] / h + k[e] * h * wd;
        let ko = -d[e] / h + k[e] * h * wo;
        di[e] += kd;
        di[e + 1] += kd;
        off[e] += ko;
        b[e] += f[e] * h / 2.0;
        b[e + 1] += f[e] * h / 2.0;
    }
    (di, off, b)
}

/// Solve with u(x[0]) = u0 and no flux at the last node.
fn fem1d(x: &[f64], d: &[f64], k: &[f64], f: &[f64], u0: f64, lumped: bool) -> Vec<f64> {
    let (di, off, b) = assemble(x, d, k, f, lumped);
    let mut rhs = b[1..].to_vec();
    rhs[0] -= off[0] * u0;                     // move the known u0 to the right
    let mut c = off[1..].to_vec();
    c.push(0.0);
    let mut u = vec![u0];
    u.extend(thomas(&off, &di[1..], &c, &rhs));
    u
}
fn main() {
    let (l, dd, k) = (1000.0, 100.0, 0.04);
    let lam = f64::sqrt(dd / k);
    let uniform = |n: usize| (0..=n).map(|i| l * i as f64 / n as f64).collect::<Vec<f64>>();
    let minval = |u: &[f64]| u.iter().cloned().fold(f64::INFINITY, f64::min);
    for n in [2, 4, 6, 8, 10] {
        let x = uniform(n);
        let u = fem1d(&x, &vec![dd; n], &vec![k; n], &vec![0.0; n], 1.0, false);
        let ul = fem1d(&x, &vec![dd; n], &vec![k; n], &vec![0.0; n], 1.0, true);
        println!("N = {:2}  h/lambda = {:4.1}  min u = {:9.2e}  lumped min = {:.2e}",
                 n, l / n as f64 / lam, minval(&u), minval(&ul));
    }
    // cell-free top layer (k = 0) of thickness c, cells below
    let c = 100.0;
    let uc = 1.0 / (1.0 + c / lam * ((l - c) / lam).tanh());
    println!("{}", uc);
    for n in [50, 49, 100, 99, 200, 199] {
        let x = uniform(n);
        let kk: Vec<f64> = (0..n).map(|e| if (x[e] + x[e + 1]) / 2.0 < c { 0.0 } else { k }).collect();
        let u = fem1d(&x, &vec![dd; n], &kk, &vec![0.0; n], 1.0, false);
        let e = x.iter().position(|&xi| xi >= c).unwrap();   // linear interpolation at x = c
        let u100 = if (x[e] - c).abs() < 1e-9 { u[e] }
                   else { u[e - 1] + (u[e] - u[e - 1]) * (c - x[e - 1]) / (x[e] - x[e - 1]) };
        let node = x.iter().any(|&xi| (xi - c).abs() < 1e-9);
        println!("N = {:3}  node at 100: {:5}  u(100) = {:.4}  error = {:9.2e}", n, node, u100, u100 - uc);
    }

  1. The consistent matrix gives negative minima for \(h/\lambda = 10, 5, 3.3, 2.5\), all above \(\sqrt6 \approx 2.45\) (B3(d)); at \(h/\lambda = 2\) every value is positive. The lumped (finite-difference) matrix stays positive at every \(h\). The check that finds this in your own work: look at the minimum and maximum of the solution (a concentration must stay between its boundary values here, the maximum principle) and refine.
  2. The exact interface value is \(1/3\): the coating is a straight-line drop from 1 to \(u(100)\), and the gel below takes up the drug as if it were an infinitely deep slab. With a node at the interface the error falls by 4 per doubling (second order: \(1.5\cdot10^{-3}\), \(3.7\cdot10^{-4}\), \(9.3\cdot10^{-5}\)). Without one, it only halves (first order: \(7.5\cdot10^{-3}\), \(4.1\cdot10^{-3}\), \(2.1\cdot10^{-3}\)), because the element that straddles the interface has the wrong \(k\) on part of its length, and \(u'\) has a kink inside it that a straight line cannot follow. Rule: put mesh nodes (in 2D, mesh edges) on material interfaces. Mesh generators do this when the interface is part of the geometry you draw.

Where this leads

  • Steady state in two dimensions (Part 10): the same kind of steady problem (diffusion plus uptake, there oxygen under a lid) on a 2D rectangle with the five-point stencil. A 2D finite element code replaces the loop over intervals by a loop over triangles with 3 × 3 element matrices; the resulting sparse matrix is solved with the same sparse direct solvers.
  • Iterative linear solvers in depth (Part 11): for 3D meshes with millions of nodes the sparse system is solved iteratively (conjugate gradients works because \(K\) is symmetric positive definite), with preconditioning.
  • Flow plus diffusion (Part 10) took the Poiseuille profile as given. A Stokes solver (COMSOL, FEniCS, Firedrake, scikit-fem) computes the flow in any geometry; that velocity field can then be fed into the advection–diffusion equation on the same mesh.
