Exercise: pivoting, norms and conditioning

Goal

By the end of this exercise you should be able to:

  • explain why Gaussian elimination without pivoting fails on a tiny pivot, and show it with 3-digit arithmetic,
  • carry out partial pivoting by hand and write \(PA = LU\) for a \(3\times 3\) matrix,
  • compute the 1-, 2- and \(\infty\)-norms of a vector and the 1- and \(\infty\)-norms of a matrix,
  • compute the condition number \(\kappa(A)\) of a \(2\times2\) matrix by hand and with kappa() / np.linalg.cond / nalgebra’s singular_values(),
  • use the rule “lose about \(\log_{10}\kappa\) digits” for rounding errors and for measurement noise,
  • tell the residual from the error, and say what each one checks,
  • predict how much detector noise is amplified when unmixing dyes with overlapping spectra.

The by-hand part uses pen and paper (and a calculator for B1, where you must round to 3 digits on purpose). The code part checks the hand answers and then works at sizes where only code works.

Background

Spectral unmixing. A cell carries unknown amounts \(\mathbf x\) of several dyes. Detector \(i\) records \(b_i = \sum_j A_{ij} x_j\), where \(A_{ij}\) is the signal of one unit of dye \(j\) in detector \(i\) (measured from single-stained controls). Unmixing one cell means solving \(A\mathbf x = \mathbf b\). Our running example is two dyes with detectors at their two peaks and overlap \(c\):

\[A = \begin{pmatrix}1 & c\\ c & 1\end{pmatrix}, \qquad c = 0.95 \text{ (peaks about 10 nm apart)}.\]

Facts used below:

  1. Elimination (from Gaussian elimination as LU) subtracts \(m = a_{ik}/a_{kk}\) times row \(k\) from row \(i\). The pivot \(a_{kk}\) is divided by twice: in the multiplier and in back substitution. A tiny pivot gives huge multipliers, and the rows below are swamped by rounding.
  2. Partial pivoting: before eliminating column \(k\), swap rows so that the entry of largest absolute value in column \(k\) (on or below the diagonal) is the pivot. Then \(|m| \le 1\). The swaps are collected in a permutation matrix \(P\): \(PA = LU\).
  3. Vector norms: \(\|\mathbf v\|_1 = \sum_i |v_i|\), \(\|\mathbf v\|_2 = \sqrt{\sum_i v_i^2}\), \(\|\mathbf v\|_\infty = \max_i |v_i|\). Relative error of a vector: \(\|\hat{\mathbf x} - \mathbf x\|/\|\mathbf x\|\).
  4. Matrix norms: \(\|A\| = \max_{\mathbf v\ne 0}\|A\mathbf v\|/\|\mathbf v\|\), the largest stretch. \(\|A\|_1\) = largest absolute column sum, \(\|A\|_\infty\) = largest absolute row sum, \(\|A\|_2 = \sigma_{\max}\), the largest singular value (for a symmetric matrix: the largest \(|\lambda|\)).
  5. Condition number \(\kappa(A) = \|A\|\,\|A^{-1}\|\); in the 2-norm \(\kappa = \sigma_{\max}/\sigma_{\min}\). If \(A\mathbf x = \mathbf b\) and \(A(\mathbf x + \Delta\mathbf x) = \mathbf b + \Delta\mathbf b\), then \[\frac{\|\Delta\mathbf x\|}{\|\mathbf x\|} \le \kappa(A)\,\frac{\|\Delta\mathbf b\|}{\|\mathbf b\|}, \qquad \text{digits lost} \approx \log_{10}\kappa.\]
  6. Residual vs error. The residual \(\mathbf r = \mathbf b - A\hat{\mathbf x}\) can be computed; the error \(\hat{\mathbf x} - \mathbf x\) cannot. \(\|\hat{\mathbf x} - \mathbf x\|/\|\mathbf x\| \le \kappa(A)\,\|\mathbf r\|/\|\mathbf b\|\). A backward-stable solver (LU with partial pivoting) always returns a residual near rounding level, whatever \(\kappa\) is.
  7. Inverse of a \(2\times2\): \(\begin{pmatrix}a & b\\ c & d\end{pmatrix}^{-1} = \dfrac{1}{ad - bc}\begin{pmatrix}d & -b\\ -c & a\end{pmatrix}\).

// Solve, norms and condition number with nalgebra
// (R: solve, norm, kappa; numpy: linalg.solve, linalg.norm, linalg.cond).
use nalgebra::{matrix, vector};

fn main() {
    let a = matrix![1.0,  0.95;
                    0.95, 1.0];
    let x = a.lu().solve(&vector![1.96, 1.94]).unwrap(); // LU with partial pivoting
    println!("{}  {}", x[0], x[1]);
    let v = vector![3.0, -4.0, 12.0];
    println!("{} {} {}", v.lp_norm(1), v.norm(), v.amax()); // 1-, 2- and inf-norm
    // nalgebra has no induced 1- and inf-norm. row_sum() adds up the rows, giving
    // the column sums (1-norm); column_sum() gives the row sums (inf-norm).
    let abs_a = a.abs();
    let s = a.singular_values();
    println!("{} {} {}", abs_a.row_sum().max(), abs_a.column_sum().max(), s.max());
    println!("{}", s.max() / s.min());                   // condition number (2-norm)
}

// Output:
// 1.1999999999999995  0.8000000000000005
// 19 13 12
// 1.95 1.95 1.95
// 38.999999999999964

R’s solve(), numpy’s np.linalg.solve and nalgebra’s lu().solve() all use LU with partial pivoting. The last digits differ between languages (0.8000000000000005, 39.00000000000007): different libraries round differently in the last place. R prints only 7 significant digits by default, which hides this.

By hand

B1. A tiny pivot in 3-digit arithmetic. Solve \[\begin{pmatrix}0.0001 & 1\\ 1 & 1\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix} = \begin{pmatrix}1\\2\end{pmatrix}\] on a “computer” that rounds every intermediate result to 3 significant digits. (a) Without pivoting: compute the multiplier, the new row 2, then \(x_2\) and \(x_1\). (b) With partial pivoting: swap the rows first and repeat. (c) The exact solution is \(x_1 = 1/0.9999 = 1.0001\ldots\), \(x_2 = 0.9998/0.9999 = 0.9999\ldots\). Which answer is right to 3 digits? Where exactly was the information lost in (a)?

B2. \(PA = LU\) by hand. Use partial pivoting on \[A = \begin{pmatrix}2 & 1 & 1\\ 4 & 3 & 3\\ 8 & 7 & 9\end{pmatrix}, \qquad \mathbf b = \begin{pmatrix}4\\10\\24\end{pmatrix}.\] (a) Which row becomes the first pivot row? Eliminate column 1 and write down the multipliers. (b) Which row becomes the second pivot row? Eliminate column 2. (c) Write \(P\), \(L\) (unit lower triangular, holding the multipliers) and \(U\). Check that \(PA = LU\) in at least one row. (d) Solve \(A\mathbf x = \mathbf b\) using \(L\mathbf y = P\mathbf b\) and \(U\mathbf x = \mathbf y\).

B3. Vector norms. (a) Compute \(\|\mathbf v\|_1\), \(\|\mathbf v\|_2\) and \(\|\mathbf v\|_\infty\) for \(\mathbf v = (3, -4, 12)\) and for \(\mathbf w = (1, 1, 1, 1)\). (b) Two dyes, true amounts \(\mathbf x = (1, 1)\), unmixed \(\hat{\mathbf x} = (1.2, 0.8)\). Compute the relative error in all three norms. (c) Sketch the sets \(\|\mathbf v\| = 1\) in 2D for the three norms. For which vectors is \(\|\mathbf v\|_1 = \|\mathbf v\|_\infty\)?

B4. The condition number of the two-dye matrix. \(A = \begin{pmatrix}1 & 0.95\\ 0.95 & 1\end{pmatrix}\). (a) Compute \(\|A\|_1\) and \(\|A\|_\infty\). (b) Compute \(A^{-1}\) (fact 7), then \(\|A^{-1}\|_\infty\) and \(\kappa_\infty(A)\). (c) The eigenvalues of \(A\) are \(1 + 0.95\) and \(1 - 0.95\), with eigenvectors \((1, 1)\) and \((1, -1)\). What are \(\sigma_{\max}\), \(\sigma_{\min}\) and \(\kappa_2(A)\)? (d) For general overlap \(0 \le c < 1\), show that \(\kappa_2 = (1 + c)/(1 - c)\). Evaluate it for \(c = 0.5, 0.9, 0.99\). (e) The detector readings have 3 significant digits. About how many digits of the dye amounts can you trust for \(c = 0.5\), \(0.95\) and \(0.99\)?

B5. Worst and best directions. Keep \(A\) from B4 and \(\mathbf b = (1.95, 1.95)\), so \(\mathbf x = (1, 1)\). Use the 2-norm. (a) For \(\Delta\mathbf b = (0.01, -0.01)\), find \(\Delta\mathbf x = A^{-1}\Delta\mathbf b\) and the amplification \(\dfrac{\|\Delta\mathbf x\|/\|\mathbf x\|}{\|\Delta\mathbf b\|/\|\mathbf b\|}\). (b) Same for \(\Delta\mathbf b = (0.01, 0.01)\). (c) Explain the two answers with the eigenvectors from B4(c). What kind of detector error is dangerous?

B6. Residual vs error. Still \(A\) from B4, \(\mathbf b = (1.95, 1.95)\), true \(\mathbf x = (1, 1)\). Two programs return \(\hat{\mathbf x}_a = (1.2, 0.8)\) and \(\hat{\mathbf x}_b = (1.01, 1.01)\). (a) Compute both residuals \(\mathbf r = \mathbf b - A\hat{\mathbf x}\) and the relative residuals \(\|\mathbf r\|_\infty/\|\mathbf b\|_\infty\). (b) Compute both relative errors \(\|\hat{\mathbf x} - \mathbf x\|_\infty/\|\mathbf x\|_\infty\). (c) Which answer would you pick by looking at the residual? Check the bound \(\text{error} \le \kappa_\infty \times \text{residual}\) for \(\hat{\mathbf x}_a\).

B7. A zero pivot in a well-conditioned matrix. Detector 1 sees no dye 1: \[A = \begin{pmatrix}0 & 1\\ 1 & 0.3\end{pmatrix}, \qquad \mathbf b = \begin{pmatrix}1\\1.3\end{pmatrix}.\] (a) What happens if you eliminate without pivoting? (b) Solve with partial pivoting. (c) Compute \(\kappa_\infty(A)\). Is the problem hard? Whose fault was the failure in (a)?

In code

C1. Elimination without pivoting. Write solve_nopivot(A, b) (elimination, then back substitution). For \(A = \begin{pmatrix}\delta & 1\\ 1 & 1\end{pmatrix}\), \(\mathbf b = (1, 2)\) and \(\delta = 10^{-2}, 10^{-5}, \ldots, 10^{-20}\), compute the relative error (2-norm) against the exact solution \(x_1 = 1/(1-\delta)\), \(x_2 = (1-2\delta)/(1-\delta)\), and compare it with \(\varepsilon/\delta\).

C2. Partial pivoting. (a) Add partial pivoting to your function (solve_pivot) and repeat C1. (b) Solve B2 with solve_pivot and compare \(P\), \(L\) and \(U\) with a library: Matrix::lu with expand() in R, scipy.linalg.lu in Python, nalgebra’s lu() with .l(), .u(), .p() in Rust. Careful: R and scipy return \(A = PLU\), so their \(P\) is the transpose of ours.

C3. Norms. (a) Check B3(a)–(b) in code. (b) Compute \(\|A\|_1\), \(\|A\|_\infty\) and \(\|A\|_2\) of the two-dye matrix from the formulas (column sums, row sums, largest singular value) and with norm() / np.linalg.norm. (c) The 2-norm as the largest stretch. Compute \(\|A\mathbf v\|_2\) for 1001 unit vectors \(\mathbf v = (\cos\theta, \sin\theta)\), \(\theta \in [0, 2\pi]\). Compare the largest and smallest values with \(\sigma_{\max}\) and \(\sigma_{\min}\).

C4. Condition number and overlap. For \(c = 0.5, 0.9, 0.95, 0.99, 0.999\), compute \(\kappa_2\) of \(\begin{pmatrix}1 & c\\ c & 1\end{pmatrix}\) with kappa(A, exact = TRUE) (Python: np.linalg.cond(A); Rust: largest over smallest of singular_values()) and compare with \((1+c)/(1-c)\) from B4(d). In R, also print the default estimate kappa(A) and 1 / rcond(A); in Python, np.linalg.cond(A, 1).

C5. Lose \(\log_{10}\kappa\) digits. A panel of 6 dyes with Gaussian emission spectra (width 30 nm), detectors at the peaks, peaks spacing nm apart:

\[A_{ij} = \exp\!\left(-\frac{(p_i - p_j)^2}{2\cdot 30^2}\right), \qquad p_i = 500 + \text{spacing}\cdot(i - 1).\]

For spacing \(= 60, 30, 20, 10, 5\) nm, take the true amounts \(\mathbf x = (5, 1, 3, 2, 4, 1)\), compute \(\mathbf b = A\mathbf x\), solve, and print \(\kappa\), the relative error, the number of correct digits \(-\log_{10}(\text{error})\) and the prediction \(16 - \log_{10}\kappa\).

C6. Residual vs error. For the panel with spacing 6 nm, solve as in C5 and print \(\kappa\), the relative residual \(\|\mathbf b - A\hat{\mathbf x}\|/\|\mathbf b\|\), the relative error, and the bound \(\kappa\times\) residual. What does the residual tell you about solve()? What does it tell you about the answer?

C7. Detector noise in unmixed cells. Simulate 1000 cells that all carry 1 unit of each of two dyes. Add independent Gaussian noise with standard deviation 0.01 to both detector readings of every cell, and unmix all cells with \(c = 0.5\) and with \(c = 0.95\). Compare the standard deviation of the unmixed dye 1 with the prediction \(0.01 \times \|\text{row 1 of } A^{-1}\|_2\) and with \(\kappa\).

Answer E1

\(\Delta\mathbf b = (+0.01, -0.01)\): \(\mathbf b = (1.960, 1.940)\), \(\hat{\mathbf x} = (1.200, 0.800)\), \(\|\Delta\mathbf b\|/\|\mathbf b\| = 0.51\,\%\), \(\|\Delta\mathbf x\|/\|\mathbf x\| = 20.0\,\%\), amplification \(39.0 = \kappa\): the teaser of the lecture, and the worst case. \(\Delta\mathbf b = (+0.01, +0.01)\): \(\hat{\mathbf x} = (1.005, 1.005)\), both relative changes \(0.51\,\%\), amplification \(1.0\). The two lines have slopes \(-1/0.95\) and \(-0.95\): nearly parallel, both along \((1, -1)\). Changing \(\mathbf b\) along \((1, 1)\) shifts both lines the same way, perpendicular to themselves, and the crossing moves only a little along \((1, 1)\). Changing \(\mathbf b\) along \((1, -1)\) shifts them in opposite directions; two nearly parallel lines that move apart a little cross far away, sliding along \((1, -1)\), the squashed direction of the ellipse in the lecture.

E3. (a single noisy detector) Set \(c = 0.95\) and click \(\Delta\mathbf b = (+0.01, 0)\): only detector 1 is off. Read the amplification. Then drag the red point in (b) around the dashed circle and watch the amplification. Where is it largest, where smallest? Is it ever above \(\kappa\)?

Answer E3

\((+0.01, 0)\): \(\hat{\mathbf x} = (1.103, 0.903)\), \(0.36\,\% \to 10.0\,\%\), amplification \(27.6\), between 1 and \(\kappa = 39\). An error in one detector is half “along \((1, 1)\)” and half “along \((1, -1)\)”, and the second half is the one amplified. Dragging around the circle, the amplification is largest (39) when \(\Delta\mathbf b\) points along \((1, -1)\) or \((-1, 1)\) and smallest (1) along \((1, 1)\) or \((-1, -1)\). E4. (spillover spreading) Click \(\Delta\mathbf b = 0\) and untick lines, so panel (c) shows only the cells. Click \(c = 0.5\), \(0.9\), \(0.95\), \(0.99\) and read the standard deviation of the unmixed dye 1 each time. What shape does the noise circle in (b) take in (c), and along which direction? Answer E4

With noise sd \(0.01\): sd of unmixed dye 1 \(= 0.015\), \(0.070\), \(0.140\), \(0.700\) for \(c = 0.5, 0.9, 0.95, 0.99\) (predicted \(0.015\), \(0.071\), \(0.141\), \(0.707\); the factor \(\|\text{row 1 of } A^{-1}\|_2 = \sqrt{1+c^2}/(1-c^2)\) is \(1.5\), \(7.1\), \(14.1\), \(70.7\), as in C7). The round cloud of readings becomes an ellipse along \((1, -1)\), dye 1 against dye 2, with half-axes \(2\sigma/(1-c)\) and \(2\sigma/(1+c)\): the ratio of the axes is exactly \(\kappa\). At \(c = 0.99\), 158 of the 400 cells lie outside the plotted square. At \(c = 0.95\), noise sd \(0.005\) gives sd \(0.070\) and \(0.02\) gives \(0.280\): the spread is proportional to the detector noise, so a better detector shrinks the cloud, but the amplification factor (\(\times 14.1\)) and the shape stay the same. Only the overlap \(c\), that is the choice of dyes, changes \(\kappa\).

Hints

Hint 1 — 3-digit arithmetic (B1)

Round after every operation: \(1 - 10000 = -9999\) becomes \(-1.00\times10^4\) with 3 significant digits. Keep the exact numbers next to the rounded ones so you see which digits disappear.

Hint 2 — partial pivoting by hand (B2, B7)

At step \(k\), look only at column \(k\) from the diagonal down. Swap the row with the largest \(|a_{ik}|\) into position \(k\) (swap the whole row, including \(b_i\), and the multipliers already stored in that row of \(L\)). \(P\) is the identity with its rows in the final pivot order; \(P\mathbf b\) is \(\mathbf b\) in that order.

Hint 3 — norms of a 2 × 2 matrix (B4, C3)

1-norm: add the absolute values in each column, take the largest. \(\infty\)-norm: same with rows. For a symmetric matrix, the singular values are the absolute values of the eigenvalues. In code: R norm(A, "1"), norm(A, "I"), norm(A, "2") and svd(A)$d; Python np.linalg.norm(A, 1), np.linalg.norm(A, np.inf), np.linalg.norm(A, 2) and np.linalg.svd(A, compute_uv=False); Rust nalgebra v.lp_norm(1), v.norm(), v.amax(), a.singular_values() (docs).

Hint 4 — κ for overlap c (B4(d))

The eigenvalues of \(\begin{pmatrix}1 & c\\ c & 1\end{pmatrix}\) are \(1 + c\) (eigenvector \((1, 1)\)) and \(1 - c\) (eigenvector \((1, -1)\)). Check by multiplying.

Hint 5 — writing the elimination (C1, C2)

Loop over \(k = 1, \ldots, n-1\) and \(i = k+1, \ldots, n\). Back substitution runs \(i = n, \ldots, 1\): \(x_i = (b_i - \sum_{j>i} a_{ij}x_j)/a_{ii}\). R has backsolve() for the last step, Python scipy.linalg.solve_triangular. To find the pivot row: which.max(abs(A[k:n, k])) + k - 1 in R, k + np.argmax(np.abs(A[k:, k])) in Python. Swap rows with A[c(k, p), ] <- A[c(p, k), ] (R) or A[[k, p], :] = A[[p, k], :] (Python). In Python, copy the inputs first (A = A.astype(float).copy()), or you will overwrite the caller’s matrix.

Hint 6 — building the spectra matrix (C5, C6)

R: outer(p, p, function(d, q) exp(-(d - q)^2 / (2 * 30^2))). Python: broadcasting, np.exp(-(p[:, None] - p[None, :])**2 / (2 * 30**2)). Rust: DMatrix::from_fn(n, n, |i, j| ...). The relative error is sqrt(sum((xh - x)^2)) / sqrt(sum(x^2)) in R and np.linalg.norm(xh - x) / np.linalg.norm(x) in Python.

Hint 7 — many cells at once (C7)

Put the readings of all cells in a \(2\times 1000\) matrix \(B\) (one column per cell); solve(A, B) (R) or np.linalg.solve(A, B) (Python) solves all 1000 systems with one LU factorisation. Generate the noise with rnorm(2 * 1000, sd = 0.01) (R) or rng.normal(0, 0.01, size=(2, 1000)) (Python).

def solve_nopivot(A, b):
    A = A.astype(float).copy(); b = np.array(b, dtype=float)
    n = A.shape[0]
    for k in range(n - 1):
        for i in range(k + 1, n):
            m = A[i, k] / A[k, k]
            A[i, :] -= m * A[k, :]; b[i] -= m * b[k]

    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - A[i, i + 1:] @ x[i + 1:]) / A[i, i]
    return x

fn solve_nopivot(mut a: Vec<Vec<f64>>, mut b: Vec<f64>) -> Vec<f64> {
    let n = b.len();
    for k in 0..n - 1 {
        for i in k + 1..n {
            let m = a[i][k] / a[k][k]; // multiplier
            for j in 0..n {
                a[i][j] -= m * a[k][j];
            }
            b[i] -= m * b[k];
        }
    }
    let mut x = vec![0.0; n]; // back substitution
    for i in (0..n).rev() {
        let s: f64 = (i + 1..n).map(|j| a[i][j] * x[j]).sum();
        x[i] = (b[i] - s) / a[i][i];
    }
    x
}

fn rel(u: &[f64], v: &[f64]) -> f64 {
    let num: f64 = u.iter().zip(v).map(|(a, b)| (a - b).powi(2)).sum();
    let den: f64 = v.iter().map(|a| a * a).sum();
    (num / den).sqrt()
}

// Gaussian elimination WITH partial pivoting (hand-written), then nalgebra's LU.
use nalgebra::{matrix, vector};

fn solve_pivot(mut a: Vec<Vec<f64>>, mut b: Vec<f64>) -> Vec<f64> {
    let n = b.len();
    for k in 0..n - 1 {
        // row index p >= k of the largest |a[p][k]|
        let p = (k..n).max_by(|&i, &j| a[i][k].abs().total_cmp(&a[j][k].abs())).unwrap();
        a.swap(k, p); // swap rows k and p
        b.swap(k, p);
        for i in k + 1..n {
            let m = a[i][k] / a[k][k]; // now |m| <= 1
            for j in 0..n {
                a[i][j] -= m * a[k][j];
            }
            b[i] -= m * b[k];
        }
    }
    let mut x = vec![0.0; n];
    for i in (0..n).rev() {
        let s: f64 = (i + 1..n).map(|j| a[i][j] * x[j]).sum();
        x[i] = (b[i] - s) / a[i][i];
    }
    x
}

fn rel(u: &[f64], v: &[f64]) -> f64 {
    let num: f64 = u.iter().zip(v).map(|(a, b)| (a - b).powi(2)).sum();
    let den: f64 = v.iter().map(|a| a * a).sum();
    (num / den).sqrt()
}

The random numbers differ between languages, so the measured standard deviations differ by a few per cent; the predictions are the same. With overlap 0.5 the noise in the unmixed dye is \(1.5\times\) the detector noise; with overlap 0.95 it is \(14\times\): a 1 % detector noise becomes a 14 % spread in the unmixed abundance. The factor \(\|\text{row 1 of } A^{-1}\|_2\) (\(1.49\) and \(14.1\)) is below \(\kappa\) (\(3\) and \(39\)): \(\kappa\) is the worst case over all directions of \(\mathbf b\) and \(\Delta\mathbf b\), while independent noise in both detectors falls only partly in the worst direction. The spread is along \((1, -1)\), dye 1 against dye 2 (lecture figure): this is what cytometrists call spillover spreading. No solver can remove it; only better-separated dyes (smaller \(c\)) or more detectors (Part 4) can.

Where this leads

  • Structure: symmetric, banded, sparse (next unit): the same LU machinery, made faster when \(A\) is symmetric positive definite (Cholesky needs no pivoting) or banded or sparse.
  • Least squares: normal equations vs QR (Part 4): spectral cytometers have more detectors than dyes, so unmixing becomes least squares (that unit teaches the method on calibration curves rather than spectra). Forming the normal equations \(A^\top A\) squares the condition number; QR avoids that.
  • The SVD, rank deficiency and regularisation (Part 4): the singular values used here as numbers get their full meaning, and regularisation trades a little bias for much less noise when \(\kappa\) is large.
  • Every Newton step in Newton for systems of equations (Part 2) solves a linear system with the Jacobian; a large \(\kappa\) there means an inaccurate step. In Identifiability and uncertainty of fitted parameters (Part 9), a nearly singular matrix means parameters the data cannot pin down.
