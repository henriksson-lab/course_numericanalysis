Exercise: the diffusion (heat) equation by finite differences

Goal

By the end of this exercise you should be able to:

  • read a concentration \(c(x, t)\) as a function of space and time, and its two partial derivatives as slopes of slices,
  • derive the diffusion equation from Fick’s law and a mass balance, and estimate a diffusion time \(L^2/D\) with the right units,
  • set up a grid in \(x\) and \(t\) and carry out FTCS steps by hand,
  • write FTCS in code (vectorised over space) with fixed-value (Dirichlet) and no-flux boundaries,
  • check a simulation against an exact solution, by grid refinement, by the maximum principle and by conservation,
  • explain the stability limit \(D\,\Delta t/\Delta x^2 \le 1/2\) from the zigzag mode and from the eigenvalues of the second-difference matrix, and recognise what breaking it looks like.

The by-hand part uses pen, paper and a pocket calculator. The code part works with 51 grid points and thousands of time steps, where only code works.

Background

  1. Fick’s law and the diffusion equation. The flux (amount per unit area per second) is \(J = -D\,\partial c/\partial x\). A mass balance on a thin slice (rate in − rate out) gives \[\frac{\partial c}{\partial t} = D\,\frac{\partial^2 c}{\partial x^2}.\] Heat conduction is the same equation with temperature \(T\) and thermal diffusivity \(\alpha\) (water: \(\alpha \approx 1.4\cdot10^{-7}\) m²/s).
  2. Initial and boundary conditions. A start profile \(c(x, 0)\), and at each end either a fixed value (a large reservoir, Dirichlet) or no flux, \(\partial c/\partial x = 0\) (a wall).
  3. Time scale. Any diffusion time is a multiple of \(L^2/D\). Work in µm and s: \(10^{-9}\) m²/s \(= 1000\) µm²/s.
  4. Grid. \(x_i = i\,\Delta x\), \(i = 0, \dots, N\), \(t_n = n\,\Delta t\), \(c_i^n \approx c(x_i, t_n)\). The second difference \((c_{i-1} - 2c_i + c_{i+1})/\Delta x^2\) from Numerical differentiation replaces \(\partial^2 c/\partial x^2\), with error \(\tfrac{\Delta x^2}{12}\,\partial^4 c/\partial x^4\).
  5. FTCS (forward in time, centred in space) is Euler’s method (Initial value problems and Euler’s method) on the grid ODEs: \[c_i^{n+1} = c_i^n + r\,\bigl(c_{i-1}^n - 2c_i^n + c_{i+1}^n\bigr), \qquad r = \frac{D\,\Delta t}{\Delta x^2}.\] Stable only for \(r \le 1/2\). For \(r \le 1/2\) the new value is a weighted average of three old ones with non-negative weights, so no value can leave the range of the start and boundary values (maximum principle).
  6. No-flux wall at \(x_N\): a ghost point \(c_{N+1} = c_{N-1}\) gives \(c_N^{n+1} = c_N^n + 2r\,(c_{N-1}^n - c_N^n)\).
  7. Exact solution for the chamber below (empty at \(t = 0\), \(c = 1\) at \(x = 0\), \(c = 0\) at \(x = L\)): \[c(x, t) = 1 - \frac{x}{L} - \sum_{n=1}^{\infty} \frac{2}{n\pi}\,\sin\frac{n\pi x}{L}\;e^{-n^2\pi^2 D t/L^2}.\]

The running example: a flow-free chemotaxis chamber. A straight channel of length \(L = 500\) µm joins a source reservoir (\(c = 1\), concentrations scaled by the source) to a sink reservoir (\(c = 0\)); there is no flow, so the attractant moves only by diffusion. Diffusion-based gradient devices of this kind are described in the reviews by Kim, Kim & Jeon (2010) [G1] and in Frontiers in Bioengineering and Biotechnology (2015) [G3]; our channel is a simplified version with typical, not device-specific, numbers. Small molecule: \(D = 1000\) µm²/s (\(10^{-9}\) m²/s); protein chemokine: \(D = 100\) µm²/s (\(10^{-10}\) m²/s). Grid: \(N = 50\) intervals of \(\Delta x = 10\) µm, \(r = 0.4\), so \(\Delta t = 0.04\) s.

FTCS is hand-written in all three languages: vectorised over space in R and numpy, a plain loop in Rust. The one trap: every point must be updated from the old time level. R and numpy evaluate the whole right-hand side before assigning, so this happens automatically; in Rust we copy the old level first.

D  <- 1000                         # µm^2/s: small molecule, 1e-9 m^2/s
L  <- 500                          # µm: source at x = 0, sink at x = L
N  <- 50; dx <- L / N              # 50 intervals of 10 µm, 51 grid points
x  <- seq(0, L, by = dx)
r  <- 0.4; dt <- r * dx^2 / D      # 0.04 s; FTCS needs r <= 1/2

ftcs <- function(c, r, nsteps) {   # Dirichlet: c[1] and c[n] never change
  i <- 2:(length(c) - 1)           # interior points
  for (k in seq_len(nsteps))
    c[i] <- c[i] + r * (c[i - 1] - 2 * c[i] + c[i + 1])
  c
}
exact <- function(x, t, L, D, nterm = 200) {   # chamber empty at t = 0
  s <- 1 - x / L
  for (n in 1:nterm)
    s <- s - 2 / (n * pi) * sin(n * pi * x / L) * exp(-(n * pi / L)^2 * D * t)
  s
}

c60 <- ftcs(c0, r, round(60 / dt)) # 1500 steps to t = 60 s

import numpy as np

D = 1000.0                          # µm^2/s: small molecule, 1e-9 m^2/s
L = 500.0                           # µm: source at x = 0, sink at x = L
N = 50; dx = L / N                  # 50 intervals of 10 µm, 51 grid points
x = np.linspace(0, L, N + 1)
r = 0.4; dt = r * dx**2 / D         # 0.04 s; FTCS needs r <= 1/2

def ftcs(c, r, nsteps):             # Dirichlet: c[0] and c[-1] never change
    c = c.copy()
    for k in range(nsteps):         # right-hand side uses the old values only
        c[1:-1] = c[1:-1] + r * (c[:-2] - 2 * c[1:-1] + c[2:])
    return c

def exact(x, t, L, D, nterm=200):   # chamber empty at t = 0
    s = 1 - x / L
    for n in range(1, nterm + 1):
        s = s - 2 / (n * np.pi) * np.sin(n * np.pi * x / L) * np.exp(-(n * np.pi / L)**2 * D * t)
    return s

c0 = np.zeros(N + 1); c0[0] = 1.0   # source 1, channel empty, sink 0

// rust/examples/diffusion_explicit_background.rs  —  cargo run --example diffusion_explicit_background
// Background: FTCS for the chemotaxis chamber (source at x = 0, sink at x = L).
use std::f64::consts::PI;

const D: f64 = 1000.0; // µm^2/s: small molecule, 1e-9 m^2/s
const L: f64 = 500.0; // µm

// FTCS with fixed (Dirichlet) ends: c[0] and c[n-1] never change.
// `old` keeps the previous time level, so every update uses old values only.
fn ftcs(c: &[f64], r: f64, nsteps: usize) -> Vec<f64> {
    let n = c.len();
    let mut c = c.to_vec();
    let mut old = c.clone();
    for _ in 0..nsteps {
        old.copy_from_slice(&c);
        for i in 1..n - 1 {
            c[i] = old[i] + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
    }
    c
}

// exact solution (Fourier series), chamber empty at t = 0
fn exact(x: f64, t: f64, l: f64, d: f64, nterm: usize) -> f64 {
    let mut s = 1.0 - x / l;
    for n in 1..=nterm {
        let k = n as f64 * PI / l;
        s -= 2.0 / (n as f64 * PI) * (k * x).sin() * (-k * k * d * t).exp();
    }
    s
}

fn main() {
    let n = 50; // 50 intervals of 10 µm, 51 grid points
    let dx = L / n as f64;
    let x: Vec<f64> = (0..=n).map(|i| i as f64 * dx).collect();
    let r = 0.4;
    let dt = r * dx * dx / D; // 0.04 s; FTCS needs r <= 1/2
    let mut c0 = vec![0.0; n + 1];
    c0[0] = 1.0; // source 1, channel empty, sink 0
    let c60 = ftcs(&c0, r, (60.0 / dt).round() as usize); // 1500 steps to t = 60 s
    for j in (5..n).step_by(10) {
        // x = 50, 150, ..., 450 µm
        println!("x = {:3.0} um   FTCS {:.4}   exact {:.4}", x[j], c60[j], exact(x[j], 60.0, L, D, 200));
    }
}

By hand

B1. Units and gradients. (a) Convert \(D = 10^{-9}\), \(10^{-10}\) and \(2\cdot10^{-9}\) m²/s to µm²/s. (b) A chemokine reservoir holds 10 nM, the sink 0, and the channel is \(L = 500\) µm long. At steady state, what is the gradient in nM/µm? What concentration difference does a cell 10 µm long see across its body in the middle of the channel, as a fraction of the local concentration? (c) Where in the channel is the relative difference across a cell largest? (Cells are thought to sense relative differences of a few per cent.)

B2. Diffusion times. (a) Fill in \(L^2/D\) for \(L = 100\) µm, \(500\) µm, \(1\) mm and \(1\) cm, for a small molecule (\(D = 1000\) µm²/s) and a protein (\(D = 100\) µm²/s). Give the answers in convenient units. (b) The lecture found that the gradient is within 5 % of the straight line at \(t \approx 0.26\,L^2/D\). How long is that for the protein in a 1 mm channel? (c) An experimenter wants the protein gradient established within 10 minutes. What is the longest channel she can use? (d) Heat in a 1 mm layer of water (\(\alpha = 1.4\cdot10^{-7}\) m²/s): compute \(L^2/\alpha\). Why can a microfluidic chip change the temperature of a sample much faster than it can change a protein concentration?

B3. The second difference tells the direction of change. On a grid with \(\Delta x = 10\) µm and \(D = 1000\) µm²/s, compute \(\partial c/\partial t \approx D\,(c_{i-1} - 2c_i + c_{i+1})/\Delta x^2\) at the middle point for: (a) \(c = (0.80, 0.78, 0.76)\); (b) \(c = (0.50, 0.40, 0.35)\); (c) \(c = (0, 1, 0)\). Which values rise, which fall, which stay? Relate this to the shape of the profile.

B4. FTCS by hand. Take \(L = 500\) µm, \(N = 4\) (\(\Delta x = 125\) µm), \(D = 1000\) µm²/s, start \((c_0, \dots, c_4) = (1, 0, 0, 0, 0)\) with \(c_0 = 1\) and \(c_4 = 0\) fixed. (a) Take three FTCS steps with \(r = 0.25\). What is \(\Delta t\)? What is the steady state on this grid, and does FTCS leave it unchanged? (b) Take three steps with \(r = 0.5\). Show that the update is then simply the average of the two neighbours. (c) Take three steps with \(r = 1\). What is wrong with the result?

B5. The zigzag. (a) For \(c_i = \varepsilon(-1)^i\) show that \(c_{i-1} - 2c_i + c_{i+1} = -4c_i\), so one FTCS step multiplies the zigzag by \(1 - 4r\). (b) Compute \(1 - 4r\) for \(r = 0.1\), \(0.25\), \(0.4\), \(0.5\), \(0.52\), \(0.6\) and \(1\). For which \(r\) does the zigzag decay? Flip sign? Grow? (c) With \(r = 0.52\), a zigzag of rounding size \(10^{-16}\) grows by about \(1.08\) per step. After how many steps is it of size 1? (d) What is the largest stable \(\Delta t\) with \(\Delta x = 10\) µm for the small molecule? For the protein? For a simulation of both together?

B6. Eigenvalues on a tiny grid. With \(N = 4\) there are three interior points and \[A = \begin{pmatrix} -2 & 1 & 0 \\ 1 & -2 & 1 \\ 0 & 1 & -2 \end{pmatrix}.\] (a) Find the eigenvalues of \(A\) (expand \(\det(A - \lambda I)\) along the first row) and check them against \(-4\sin^2\bigl(k\pi/(2N)\bigr)\), \(k = 1, 2, 3\). Check that \((1, \sqrt2, 1)\), \((1, 0, -1)\) and \((1, -\sqrt2, 1)\) are eigenvectors. Which one is the zigzag? (b) With \(\Delta x = 125\) µm and \(D = 1000\) µm²/s the grid ODEs are \(\mathbf c' = \tfrac{D}{\Delta x^2}A\mathbf c + \mathbf b\). Give the three decay rates. What is the largest stable Euler step, and the matching \(r\)? (c) Compare the slowest rate with the exact \(\pi^2 D/L^2\).

B7. A wall and the ghost point. (a) Derive the wall update \(c_N^{n+1} = c_N^n + 2r(c_{N-1}^n - c_N^n)\) from FTCS with the ghost point \(c_{N+1} = c_{N-1}\). (b) Close both ends of a three-point grid \((c_0, c_1, c_2)\). Write the three updates and show that the trapezoid total \(\tfrac12 c_0 + c_1 + \tfrac12 c_2\) does not change in a step, but the plain sum \(c_0 + c_1 + c_2\) does. (c) With a source at \(x = 0\) and a wall at \(x = L\), what is the steady state? What does this mean for a dead-end side channel on a chip?

B8. The cost of a fine grid. The protein (\(D = 100\) µm²/s) in a 1 mm channel, simulated to \(t = 0.26\,L^2/D\). (a) With \(\Delta x = 10\) µm and \(r = 1/2\): how many time steps, and roughly how many point updates? (b) The same with \(\Delta x = 1\) µm. (c) The slowest decay time in the problem is \(L^2/(\pi^2 D)\). How many times longer is it than the largest stable step in (b)? Why is this wasteful?

C5. Walls. (a) Write ftcs_closed with a no-flux wall at \(x = L\) (ghost point), with an option to close \(x = 0\) too. Compare the open chamber and the dead-end chamber at \(t = 64.4\) s (when the open one has its gradient). (b) How long until the closed end of the dead-end chamber reaches \(c = 0.95\)? Express it as a multiple of \(L^2/D\). (c) Close both ends and start with a bolus: \(c = 1\) for \(230 \le x \le 270\) µm, 0 elsewhere. At \(t = 0\), \(5\) and \(60\) s print the trapezoid total \(\Delta x\,(\tfrac12 c_0 + c_1 + \dots + c_{N-1} + \tfrac12 c_N)\), the plain \(\Delta x \sum_i c_i\), and the largest \(c\). Which total is conserved? What does the profile approach?

Answer E1

Small molecule: within 5 % after 64.4 s = 1.07 min, \(0.2578\,L^2/D\), 1611 steps of \(\Delta t = 0.04\) s. Early on the attractant fills only the first few grid points and the distance stays near 1; it then falls steeply once the profile straightens. Protein (\(D = 100\) µm²/s): 644 s = 10.7 min, again \(0.2578\,L^2/D\) and again 1611 steps, now of \(\Delta t = 0.4\) s. Ten times smaller \(D\), ten times longer. Hints

Hint 1 — units (B1, B2)

\(1\) m \(= 10^6\) µm, so \(1\) m² \(= 10^{12}\) µm². \(L^2/D\) with \(L\) in µm and \(D\) in µm²/s is in seconds. For B1(c), divide the gradient by the local concentration \(1 - x/L\).

Hint 2 — FTCS by hand (B4)

Write one row per time level. Compute every new value from the old row, and only then write the new row. The end values never change. The steady state is the profile that the update leaves unchanged: second difference 0 at every interior point.

Hint 3 — stability (B5, B6, C4)

Euler on \(y' = -ky\) multiplies by \(1 - kh\) and needs \(|1 - kh| \le 1\) (Initial value problems and Euler’s method; for a system, the rule holds for every eigenvalue: Stiffness and implicit methods). For the grid, \(k\) runs over the decay rates \(-\tfrac{D}{\Delta x^2}\lambda_k\); the largest one decides. For the \(3 \times 3\) determinant, set \(\mu = -2 - \lambda\): then \(\det = \mu^3 - 2\mu\). In code use eigen(A, symmetric = TRUE) (Python: np.linalg.eigvalsh; Rust: symmetric_eigenvalues() in nalgebra). Build \(A\) with diag and index pairs cbind(i, j) (Python: np.diag with an offset).

Hint 4 — vectorised FTCS (C1–C5)

With i <- 2:(length(c) - 1), the vectors c[i - 1], c[i], c[i + 1] are the left neighbours, the points and the right neighbours (Python: c[:-2], c[1:-1], c[2:]). Use seq_len(nsteps) so that nsteps = 0 runs no steps. Python’s ftcs must work on a copy (c = c.copy()), or it changes the caller’s array. Make step counts whole numbers with round(t / dt).

Hint 5 — order and slopes (C3)

If error \(\approx C\,\Delta x^p\), halving \(\Delta x\) divides the error by \(2^p\). Fit the slope with lm on the logs (Python: np.polyfit, degree 1). With \(r\) fixed, \(\Delta t = r\,\Delta x^2/D\).

Hint 6 — walls and totals (B7, C5)

Compute the new wall value from old values before the interior update overwrites its neighbour. The total amount is the integral \(\int_0^L c\,dx\); on the grid the trapezoid rule from Numerical integration gives the end points half weight.

use std::f64::consts::PI;

const D: f64 = 1000.0; // µm^2/s
const L: f64 = 500.0; // µm

fn ftcs(c: &[f64], r: f64, nsteps: usize) -> Vec<f64> {
    let n = c.len();
    let mut c = c.to_vec();
    let mut old = c.clone();
    for _ in 0..nsteps {
        old.copy_from_slice(&c); // previous time level
        for i in 1..n - 1 {
            c[i] = old[i] + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
    }
    c
}

fn exact(x: f64, t: f64, l: f64, d: f64, nterm: usize) -> f64 {
    let mut s = 1.0 - x / l;
    for n in 1..=nterm {
        let k = n as f64 * PI / l;
        s -= 2.0 / (n as f64 * PI) * (k * x).sin() * (-k * k * d * t).exp();
    }
    s
}

// scientific notation as R and Python print it: 5.11e-04 rather than Rust's 5.11e-4
fn sci(x: f64, digits: usize) -> String {
    let s = format!("{:.*e}", digits, x);
    let (m, e) = s.split_once('e').unwrap();
    let e: i32 = e.parse().unwrap();
    format!("{}e{}{:02}", m, if e < 0 { '-' } else { '+' }, e.abs())
}

fn maxabs(a: &[f64], b: &[f64]) -> f64 {
    a.iter().zip(b).map(|(u, v)| (u - v).abs()).fold(0.0, f64::max)
}

        }
    }

fn t_grad(d: f64, l: f64, tol: f64, n: usize, r: f64) -> f64 {
    let dx = l / n as f64;
    let dt = r * dx * dx / d;
    let lin: Vec<f64> = (0..=n).map(|i| 1.0 - i as f64 * dx / l).collect();
    let mut c = vec![0.0; n + 1];
    c[0] = 1.0;
    let mut steps = 0;
    while c.iter().zip(&lin).map(|(u, v)| (u - v).abs()).fold(0.0, f64::max) > tol {
        c = ftcs(&c, r, 1);
        steps += 1;
    }
    steps as f64 * dt
}

// C3: grid refinement with r = 0.4 fixed: error at t = 30 s against the exact solution.
use std::f64::consts::PI;

const D: f64 = 1000.0; // µm^2/s
const L: f64 = 500.0; // µm

fn ftcs(c: &[f64], r: f64, nsteps: usize) -> Vec<f64> {
    let n = c.len();
    let mut c = c.to_vec();
    let mut old = c.clone();
    for _ in 0..nsteps {
        old.copy_from_slice(&c); // previous time level
        for i in 1..n - 1 {
            c[i] = old[i] + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
    }
    c
}

fn exact(x: f64, t: f64, l: f64, d: f64, nterm: usize) -> f64 {
    let mut s = 1.0 - x / l;
    for n in 1..=nterm {
        let k = n as f64 * PI / l;
        s -= 2.0 / (n as f64 * PI) * (k * x).sin() * (-k * k * d * t).exp();
    }
    s
}

}

ftcs_closed <- function(c, r, nsteps, left_closed = FALSE) {  # wall (no flux) at x = L
  n <- length(c); i <- 2:(n - 1)
  for (k in seq_len(nsteps)) {
    cn <- c[n] + 2 * r * (c[n - 1] - c[n])          # ghost point c[n+1] = c[n-1]
    c1 <- c[1] + 2 * r * (c[2] - c[1])              # used only if left_closed
    c[i] <- c[i] + r * (c[i - 1] - 2 * c[i] + c[i + 1])
    c[n] <- cn
    if (left_closed) c[1] <- c1
  }
  c
}

    return c

// rust/examples/diffusion_explicit_c5.rs  —  cargo run --example diffusion_explicit_c5
// C5: no-flux walls: a dead-end chamber, and mass conservation with both ends closed.
const D: f64 = 1000.0; // µm^2/s
const L: f64 = 500.0; // µm

fn ftcs(c: &[f64], r: f64, nsteps: usize) -> Vec<f64> {
    let n = c.len();
    let mut c = c.to_vec();
    let mut old = c.clone();
    for _ in 0..nsteps {
        old.copy_from_slice(&c); // previous time level
        for i in 1..n - 1 {
            c[i] = old[i] + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
    }
    c
}

// wall (no flux) at x = L via the ghost point c[N+1] = c[N-1]; optionally also at x = 0
fn ftcs_closed(c: &[f64], r: f64, nsteps: usize, left_closed: bool) -> Vec<f64> {
    let n = c.len();
    let mut c = c.to_vec();
    let mut old = c.clone();
    for _ in 0..nsteps {
        old.copy_from_slice(&c);
        for i in 1..n - 1 {
            c[i] = old[i] + r * (old[i - 1] - 2.0 * old[i] + old[i + 1]);
        }
        c[n - 1] = old[n - 1] + 2.0 * r * (old[n - 2] - old[n - 1]);
        if left_closed {
            c[0] = old[0] + 2.0 * r * (old[1] - old[0]);
        }
    }
    c
}

fn main() {
    let n = 50;
    let dx = L / n as f64;
    let x: Vec<f64> = (0..=n).map(|i| i as f64 * dx).collect();
    let (r, dt) = (0.4, 0.4 * dx * dx / D);
    let mut c0 = vec![0.0; n + 1];
    c0[0] = 1.0;
    // (a) open vs dead-end chamber at t = 64.4 s (gradient time of the open chamber)
    let nst = (64.4 / dt).round() as usize;
    let open = ftcs(&c0, r, nst);
    let dead = ftcs_closed(&c0, r, nst, false);
    for j in (0..=n).step_by(10) {
        println!("x = {:3.0} um   open {:.3}   dead end {:.3}", x[j], open[j], dead[j]);
    }
    // (b) time until the closed end reaches 0.95
    let mut c = c0.clone();
    let mut steps = 0;
    while c[n] < 0.95 {
        c = ftcs_closed(&c, r, 1, false);
        steps += 1;
    }
    let t = steps as f64 * dt;
    println!("closed end reaches 0.95 after {:.1} s; t D / L^2 = {:.3}", t, t * D / (L * L));
    // (c) both ends closed: a bolus of chemokine in the middle
    let b: Vec<f64> = x.iter().map(|&xi| if (xi - 250.0).abs() <= 20.0 { 1.0 } else { 0.0 }).collect();
    let w: Vec<f64> = (0..=n).map(|i| if i == 0 || i == n { 0.5 * dx } else { dx }).collect(); // trapezoid
    for t in [0.0, 5.0, 60.0] {
        let bt = ftcs_closed(&b, r, (t / dt).round() as usize, true);
        let trap: f64 = w.iter().zip(&bt).map(|(a, b)| a * b).sum();
        let plain: f64 = bt.iter().sum::<f64>() * dx;
        let mx = bt.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
        println!("t = {:3.0} s   trapezoid amount {:.10}   plain sum*dx {:.6}   max {:.4}", t, trap, plain, mx);
    }
}
