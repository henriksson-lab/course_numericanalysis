Exercise: power iteration and friends

Goal

By the end of this exercise you should be able to:

  • find the eigenvalues and eigenvectors of a 2 × 2 matrix by hand, and read a Leslie matrix (long-term growth rate, stable age distribution) and a Markov chain (stationary distribution) in terms of them,
  • write power iteration with normalisation and a residual-based stopping rule, and check it against eigen(),
  • predict the number of iterations from \(|\lambda_2/\lambda_1|\), measure the rate from an error plot, and recognise the two failures: \(|\lambda_2| = |\lambda_1|\) (no convergence) and \(|\lambda_2/\lambda_1| \approx 1\) (false convergence),
  • compute the Rayleigh quotient and explain why it doubles the digits for symmetric matrices,
  • use inverse iteration with a shift (factor once, solve many times) to find the eigenvalue nearest a chosen number.

The by-hand part needs pen, paper and a pocket calculator. The code part checks the hand answers and then works with the fish population and the cell-state chain from the lecture.

Background

An eigenvector \(\mathbf v \ne \mathbf 0\) of a square matrix \(A\) satisfies \(A\mathbf v = \lambda\mathbf v\); the number \(\lambda\) is its eigenvalue. We order eigenvalues by size: \(|\lambda_1| \ge |\lambda_2| \ge \dots\)

Facts used below:

  1. 2 × 2 by hand. The eigenvalues solve \(\det(A - \lambda I) = \lambda^2 - (\text{trace})\lambda + \det A = 0\). For each \(\lambda\), solve \((A - \lambda I)\mathbf v = \mathbf 0\) (one equation is enough, the other is a multiple of it).
  2. Leslie matrix. Fertilities \(F_i\) in the first row, survival probabilities \(s_i\) on the subdiagonal; \(\mathbf n_{t+1} = L\mathbf n_t\). The dominant eigenvalue \(\lambda_1\) is the long-term growth rate per time step, and its eigenvector, rescaled to sum 1, is the stable age distribution.
  3. Markov chain. \(P_{ij}\) = probability of moving from state \(i\) to state \(j\) in one step; rows sum to 1; proportions evolve as \(\mathbf p_{t+1} = \mathbf p_tP\) (row vector). The stationary distribution \(\boldsymbol\pi\) satisfies \(\boldsymbol\pi P = \boldsymbol\pi\): it is the eigenvector of \(P^T\) for \(\lambda_1 = 1\), rescaled to sum 1.
  4. Power iteration. \(\mathbf y = A\mathbf x_k\), estimate \(\lambda\), \(\mathbf x_{k+1} = \mathbf y/\|\mathbf y\|\). For nonnegative matrices normalise by the sum (\(\mathbf x\) = proportions, estimate \(\lambda \approx \mathrm{sum}(A\mathbf x_k)\)); in general by the 2-norm.
  5. Rate. If \(\mathbf x_0 = c_1\mathbf v_1 + c_2\mathbf v_2 + \dots\) with \(c_1 \ne 0\), then \(A^k\mathbf x_0 = \lambda_1^k\big(c_1\mathbf v_1 + c_2(\lambda_2/\lambda_1)^k\mathbf v_2 + \dots\big)\): the error falls by about \(|\lambda_2/\lambda_1|\) per step (linear convergence), so one digit takes \(1/\log_{10}(|\lambda_1/\lambda_2|)\) steps. No convergence if \(|\lambda_2| = |\lambda_1|\).
  6. Stopping. Stop when the residual \(\|A\mathbf x - \lambda\mathbf x\|\) is small. If successive changes shrink by a factor \(c\) per step, the remaining error is about \(\text{change}\cdot c/(1-c)\), which is much larger than the change when \(c\) is near 1.
  7. Rayleigh quotient. \(R(\mathbf x) = \mathbf x^TA\mathbf x / \mathbf x^T\mathbf x\), equal to \(\lambda\) for an eigenvector. For symmetric \(A\), an error \(\delta\) in \(\mathbf x\) gives an error of order \(\delta^2\) in \(R(\mathbf x)\).
  8. Inverse iteration. \((A - \sigma I)^{-1}\) has the same eigenvectors as \(A\) and eigenvalues \(1/(\lambda_i - \sigma)\). Power iteration with it (one linear solve per step) finds the eigenvalue nearest the shift \(\sigma\), at rate \(|\lambda_\text{nearest} - \sigma| / |\lambda_\text{next nearest} - \sigma|\). Factor \(A - \sigma I\) once; then each step costs only a forward and back substitution.

// Background: eigenvalues of the fish Leslie matrix with nalgebra.
// nalgebra has no general (nonsymmetric) eigenvector routine, so we only get
// the eigenvalues here; the eigenvector comes from power iteration (C1).
use nalgebra::DMatrix;

fn main() {
    let l = DMatrix::from_row_slice(4, 4, &[
        0.0, 1.5, 4.0, 5.0,      // offspring per fish of each age
        0.3, 0.0, 0.0, 0.0,      // survival to the next age
        0.0, 0.6, 0.0, 0.0,
        0.0, 0.0, 0.5, 0.0,
    ]);
    let mut ev: Vec<_> = l.complex_eigenvalues().iter().cloned().collect();
    ev.sort_by(|a, b| b.norm().partial_cmp(&a.norm()).unwrap()); // largest |lambda| first
    for z in &ev {
        println!("{:.7} {:+.7}i   |lambda| = {:.7}", z.re, z.im, z.norm());
    }
}

R’s eigen sorts by decreasing \(|\lambda|\); numpy’s np.linalg.eig does not sort, so sort yourself. Both return complex numbers for a nonsymmetric matrix and eigenvectors of length 1 with an arbitrary sign: rescale before you interpret them. nalgebra’s complex_eigenvalues gives eigenvalues only; for eigenvectors of a nonsymmetric matrix the Rust code below uses power and inverse iteration, written by hand. Rust prints numbers in its own format; the values agree with R and Python to the digits shown unless the text says otherwise.

By hand

B1. A two-age-class plant. A perennial plant has first-year plants (class 1) and older plants (class 2). First-year plants produce 0.6 seedlings each, older plants 0.9; 80 % of first-year plants survive to the next year, older plants all die: \[L = \begin{pmatrix} 0.6 & 0.9 \\ 0.8 & 0 \end{pmatrix}.\] (a) Find the characteristic polynomial and both eigenvalues. (b) Find an eigenvector for each eigenvalue, and check \(L\mathbf v = \lambda\mathbf v\). (c) What are the long-term growth rate and the stable stage distribution (as proportions)? (d) What is \(|\lambda_2/\lambda_1|\)? About how many power iterations does one decimal digit take?

B2. Power iteration by hand. Same plant, start with older plants only: \(\mathbf x_0 = (0, 1)\). (a) Compute \(\mathbf x_1, \dots, \mathbf x_4\) without normalising (\(\mathbf x_{k} = L\mathbf x_{k-1}\)). For each \(k\), compute the growth of the total, \(\text{sum}(\mathbf x_k)/\text{sum}(\mathbf x_{k-1})\), and its error compared with \(\lambda_1\). (b) Compute the ratio of successive errors. What number does it approach, and why does the sign alternate? (c) Write \(\mathbf x_0\) as a combination of the eigenvectors from B1 and use it to predict the proportion of first-year plants after 10 years. How far is it from the stable distribution?

B3. A biennial plant. A biennial plant forms a rosette in its first year and flowers in its second year (4 seedlings per plant), then dies; 25 % of rosettes survive to flower: \(L = \begin{pmatrix} 0 & 4 \\ 0.25 & 0 \end{pmatrix}\). (a) Find the eigenvalues. What is \(|\lambda_2/\lambda_1|\)? (b) Compute \(L^2\). Starting from 100 rosettes, \(\mathbf x_0 = (100, 0)\), what are \(\mathbf x_1, \mathbf x_2, \mathbf x_3\)? What does the power-iteration estimate \(\text{sum}(\mathbf x_k)/\text{sum}(\mathbf x_{k-1})\) do? (c) What is the growth per two years? Is there a stable stage distribution? (d) In a variant, 10 % of first-year plants flower early (fertility 0.4 in class 1): \(L = \begin{pmatrix} 0.4 & 4 \\ 0.25 & 0 \end{pmatrix}\). Find the eigenvalues and \(|\lambda_2/\lambda_1|\). Does power iteration converge now?

B4. A two-state cell chain. Cells switch between proliferating (P) and quiescent (Q). Per day, a proliferating cell becomes quiescent with probability 0.1, a quiescent cell becomes proliferating with probability 0.2: \[P = \begin{pmatrix} 0.9 & 0.1 \\ 0.2 & 0.8 \end{pmatrix}.\] (a) Find the stationary distribution \(\boldsymbol\pi\) from \(\boldsymbol\pi P = \boldsymbol\pi\) and \(\pi_1 + \pi_2 = 1\). (b) The eigenvalues of \(P\) (and of \(P^T\)) are 1 and \(\text{trace}(P) - 1\). Why? What is \(\lambda_2\)? (c) Start with proliferating cells only, \(\mathbf p_0 = (1, 0)\). Compute \(\mathbf p_1, \mathbf p_2, \mathbf p_3\) and the error in the first entry. By what factor does it shrink each day? (d) How many days until the error is below 0.01? (e) Another cell type switches with probabilities 0.001 and 0.002. What is \(\lambda_2\)? In a simulation the proportions change by only \(10^{-6}\) from one day to the next. Roughly how far from equilibrium are they?

B5. Rayleigh quotient. \(A = \begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}\) (a covariance matrix of two traits) has eigenvalues 6 and 1 with eigenvectors \((2, 1)\) and \((1, -2)\). (a) For \(\mathbf x = (1, 0.45)\), compute \(A\mathbf x\), the sum ratio \(\text{sum}(A\mathbf x)/\text{sum}(\mathbf x)\) and the Rayleigh quotient \(\mathbf x^TA\mathbf x/\mathbf x^T\mathbf x\). Give the error of each. (b) Repeat for \(\mathbf x = (1, 0.495)\), which is 10 times closer to the eigenvector direction \((1, 0.5)\). By what factor did each error shrink? (c) Explain the difference in one sentence.

B6. Inverse iteration. Use the plant matrix of B1 (\(\lambda = 1.2, -0.6\)). (a) For the shifts \(\sigma = 1\), \(\sigma = 0\) and \(\sigma = -0.5\), give the eigenvalues of \((L - \sigma I)^{-1}\), the eigenvalue of \(L\) that inverse iteration finds, and the convergence rate. Compare with plain power iteration. (b) Do one step of inverse iteration with \(\sigma = 1\) from \(\mathbf x_0 = (0, 1)\): solve \((L - I)\mathbf y = \mathbf x_0\) by hand and rescale \(\mathbf y\) to proportions. Compare the error with one step of power iteration (B2). (c) What happens with the shift \(\sigma = 1.2\) exactly? Would the result still be useful in exact arithmetic? In floating point?

In code

C1. Power iteration. Write power_it(A, x, tol, maxit) that normalises by the sum, estimates \(\lambda\) as the growth of the total, stops when the residual \(\|A\mathbf x - \lambda\mathbf x\|\) falls below tol, and returns \(\lambda\), \(\mathbf x\), the number of iterations and the residual. (a) Apply it to the fish Leslie matrix (Background) starting from the stocked lake, \((0, 1000, 0, 0)\), with tol = 1e-10. Report the growth rate, the stable age distribution and the iteration count. (b) Compare with eigen() (Python: np.linalg.eig): how large are the differences in \(\lambda_1\) and in the distribution? (c) Check your answers to B1 with the plant matrix.

C2. The convergence rate. For the fish, run 60 power iterations from \((0, 1, 0, 0)\) and record the error in the estimate of \(\lambda_1\) and the largest error in the age distribution (take eigen() as the truth). (a) Plot both errors against \(k\) on a log scale (R: plot(..., log = "y"); Python: plt.semilogy). (b) Fit a straight line to \(\log_{10}\)(distribution error) for \(k = 10, \dots, 50\) and compare its slope with \(\log_{10}|\lambda_2/\lambda_1|\). (c) Predict how many iterations it takes to shrink an error of 1 to \(10^{-10}\). Compare with C1.

C3. Failures. (a) Make the semelparous fish of the lecture (first row \((0, 0, 0, 12)\)). Print \(|\lambda_i|\), run power_it with maxit = 200, and report the iteration count and the final residual. (b) Run power_it on the biennial plant of B3 and on its early-flowering variant. Compare with your hand answers. (c) Run 5000 steps of \(\mathbf x \leftarrow L\mathbf x\) for the fish without normalising. What do you get, and after roughly how many steps does it go wrong?

C4. The stationary distribution of cell states. Use the cell-state chain of the lecture, \(P\) = (0.80, 0.15, 0.05; 0.05, 0.90, 0.05; 0.05, 0.10, 0.85) (rows S, B, L). (a) Find \(\boldsymbol\pi\) three ways: 100 steps of \(\mathbf p \leftarrow \mathbf pP\) from \((1, 0, 0)\); the eigenvector of \(P^T\) from eigen(); and as a linear system: \((P^T - I)\boldsymbol\pi^T = \mathbf 0\) with the last equation replaced by \(\pi_1 + \pi_2 + \pi_3 = 1\). (b) The slow chain \(P_\text{slow} = I + 0.01(P - I)\): iterate from \((1, 0, 0)\) until the largest change in one step is below \(10^{-8}\). Report the number of steps and the true error. (c) Estimate the rate \(c\) from the last two changes and the remaining error from \(\text{change}\cdot c/(1-c)\) (fact 6). Compare with the true error.

C5. Rayleigh quotient against sum ratio. Run power iteration with 2-norm normalisation for 80 steps. At each step compute the sum ratio \(\text{sum}(A\mathbf x)/\text{sum}(\mathbf x)\) and the Rayleigh quotient \(\mathbf x^TA\mathbf x/\mathbf x^T\mathbf x\), and record the first iteration at which each is within \(10^{-10}\) of \(\lambda_1\). Do this for (a) the trait correlation matrix \(C\) = (1, 0.4, 0.3; 0.4, 1, 0.2; 0.3, 0.2, 1) (symmetric), starting from \((1, 0, 0)\), and (b) the fish Leslie matrix, starting from \((0, 1, 0, 0)\). Explain the difference with fact 7.

C6. Inverse iteration with a shift. Write inv_it(A, sigma, x, tol, maxit) that factors \(A - \sigma I\) once (R: Matrix::lu and solve; Python: scipy.linalg.lu_factor and lu_solve), normalises in the 2-norm, estimates \(\lambda\) with the Rayleigh quotient of \(A\), and stops on the residual. (a) Find the stationary distribution of the slow chain with \(\sigma = 1 + 10^{-6}\). How many iterations? Compare with C4(b). (b) Find \(\lambda_2\) of \(P^T\) and its eigenvector with \(\sigma = 0.82\), then try \(\sigma = 0.77\). Which eigenvalues do you get, in how many iterations? Explain with fact 8. (c) The deviation from equilibrium shrinks by \(\lambda_2\) per day. How many days after sorting does it take to fall to 1 % of its initial size?

C7. Rayleigh quotient iteration. Write rqi(A, x, tol, maxit): at each step set the shift to the current Rayleigh quotient, print it with 16 digits together with the residual, stop when the residual is below \(10^{-9}\), otherwise solve \((A - \sigma I)\mathbf y = \mathbf x\) and normalise. (a) Run it on \(C\) from \((1, 1, 1)\). How does the residual fall from step to step? (b) Run it from \((1, 0, 0)\) and from \((1, -1, 0)\). Which eigenvalues do you get? (c) What happens if you lower the tolerance to \(10^{-12}\) in (a)? Why?

Hints

Hint 1 — eigenvalues and eigenvectors of a 2 × 2 (B1, B3, B4, B5)

\(\det\begin{pmatrix} a-\lambda & b \\ c & d-\lambda\end{pmatrix} = (a-\lambda)(d-\lambda) - bc\). For an eigenvector, take the first row of \((A - \lambda I)\mathbf v = \mathbf 0\), \((a - \lambda)v_1 + bv_2 = 0\), and pick \(v_1\) to make the numbers nice. To check, multiply \(A\mathbf v\) and compare entry by entry with \(\lambda\mathbf v\). For a Markov chain, \(\boldsymbol\pi P = \boldsymbol\pi\) gives one useful equation, e.g. \(0.1\pi_1 = 0.2\pi_2\) (“flow out of P = flow into P”).

Hint 2 — the convergence rate (B2, B4, C2)

Error after \(k\) steps \(\approx C\,|\lambda_2/\lambda_1|^k\). To reach a factor \(10^{-d}\) you need \(k = d/\log_{10}|\lambda_1/\lambda_2|\) steps. For a straight-line fit of \(\log_{10}\) error against \(k\): R lm(log10(err) ~ k), Python np.polyfit(k, np.log10(err), 1); the slope is the first coefficient in Python and the second in R.

Hint 3 — matrix products and the Markov chain (C1, C4)

R: A %*% x is the matrix product; drop() turns a one-column matrix into a vector; for the row vector of proportions, p %*% P. eigen(t(P)) gives the eigenvectors of \(P^T\) as columns. Python: A @ x, p @ P, np.linalg.eig(P.T). For the linear system, solve(M, b) / np.linalg.solve.

Hint 4 — inverse iteration (B6, C6, C7)

\((L - \sigma I)\mathbf y = \mathbf x\) for a 2 × 2: \(\begin{pmatrix} a & b \\ c & d\end{pmatrix}^{-1} = \dfrac{1}{ad - bc}\begin{pmatrix} d & -b \\ -c & a\end{pmatrix}\). In code, never form the inverse: factor once and solve. R: F <- Matrix::lu(Matrix::Matrix(M)), then as.vector(solve(F, x)). Python: F = scipy.linalg.lu_factor(M), then scipy.linalg.lu_solve(F, x). Rust: let lu = m.lu(); then lu.solve(&x). RQI changes the shift every step, so there it has to factor every step (solve(A - sigma * diag(n), x)).

Hint 5 — failure checks (C3, C4)

Mod() (R) / np.abs() (Python) of the eigenvalues shows whether two have the same size. power_it returns the iteration count: if it equals maxit, it did not converge. In C4, keep all changes in a vector so you can divide the last one by the one before.

use nalgebra::{DMatrix, DVector};

// returns (lambda, x, iterations, residual)
fn power_it(a: &DMatrix<f64>, x0: &[f64], tol: f64, maxit: usize) -> (f64, DVector<f64>, usize, f64) {
    let mut x = DVector::from_row_slice(x0);
    x /= x.sum();
    let (mut lambda, mut r, mut k) = (0.0, f64::INFINITY, 0);
    while k < maxit {
        k += 1;
        let y = a * &x;
        lambda = y.sum();                       // growth factor of the total
        r = (&y - lambda * &x).norm();          // residual ||Ax - lambda x||
        x = y / lambda;                         // normalise: proportions
        if r < tol {
            break;
        }
    }
    (lambda, x, k, r)
}

}

Where this leads

  • How eigen() works, and big problems (next unit): eigen() finds all eigenvalues with the QR algorithm, which is, in outline, a clever shifted inverse iteration on all vectors at once. For a few eigenpairs of a large sparse matrix (the top principal components of a 20 000-cell dataset), Krylov methods (Lanczos, irlba, RSpectra, scipy.sparse.linalg.eigsh) improve on power iteration by keeping all the vectors \(\mathbf x, A\mathbf x, A^2\mathbf x, \dots\) instead of only the last one.
  • Equilibria, stability and the phase plane (Part 8): the stability of an equilibrium of an ODE model is decided by the eigenvalues of its Jacobian, and the slowest-decaying direction is again an eigenvector.
  • Stochastic simulation (Part 8): the Markov chains there run in continuous time; their long-run behaviour is again a stationary distribution.
  • Iterative linear solvers in depth (Part 11): Jacobi and similar methods converge at a rate set by the largest eigenvalue of an iteration matrix, the same \(|\lambda|^k\) argument as in this unit.
