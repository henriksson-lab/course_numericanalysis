Exercise: identifiability and uncertainty of fitted parameters

Goal

By the end of this exercise you should be able to:

  • recognise structural non-identifiability (parameters that only appear as a product; the \(k_a/k_e\) flip-flop) from the model equations and from the Jacobian,
  • compute standard errors and the correlation matrix of fitted parameters from \(s^2(J^TJ)^{-1}\), and check them against the Hessian of the sum of squares,
  • read the badly determined parameter combinations off the SVD of the Jacobian (in log-parameters),
  • compute a profile likelihood by re-fitting with one parameter fixed, and spot a flat profile that the standard error hides,
  • recognise a sloppy model from the spread of the eigenvalues of \(J^TJ\),
  • compare sampling designs before an experiment, and add a prior as an extra residual.

The running example is the pharmacokinetic model and the simulated plasma concentrations of Nonlinear least squares and ODE fitting: one oral dose of 100 mg, true \(k_a = 1\) /h, \(k_e = 0.2\) /h, \(V = 20\) L, noise SD 0.1 mg/L. The code uses that unit’s names: bateman(t, ka, ke, V) with the dose D, the sample times tt and the concentrations y. The by-hand part uses pen, paper and a calculator.

Background

The one-compartment model with first-order absorption from the gut (rate \(k_a\)), first-order elimination (rate \(k_e\)), volume \(V\), dose \(D\) and bioavailability \(F\):

\[C(t) = \frac{F\,D\,k_a}{V\,(k_a - k_e)}\left(e^{-k_e t} - e^{-k_a t}\right)\]

Facts used below:

  1. Identifiable means: different parameter values give different model outputs. Structural non-identifiability is a property of the model (no data can fix it); practical non-identifiability is a property of the data (too few, too noisy, badly placed samples).
  2. Jacobian. \(J_{ij} = \partial C(t_i)/\partial\theta_j\) (\(n\) samples × \(p\) parameters). In log-parameters, \(\partial C/\partial\log\theta_j = \theta_j\,\partial C/\partial\theta_j\): multiply column \(j\) by \(\theta_j\). An exact linear dependence between columns (a zero singular value) is structural non-identifiability.
  3. Hessian. For \(S(\theta) = \sum_i r_i^2\) with \(r_i = y_i - C(t_i)\): \(H = 2J^TJ - 2\sum_i r_i\nabla^2C(t_i) \approx 2J^TJ\) (Gauss–Newton).
  4. Covariance. With independent noise of variance \(\sigma^2\): \(\operatorname{Cov}(\hat\theta) \approx \sigma^2(J^TJ)^{-1} = 2\sigma^2 H^{-1}\), with \(\sigma^2\) estimated by \(s^2 = S(\hat\theta)/(n-p)\) if not known. Standard errors are the square roots of the diagonal; the correlation is \(r_{jk} = \operatorname{Cov}_{jk}/(\mathrm{SE}_j\,\mathrm{SE}_k)\). The Fisher information is \(\mathcal I = J^TJ/\sigma^2\).
  5. SVD of \(J\). With \(J = U\Sigma V^T\), the uncertainty along the right singular vector \(v_i\) is \(\sigma/\sigma_i\): small singular values are badly determined directions. The eigenvalues of \(J^TJ\) are \(\sigma_i^2\).
  6. Profile likelihood. \(\text{PL}(\theta_j) = \min\) of \(S\) over all other parameters, with \(\theta_j\) fixed. A 95 % interval is where \((\text{PL}(\theta_j) - S(\hat\theta))/s^2 \le 3.84\) (\(= 1.96^2\), the 95 % point of \(\chi^2_1\)). For a linear model this equals the Wald interval \(\hat\theta_j \pm 1.96\,\mathrm{SE}_j\).
  7. Prediction uncertainty (delta method): for any derived quantity \(g(\theta)\), \(\operatorname{Var}g(\hat\theta) \approx \nabla g^T\operatorname{Cov}(\hat\theta)\nabla g\).
  8. A prior \(\log\theta_j \sim N(\mu, \tau^2)\) adds the residual \((\log\theta_j - \mu)/\tau\) to the data residuals \(r_i/\sigma\). This is ridge regularisation, and the maximum a posteriori estimate.

import numpy as np
from scipy.optimize import least_squares

D = 100.0                                                                         # oral dose, mg
tt = np.array([0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6, 8, 10, 12])                      # hours
y = np.array([1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61])  # mg/L
late = tt >= 3                                                                    # sparse design

def bateman(t, ka, ke, V):
    return D * ka / (V * (ka - ke)) * (np.exp(-ke * t) - np.exp(-ka * t))

def jacobian(f, p, h=1e-5):
    """Central-difference Jacobian of a vector function f at p (step relative to |p|)."""
    p = np.asarray(p, float)
    cols = []
    for j in range(len(p)):
        e = np.zeros_like(p); e[j] = h * max(abs(p[j]), 1.0)
        cols.append((f(p + e) - f(p - e)) / (2 * e[j]))
    return np.column_stack(cols)

def fit_pk(ts, ys, start):
    res = least_squares(lambda p: ys - bateman(ts, *p), start, xtol=1e-12, ftol=1e-12, gtol=1e-12)
    return res.x, np.sum(res.fun**2), res

th, S, res = fit_pk(tt, y, [0.5, 0.1, 10])
s2 = S / (len(y) - 3)                      # residual variance s^2
cov = s2 * np.linalg.inv(res.jac.T @ res.jac)
se = np.sqrt(np.diag(cov))
for name, est, s in zip(["ka", "ke", "V"], th, se):
    print(f"{name:2s} {est:10.7f} {s:10.8f}")  # estimates and standard errors
# ka  1.0150722 0.06243155
# ke  0.1906157 0.01040041
# V  20.2162105 0.71647068
print(np.round(cov / np.outer(se, se), 2))     # correlation matrix of the estimates

// rust/examples/identifiability_background.rs  —  cargo run --example identifiability_background
// Fit the PK model, standard errors and correlations (nalgebra, hand-written LM).
#![allow(dead_code)]
use nalgebra::{DMatrix, DVector};

// One-compartment model with oral absorption, dose D = 100 mg (mg/L)
const D: f64 = 100.0; // oral dose, mg
fn bateman(t: f64, ka: f64, ke: f64, v: f64) -> f64 {
    D * ka / (v * (ka - ke)) * ((-ke * t).exp() - (-ka * t).exp())
}
const TT: [f64; 12] = [0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, 8.0, 10.0, 12.0];
const Y: [f64; 12] = [1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61];

// Central-difference Jacobian of f at p (like numDeriv::jacobian, less refined)
fn jacobian(f: &dyn Fn(&[f64]) -> Vec<f64>, p: &[f64]) -> DMatrix<f64> {
    let n = f(p).len();
    let mut j = DMatrix::zeros(n, p.len());
    for k in 0..p.len() {
        let h = 1e-5 * p[k].abs().max(1.0);
        let (mut pp, mut pm) = (p.to_vec(), p.to_vec());
        pp[k] += h;
        pm[k] -= h;
        let (fp, fm) = (f(&pp), f(&pm));
        for i in 0..n { j[(i, k)] = (fp[i] - fm[i]) / (2.0 * h); }
    }
    j
}

// Levenberg-Marquardt for min sum r(p)^2, hand-written (R: nls / nls.lm, Python: least_squares)
fn levmar(r: &dyn Fn(&[f64]) -> Vec<f64>, p0: &[f64]) -> Vec<f64> {
    let ss = |p: &[f64]| -> f64 { let v = r(p); if v.iter().all(|x| x.is_finite()) { v.iter().map(|x| x * x).sum() } else { f64::INFINITY } };
    let (mut p, mut mu) = (p0.to_vec(), 1e-3);
    for _ in 0..500 {
        let j = jacobian(r, &p);                     // Jacobian of the residuals
        let rv = DVector::from_vec(r(&p));
        let jtj = j.transpose() * &j;
        let g = j.transpose() * &rv;
        loop {
            let a = &jtj + DMatrix::from_diagonal(&jtj.diagonal()) * mu;
            let step = a.lu().solve(&(-&g)).unwrap();
            let pn: Vec<f64> = p.iter().zip(step.iter()).map(|(a, b)| a + b).collect();
            if ss(&pn) <= ss(&p) {
                let small = step.norm() < 1e-12 * (1.0 + DVector::from_vec(p.clone()).norm());
                p = pn;
                mu = (mu / 10.0).max(1e-12);
                if small { return p; }
                break;
            }
            mu *= 10.0;
            if mu > 1e12 { return p; }
        }
    }
    p
}

// Residuals y - C(t) for the one-compartment model at the sample times ts
fn resid(ts: &[f64], ys: &[f64]) -> impl Fn(&[f64]) -> Vec<f64> {
    let (ts, ys) = (ts.to_vec(), ys.to_vec());
    move |p: &[f64]| ts.iter().zip(&ys).map(|(ti, yi)| yi - bateman(*ti, p[0], p[1], p[2])).collect()
}
fn sse(r: &dyn Fn(&[f64]) -> Vec<f64>, p: &[f64]) -> f64 { r(p).iter().map(|x| x * x).sum() }

fn main() {
    let r = resid(&TT, &Y);
    let th = levmar(&r, &[0.5, 0.1, 10.0]);
    let s2 = sse(&r, &th) / (TT.len() - 3) as f64;          // residual variance s^2
    let j = jacobian(&r, &th);
    let cov = (j.transpose() * &j).try_inverse().unwrap() * s2;
    let se: Vec<f64> = (0..3).map(|i| cov[(i, i)].sqrt()).collect();
    println!("estimate: {:.5} {:.5} {:.4}", th[0], th[1], th[2]);
    println!("SE:       {:.5} {:.5} {:.4}", se[0], se[1], se[2]);
    println!("correlation:");
    for i in 0..3 {
        let row: Vec<String> = (0..3).map(|k| format!("{:6.2}", cov[(i, k)] / (se[i] * se[k]))).collect();
        println!("{}", row.join(" "));
    }
}

R’s vcov gives \(s^2(J^TJ)^{-1}\) for an nls fit, and cov2cor turns it into correlations. numDeriv::jacobian and numDeriv::hessian compute derivatives numerically (Richardson extrapolation); the Python jacobian above and the Rust jacobian are plain central differences, accurate to about 8–10 digits, which is enough here. Rust prints numbers in its own format; the values agree with R and Python to the digits shown unless the text says otherwise.

By hand

B1. Two parameters that only appear as a product. An enzyme assay measures the initial rate \(v(S) = k_\text{cat}E_0\,S/(K_m + S)\) at substrate concentrations \(S = 1, 2, 5\) mM. The enzyme concentration \(E_0\) is not known. Take \(k_\text{cat} = 10\) /s, \(E_0 = 0.1\) µM, \(K_m = 2\) mM. (a) Write down the three columns of the Jacobian, \(\partial v/\partial k_\text{cat}\), \(\partial v/\partial E_0\), \(\partial v/\partial K_m\), and evaluate them at the three values of \(S\). (b) Show that the first two columns are proportional. What is the rank of \(J\)? What happens to \(J^TJ\)? (c) In log-parameters (fact 2), what do the first two columns become? Give the null direction \(v\) in \((\log k_\text{cat}, \log E_0, \log K_m)\). (d) Which combinations of the three parameters are identifiable? What extra measurement would separate \(k_\text{cat}\) from \(E_0\)?

B2. The flip-flop. (a) Show that swapping \(k_a \leftrightarrow k_e\) in the model and replacing \(V\) by \(V' = V k_e/k_a\) leaves \(C(t)\) unchanged for every \(t\). (b) For \(k_a = 1\), \(k_e = 0.2\) /h, \(V = 20\) L, \(F = 1\), \(D = 100\) mg: what is the flip-flop parameter set? Compute \(C(2)\) for both sets (\(e^{-0.4} = 0.6703\), \(e^{-2} = 0.1353\)). (c) An intravenous bolus of the same drug gives \(C(t) = (D/V)e^{-k_e t}\). Why does that experiment break the symmetry? What half-lives would the two parameter sets predict? (d) Is each of the two parameter sets locally identifiable? What does a multistart fit show?

B3. Standard errors for a 2-parameter fit. After an intravenous dose the concentration falls as \(C(t) = A e^{-kt}\). Samples at \(t = 0, 1, 2\) h, \(A = 10\) mg/L, \(k = 0.5\) /h, noise SD \(\sigma = 0.2\) mg/L (\(e^{-0.5} = 0.6065\), \(e^{-1} = 0.3679\)). (a) The columns of \(J\) are \(\partial C/\partial A = e^{-kt}\) and \(\partial C/\partial k = -At\,e^{-kt}\). Write down \(J\) (\(3\times2\)). (b) Compute \(J^TJ\) and its inverse. (c) Compute the standard errors of \(\hat A\) and \(\hat k\) (fact 4, \(\sigma\) known) and their correlation. Explain the sign of the correlation. (d) Move the third sample from \(t = 2\) to \(t = 4\) h (\(e^{-2} = 0.1353\)). Recompute \(\mathrm{SE}(\hat k)\). Did a longer time course help?

B4. Where to sample. In B3, suppose \(A = 10\) is known and only \(k\) is fitted, from a single sample at time \(t\). (a) Show that \(\mathrm{SE}(\hat k) = \sigma/|A t e^{-kt}|\). (b) Evaluate it at \(t = 0.5\), \(2\) and \(8\) h (\(e^{-0.25} = 0.7788\), \(e^{-4} = 0.0183\)). Which time is best? (c) Find the best \(t\) by setting the derivative of \(t e^{-kt}\) to zero. Use the answer to explain B3(d). (d) In the PK model, \(\partial C/\partial k_a\) is large only during the first 2–3 hours (lecture, “Fix 1”). What does that predict for a study whose first sample is at 3 h?

B5. A profile by hand. Same model as B3, data \(y = (10.2, 5.9, 3.8)\) at \(t = 0, 1, 2\), noise SD \(\sigma = 0.2\) known. The best fit is \(\hat A = 10.145\), \(\hat k = 0.5115\) with \(S(\hat\theta) = 0.0598\). (a) With \(k\) fixed, \(C = A e^{-kt}\) is linear in \(A\). Show that the best \(A\) is \(\hat A(k) = \sum_i y_i e^{-kt_i}/\sum_i e^{-2kt_i}\). (b) Compute \(\hat A(k)\) and \(\text{PL}(k) = S(\hat A(k), k)\) for \(k = 0.4\), \(0.5\) and \(0.6\) (\(e^{-0.4} = 0.6703\), \(e^{-0.8} = 0.4493\), \(e^{-0.6} = 0.5488\), \(e^{-1.2} = 0.3012\)). (c) With \(\sigma\) known, the 95 % criterion is \((\text{PL}(k) - S(\hat\theta))/\sigma^2 \le 3.84\). Which of the three \(k\) values lie inside the interval? (d) The Wald interval is \(\hat k \pm 1.96\,\mathrm{SE}\) with \(\mathrm{SE} \approx 0.025\) from B3. Compare.

B6. Reading \(J^TJ\). A model has two positive parameters \(a, b\). At the fit, in log-parameters, \(J^TJ = \begin{pmatrix}4 & 3.9\\ 3.9 & 4\end{pmatrix}\), and \(\sigma = 0.1\). (a) Find the eigenvalues and eigenvectors of \(J^TJ\). (b) What is the standard error along each eigenvector? Which combinations, \(\log a + \log b\) or \(\log a - \log b\), are well and badly determined? What are they in terms of \(a\) and \(b\)? (c) Compute \(\operatorname{Cov} = \sigma^2(J^TJ)^{-1}\), the standard errors of \(\log a\) and \(\log b\), and their correlation. (d) What would you report from this fit?

In code

C1. Standard errors three ways. Continue from the Background block. (a) Compute the Jacobian \(J\) (\(12\times3\)) at the fit (numDeriv::jacobian; Python: the jacobian helper, or res.jac). C2. The Hessian. (a) Compute the Hessian \(H\) of \(S(\theta)\) at the fit with numDeriv::hessian (Python: scipy.differentiate.hessian; Rust: central differences). How close is it to \(2J^TJ\)? Compare the standard errors from it with those from the real Hessian.

Hints

Hint 1 — Jacobians by hand (B1, B3)

Differentiate the model with respect to one parameter, holding the others fixed. For B1, \(\partial v/\partial k_\text{cat} = E_0 S/(K_m+S)\) and \(\partial v/\partial K_m = -k_\text{cat}E_0S/(K_m+S)^2\). Two columns are proportional if their ratio is the same in every row.

Hint 2 — inverting a 2×2 matrix (B3, B6)

\(\begin{pmatrix}a & b\\ b & d\end{pmatrix}^{-1} = \dfrac{1}{ad - b^2}\begin{pmatrix}d & -b\\ -b & a\end{pmatrix}\). Eigenvalues of \(\begin{pmatrix}a & b\\ b & a\end{pmatrix}\) are \(a \pm b\), with eigenvectors \((1, \pm1)/\sqrt2\).

Hint 3 — the flip-flop algebra (B2)

Write \(C\) as (prefactor) × (bracket). Swapping \(k_a\) and \(k_e\) changes the sign of both \(k_a - k_e\) and the bracket \(e^{-k_et} - e^{-k_at}\). What is left to match is the prefactor \(k_a/V\).

Hint 4 — profile of a linear parameter (B5)

For fixed \(k\), minimising \(\sum_i(y_i - Ae^{-kt_i})^2\) over \(A\) is a one-parameter linear least-squares problem: set the derivative with respect to \(A\) to zero.

Hint 5 — fitting and standard errors (C1, C2)

R: vcov(fit), cov2cor(vcov(fit)), chol2inv(qr.R(qr(J))) is \((J^TJ)^{-1}\). Python: least_squares minimises half the sum of squares of the residual vector you return; res.jac is the Jacobian of the residuals (\(= -J\)), which gives the same \(J^TJ\). scipy.differentiate.hessian calls your function with an array of shape (3, ...), so loop over the extra axes (as in the solution) or write a vectorised SSE. optim(..., hessian = TRUE) returns the numerical Hessian at the solution in $hessian.

Hint 6 — singular gradient and the SVD (C3, C4)

Multiply column \(j\) of \(J\) by \(\theta_j\) (R: J %*% diag(th); Python: J * th; Rust: DMatrix::from_fn). The signs of singular vectors are arbitrary; fix them (e.g. first entry positive) before comparing. nalgebra’s svd does not sort the singular values: sort them yourself.

Hint 7 — profiles (C5)

In R, a parameter that is not in start is taken from the calling environment, so nls(ys ~ bateman(ts, ka, ke, V), start = list(ke = 0.2, V = 20)) inside a function with argument ka fits only ke and V. In Python, write the residual as a function of q = (ke, V) with ka fixed. If a fit fails at an extreme grid point, start it from the solution at the neighbouring point.

Hint 8 — a prior as a residual (C7)

Divide the data residuals by \(\sigma\) and append \((\log k_a - \mu)/\tau\). Then the sum of squares is \(-2\log(\text{likelihood} \times \text{prior})\) + constant, and the covariance is \((J_a^TJ_a)^{-1}\) without a factor \(s^2\), where \(J_a\) is the Jacobian of the augmented residual vector. Fit in log-parameters so that the prior is a plain difference.

use nalgebra::{DMatrix, DVector};

// One-compartment model with oral absorption, dose D = 100 mg (mg/L)
const D: f64 = 100.0; // oral dose, mg
fn bateman(t: f64, ka: f64, ke: f64, v: f64) -> f64 {
    D * ka / (v * (ka - ke)) * ((-ke * t).exp() - (-ka * t).exp())
}
const TT: [f64; 12] = [0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 4.0, 6.0, 8.0, 10.0, 12.0];
const Y: [f64; 12] = [1.02, 1.88, 2.34, 2.98, 3.27, 3.26, 3.17, 2.77, 1.92, 1.23, 1.00, 0.61];

// Central-difference Jacobian of f at p (like numDeriv::jacobian, less refined)
fn jacobian(f: &dyn Fn(&[f64]) -> Vec<f64>, p: &[f64]) -> DMatrix<f64> {
    let n = f(p).len();
    let mut j = DMatrix::zeros(n, p.len());
    for k in 0..p.len() {
        let h = 1e-5 * p[k].abs().max(1.0);
        let (mut pp, mut pm) = (p.to_vec(), p.to_vec());
        pp[k] += h;
        pm[k] -= h;
        let (fp, fm) = (f(&pp), f(&pm));
        for i in 0..n { j[(i, k)] = (fp[i] - fm[i]) / (2.0 * h); }
    }
    j
}

// Levenberg-Marquardt for min sum r(p)^2, hand-written (R: nls / nls.lm, Python: least_squares)
fn levmar(r: &dyn Fn(&[f64]) -> Vec<f64>, p0: &[f64]) -> Vec<f64> {
    let ss = |p: &[f64]| -> f64 { let v = r(p); if v.iter().all(|x| x.is_finite()) { v.iter().map(|x| x * x).sum() } else { f64::INFINITY } };
    let (mut p, mut mu) = (p0.to_vec(), 1e-3);
    for _ in 0..500 {
        let j = jacobian(r, &p);                     // Jacobian of the residuals
        let rv = DVector::from_vec(r(&p));
        let jtj = j.transpose() * &j;
        let g = j.transpose() * &rv;
        loop {
            let a = &jtj + DMatrix::from_diagonal(&jtj.diagonal()) * mu;
            let step = a.lu().solve(&(-&g)).unwrap();
            let pn: Vec<f64> = p.iter().zip(step.iter()).map(|(a, b)| a + b).collect();
            if ss(&pn) <= ss(&p) {
                let small = step.norm() < 1e-12 * (1.0 + DVector::from_vec(p.clone()).norm());
                p = pn;
                mu = (mu / 10.0).max(1e-12);
                if small { return p; }
                break;
            }
            mu *= 10.0;
            if mu > 1e12 { return p; }
        }
    }
    p
}

// Central-difference Hessian of a scalar function (R: numDeriv::hessian)
fn hessian(f: &dyn Fn(&[f64]) -> f64, p: &[f64]) -> DMatrix<f64> {
    let n = p.len();
    let h: Vec<f64> = p.iter().map(|x| 1e-4 * x.abs().max(1.0)).collect();
    let fe = |di: usize, si: f64, dk: usize, sk: f64| {
        let mut q = p.to_vec();
        q[di] += si * h[di];
        q[dk] += sk * h[dk];
        f(&q)
    };
    DMatrix::from_fn(n, n, |i, k| {
        (fe(i, 1.0, k, 1.0) - fe(i, 1.0, k, -1.0) - fe(i, -1.0, k, 1.0) + fe(i, -1.0, k, -1.0))
            / (4.0 * h[i] * h[k])
    })
}

// Central-difference Jacobian of f at p (like numDeriv::jacobian, less refined)
fn jacobian(f: &dyn Fn(&[f64]) -> Vec<f64>, p: &[f64]) -> DMatrix<f64> {
    let n = f(p).len();
    let mut j = DMatrix::zeros(n, p.len());
    for k in 0..p.len() {
        let h = 1e-5 * p[k].abs().max(1.0);
        let (mut pp, mut pm) = (p.to_vec(), p.to_vec());
        pp[k] += h;
        pm[k] -= h;
        let (fp, fm) = (f(&pp), f(&pm));
        for i in 0..n { j[(i, k)] = (fp[i] - fm[i]) / (2.0 * h); }
    }
    j
}

// Levenberg-Marquardt for min sum r(p)^2, hand-written (R: nls / nls.lm, Python: least_squares)
fn levmar(r: &dyn Fn(&[f64]) -> Vec<f64>, p0: &[f64]) -> Vec<f64> {
    let ss = |p: &[f64]| -> f64 { let v = r(p); if v.iter().all(|x| x.is_finite()) { v.iter().map(|x| x * x).sum() } else { f64::INFINITY } };
    let (mut p, mut mu) = (p0.to_vec(), 1e-3);
    for _ in 0..500 {
        let j = jacobian(r, &p);                     // Jacobian of the residuals
        let rv = DVector::from_vec(r(&p));
        let jtj = j.transpose() * &j;
        let g = j.transpose() * &rv;
        loop {
            let a = &jtj + DMatrix::from_diagonal(&jtj.diagonal()) * mu;
            let step = a.lu().solve(&(-&g)).unwrap();
            let pn: Vec<f64> = p.iter().zip(step.iter()).map(|(a, b)| a + b).collect();
            if ss(&pn) <= ss(&p) {
                let small = step.norm() < 1e-12 * (1.0 + DVector::from_vec(p.clone()).norm());
                p = pn;
                mu = (mu / 10.0).max(1e-12);
                if small { return p; }
                break;
            }
            mu *= 10.0;
            if mu > 1e12 { return p; }
        }
    }
    p
}

fn bateman(t: f64, ka: f64, ke: f64, v: f64) -> f64 {
    D * ka / (v * (ka - ke)) * ((-ke * t).exp() - (-ka * t).exp())
}

// Central-difference Jacobian of f at p (like numDeriv::jacobian, less refined)
fn jacobian(f: &dyn Fn(&[f64]) -> Vec<f64>, p: &[f64]) -> DMatrix<f64> {
    let n = f(p).len();
    let mut j = DMatrix::zeros(n, p.len());
    for k in 0..p.len() {
        let h = 1e-5 * p[k].abs().max(1.0);
        let (mut pp, mut pm) = (p.to_vec(), p.to_vec());
        pp[k] += h;
        pm[k] -= h;
        let (fp, fm) = (f(&pp), f(&pm));
        for i in 0..n { j[(i, k)] = (fp[i] - fm[i]) / (2.0 * h); }
    }
    j
}

// Levenberg-Marquardt for min sum r(p)^2, hand-written (R: nls / nls.lm, Python: least_squares)
fn levmar(r: &dyn Fn(&[f64]) -> Vec<f64>, p0: &[f64]) -> Vec<f64> {
    let ss = |p: &[f64]| -> f64 { let v = r(p); if v.iter().all(|x| x.is_finite()) { v.iter().map(|x| x * x).sum() } else { f64::INFINITY } };
    let (mut p, mut mu) = (p0.to_vec(), 1e-3);
    for _ in 0..500 {
        let j = jacobian(r, &p);                     // Jacobian of the residuals
        let rv = DVector::from_vec(r(&p));
        let jtj = j.transpose() * &j;
        let g = j.transpose() * &rv;
        loop {
            let a = &jtj + DMatrix::from_diagonal(&jtj.diagonal()) * mu;
            let step = a.lu().solve(&(-&g)).unwrap();
            let pn: Vec<f64> = p.iter().zip(step.iter()).map(|(a, b)| a + b).collect();
            if ss(&pn) <= ss(&p) {
                let small = step.norm() < 1e-12 * (1.0 + DVector::from_vec(p.clone()).norm());
                p = pn;
                mu = (mu / 10.0).max(1e-12);
                if small { return p; }
                break;
            }
            mu *= 10.0;
            if mu > 1e12 { return p; }
        }
    }
    p
}
