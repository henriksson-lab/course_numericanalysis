Exercise: gradient descent, Newton and quasi-Newton

Goal

By the end of this exercise you should be able to:

  • compute a gradient and a Hessian by hand for a function of two variables, and check a coded gradient against finite differences,
  • decide from the Hessian whether a point with zero gradient is a minimum, a maximum or a saddle,
  • take steepest descent steps with an exact and with a backtracking (Armijo) line search, and predict from the condition number how slow steepest descent will be,
  • take a Newton step for minimisation, and recognise when the Hessian is not positive definite,
  • explain what the BFGS update does and why it needs only gradients, and do one Nelder–Mead move by hand,
  • fit a 4-parameter logistic dose–response curve with your own methods and with optim / scipy.optimize.minimize / argmin, and detect the usual failures: a wrong gradient, bad scaling, a bad start.

The by-hand part needs pen and paper (a calculator helps in B7). The code part uses the dose–response data from the lecture.

Background

To minimise a smooth function \(f(\mathbf x)\) of \(n\) variables:

  1. Gradient \(\nabla f\): the vector of partial derivatives \(\partial f/\partial x_j\) (the Jacobian of a scalar function, written as a column). It points uphill, perpendicular to the contour lines. At a minimum, \(\nabla f = \mathbf 0\).
  2. Hessian \(H\): the matrix of second derivatives \(H_{ij} = \partial^2 f/\partial x_i\partial x_j\), the Jacobian of the gradient. Symmetric. Near \(\mathbf x\), \(f(\mathbf x + \mathbf s) \approx f(\mathbf x) + \nabla f^\mathsf T \mathbf s + \tfrac12 \mathbf s^\mathsf T H \mathbf s\). A point with \(\nabla f = \mathbf 0\) is a minimum if \(H\) is positive definite (all eigenvalues \(> 0\); for \(2\times2\): \(\det H > 0\) and \(\operatorname{tr} H > 0\)), a maximum if all eigenvalues are negative, a saddle if they have both signs.
  3. Gradient of a sum of squares. If \(\mathrm{SSE}(\mathbf p) = \sum_i (y_i - m(c_i;\mathbf p))^2\), then \(\nabla\mathrm{SSE} = -2J^\mathsf T\mathbf r\), with residuals \(r_i = y_i - m(c_i)\) and the model Jacobian \(J_{ij} = \partial m(c_i)/\partial p_j\).
  4. Steepest descent: \(\mathbf x_{k+1} = \mathbf x_k - \alpha_k \nabla f(\mathbf x_k)\). Backtracking (Armijo): start with \(\alpha = 1\) and halve until \(f(\mathbf x - \alpha\mathbf g) \le f(\mathbf x) - c\,\alpha\,\|\mathbf g\|^2\), \(c = 10^{-4}\). On a quadratic with exact line search the error shrinks by about \((\kappa - 1)/(\kappa + 1)\) per step, where \(\kappa = \lambda_{\max}/\lambda_{\min}\) is the condition number of \(H\).
  5. Newton: solve \(H\mathbf s = -\nabla f\), set \(\mathbf x \leftarrow \mathbf x + \alpha\mathbf s\). Quadratic convergence near a minimum. \(\mathbf s\) is a descent direction only if \(\nabla f^\mathsf T\mathbf s < 0\), which is guaranteed when \(H\) is positive definite.
  6. BFGS keeps \(B \approx H^{-1}\), moves along \(-B\nabla f\), and after each step updates \(B\) from \(\mathbf s = \mathbf x_{k+1} - \mathbf x_k\) and \(\mathbf y = \nabla f_{k+1} - \nabla f_k\) so that \(B\mathbf y = \mathbf s\) (secant condition): \(B \leftarrow V^\mathsf T B V + \rho\,\mathbf s\mathbf s^\mathsf T\), \(V = I - \rho\,\mathbf y\mathbf s^\mathsf T\), \(\rho = 1/\mathbf y^\mathsf T\mathbf s\). L-BFGS stores only the last few \((\mathbf s, \mathbf y)\) pairs.
  7. Nelder–Mead keeps \(n+1\) points (a simplex) and replaces the worst by reflecting it through the centroid \(\bar{\mathbf x}\) of the others: \(\mathbf x_r = \bar{\mathbf x} + (\bar{\mathbf x} - \mathbf x_\text{worst})\). If \(\mathbf x_r\) beats the best point, try the expansion \(\bar{\mathbf x} + 2(\bar{\mathbf x} - \mathbf x_\text{worst})\); if it is no better than the second-worst, contract towards \(\bar{\mathbf x}\).
  8. Libraries. R: optim (default "Nelder-Mead"; "BFGS", "CG", "L-BFGS-B"; option gr for the gradient, control = list(parscale = ...) for scaling). Python: scipy.optimize.minimize (default "BFGS", jac= for the gradient; no parscale, so rescale by hand). Rust: the argmin crate (NelderMead, BFGS, LBFGS, NonlinearConjugateGradient). Gradient checks: R numDeriv::grad, jacobian and hessian; Python scipy.optimize.approx_fprime; Rust: hand-written differences.

The running example. A reporter assay: 9 doses of an agonist from 0.01 to 100 µM (half-log steps), 2 wells each, response in % of the maximum. The 4-parameter logistic model is

\[m(c) = b + \frac{t - b}{1 + (\mathrm{EC50}/c)^{h}}, \qquad \mathbf p = (b, t, \mathrm{EC50}, h) = (\text{bottom}, \text{top}, \mathrm{EC50}, \text{hill}).\]

With \(u = (\mathrm{EC50}/c)^h\) and \(D = 1 + u\) the model derivatives are \(\partial m/\partial b = u/D\), \(\partial m/\partial t = 1/D\), \(\partial m/\partial \mathrm{EC50} = -(t-b)\,h\,u/(\mathrm{EC50}\,D^2)\), \(\partial m/\partial h = -(t-b)\,u\log(\mathrm{EC50}/c)/D^2\). The best fit is \(\mathbf p^* = (5.3932,\ 96.1737,\ 1.27098,\ 1.23955)\) with \(\mathrm{SSE} = 314.92396\); the start used throughout is \(\mathbf p_0 = (0, 100, 1, 1)\).

// rust/examples/gradient_methods_background.rs  —  cargo run --example gradient_methods_background
// The 4PL fit: SSE, gradient, a central-difference check, and argmin's BFGS
// (the counterpart of optim(method = "BFGS") and minimize(method="BFGS")).
use argmin::core::{Executor, State};
use argmin::solver::linesearch::MoreThuenteLineSearch;
use argmin::solver::quasinewton::BFGS;
include!("gradient_methods_shared/defs.rs");

fn main() -> Result<(), Error> {
    let p0 = P0.to_vec();
    println!("{:.4}", sse(&p0));
    println!("{:.6?}", grad_sse(&p0));
    let fd: Vec<f64> = (0..4).map(|j| {           // central differences
        let h = 1e-6 * p0[j].abs().max(1.0);
        let (mut a, mut b) = (p0.clone(), p0.clone());
        a[j] += h; b[j] -= h;
        (sse(&a) - sse(&b)) / (2.0 * h)
    }).collect();
    println!("{:.6?}", fd);
    let eye: Vec<Vec<f64>> = (0..4).map(|i| (0..4).map(|j| (i == j) as i32 as f64).collect()).collect();
    let res = Executor::new(Fit, BFGS::new(MoreThuenteLineSearch::new()))
        .configure(|s| s.param(p0.clone()).inv_hessian(eye).max_iters(200))
        .run()?;
    let s = res.state();
    println!("{:.6?}  SSE {:.6}  iterations {}", s.get_best_param().unwrap(), s.get_best_cost(), s.get_iter());
    Ok(())
}

// Shared by the gradient_methods_* examples: include!("gradient_methods_shared/defs.rs")
// The 4PL dose-response data, model, SSE and analytic gradient.
use argmin::core::{CostFunction, Error, Gradient};

const Y: [f64; 18] = [12.9, 9.8, 2.9, 0.1, 4.2, 9.7, 17.7, 22.3, 49.7, 42.1,
                      67.3, 72.6, 97.4, 91.8, 94.6, 93.3, 92.9, 95.1];
const P0: [f64; 4] = [0.0, 100.0, 1.0, 1.0];

fn doses() -> Vec<f64> {          // 9 doses 0.01 ... 100 µM, 2 wells each
    (0..18).map(|i| 10f64.powf(-2.0 + 0.5 * (i / 2) as f64)).collect()
}
fn f4(p: &[f64], c: f64) -> f64 {  // p = (bottom, top, EC50, hill)
    p[0] + (p[1] - p[0]) / (1.0 + (p[2] / c).powf(p[3]))
}
fn sse(p: &[f64]) -> f64 {
    doses().iter().zip(Y.iter()).map(|(&c, &y)| (y - f4(p, c)).powi(2)).sum()
}
fn grad_sse(p: &[f64]) -> Vec<f64> {   // -2 J^T r, one dose at a time
    let mut g = vec![0.0; 4];
    for (&c, &y) in doses().iter().zip(Y.iter()) {
        let u = (p[2] / c).powf(p[3]);
        let d = 1.0 + u;
        let r = y - f4(p, c);
        let j = [u / d, 1.0 / d,
                 -(p[1] - p[0]) * p[3] * u / (p[2] * d * d),
                 -(p[1] - p[0]) * u * (p[2] / c).ln() / (d * d)];
        for k in 0..4 { g[k] -= 2.0 * j[k] * r; }
    }
    g
}
fn norm(v: &[f64]) -> f64 { v.iter().map(|x| x * x).sum::<f64>().sqrt() }
fn dot(a: &[f64], b: &[f64]) -> f64 { a.iter().zip(b).map(|(x, y)| x * y).sum() }
// x + a * s
fn axpy(x: &[f64], a: f64, s: &[f64]) -> Vec<f64> { x.iter().zip(s).map(|(x, s)| x + a * s).collect() }

// argmin wants the problem as a type with a cost (and gradient) method
struct Fit;
impl CostFunction for Fit {
    type Param = Vec<f64>;
    type Output = f64;
    fn cost(&self, p: &Vec<f64>) -> Result<f64, Error> { Ok(sse(p)) }
}
impl Gradient for Fit {
    type Param = Vec<f64>;
    type Gradient = Vec<f64>;
    fn gradient(&self, p: &Vec<f64>) -> Result<Vec<f64>, Error> { Ok(grad_sse(p)) }
}

By hand

B1. Gradient and Hessian. Let \(f(x_1, x_2) = x_1^2 - 2x_1x_2 + 2x_2^2 - 2x_2\). (a) Compute \(\nabla f\) and evaluate it at \((0, 0)\) and at \((3, 1)\). (b) Compute the Hessian \(H\). Does it depend on \(\mathbf x\)? (c) Find the point where \(\nabla f = \mathbf 0\). (d) Is it a minimum? Use the determinant and trace, then find the eigenvalues of \(H\) and its condition number \(\kappa\). (e) Take one Newton step from \((0, 0)\). Where do you land, and why?

B2. Minimum, maximum or saddle? Let \(f(x, y) = x^3 - 3x + y^2\). (a) Find all points with \(\nabla f = \mathbf 0\). (b) Classify each with the Hessian. (c) Take one Newton step from \((-0.5, 1)\). Does it move towards the minimum? Is \(\nabla f^\mathsf T\mathbf s < 0\) (a descent direction)?

B3. Steepest descent zig-zags. Let \(f(\mathbf x) = \tfrac12(x_1^2 + 9x_2^2)\), start \(\mathbf x_0 = (9, 1)\). (a) Give \(H\) and \(\kappa\). (b) For a quadratic \(f = \tfrac12\mathbf x^\mathsf T H\mathbf x\), the exact line search step along \(-\mathbf g\) is \(\alpha = \mathbf g^\mathsf T\mathbf g / \mathbf g^\mathsf T H\mathbf g\). Take two steepest-descent steps with exact line search. (c) Show that the two search directions are perpendicular. (d) By what factor did the distance to the minimum shrink per step? Compare with \((\kappa-1)/(\kappa+1)\). (e) How many steps does it take to reduce the distance by \(10^6\)? How many does Newton need?

B4. Backtracking by hand. Same \(f\) and \(\mathbf x_0 = (9, 1)\). Run the Armijo rule with \(c = 10^{-4}\): try \(\alpha = 1, \tfrac12, \tfrac14, \ldots\) and stop at the first \(\alpha\) with \(f(\mathbf x_0 - \alpha\mathbf g) \le f(\mathbf x_0) - c\,\alpha\,\|\mathbf g\|^2\). Which \(\alpha\) is accepted, and how does the new \(f\) compare with the exact line search of B3?

B5. A fixed step size. Same \(f\), steepest descent with a fixed \(\alpha\). (a) Show that each component evolves separately: \(x_{1,k+1} = (1-\alpha)x_{1,k}\), \(x_{2,k+1} = (1-9\alpha)x_{2,k}\). (b) For which \(\alpha\) does the iteration converge? Relate the bound to the largest eigenvalue of \(H\). (c) Which \(\alpha\) makes the slower of the two factors as small as possible, and what is that factor?

B6. The BFGS secant condition. Same \(f\). The first BFGS step (with \(B_0 = I\) and exact line search) is the first steepest-descent step of B3: \(\mathbf s = (-1.8, -1.8)\). (a) Compute \(\mathbf y = \nabla f(\mathbf x_1) - \nabla f(\mathbf x_0)\) and \(\mathbf y^\mathsf T\mathbf s\). (b) Show that for any \(B_0\), the update \(B_1 = V^\mathsf TB_0V + \rho\,\mathbf s\mathbf s^\mathsf T\) with \(V = I - \rho\,\mathbf y\mathbf s^\mathsf T\), \(\rho = 1/\mathbf y^\mathsf T\mathbf s\) satisfies \(B_1\mathbf y = \mathbf s\). (Hint: compute \(V\mathbf y\) first.) (c) In one variable, what does \(B_1 y = s\) say? Which method from Newton and secant methods is this?

B7. Units and the condition number. At the best 4PL fit with dose in µM, the diagonal of the SSE Hessian is \((16.0,\ 14.4,\ 3611.5,\ 3701.6)\) for (bottom, top, EC50, hill). (a) If EC50 is measured in nM instead (\(q = 1000\,\mathrm{EC50}\)), how do \(\partial\,\mathrm{SSE}/\partial q\) and \(\partial^2\mathrm{SSE}/\partial q^2\) relate to the µM versions? (Chain rule.) (b) Use the ratio of the largest to the smallest diagonal entry as a rough guess for \(\kappa\), in µM and in nM. (The true values are 550 and \(1.9\times10^6\).) (c) R’s optim takes finite-difference gradient steps of \(10^{-3}\) in every parameter. What is that as a relative change of EC50 = 1271 nM, and of hill = 1.24? (d) What happens to \(\partial^2\mathrm{SSE}/\partial p^2\) for EC50 if you fit \(\ell = \log_{10}\mathrm{EC50}\) instead (at the minimum)? Use \(d\,\mathrm{EC50}/d\ell = \ln(10)\,\mathrm{EC50}\).

B8. Nelder–Mead by hand. Let \(f(x, y) = x^2 + 2y^2\) and the simplex \((1, 1), (2, 1), (1, 2)\). (a) Evaluate \(f\) at the three points; which is the worst? (b) Reflect the worst point through the centroid of the other two. Is the reflection accepted? (c) Do a second move: identify the new worst point, reflect, and decide whether to expand.

In code

C1. Check the gradient. (a) Compare grad_sse(p0) with a forward-difference gradient (step \(h_j = \sqrt\varepsilon\max(|p_j|, 1)\)) and with numDeriv::grad (Python: approx_fprime; Rust: central differences). Hints

Hint 1 — gradients and Hessians by hand (B1, B2)

Differentiate with respect to one variable while treating the other as a constant. The Hessian is the matrix of derivatives of the two gradient components: row \(i\) = derivatives of \(\partial f/\partial x_i\). For a \(2\times2\) symmetric matrix the eigenvalues are \(\tfrac12\left(\operatorname{tr} \pm \sqrt{\operatorname{tr}^2 - 4\det}\right)\). A Newton step solves \(H\mathbf s = -\nabla f\); for a \(2\times 2\) matrix \(\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1} = \frac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\).

Hint 2 — line searches (B3, B4, B5)

For \(f = \tfrac12(x_1^2 + 9x_2^2)\): \(\mathbf g = (x_1, 9x_2)\) and \(\mathbf g^\mathsf TH\mathbf g = g_1^2 + 9g_2^2\). For B5, the iteration in each component is \(x \leftarrow (1 - \alpha\lambda)x\) with \(\lambda\) the curvature in that direction; it converges if \(|1 - \alpha\lambda| < 1\).

Hint 3 — BFGS (B6, C5)

\(V\mathbf y = \mathbf y - \rho\,\mathbf y(\mathbf s^\mathsf T\mathbf y)\) and \(\rho\,\mathbf s^\mathsf T\mathbf y = 1\). In code, outer(s, s) (Python np.outer) is the matrix \(\mathbf s\mathbf s^\mathsf T\). Skip the update when \(\mathbf y^\mathsf T\mathbf s \le 0\).

Hint 4 — checking a gradient (C1)

Compare component by component, relative to the size of each component. A forward difference is good to about \(10^{-6}\)–\(10^{-8}\) relative, numDeriv::grad (Richardson extrapolation, see Numerical differentiation) to about \(10^{-10}\). A bug gives errors of order \(10^{-1}\) or 1. Check at a “generic” point: one where no parameter is 0 or 1.

Hint 5 — the Hessian and its eigenvalues (C3, C4)

R: eigen(H, symmetric = TRUE)$values, solve(H, -g). Python: np.linalg.eigvalsh (ascending order), np.linalg.solve. Rust: nalgebra::SymmetricEigen, DMatrix::lu().solve. Symmetrise a finite-difference Hessian with \((H + H^\mathsf T)/2\) before taking eigenvalues.

Hint 6 — library calls (C5–C8)

optim returns par, value, counts (calls of fn and gr, not counting finite-difference calls) and convergence (0 = a stopping rule was met, 1 = maxit reached). minimize returns x, fun, nfev, njev, success, message. In argmin, the starting point goes in configure(|s| s.param(...)), BFGS also needs inv_hessian (start with the identity), and Nelder–Mead needs the whole starting simplex. Python has no parscale: write lambda q: sse_nM(q * scale) and start from p / scale.

fn sd_armijo(f: &dyn Fn(&[f64]) -> f64, g: &dyn Fn(&[f64]) -> Vec<f64>,
             mut x: Vec<f64>, tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let mut k = 0;
    while k < maxit {
        let gk = g(&x);
        let g2: f64 = gk.iter().map(|v| v * v).sum();
        if g2.sqrt() < tol { break; }

        x = trial(a);
        k += 1;
    }
    (x, k)
}

        a[j] += s; b[j] -= s;
        let (ga, gb) = (grad_sse(&a), grad_sse(&b));
        for i in 0..4 { h[(i, j)] = (ga[i] - gb[i]) / (2.0 * s); }
    }
    h
}
fn eig_sorted(h: &DMatrix<f64>) -> Vec<f64> {
    let mut ev: Vec<f64> = SymmetricEigen::new((h + h.transpose()) / 2.0).eigenvalues.iter().cloned().collect();
    ev.sort_by(|a, b| b.partial_cmp(a).unwrap());
    ev
}
fn newton_dir(h: DMatrix<f64>, g: &[f64]) -> Vec<f64> {
    let s = h.lu().solve(&(-DVector::from_column_slice(g))).expect("singular Hessian");
    s.iter().cloned().collect()
}
fn backtrack(x: &[f64], g: &[f64], s: &[f64]) -> f64 {
    let (fx, gs) = (sse(x), dot(g, s));
    let mut a = 1.0;
    while !(sse(&axpy(x, a, s)) <= fx + 1e-4 * a * gs) { a /= 2.0; }
    a
}

        if norm(&g) < 1e-4 { break; }
        let s = newton_dir(hess(&x), &g);

    println!("{:.2?}  {:.2}", x, sse(&x));

        x = axpy(&x, backtrack(&x, &g, &s), &s);
        steps += 1;
    }
    println!("{}  {:.6?}  {:.4}", steps, x, sse(&x));
}

// argmin owns the problem, so count its calls with global counters
static NF: AtomicU64 = AtomicU64::new(0);
static NG: AtomicU64 = AtomicU64::new(0);
struct Counted;
impl CostFunction for Counted {
    type Param = Vec<f64>;
    type Output = f64;
    fn cost(&self, p: &Vec<f64>) -> Result<f64, Error> { NF.fetch_add(1, Ordering::Relaxed); Ok(sse(p)) }
}
impl Gradient for Counted {
    type Param = Vec<f64>;
    type Gradient = Vec<f64>;
    fn gradient(&self, p: &Vec<f64>) -> Result<Vec<f64>, Error> { NG.fetch_add(1, Ordering::Relaxed); Ok(grad_sse(p)) }
}

fn bfgs(f: &dyn Fn(&[f64]) -> f64, g: &dyn Fn(&[f64]) -> Vec<f64>,
        mut x: Vec<f64>, tol: f64, maxit: usize) -> (Vec<f64>, usize) {
    let n = x.len();
    let mut b = vec![vec![0.0; n]; n];          // B ~ inverse Hessian, start = I
    for i in 0..n { b[i][i] = 1.0; }
    let mut gk = g(&x);
    let mut k = 0;
    while k < maxit && norm(&gk) >= tol {
        let s: Vec<f64> = (0..n).map(|i| -dot(&b[i], &gk)).collect();
        let (fx, gs) = (f(&x), dot(&gk, &s));
        let mut a = 1.0;
        while !(f(&axpy(&x, a, &s)) <= fx + 1e-4 * a * gs) { a /= 2.0; }
        let s: Vec<f64> = s.iter().map(|v| a * v).collect();
        x = axpy(&x, 1.0, &s);
        let gn = g(&x);
        let yv: Vec<f64> = gn.iter().zip(&gk).map(|(a, b)| a - b).collect();
        gk = gn;
        let sy = dot(&yv, &s);
        if sy > 0.0 {   // B <- V^T B V + s s^T / sy,  V = I - y s^T / sy
            let v: Vec<Vec<f64>> = (0..n).map(|i| (0..n).map(|j|
                (i == j) as i32 as f64 - yv[i] * s[j] / sy).collect()).collect();
            let bv: Vec<Vec<f64>> = (0..n).map(|i| (0..n).map(|j|
                (0..n).map(|l| b[i][l] * v[l][j]).sum()).collect()).collect();
            b = (0..n).map(|i| (0..n).map(|j|
                (0..n).map(|l| v[l][i] * bv[l][j]).sum::<f64>() + s[i] * s[j] / sy).collect()).collect();
        }
        k += 1;
    }
    (x, k)
}

    Ok(())
}

// p = q * scale; optionally p[2] = 10^p[2]; doses multiplied by `unit`
#[derive(Clone)]
struct Fd { unit: f64, scale: [f64; 4], log_ec50: bool }
impl Fd {
    fn par(&self, q: &[f64]) -> Vec<f64> {
        let mut p: Vec<f64> = q.iter().zip(&self.scale).map(|(q, s)| q * s).collect();
        if self.log_ec50 { p[2] = 10f64.powf(p[2]); }
        p
    }
}
impl CostFunction for Fd {
    type Param = Vec<f64>;
    type Output = f64;
    fn cost(&self, q: &Vec<f64>) -> Result<f64, Error> {
        NF.fetch_add(1, Ordering::Relaxed);
        let p = self.par(q);
        Ok(doses().iter().zip(Y.iter()).map(|(&c, &y)| (y - f4(&p, c * self.unit)).powi(2)).sum())
    }
}
impl Gradient for Fd {
    type Param = Vec<f64>;
    type Gradient = Vec<f64>;
    fn gradient(&self, q: &Vec<f64>) -> Result<Vec<f64>, Error> {
        (0..q.len()).map(|j| {
            let (mut a, mut b) = (q.clone(), q.clone());
            a[j] += 1e-3; b[j] -= 1e-3;
            Ok((self.cost(&a)? - self.cost(&b)?) / 2e-3)
        }).collect()
    }
}
fn eye() -> Vec<Vec<f64>> { (0..4).map(|i| (0..4).map(|j| (i == j) as i32 as f64).collect()).collect() }

fn run(name: &str, prob: Fd, q0: Vec<f64>, method: &str) {
    NF.store(0, Ordering::Relaxed);
    let ls = BacktrackingLineSearch::new(ArmijoCondition::new(1e-4).unwrap());
    let res = match method {
        "NM" => {
            let mut simplex = vec![q0.clone()];
            for j in 0..4 { let mut v = q0.clone(); v[j] += 0.1 * q0[j].abs().max(1.0); simplex.push(v); }
            let solver = NelderMead::new(simplex).with_sd_tolerance(1e-8).unwrap();
            Executor::new(prob.clone(), solver).configure(|s| s.max_iters(500)).run().map(|r| r.state().clone())
                .map(|s| (s.get_best_param().unwrap().clone(), s.get_best_cost(), s.get_iter(), s.get_func_counts().clone(), s.get_termination_status().clone()))
        }
        "BFGS" => Executor::new(prob.clone(), BFGS::new(ls))
            .configure(|s| s.param(q0.clone()).inv_hessian(eye()).max_iters(100)).run()
            .map(|r| { let s = r.state().clone(); (s.get_best_param().unwrap().clone(), s.get_best_cost(), s.get_iter(), s.get_func_counts().clone(), s.get_termination_status().clone()) }),
        "LBFGS" => Executor::new(prob.clone(), LBFGS::new(ls, 5))
            .configure(|s| s.param(q0.clone()).max_iters(100)).run()
            .map(|r| { let s = r.state().clone(); (s.get_best_param().unwrap().clone(), s.get_best_cost(), s.get_iter(), s.get_func_counts().clone(), s.get_termination_status().clone()) }),
        _ => Executor::new(prob.clone(), NonlinearConjugateGradient::new(ls, PolakRibiere::new()).restart_iters(10))
            .configure(|s| s.param(q0.clone()).max_iters(100)).run()
            .map(|r| { let s = r.state().clone(); (s.get_best_param().unwrap().clone(), s.get_best_cost(), s.get_iter(), s.get_func_counts().clone(), s.get_termination_status().clone()) }),
    };
    match res {
        Ok((q, cost, iters, _counts, status)) => {

            println!("{:<16} {:<5} SSE {:10.4}  EC50 {:9.4}  hill {:7.3}  iter {:3}  cost calls {:4}  ({})",

        }
        Err(e) => println!("{:<16} {:<5} error: {}", name, method, e),
    }
}

// BFGS of C5, on the problem `prob`, with at most 60 halvings per line search;
// like optim, stop when the relative decrease of the SSE is below 1.5e-8
fn own_bfgs(name: &str, prob: &Fd, q0: Vec<f64>) {
    NF.store(0, Ordering::Relaxed);
    let f = |q: &[f64]| prob.cost(&q.to_vec()).unwrap();
    let g = |q: &[f64]| prob.gradient(&q.to_vec()).unwrap();
    let n = q0.len();
    let mut x = q0;
    let mut b: Vec<Vec<f64>> = eye();
    let mut gk = g(&x);
    let mut k = 0;
    while k < 100 && norm(&gk) >= 1e-4 {
        let s: Vec<f64> = (0..n).map(|i| -dot(&b[i], &gk)).collect();
        let (fx, gs) = (f(&x), dot(&gk, &s));
        let mut a = 1.0;
        let mut halvings = 0;
        while !(f(&axpy(&x, a, &s)) <= fx + 1e-4 * a * gs) && halvings < 60 { a /= 2.0; halvings += 1; }
        if halvings == 60 { break; }                       // no downhill step found
        let s: Vec<f64> = s.iter().map(|v| a * v).collect();
        x = axpy(&x, 1.0, &s);
        let fnew = f(&x);
        if fx - fnew < 1.5e-8 * (fx.abs() + 1.5e-8) { k += 1; break; }
        let gn = g(&x);

                (0..n).map(|l| v[l][i] * bv[l][j]).sum::<f64>() + s[i] * s[j] / sy).collect()).collect();
        }

fn logistic(p: &[f64], t: f64) -> f64 {        // p = (r, K, N0)
    p[1] / (1.0 + (p[1] / p[2] - 1.0) * (-p[0] * t).exp())

#[derive(Clone)]
struct Growth { t: Vec<f64> }
impl CostFunction for Growth {
    type Param = Vec<f64>;
    type Output = f64;
    fn cost(&self, p: &Vec<f64>) -> Result<f64, Error> {
        Ok(self.t.iter().zip(OD.iter()).map(|(&t, &y)| (y - logistic(p, t)).powi(2)).sum())
    }
}
impl Gradient for Growth {
    type Param = Vec<f64>;
    type Gradient = Vec<f64>;
    fn gradient(&self, p: &Vec<f64>) -> Result<Vec<f64>, Error> {
        (0..3).map(|j| {
            let h = 1e-6 * p[j].abs().max(1.0);
            let (mut a, mut b) = (p.clone(), p.clone());
            a[j] += h; b[j] -= h;
            Ok((self.cost(&a)? - self.cost(&b)?) / (2.0 * h))
        }).collect()
    }
}

    type Param = Vec<f64>;
    type Output = f64;

fn bfgs(mut x: Vec<f64>) -> f64 {           // as in C5, at most 60 halvings
    let n = x.len();
    let mut b = vec![vec![0.0; n]; n];
    for i in 0..n { b[i][i] = 1.0; }
    let mut gk = grad_sse(&x);
    for _ in 0..200 {
        if norm(&gk) < 1e-4 { break; }
        let s: Vec<f64> = (0..n).map(|i| -dot(&b[i], &gk)).collect();
        let (fx, gs) = (sse(&x), dot(&gk, &s));
        let (mut a, mut halvings) = (1.0, 0);
        while !(sse(&axpy(&x, a, &s)) <= fx + 1e-4 * a * gs) && halvings < 60 { a /= 2.0; halvings += 1; }
        if halvings == 60 { break; }
        let s: Vec<f64> = s.iter().map(|v| a * v).collect();
        x = axpy(&x, 1.0, &s);
        let gn = grad_sse(&x);
        let yv: Vec<f64> = gn.iter().zip(&gk).map(|(a, b)| a - b).collect();
        gk = gn;
        let sy = dot(&yv, &s);
        if sy > 0.0 {
            let v: Vec<Vec<f64>> = (0..n).map(|i| (0..n).map(|j|
                (i == j) as i32 as f64 - yv[i] * s[j] / sy).collect()).collect();

                (0..n).map(|l| v[l][i] * bv[l][j]).sum::<f64>() + s[i] * s[j] / sy).collect()).collect();
        }
    }
    sse(&x)
}

Where this leads

  • Nonlinear least squares and ODE fitting (Part 9): the SSE has extra structure: its Hessian is approximately \(2J^\mathsf TJ\), built from the same model Jacobian as the gradient. That gives Gauss–Newton, and adding \(\mu I\) (as in C4(c)) gives Levenberg–Marquardt, the method behind nls, minpack.lm and scipy.optimize.least_squares. There we also fit ODE models, use log-parameters for positive rates, and multistart systematically.
  • Identifiability and uncertainty of fitted parameters (Part 9): the Hessian at the minimum (C3) gives standard errors of the fitted parameters; a near-zero eigenvalue means a direction the data cannot pin down.
  • Constraints and linear programming (Part 9): bounds (as in L-BFGS-B) and general constraints.
  • Our line searches only enforce sufficient decrease (Armijo). Library codes add a curvature condition (Wolfe) and interpolate the step; trust-region methods replace the line search altogether. We use those through the libraries rather than writing them.
