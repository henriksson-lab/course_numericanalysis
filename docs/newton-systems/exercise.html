Exercise: Newton for systems of equations

Goal

By the end of this exercise you should be able to:

  • compute partial derivatives of a function of two variables, and check them with a difference quotient,
  • write down the Jacobian of a small system and explain what each entry means for the biology,
  • do a Newton step for a system by hand (one \(2\times2\) linear solve) and in code (solve(J, -F)),
  • recognise quadratic convergence in a table of errors,
  • build a finite-difference Jacobian and explain how the step \(h\) affects Newton’s convergence,
  • use a library routine (rootSolve::multiroot in R, scipy.optimize.root in Python) and check its answer,
  • find all steady states of the genetic toggle switch with many starts, and spot when Newton fails (nearly singular Jacobian, negative concentrations, NaN, a root you did not want).

The by-hand part needs pen, paper and a calculator. The code part checks your hand answers and then explores where only code works.

Background

The toggle switch. Two genes repress each other. With concentrations \(u\), \(v\) (in units of the repression threshold) and time in units of the protein lifetime,

\[\frac{du}{dt} = \frac{\alpha}{1 + v^{n}} - u, \qquad \frac{dv}{dt} = \frac{\alpha}{1 + u^{n}} - v,\]

with promoter strength \(\alpha = 3\) and Hill coefficient \(n = 2\) unless stated otherwise. A steady state is a root of \(\mathbf F(\mathbf x) = \mathbf 0\), with \(\mathbf x = (u, v)\) and

\[F_1(u, v) = \frac{\alpha}{1 + v^{n}} - u, \qquad F_2(u, v) = \frac{\alpha}{1 + u^{n}} - v.\]

Facts used below:

  1. Partial derivative. \(\partial F_i / \partial x_j\) is the ordinary derivative of \(F_i\) with respect to \(x_j\), with every other variable held fixed at its value. Check: \(\big(F_i(\mathbf x + h\,\mathbf e_j) - F_i(\mathbf x)\big)/h\) for small \(h\), where \(\mathbf e_j\) moves only \(x_j\).
  2. Jacobian. \(J_{ij} = \partial F_i / \partial x_j\): row = equation, column = variable. For the toggle switch \[J(u, v) = \begin{pmatrix} -1 & -\dfrac{\alpha n v^{n-1}}{(1+v^n)^2} \\[6pt] -\dfrac{\alpha n u^{n-1}}{(1+u^n)^2} & -1 \end{pmatrix}.\]
  3. Linear approximation. \(\mathbf F(\mathbf x + \boldsymbol\delta) \approx \mathbf F(\mathbf x) + J(\mathbf x)\,\boldsymbol\delta\), with an error of order \(\|\boldsymbol\delta\|^2\).
  4. Newton step. Solve \(J(\mathbf x_k)\,\boldsymbol\delta = -\mathbf F(\mathbf x_k)\), then \(\mathbf x_{k+1} = \mathbf x_k + \boldsymbol\delta\). Near a root with a non-singular Jacobian, convergence is quadratic: \(e_{k+1} \approx C e_k^2\).
  5. Length of a vector (Euclidean norm): \(\|\mathbf a\| = \sqrt{a_1^2 + a_2^2}\). Used for the residual \(\|\mathbf F\|\), the step \(\|\boldsymbol\delta\|\) and the error \(\|\mathbf x_k - \mathbf x^*\|\).
  6. Finite-difference Jacobian. Column \(j\) is \(\big(\mathbf F(\mathbf x + h_j \mathbf e_j) - \mathbf F(\mathbf x)\big)/h_j\) with \(h_j = \sqrt{\varepsilon}\,\max(|x_j|, 1)\), \(\sqrt\varepsilon \approx 1.5\times10^{-8}\). About 8 correct digits; \(n + 1\) evaluations of \(\mathbf F\).
  7. Library routines. R: rootSolve::multiroot (Newton with a finite-difference Jacobian unless you pass jacfunc). Python: scipy.optimize.root (default method "hybr", Powell’s hybrid method from MINPACK) or the older scipy.optimize.fsolve. Rust: none in our crate list, so we hand-write Newton with nalgebra’s LU solve.

alpha <- 3; n <- 2
F <- function(x) {                       # x = c(u, v); returns c(F1, F2)
  u <- x[1]; v <- x[2]
  c(alpha / (1 + v^n) - u,
    alpha / (1 + u^n) - v)
}
J <- function(x) {                       # row i = equation i, column j = variable j
  u <- x[1]; v <- x[2]
  matrix(c(-1, -alpha * n * v^(n - 1) / (1 + v^n)^2,
           -alpha * n * u^(n - 1) / (1 + u^n)^2, -1),
         nrow = 2, byrow = TRUE)
}

F(x0)

J(x0)

import numpy as np

alpha, n = 3.0, 2.0

def F(x):                                # x = [u, v]; returns [F1, F2]
    u, v = x
    return np.array([alpha / (1 + v**n) - u,
                     alpha / (1 + u**n) - v])

def J(x):                                # row i = equation i, column j = variable j
    u, v = x
    return np.array([[-1, -alpha * n * v**(n - 1) / (1 + v**n)**2],
                     [-alpha * n * u**(n - 1) / (1 + u**n)**2, -1]])

x0 = np.array([3.0, 0.5])
print(F(x0))
# [-0.6 -0.2]
print(J(x0))
# [[-1.   -1.92]
#  [-0.18 -1.  ]]
delta = np.linalg.solve(J(x0), -F(x0))   # one Newton step = one linear solve
print(x0 + delta)
# [2.66992665 0.3594132 ]
// rust/examples/newton_systems_background.rs  —  cargo run --example newton_systems_background
// Background: the toggle switch F, its Jacobian J, and one Newton step.
use nalgebra::{Matrix2, Vector2};

const ALPHA: f64 = 3.0;
const N: f64 = 2.0;

// x = (u, v); returns (F1, F2)
fn f(x: &Vector2<f64>) -> Vector2<f64> {
    let (u, v) = (x[0], x[1]);
    Vector2::new(ALPHA / (1.0 + v.powf(N)) - u,
                 ALPHA / (1.0 + u.powf(N)) - v)
}

// row i = equation i, column j = variable j
fn jac(x: &Vector2<f64>) -> Matrix2<f64> {
    let (u, v) = (x[0], x[1]);
    Matrix2::new(-1.0, -ALPHA * N * v.powf(N - 1.0) / (1.0 + v.powf(N)).powi(2),
                 -ALPHA * N * u.powf(N - 1.0) / (1.0 + u.powf(N)).powi(2), -1.0)
}

fn main() {
    let x0 = Vector2::new(3.0, 0.5);
    println!("{:?}", f(&x0).as_slice());
    println!("{}", jac(&x0));            // nalgebra prints matrices as a box
    // one Newton step = one linear solve (LU); solve() returns None if J is singular
    let delta = jac(&x0).lu().solve(&(-f(&x0))).expect("singular Jacobian");
    println!("{:?}", (x0 + delta).as_slice());
}

By hand

B1. Partial derivatives. (a) \(g(u, v) = u^2 v + 3v\). Compute \(\partial g/\partial u\) and \(\partial g/\partial v\), and evaluate both at \((u, v) = (1, 2)\). (b) An enzyme makes product at rate \(r(S, E) = \dfrac{k\,E\,S}{K + S}\) (Michaelis–Menten, with enzyme concentration \(E\) and substrate \(S\)). With \(k = 2\) and \(K = 1\), compute \(\partial r/\partial E\) and \(\partial r/\partial S\) at \(S = 1\), \(E = 0.5\). Say in words what each number means. (c) Check \(\partial r/\partial S\) from (b) with a difference quotient, \(h = 0.01\).

B2. The Jacobian of the toggle switch. (a) Derive the four entries of \(J\) for general \(\alpha\) and \(n\) (Fact 2) yourself, using the chain rule on \(\alpha(1 + v^n)^{-1}\). (b) Evaluate \(J\) at \((u, v) = (1, 2)\) for \(\alpha = 3\), \(n = 2\). (c) Which entries describe degradation, and which repression? Why is \(|\partial F_2/\partial u|\) at \((1, 2)\) larger than \(|\partial F_1/\partial v|\)? (d) Evaluate \(J\) and \(\det J\) at the middle steady state \(u = v = 1.2134\).

B3. The linear approximation. At \(\mathbf x = (1, 2)\), compute \(\mathbf F(\mathbf x)\). Use \(J\) from B2(b) to predict \(\mathbf F(1.1, 1.9)\), then compute the true value. How close is the prediction?

B4. Two Newton steps. Start at \(\mathbf x_0 = (3, 0)\), with \(\alpha = 3\), \(n = 2\). (a) Compute \(\mathbf F(\mathbf x_0)\) and \(J(\mathbf x_0)\). Why is this first step especially easy? (b) Solve \(J\boldsymbol\delta = -\mathbf F\) and give \(\mathbf x_1\). (c) Do a second step from \(\mathbf x_1\) (keep 4–5 significant digits). Compare \(\mathbf x_2\) with the steady state \((2.6180, 0.3820)\).

B5. All steady states, exactly. For the toggle switch with \(n = 2\): (a) Write the two steady-state equations as \(u(1 + v^2) = \alpha\) and \(v(1 + u^2) = \alpha\). Subtract them and show that \((u - v)(1 - uv) = 0\). (b) Case \(u = v\): show that \(u^3 + u - \alpha = 0\). For \(\alpha = 3\), find the root with two Newton steps from \(u_0 = 1\) (one variable). (c) Case \(uv = 1\): show that \(u + v = \alpha\). Find \(u\) and \(v\) for \(\alpha = 3\) exactly. (You need \(t^2 - \alpha t + 1 = 0\).) (d) For which \(\alpha\) does case (c) give real, positive solutions? What does that mean for the switch?

B6. A linear system. Suppose \(\mathbf F(\mathbf x) = A\mathbf x - \mathbf b\) with a fixed invertible matrix \(A\). What is \(J\)? Show that Newton reaches the exact root in one step, from any start.

B7. A finite-difference Jacobian by hand. At \(\mathbf x = (3, 0.5)\) use \(h = 0.01\) (not scaled). (a) Compute column 2: \(\big(\mathbf F(3, 0.51) - \mathbf F(3, 0.5)\big)/0.01\). Compare with the exact column \((-1.92, -1)\). (b) Compute column 1 the same way and compare with \((-1, -0.18)\). (c) How many evaluations of \(\mathbf F\) did the whole Jacobian cost? How many for a network of 100 genes?

B8. Symmetry and cost. (a) Suppose \(u_0 = v_0\). Show that \(F_1 = F_2\) and that \(J\) is symmetric with equal diagonal entries. Conclude that \(\delta_u = \delta_v\), so every Newton iterate stays on the line \(u = v\). Which steady state can Newton then find? (b) Solving a dense \(n\times n\) system costs about \(\tfrac23 n^3\) operations. At \(10^9\) operations per second, how long does one Newton step take for \(n = 2\), \(1000\) and \(20\,000\) genes? With a finite-difference Jacobian and an \(\mathbf F\) costing \(10n\) operations, how much does building the Jacobian cost in comparison?

In code

The solutions build on each other: the Background defines F and J, C1 defines fd_jacobian, C2 defines newton_sys and the exact root xstar. Each Rust file is a complete program.

C1. Check the Jacobian. Write F and J (Background) and a function fd_jacobian(F, x, h) that returns the finite-difference Jacobian (Fact 6). Check B2(b), and compare J(x) with fd_jacobian(F, x) at \((3, 0.5)\), \((1, 2)\), \((1.2, 1.2)\) and \((0.1, 4)\). What size of difference do you expect? Also compare with a library routine: R numDeriv::jacobian, Python scipy.optimize.approx_fprime.

C2. Newton for the toggle switch. Write newton_sys(F, J, x0, tol, maxit) that returns all iterates (one per row). Check your B4 answers with a start at \((3, 0)\). Then start at \((3, 0.5)\): print the error \(\|\mathbf x_k - \mathbf x^*\|\) (use the exact root from B5) and the residual \(\|\mathbf F(\mathbf x_k)\|\) per step, and the ratios \(e_{k+1}/e_k^2\). Is the convergence quadratic?

C3. All steady states from many starts. Run Newton from a \(10\times10\) grid of starts with \(u_0, v_0 \in \{0.2, 0.6, \dots, 3.8\}\). Collect the distinct roots (round to 6 decimals). What fraction of starts goes to each? Check the residual of every run. Compare with the basin picture in the lecture.

C4. A finite-difference Jacobian inside Newton. Run Newton from \((3, 0.5)\) with fd_jacobian in place of J, for \(h = \sqrt\varepsilon\), \(10^{-4}\), \(10^{-2}\) and \(0.3\). Print the number of steps and the first five errors. What happens to the convergence when \(h\) is large?

C5. The library routine. Solve the same problem with multiroot (R) or scipy.optimize.root (Python), first with the default settings and then with your J and a tighter tolerance. How large are the residual and the error at the default settings? Do the starts \((0.5, 3)\), \((1, 1)\) and \((1, 0.2)\) give the same roots as your Newton? (Rust: no library, so count how many evaluations of \(\mathbf F\) your Newton with a finite-difference Jacobian needs.)

C6. Failure: a nearly singular Jacobian. (a) Run Newton from \((1.9, 0.5)\) and from \((2.0, 0.55)\). For each, print \(\det J(\mathbf x_0)\) (R det, Python np.linalg.det), the length of the first step, the smallest \(u\) or \(v\) along the way, and where it ends. (b) Set the Hill coefficient to \(n = 2.5\) and take two plain Newton steps from \((2, 0.5)\). What happens, and why? (c) Write a damped Newton: after computing \(\boldsymbol\delta\), try \(t = 1, \tfrac12, \tfrac14, \dots\) and accept \(\mathbf x + t\boldsymbol\delta\) as soon as all entries are \(\ge 0\) and \(\|\mathbf F\|\) has not grown. Does it solve (b)?

C7. When is the switch bistable? For \(\alpha = 1, 1.5, 2, \dots, 5\), run Newton from an \(8\times 8\) grid of starts in \([0.25, 5]^2\) and count the distinct roots with residual below \(10^{-10}\). Also count the runs that hit maxit = 50. Compare with B5(d) and the formula \(u = (\alpha + \sqrt{\alpha^2 - 4})/2\) for the “U on” state. What goes wrong at \(\alpha = 2\)?

Hints

Hint 1 — partial derivatives (B1, B2)

Pretend the other variable is a number like 7. For \(\alpha(1 + v^n)^{-1}\): the derivative of \((\cdot)^{-1}\) is \(-(\cdot)^{-2}\), times the derivative of the inside, \(n v^{n-1}\). For \(r(S, E)\) in \(S\), use the quotient rule: \(\dfrac{d}{dS}\dfrac{S}{K+S} = \dfrac{K}{(K+S)^2}\).

Hint 2 — a 2×2 linear solve (B4)

Write the two equations out. Use one equation to express one unknown in terms of the other, and substitute. For \(\begin{pmatrix} a & b\\ c & d\end{pmatrix}\boldsymbol\delta = \mathbf r\) the closed form is \(\delta_1 = (d r_1 - b r_2)/\det\), \(\delta_2 = (a r_2 - c r_1)/\det\) with \(\det = ad - bc\). Remember the right-hand side is \(-\mathbf F\).

Hint 3 — exact steady states (B5)

\(u(1 + v^2) - v(1 + u^2) = (u - v) + uv(v - u)\). Factor out \((u - v)\). With \(uv = 1\), \(u(1 + v^2) = u + v\,(uv) = u + v\). Two numbers with sum \(\alpha\) and product 1 are the roots of \(t^2 - \alpha t + 1 = 0\).

Hint 4 — Newton in code (C2, C3)

R: solve(A, b) solves \(A\mathbf x = \mathbf b\); collect the iterates with rbind. Python: np.linalg.solve, collect them in a list and convert with np.array. Rust: jac(&x).lu().solve(&(-f(&x))) returns None if the matrix is singular. For the grid of starts: R expand.grid and apply; distinct rows with unique after round. Python: np.unique(..., axis=0, return_counts=True).

Hint 5 — finite differences (C1, C4)

Copy x, add \(h_j\) to entry \(j\) only, and fill column \(j\) with the difference of the two \(\mathbf F\) vectors divided by \(h_j\). In R, .Machine$double.eps; in Python, np.finfo(float).eps; in Rust, f64::EPSILON. For C4, pass a small function function(x) fd_jacobian(F, x, h) (Python: lambda x: fd_jacobian(F, x, h)) as the Jacobian.

Hint 6 — library routines (C5)

multiroot(f, start, jacfunc = NULL, rtol, atol, ctol) returns a list with root, f.root (the residual), iter and estim.precis. scipy.optimize.root(fun, x0, jac=None, tol=None) returns an object with .x, .fun, .nfev and .success. Always look at the residual, not just at success.

Hint 7 — failures and damping (C6, C7)

A negative number raised to a non-integer power is NaN in R and numpy (and in Rust’s powf). For the damped step, a while loop that halves t; stop with an error if t becomes tiny. In C7, wrap the Newton call in tryCatch (Python: try/except np.linalg.LinAlgError) because the Jacobian can be exactly singular. At \(\alpha = 2\), compute \(\det J\) at the root \(u = v = 1\).

B1. (a) \(\partial g/\partial u = 2uv\) (treat \(v\) as a constant), \(\partial g/\partial v = u^2 + 3\) (treat \(u\) as a constant). At \((1, 2)\): \(\partial g/\partial u = 4\), \(\partial g/\partial v = 4\). (b) \(\partial r/\partial E = \dfrac{kS}{K + S} = \dfrac{2\cdot1}{2} = 1\): one more unit of enzyme raises the rate by 1 unit (the rate is proportional to \(E\)). \(\partial r/\partial S = kE\,\dfrac{K}{(K+S)^2} = 2\cdot0.5\cdot\dfrac{1}{4} = 0.25\): at \(S = K\) the enzyme is half saturated, and one more unit of substrate raises the rate by only 0.25. B2. (a) \(\partial F_1/\partial u = -1\), \(\partial F_1/\partial v = \alpha\cdot\big(-(1+v^n)^{-2}\big)\cdot n v^{n-1} = -\dfrac{\alpha n v^{n-1}}{(1+v^n)^2}\); by symmetry \(\partial F_2/\partial u = -\dfrac{\alpha n u^{n-1}}{(1+u^n)^2}\) and \(\partial F_2/\partial v = -1\). (b) At \((1, 2)\): \(\partial F_1/\partial v = -\dfrac{6\cdot2}{5^2} = -0.48\), \(\partial F_2/\partial u = -\dfrac{6\cdot1}{2^2} = -1.5\). So \(J = \begin{pmatrix} -1 & -0.48\\ -1.5 & -1\end{pmatrix}\). (c) The diagonal \(-1\) is degradation/dilution: each protein lowers its own rate of change. The off-diagonal entries are repression. At \((1, 2)\), \(u = 1\) sits exactly at the repression threshold, the steepest part of the Hill curve, so a change in U has a strong effect on V’s production (\(-1.5\)). \(v = 2\) is above threshold, where the Hill curve flattens, so V’s effect on U is weaker (\(-0.48\)). (d) At \(u = v = 1.2134\): off-diagonals \(-\dfrac{6\cdot1.2134}{(1 + 1.4724)^2} = -\dfrac{7.2805}{6.1128} = -1.1911\), so \(J = \begin{pmatrix} -1 & -1.1911\\ -1.1911 & -1\end{pmatrix}\) and \(\det J = 1 - 1.1911^2 = -0.4186\). Not singular, so Newton converges quadratically there too.

B3. \(\mathbf F(1, 2) = (3/5 - 1,\; 3/2 - 2) = (-0.4, -0.5)\). With \(\boldsymbol\delta = (0.1, -0.1)\): \(J\boldsymbol\delta = (-0.1 + 0.048,\; -0.15 + 0.1) = (-0.052, -0.05)\), so the prediction is \((-0.452, -0.550)\). B4. (a) \(\mathbf F(3, 0) = (3/1 - 3,\; 3/10 - 0) = (0, 0.3)\). \(J(3, 0) = \begin{pmatrix} -1 & 0\\ -0.18 & -1\end{pmatrix}\): at \(v = 0\) the Hill curve is flat (\(\partial F_1/\partial v = 0\)), so \(J\) is triangular. (b) Row 1: \(-\delta_u = 0\), so \(\delta_u = 0\). Row 2: \(-0.18\cdot0 - \delta_v = -0.3\), so \(\delta_v = 0.3\). \(\mathbf x_1 = (3, 0.3)\). (c) \(\mathbf F(3, 0.3) = (3/1.09 - 3,\; 0.3 - 0.3) = (-0.24771, 0)\). \(\partial F_1/\partial v = -6\cdot0.3/1.09^2 = -1.51502\), \(\partial F_2/\partial u = -0.18\). Solve \(\begin{pmatrix} -1 & -1.51502\\ -0.18 & -1\end{pmatrix}\boldsymbol\delta = \begin{pmatrix} 0.24771\\ 0\end{pmatrix}\). Row 2 gives \(\delta_v = -0.18\,\delta_u\); row 1 then gives \((-1 + 0.27270)\,\delta_u = 0.24771\), so \(\delta_u = -0.34058\), \(\delta_v = 0.06131\). \(\mathbf x_2 = (2.6594, 0.3613)\), error about \(0.046\) (C2 confirms these digits).

B5. (a) \(u + uv^2 - v - vu^2 = (u - v) - uv(u - v) = (u - v)(1 - uv) = 0\). (b) \(u = v\) in \(u(1 + u^2) = \alpha\) gives \(u^3 + u - \alpha = 0\). Newton with \(f(u) = u^3 + u - 3\), \(f'(u) = 3u^2 + 1\): \(u_1 = 1 - (-1)/4 = 1.25\); \(u_2 = 1.25 - 0.203125/5.6875 = 1.21429\). (The root is \(1.213412\).) (c) With \(uv = 1\): \(u(1 + v^2) = u + v(uv) = u + v = \alpha\). So \(u, v\) are the roots of \(t^2 - 3t + 1 = 0\): \(t = (3 \pm \sqrt5)/2\), i.e. \((u, v) = (2.618034, 0.381966)\) or \((0.381966, 2.618034)\). (These are \(\varphi^2\) and \(1/\varphi^2\), with \(\varphi\) the golden ratio.) (d) \(t^2 - \alpha t + 1 = 0\) has real roots when \(\alpha^2 - 4 \ge 0\), i.e. \(\alpha \ge 2\) (both positive, since their product is 1 and their sum \(\alpha > 0\)). For \(\alpha < 2\) only the symmetric state exists: the circuit is not a switch. For \(\alpha > 2\) there are three steady states: bistable. At \(\alpha = 2\) all three merge at \(u = v = 1\).

B6. \(J = A\), constant. From any \(\mathbf x_0\): \(A\boldsymbol\delta = -(A\mathbf x_0 - \mathbf b)\), so \(\mathbf x_1 = \mathbf x_0 + \boldsymbol\delta = \mathbf x_0 - \mathbf x_0 + A^{-1}\mathbf b = A^{-1}\mathbf b\), the exact root. The linear approximation is exact for a linear function, so one step suffices. (Newton is “solve the linear problem, repeat”; for a linear problem there is nothing to repeat.)

B7. (a) \(\mathbf F(3, 0.51) = (3/1.2601 - 3,\; 0.3 - 0.51) = (-0.619237, -0.21)\), \(\mathbf F(3, 0.5) = (-0.6, -0.2)\). Column 2 \(= (-0.019237, -0.01)/0.01 = (-1.9237, -1)\). Exact: \((-1.92, -1)\). The error \(0.0037\) is about \(h\,|\partial^2 F_1/\partial v^2|/2\), as for any forward difference. (b) \(\mathbf F(3.01, 0.5) = (2.4 - 3.01,\; 3/10.0601 - 0.5) = (-0.61, -0.201792)\). Column 1 \(= (-0.01, -0.001792)/0.01 = (-1, -0.1792)\). Exact: \((-1, -0.18)\). (c) 3 evaluations: \(\mathbf F(\mathbf x)\) once, plus one per column. For 100 genes: 101 evaluations.

B8. (a) With \(u = v\): \(F_1 = \alpha/(1 + u^n) - u = F_2\). The off-diagonal entries are the same function evaluated at \(v\) and at \(u\), so they are equal (\(= b\), say), and both diagonal entries are \(-1\). The system \(\begin{pmatrix} -1 & b\\ b & -1\end{pmatrix}\boldsymbol\delta = -\begin{pmatrix} F_1\\ F_1\end{pmatrix}\) is unchanged when we swap \(\delta_u\) and \(\delta_v\), so its unique solution has \(\delta_u = \delta_v\). Every iterate stays on the diagonal, so Newton can only find the middle state \((1.2134, 1.2134)\). (b) \(n = 2\): about 5 operations, nanoseconds. \(n = 1000\): \(6.7\times10^8\) operations, 0.67 s. \(n = 20\,000\): \(5.3\times10^{12}\), about 1.5 hours per step. Building the Jacobian costs \((n + 1)\cdot10n \approx 10n^2\) operations: \(10^7\) for \(n = 1000\) and \(4\times10^9\) for \(n = 20\,000\), small compared with the solve. For large dense problems the linear solve dominates; for cheap \(\mathbf F\) and sparse \(J\) the balance changes (Part 3).

    let (u, v) = (x[0], x[1]);
    DMatrix::from_row_slice(2, 2, &[
        -1.0, -ALPHA * N * v.powf(N - 1.0) / (1.0 + v.powf(N)).powi(2),

// works for any F: R^n -> R^m (here passed as a function)
fn fd_jacobian(f: impl Fn(&DVector<f64>) -> DVector<f64>, x: &DVector<f64>, h: f64) -> DMatrix<f64> {
    let fx = f(x);
    let mut jm = DMatrix::zeros(fx.len(), x.len());
    for j in 0..x.len() {
        let hj = h * x[j].abs().max(1.0);       // step relative to the size of x[j]
        let mut xh = x.clone();
        xh[j] += hj;                             // nudge only x[j]
        jm.set_column(j, &((f(&xh) - &fx) / hj)); // column j
    }
    jm
}

// returns the path x_0, x_1, ...; None if J is exactly singular at some step
fn newton_sys(f: impl Fn(&DVector<f64>) -> DVector<f64>,
              jac: impl Fn(&DVector<f64>) -> DMatrix<f64>,
              x0: &DVector<f64>, tol: f64, maxit: usize) -> Option<Vec<DVector<f64>>> {
    let mut x = x0.clone();
    let mut path = vec![x.clone()];
    for _ in 0..maxit {
        let delta = jac(&x).lu().solve(&(-f(&x)))?; // one linear solve per step
        x += &delta;
        path.push(x.clone());
        if delta.norm() < tol {                      // norm() = sqrt(sum of squares)
            return Some(path);
        }
    }
    eprintln!("warning: no convergence");
    Some(path)
}

fn v2(a: f64, b: f64) -> DVector<f64> { DVector::from_vec(vec![a, b]) }

const ALPHA: f64 = 3.0;
const N: f64 = 2.0;

fn f(x: &DVector<f64>) -> DVector<f64> {
    let (u, v) = (x[0], x[1]);
    DVector::from_vec(vec![ALPHA / (1.0 + v.powf(N)) - u,
                           ALPHA / (1.0 + u.powf(N)) - v])
}

fn jac(x: &DVector<f64>) -> DMatrix<f64> {
    let (u, v) = (x[0], x[1]);
    DMatrix::from_row_slice(2, 2, &[
        -1.0, -ALPHA * N * v.powf(N - 1.0) / (1.0 + v.powf(N)).powi(2),
        -ALPHA * N * u.powf(N - 1.0) / (1.0 + u.powf(N)).powi(2), -1.0])
}

// returns the path x_0, x_1, ...; None if J is exactly singular at some step
fn newton_sys(f: impl Fn(&DVector<f64>) -> DVector<f64>,
              jac: impl Fn(&DVector<f64>) -> DMatrix<f64>,
              x0: &DVector<f64>, tol: f64, maxit: usize) -> Option<Vec<DVector<f64>>> {
    let mut x = x0.clone();
    let mut path = vec![x.clone()];
    for _ in 0..maxit {
        let delta = jac(&x).lu().solve(&(-f(&x)))?; // one linear solve per step
        x += &delta;
        path.push(x.clone());
        if delta.norm() < tol {                      // norm() = sqrt(sum of squares)
            return Some(path);
        }
    }
    eprintln!("warning: no convergence");
    Some(path)
}

fn v2(a: f64, b: f64) -> DVector<f64> { DVector::from_vec(vec![a, b]) }

fn fd_jacobian(f: impl Fn(&DVector<f64>) -> DVector<f64>, x: &DVector<f64>, h: f64) -> DMatrix<f64> {
    let fx = f(x);
    let mut jm = DMatrix::zeros(fx.len(), x.len());
    for j in 0..x.len() {
        let hj = h * x[j].abs().max(1.0);
        let mut xh = x.clone();
        xh[j] += hj;
        jm.set_column(j, &((f(&xh) - &fx) / hj));
    }
    jm
}

With \(h = \sqrt\varepsilon\) the run is indistinguishable from the exact Jacobian. With \(h = 10^{-4}\) the Jacobian has about 4 correct digits and the last steps gain fewer digits. With \(h = 10^{-2}\) and \(0.3\) the convergence becomes linear (a roughly constant factor per step) and needs more steps. An approximate Jacobian still converges to the right root, because the root is defined by \(\mathbf F = \mathbf 0\), not by \(J\); only the speed suffers. This is why quasi-Newton methods, which reuse an approximate Jacobian, work (Part 9).

// returns the path x_0, x_1, ...; None if J is exactly singular at some step
fn newton_sys(f: impl Fn(&DVector<f64>) -> DVector<f64>,
              jac: impl Fn(&DVector<f64>) -> DMatrix<f64>,
              x0: &DVector<f64>, tol: f64, maxit: usize) -> Option<Vec<DVector<f64>>> {
    let mut x = x0.clone();
    let mut path = vec![x.clone()];
    for _ in 0..maxit {
        let delta = jac(&x).lu().solve(&(-f(&x)))?; // one linear solve per step
        x += &delta;
        path.push(x.clone());
        if delta.norm() < tol {                      // norm() = sqrt(sum of squares)
            return Some(path);
        }
    }
    eprintln!("warning: no convergence");
    Some(path)
}

fn v2(a: f64, b: f64) -> DVector<f64> { DVector::from_vec(vec![a, b]) }

fn newton_damped(n: f64, x0: &DVector<f64>, tol: f64, maxit: usize) -> DVector<f64> {
    let mut x = x0.clone();
    for k in 1..=maxit {
        let delta = jac(&x, n).lu().solve(&(-f(&x, n))).expect("singular Jacobian");
        let mut t = 1.0;
        // halve the step until x stays >= 0 and ||F|| does not grow
        loop {
            let xt = &x + &delta * t;
            if xt.iter().all(|&c| c >= 0.0) && f(&xt, n).norm() <= f(&x, n).norm() {
                break;
            }
            t /= 2.0;
            if t < 1e-10 { panic!("damping failed"); }
        }
        x += &delta * t;
        println!("{} {} {:?}", k, t, x.as_slice());
        if (&delta * t).norm() < tol { break; }
    }
    x
}

fn main() {
    // (a) two nearby starts
    for s in [[1.9, 0.5], [2.0, 0.55]] {
        let x0 = v2(s[0], s[1]);
        let p = newton_sys(|x: &DVector<f64>| f(x, 2.0), |x: &DVector<f64>| jac(x, 2.0), &x0, 1e-12, 50).unwrap();
        let step1 = (&p[1] - &p[0]).norm();
        let minval = p.iter().flat_map(|x| x.iter().copied()).fold(f64::INFINITY, f64::min);
        let end = p.last().unwrap();
        println!("start {:?} | det J: {:.3} | first step length: {:.3} | min u, v on the way: {:.3} | end: {:.6} {:.6}",
                 s, jac(&x0, 2.0).determinant(), step1, minval, end[0], end[1]);
    }
    // (b) Hill coefficient 2.5: plain Newton
    let mut x = v2(2.0, 0.5);
    for _ in 0..2 {
        // with NaN entries the LU still "succeeds" and returns NaN
        x += jac(&x, 2.5).lu().solve(&(-f(&x, 2.5))).unwrap();
        println!("{:?}", x.as_slice());
    }
    // (c) damped Newton

// C7: how many steady states for each promoter strength alpha?
use nalgebra::{DMatrix, DVector};

const N: f64 = 2.0;

fn f(x: &DVector<f64>, a: f64) -> DVector<f64> {
    let (u, v) = (x[0], x[1]);
    DVector::from_vec(vec![a / (1.0 + v.powf(N)) - u, a / (1.0 + u.powf(N)) - v])
}

fn jac(x: &DVector<f64>, a: f64) -> DMatrix<f64> {
    let (u, v) = (x[0], x[1]);
    DMatrix::from_row_slice(2, 2, &[
        -1.0, -a * N * v.powf(N - 1.0) / (1.0 + v.powf(N)).powi(2),
        -a * N * u.powf(N - 1.0) / (1.0 + u.powf(N)).powi(2), -1.0])
}

// last iterate and number of steps; None if J is exactly singular
fn newton_last(a: f64, x0: &DVector<f64>, tol: f64, maxit: usize) -> Option<(DVector<f64>, usize)> {
    let mut x = x0.clone();
    for k in 1..=maxit {
        let delta = jac(&x, a).lu().solve(&(-f(&x, a)))?;
        x += &delta;
        if delta.norm() < tol { return Some((x, k)); }
    }
    Some((x, maxit))
}

fn main() {
    let g: Vec<f64> = (0..8).map(|i| 0.25 + i as f64 * 4.75 / 7.0).collect();
    for i in 0..9 {
        let a = 1.0 + 0.5 * i as f64;
        let mut distinct: Vec<[f64; 2]> = Vec::new();
        let mut hit_maxit = 0;
        for &v in &g {
            for &u in &g {
                let Some((x, k)) = newton_last(a, &DVector::from_vec(vec![u, v]), 1e-12, 50) else { continue };
                if k == 50 { hit_maxit += 1; }
                if x.iter().all(|c| c.is_finite()) && f(&x, a).norm() < 1e-10 {
                    let key = [(x[0] * 1e6).round() / 1e6, (x[1] * 1e6).round() / 1e6];
                    if !distinct.contains(&key) { distinct.push(key); }
                }
            }
        }
        let umax = distinct.iter().map(|k| k[0]).fold(f64::MIN, f64::max);
        println!("alpha = {:.1}: {:2} distinct roots; largest u = {:.6}; {:2} runs hit maxit",
                 a, distinct.len(), umax, hit_maxit);
    }
    println!("{}", (5.0 + (5.0f64 * 5.0 - 4.0).sqrt()) / 2.0); // B5 formula at alpha = 5
}

For \(\alpha \le 1.5\) there is one steady state, for \(\alpha \ge 2.5\) three, and the “U on” state matches \((\alpha + \sqrt{\alpha^2 - 4})/2\) (B5) to all printed digits. At \(\alpha = 2\) the three states merge at \((1, 1)\) and there \(\det J = 1 - 1 = 0\): the Jacobian is singular at the root. Newton then converges only linearly, most runs hit maxit, and the not-quite-converged iterates are “distinct” after rounding to 6 decimals, so the count (19–21, depending on the language’s rounding) is meaningless. This is the system version of a double root in one variable. The check: many runs at maxit, or a tiny \(\det J\) at the reported roots. At exactly such parameter values (bifurcations) the number of steady states changes, which is why they are worth locating.
