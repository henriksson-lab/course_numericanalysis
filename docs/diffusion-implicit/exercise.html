Exercise: implicit schemes and the method of lines

Goal

By the end of this exercise you should be able to:

  • write one backward Euler and one Crank–Nicolson step for the diffusion equation as a tridiagonal system, solve it by hand for three unknowns and in code with the Thomas algorithm,
  • compute the growth factor of each scheme for a Fourier mode and use it to explain unconditional stability, and why Crank–Nicolson oscillates after a sharp start,
  • verify a solver against an exact solution (a decaying sine mode) and read the order in time and in space from error ratios; recognise an error floor and lucky cancellation,
  • estimate the order by grid refinement when there is no exact solution,
  • hand the grid to a stiff ODE solver (method of lines) and tell it that the Jacobian is banded,
  • answer two microfluidic heat questions: how sharp a temperature step a Drosophila embryo feels between a cold and a warm stream [M1, M2], and why the wall of a PCR chip should be thin and not made of PDMS [H1, H2].

The by-hand part needs pen, paper and a calculator. The code part checks the hand answers and then goes to grids where only code works.

Background

Facts used below. Grid \(x_i = i\,\Delta x\), \(i = 0, \dots, N\); \(c_i^n \approx c(x_i, t_n)\); units µm and s. This is the node grid of the previous unit: boundary values sit on the end nodes, the \(N - 1\) interior nodes are the unknowns. The embryo (B5, C5) and the PCR wall (C6) use the same kind of nodes, but an end with no flux or heat loss is an unknown too (ghost point, fact 8), and the variable is a temperature in °C; mesh ratio \(r = D\,\Delta t/\Delta x^2\); \(A\) = tridiagonal matrix with \(-2\) on the diagonal and \(1\) beside it.

  1. The chamber (from The diffusion (heat) equation by finite differences): a channel of length \(L = 500\) µm, small molecule \(D = 1000\) µm²/s, \(N = 50\) (\(\Delta x = 10\) µm), source \(c_0 = 1\), sink \(c_N = 0\), empty at \(t = 0\). exact(x, t, L, D) is its Fourier-series solution.
  2. Backward Euler: \(-r\,c_{i-1}^{n+1} + (1 + 2r)\,c_i^{n+1} - r\,c_{i+1}^{n+1} = c_i^n\), i.e. \((I - rA)\,\mathbf c^{n+1} = \mathbf c^n + \mathbf b\); the boundary values enter \(\mathbf b\) as \(r c_0\) (first row) and \(r c_N\) (last row).
  3. Crank–Nicolson: \(-\tfrac r2 c_{i-1}^{n+1} + (1 + r)\,c_i^{n+1} - \tfrac r2 c_{i+1}^{n+1} = c_i^n + \tfrac r2\bigl(c_{i-1}^n - 2c_i^n + c_{i+1}^n\bigr)\), plus \(\tfrac r2 c_0\) and \(\tfrac r2 c_N\) in the first and last rows.
  4. Thomas thomas(a, b, c, d) from Structure: symmetric, banded, sparse: sub-diagonal (first entry unused), diagonal, super-diagonal (last entry unused), right-hand side; about \(8N\) operations.
  5. Growth factors for a mode with \(z = 4r\sin^2(\theta/2)\) (\(\theta = \pi\): the zigzag, \(z = 4r\)): exact \(e^{-z}\), FTCS \(1 - z\), backward Euler \(1/(1 + z)\), Crank–Nicolson \((1 - z/2)/(1 + z/2)\).
  6. Exact sine mode: with \(c = 0\) at both ends, \(c(x, 0) = \sin(\pi x/L)\) gives \(c(x, t) = e^{-D(\pi/L)^2 t}\sin(\pi x/L)\).
  7. Error at a fixed time \(\approx C_t\,\Delta t^p + C_x\,\Delta x^2\), \(p = 1\) (backward Euler), \(p = 2\) (Crank–Nicolson). Halving a step divides its part by \(2^p\); \(\log_2\) of the error ratio is the observed order.
  8. No-flux end (ghost point \(c_{N+1} = c_{N-1}\)): the last row becomes \(-2r\,c_{N-1} + (1 + 2r)\,c_N\) for backward Euler. Heat loss at the end, \(-k\,\partial T/\partial z = h\,(T - T_\text{air})\): ghost point \(T_{N+1} = T_{N-1} - 2\Delta z\,(h/k)\,(T_N - T_\text{air})\).
  9. Heat obeys the same equation with the thermal diffusivity \(D = k/(\rho c_p)\) (\(k\) conductivity, \(\rho\) density, \(c_p\) heat capacity). Water: \(D \approx 1.4\times10^{-7}\) m²/s \(= 1.4\times10^5\) µm²/s.

The basic tools in each language: Thomas, one backward Euler step, one Crank–Nicolson step, and 15 steps of 4 s on the chamber. Python users can replace thomas by scipy.linalg.solve_banded; Rust has no tridiagonal solver in the allowed crates, so it is hand-written.

thomas <- function(a, b, c, d) {                 # Structure: symmetric, banded, sparse
  n <- length(d)
  for (i in 2:n) {
    w <- a[i] / b[i - 1]
    b[i] <- b[i] - w * c[i - 1]
    d[i] <- d[i] - w * d[i - 1]
  }
  x <- numeric(n)
  x[n] <- d[n] / b[n]
  for (i in (n - 1):1) x[i] <- (d[i] - c[i] * x[i + 1]) / b[i]
  x
}
be_step <- function(c, r) {                      # c includes the two boundary values
  m <- length(c) - 2; i <- 2:(m + 1)
  d <- c[i]
  d[1] <- d[1] + r * c[1]; d[m] <- d[m] + r * c[m + 2]
  c[i] <- thomas(rep(-r, m), rep(1 + 2 * r, m), rep(-r, m), d)
  c
}
cn_step <- function(c, r) {
  m <- length(c) - 2; i <- 2:(m + 1)
  d <- c[i] + r / 2 * (c[i - 1] - 2 * c[i] + c[i + 1])
  d[1] <- d[1] + r / 2 * c[1]; d[m] <- d[m] + r / 2 * c[m + 2]
  c[i] <- thomas(rep(-r / 2, m), rep(1 + r, m), rep(-r / 2, m), d)
  c
}
exact <- function(x, t, L, D, nterm = 200) {    # chamber, previous unit

  for (n in 1:nterm) s <- s - 2 / (n * pi) * sin(n * pi * x / L) * exp(-(n * pi / L)^2 * D * t)

}

import numpy as np

def thomas(a, b, c, d):                        # Structure: symmetric, banded, sparse
    n = len(d)
    b = np.array(b, dtype=float)       # copies: do not overwrite the caller's arrays
    d = np.array(d, dtype=float)
    for i in range(1, n):
        w = a[i] / b[i - 1]
        b[i] = b[i] - w * c[i - 1]
        d[i] = d[i] - w * d[i - 1]
    x = np.zeros(n)
    x[n - 1] = d[n - 1] / b[n - 1]
    for i in range(n - 2, -1, -1):
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i]
    return x

def be_step(c, r):
    c = c.copy(); m = len(c) - 2       # c includes the two boundary values
    d = c[1:-1].copy()
    d[0] += r * c[0]; d[-1] += r * c[-1]
    c[1:-1] = thomas(np.full(m, -r), np.full(m, 1 + 2 * r), np.full(m, -r), d)
    return c

def cn_step(c, r):
    c = c.copy(); m = len(c) - 2
    d = c[1:-1] + r / 2 * (c[:-2] - 2 * c[1:-1] + c[2:])
    d[0] += r / 2 * c[0]; d[-1] += r / 2 * c[-1]
    c[1:-1] = thomas(np.full(m, -r / 2), np.full(m, 1 + r), np.full(m, -r / 2), d)
    return c

def exact(x, t, L, D, nterm=200):          # chamber, previous unit
    s = 1 - x / L

        s = s - 2 / (n * np.pi) * np.sin(n * np.pi * x / L) * np.exp(-(n * np.pi / L)**2 * D * t)
    return s

// Background: Thomas algorithm, one backward Euler step and one Crank-Nicolson
// step for the chamber (hand-written; no crate needed).

/// Thomas algorithm: a = below the diagonal (a[0] unused), b = diagonal,
/// c = above the diagonal (c[n-1] unused), d = right-hand side.
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// One backward Euler step; c includes the two boundary values (kept fixed).
fn be_step(c: &mut [f64], r: f64) {
    let m = c.len() - 2;
    let mut d = c[1..=m].to_vec();
    d[0] += r * c[0];
    d[m - 1] += r * c[m + 1];
    let x = thomas(&vec![-r; m], &vec![1.0 + 2.0 * r; m], &vec![-r; m], &d);
    c[1..=m].copy_from_slice(&x);
}

/// One Crank-Nicolson step.
fn cn_step(c: &mut [f64], r: f64) {
    let m = c.len() - 2;
    let mut d: Vec<f64> = (1..=m).map(|i| c[i] + r / 2.0 * (c[i - 1] - 2.0 * c[i] + c[i + 1])).collect();
    d[0] += r / 2.0 * c[0];
    d[m - 1] += r / 2.0 * c[m + 1];
    let x = thomas(&vec![-r / 2.0; m], &vec![1.0 + r; m], &vec![-r / 2.0; m], &d);
    c[1..=m].copy_from_slice(&x);
}

fn main() {
    let (dd, l, n) = (1000.0, 500.0, 50);
    let dx = l / n as f64;
    let mut c = vec![0.0; n + 1];
    c[0] = 1.0;                                // empty channel, source 1, sink 0
    let r = dd * 4.0 / (dx * dx);              // dt = 4 s
    for _ in 0..15 { be_step(&mut c, r); }     // to t = 60 s
    let show = |c: &[f64]| {                   // x = 0, 100, ..., 500
        let s: Vec<String> = (0..=n).step_by(10).map(|i| format!("{:.4}", c[i])).collect();
        println!("[{}]", s.join(", "));
    };
    show(&c);
    let mut c2 = vec![0.0; n + 1];
    c2[0] = 1.0;
    for _ in 0..15 { cn_step(&mut c2, r); }
    show(&c2);
}

By hand

B1. Implicit steps by hand. The chamber with \(N = 4\) (\(\Delta x = 125\) µm), empty at \(t = 0\), source \(c_0 = 1\), sink \(c_4 = 0\), \(r = 1\) (\(\Delta t = 15.6\) s). (a) The lecture gives the first backward Euler step: \(\mathbf c^1 = \tfrac1{21}(8, 3, 1)\). Write the system for the second step and solve it with Thomas (keep fractions or use 4 decimals). (b) Do one Crank–Nicolson step from the empty channel with \(r = 1\). Write the \(3\times3\) system first. (c) The exact values at \(t = 15.6\) s are \((0.480, 0.157, 0.034)\) and at \(t = 31.25\) s \((0.617, 0.315, 0.121)\). Which scheme is closer after one step? Is either of them accurate?

B2. Growth factors. (a) Fill in the growth factor of the zigzag mode (\(z = 4r\)) for \(r = 0.25, 1, 10, 100\) for FTCS, backward Euler, Crank–Nicolson and the exact solution. (b) A zigzag of amplitude 1 is present at \(t = 0\). How large is it after 10 Crank–Nicolson steps with \(r = 100\)? After 10 backward Euler steps? (c) The slowest mode of the chamber decays at rate \(0.0395\) per s. With \(\Delta t = 4\) s, compute \(z\) and the three factors (exact, backward Euler, Crank–Nicolson). What is left of that mode after 15 steps (60 s) in each case? (d) Which scheme is best for the slow mode and which for the zigzag? What does that suggest for a sharp start?

B3. What a step costs. The embryo grid of the lecture: \(N = 200\) (\(\Delta x = 2.5\) µm), \(D = 1.4\times10^5\) µm²/s, simulate 1 s. (a) FTCS needs \(\Delta t \le \Delta x^2/(2D)\). How many steps, and roughly how many operations at about 5 per grid point per step? (b) Backward Euler with \(\Delta t = 5\) ms and Thomas (about 8 operations per point): how many operations? (c) Same, but with a dense solve, \(\tfrac23 N^3\) per step. And if you factorise once and reuse the factors (\(2N^2\) per step for the two triangular solves)? (d) Repeat (a) and (b) for \(\Delta x = 0.25\) µm.

B4. Reading orders. On the sine-mode test (fine grid, \(N = 400\)), Crank–Nicolson gives error \(4.22\times10^{-4}\) at \(\Delta t = 3\) s and \(1.04\times10^{-4}\) at \(\Delta t = 1.5\) s; backward Euler gives \(2.06\times10^{-2}\) at \(\Delta t = 3\) s. (a) What is the observed order of Crank–Nicolson? Predict its error at \(\Delta t = 0.75\) s. (b) On the coarse grid \(N = 50\) the space error is about \(1.2\times10^{-4}\). What happens to the Crank–Nicolson error there if you keep halving \(\Delta t\) below 1.5 s? (c) How small must \(\Delta t\) be for backward Euler to reach an error of \(10^{-4}\), and how many steps is that up to \(t = 30\) s? Compare with Crank–Nicolson.

B5. The embryo between two streams. Model of the lecture: \(\partial T/\partial t = D\,\partial^2 T/\partial x^2 + (T_\text{out} - T)/\tau\), \(\tau = R^2/(2.405^2 D)\), steady length scale \(\lambda = \sqrt{D\tau}\). (a) Compute \(\tau\) and \(\lambda\) for \(R = 100\) µm and water. (b) The steady profile on the warm side is \(T = 27 - 3.5\,e^{-d/\lambda}\) at distance \(d\) from the middle. Show that the 10–90 % width (20.7 °C to 26.3 °C) is \(2\lambda\ln 5\) and compute it. What fraction of the 500 µm embryo is that? (c) Show that \(\lambda = R/2.405\). Would a medium with half the thermal diffusivity make the step sharper? What would change? (d) How long does the profile take to form (about \(4\tau\))? Why may [M1] treat the temperature inside the embryo as steady during development?

B6. The wall of a PCR chip. A chip sits on a heater; heat reaches the sample channel through a wall of thickness \(H\). Values as in [H1]: PDMS \(k = 0.15\) W/(m K), \(\rho = 970\) kg/m³, \(c_p = 1460\) J/(kg K); glass \(k = 1.1\), \(\rho = 2200\), \(c_p = 700\) (approximate; real glasses and PDMS mixes vary). (a) Compute the thermal diffusivity of each in m²/s and in mm²/s. (b) The heater jumps from 65 °C to 95 °C (annealing to denaturation). With an insulated channel side, the slowest mode decays with time constant \(4H^2/(\pi^2 D)\) and the channel-side temperature lags by about \(\tfrac{4}{\pi}\cdot 30\,e^{-t\pi^2D/(4H^2)}\) °C. How long until it is within 0.5 °C of 95 °C, for \(H = 1\) and 2 mm, PDMS and glass? (c) Now the channel side loses heat to air, \(h \approx 10\) W/(m² K), air at 25 °C. At steady state the profile is linear; balance the conducted flux \(k(95 - T_\text{top})/H\) with the loss \(h(T_\text{top} - 25)\) and find the temperature drop \(95 - T_\text{top}\) for each case. (d) A denaturation step lasts 15–30 s. Which designs work?

Hints

Hint 1 — the implicit systems (B1, C1)

Write one equation per interior point with the unknowns \(c_1, c_2, c_3\) on the left. Known values (the old level and the boundary values \(c_0 = 1\), \(c_4 = 0\)) go to the right. For Crank–Nicolson the right-hand side contains the explicit half: at \(i = 1\) it is \(c_1^n + \tfrac r2(c_0 - 2c_1^n + c_2^n)\), plus \(\tfrac r2 c_0\) for the boundary on the new level. Thomas by hand: \(w = a_i/b_{i-1}\), \(b_i \leftarrow b_i - w\,c_{i-1}\), \(d_i \leftarrow d_i - w\,d_{i-1}\), then back substitution.

Hint 2 — growth factors and cost (B2, B3)

After \(n\) steps a mode is multiplied by \(g^n\). \(|g| < 1\) means it shrinks; a negative \(g\) means it flips sign every step. For the cost, count steps = simulated time / \(\Delta t\), then multiply by the work per step.

Hint 3 — orders (B4, C2)

Error \(\approx C\,\Delta t^p\), so halving \(\Delta t\) divides it by \(2^p\), and \(p = \log_2(e(\Delta t)/e(\Delta t/2))\). In R use log2, in Python np.log2. When two error contributions have opposite sign, their sum can be accidentally small at one step size: always look at a sequence, never at one run. Plot with plot(..., log = "xy") (R) or plt.loglog (Python).

Hint 4 — oscillation checks (C3)

diff(c1) gives the increments, sign() their signs, and a second diff of the signs is non-zero wherever the direction changes. Python: np.diff, np.sign. A smooth filling curve has no sign changes at all.

Hint 5 — method of lines (C4)

R: diff(x, differences = 2) or diff(diff(x)) is the second difference. ode.1D(y, times, func, parms, nspec = 1, method = ...) returns a matrix whose first column is time; attr(out, "istate")[2:3] are steps and function evaluations. Increase maxsteps for ode45. Python: np.diff(x, 2); pass jac_sparsity=scipy.sparse.diags([1, 1, 1], [-1, 0, 1], shape=(n, n)) (scipy.sparse.diags) to "BDF", and lband=1, uband=1 to "LSODA"; sol.t.size - 1 steps, sol.nfev evaluations. /// Thomas algorithm (a[0] and c[n-1] unused), as in Structure: symmetric, banded, sparse.
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// One backward Euler step; c includes the two (fixed) boundary values.
fn be_step(c: &mut [f64], r: f64) {
    let m = c.len() - 2;
    let mut d = c[1..=m].to_vec();
    d[0] += r * c[0];
    d[m - 1] += r * c[m + 1];

/// Thomas algorithm (a[0] and c[n-1] unused), as in Structure: symmetric, banded, sparse.
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// Thomas algorithm (a[0] and c[n-1] unused), as in Structure: symmetric, banded, sparse.
fn thomas(a: &[f64], b: &[f64], c: &[f64], d: &[f64]) -> Vec<f64> {
    let n = d.len();
    let (mut b, mut d) = (b.to_vec(), d.to_vec());
    for i in 1..n {
        let w = a[i] / b[i - 1];
        b[i] -= w * c[i - 1];
        d[i] -= w * d[i - 1];
    }
    let mut x = vec![0.0; n];
    x[n - 1] = d[n - 1] / b[n - 1];
    for i in (0..n - 1).rev() {
        x[i] = (d[i] - c[i] * x[i + 1]) / b[i];
    }
    x
}

/// One backward Euler step; c includes the two (fixed) boundary values.
fn be_step(c: &mut [f64], r: f64) {
    let m = c.len() - 2;
    let mut d = c[1..=m].to_vec();
    d[0] += r * c[0];
    d[m - 1] += r * c[m + 1];
    let x = thomas(&vec![-r; m], &vec![1.0 + 2.0 * r; m], &vec![-r; m], &d);
    c[1..=m].copy_from_slice(&x);
}

/// One Crank-Nicolson step.
fn cn_step(c: &mut [f64], r: f64) {
    let m = c.len() - 2;
    let mut d: Vec<f64> = (1..=m).map(|i| c[i] + r / 2.0 * (c[i - 1] - 2.0 * c[i] + c[i + 1])).collect();
    d[0] += r / 2.0 * c[0];
    d[m - 1] += r / 2.0 * c[m + 1];
    let x = thomas(&vec![-r / 2.0; m], &vec![1.0 + r; m], &vec![-r / 2.0; m], &d);
    c[1..=m].copy_from_slice(&x);
}

/// Exact chamber profile (Fourier series of the previous unit).
fn exact(x: f64, t: f64, l: f64, dd: f64) -> f64 {
    let pi = std::f64::consts::PI;
    let mut s = 1.0 - x / l;
    for n in 1..=200 {
        let k = n as f64 * pi / l;
        s -= 2.0 / (n as f64 * pi) * (k * x).sin() * (-k * k * dd * t).exp();
    }
    s
}

fn max_abs_diff(a: &[f64], b: &[f64]) -> f64 {
    a.iter().zip(b).map(|(p, q)| (p - q).abs()).fold(0.0, f64::max)
}

struct Chamber { dd: f64, dx: f64 }
impl System<f64, DVector<f64>> for Chamber {
    fn system(&self, _t: f64, c: &DVector<f64>, dc: &mut DVector<f64>) {
        let m = c.len();                                // interior points only
        let k = self.dd / (self.dx * self.dx);
        for i in 0..m {
            let left = if i == 0 { 1.0 } else { c[i - 1] };       // source 1
            let right = if i == m - 1 { 0.0 } else { c[i + 1] };  // sink 0
            dc[i] = k * (left - 2.0 * c[i] + right);
        }
    }
}

const D: f64 = 1.4e5;   // thermal diffusivity of water, um^2/s

fn tau_of(r: f64) -> f64 { r * r / (2.405 * 2.405 * D) }   // exchange time, s

/// Steady temperature on the nodes 0..N; no flux through the tips.
fn embryo_steady(n: usize, r: f64) -> Vec<f64> {
    let dx = L / n as f64;
    let m = n + 1;
    let tout: Vec<f64> = (0..m).map(|i| {
        let x = i as f64 * dx;
        if x < L / 2.0 { 20.0 } else if x > L / 2.0 { 27.0 } else { 23.5 }
    }).collect();
    let s = D * tau_of(r) / (dx * dx);                     // (lambda / dx)^2
    let mut a = vec![-s; m]; a[0] = 0.0; a[m - 1] = -2.0 * s;
    let mut c = vec![-s; m]; c[0] = -2.0 * s; c[m - 1] = 0.0;
    thomas(&a, &vec![1.0 + 2.0 * s; m], &c, &tout)
}

/// x where the increasing profile t crosses level v (linear interpolation).
fn cross(t: &[f64], x: &[f64], v: f64) -> f64 {
    let k = t.iter().position(|&ti| ti >= v).unwrap();
    x[k - 1] + (v - t[k - 1]) / (t[k] - t[k - 1]) * (x[k] - x[k - 1])
}

  • Flow plus diffusion: adding flow gives a non-symmetric matrix and new failure modes (numerical diffusion, wiggles); backward Euler with one Thomas solve per step carries over, as the step that marches the flow down a channel.
  • Reaction–diffusion and pattern formation: the exchange term of the embryo is a linear reaction; with nonlinear reactions one treats diffusion implicitly (one Thomas solve) and the reaction explicitly.
