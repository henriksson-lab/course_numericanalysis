Exercise: polynomial interpolation

Goal

By the end of this exercise you should be able to:

  • write down the interpolating polynomial through a few readings in Lagrange form and in Newton form (divided differences), by hand and in code, and check that the monomial (Vandermonde) route gives the same polynomial,
  • use the interpolation error formula to bound the error between readings, and to choose how far apart readings may be,
  • explain from the node polynomial why equally spaced readings and a high degree give the Runge phenomenon, and what Chebyshev times change,
  • show that interpolation copies and amplifies noise, and choose a least-squares fit instead,
  • evaluate an interpolant stably with the barycentric formula, and recognise when monomial coefficients have lost their digits.

The by-hand part needs pen, paper and a calculator. The code part checks your hand answers and then goes to sizes where only code works.

Background

We use the course’s logistic OD curve (from Convergence and cost) as the truth that the readings are sampled from:

\[N(t) = \frac{K}{1 + (K/N_0 - 1)e^{-rt}}, \qquad K = 1.2,\ N_0 = 0.05,\ r = 0.8 \text{ per hour}.\]

In the lab you only have the readings; here we can measure every error exactly.

Facts used below:

  1. Existence and uniqueness. Through \(n+1\) points with distinct times \(t_0, \dots, t_n\) there is exactly one polynomial \(p\) of degree \(\le n\) with \(p(t_i) = y_i\). In the monomial basis its coefficients solve the Vandermonde system \(V\mathbf c = \mathbf y\), \(V_{ij} = t_i^{\,j}\).
  2. Lagrange form. \(p(t) = \sum_i y_i L_i(t)\) with \(L_i(t) = \prod_{j\ne i} \dfrac{t - t_j}{t_i - t_j}\). \(L_i\) is 1 at \(t_i\) and 0 at the other nodes, and \(\sum_i L_i(t) = 1\).
  3. Newton form. \(p(t) = a_0 + a_1(t - t_0) + a_2(t - t_0)(t - t_1) + \dots\) with \(a_k = f[t_0, \dots, t_k]\), the divided differences: \(f[t_i] = y_i\), \(f[t_i, \dots, t_{i+k}] = \big(f[t_{i+1}, \dots, t_{i+k}] - f[t_i, \dots, t_{i+k-1}]\big)/(t_{i+k} - t_i)\). Adding a node adds one term.
  4. Error formula. \(f(t) - p(t) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}\, w(t)\), with the node polynomial \(w(t) = \prod_i (t - t_i)\) and some \(\xi\) in the interval spanned by the nodes and \(t\). For linear interpolation between readings \(h\) apart: \(|f - p| \le \tfrac{h^2}{8}\max|f''|\).
  5. Chebyshev nodes. On \([a, b]\): \(t_k = \tfrac{a+b}{2} - \tfrac{b-a}{2}\cos\!\big(\tfrac{(2k+1)\pi}{2n+2}\big)\), \(k = 0, \dots, n\). They make \(\max|w|\) as small as possible, \(2\big(\tfrac{b-a}{4}\big)^{n+1}\).
  6. Noise. If reading \(i\) is off by \(\delta_i\), the interpolant is off by \(\sum_i \delta_i L_i(t)\). The worst case factor \(\max_t \sum_i |L_i(t)|\) is the Lebesgue constant: 89 for 13 equally spaced nodes, 2.6 for 13 Chebyshev nodes.
  7. Barycentric form. \(p(t) = \dfrac{\sum_j w_j y_j/(t - t_j)}{\sum_j w_j/(t - t_j)}\) with \(w_j = 1/\prod_{k\ne j}(t_j - t_k)\). Multiplying all \(w_j\) by the same constant changes nothing. For Chebyshev nodes \(w_j = (-1)^j \sin\big(\tfrac{(2j+1)\pi}{2n+2}\big)\) (up to a constant).

The basic tools in each language. R has no polynomial interpolation function in base; lm with as many poly() coefficients as points interpolates, and approx interpolates piecewise linearly. Python has numpy.polynomial.Polynomial.fit (least squares, which interpolates when deg is the number of points minus one), scipy.interpolate.BarycentricInterpolator and np.interp. In Rust everything is hand-written.

// rust/examples/polynomial_interpolation_background.rs  —  cargo run --example polynomial_interpolation_background
// Background: degree-4 interpolant through five OD readings, and piecewise linear.
// Rust has no interpolation in std or our crates: both are hand-written.
const K: f64 = 1.2;
const N0: f64 = 0.05;
const R: f64 = 0.8;

fn od(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}

// barycentric formula (see the last lecture slide)
fn interp(x: &[f64], y: &[f64], z: f64) -> f64 {
    let (mut num, mut den) = (0.0, 0.0);
    for j in 0..x.len() {
        if z == x[j] {
            return y[j];
        }
        let mut w = 1.0;
        for k in 0..x.len() {
            if k != j {
                w /= x[j] - x[k];
            }
        }
        num += w * y[j] / (z - x[j]);
        den += w / (z - x[j]);
    }
    num / den
}

// piecewise linear, like R's approx() / np.interp (x increasing)
fn linear(x: &[f64], y: &[f64], z: f64) -> f64 {
    let i = (1..x.len()).find(|&i| z <= x[i]).unwrap();
    y[i - 1] + (y[i] - y[i - 1]) * (z - x[i - 1]) / (x[i] - x[i - 1])
}

fn main() {
    let t = [0.0, 2.0, 4.0, 6.0, 8.0]; // readings every 2 h
    let y: Vec<f64> = t.iter().map(|&ti| od(ti)).collect();
    for z in [3.0, 5.0] {
        println!("t = {z}: interpolant {:.7}  linear {:.7}  truth {:.7}",
                 interp(&t, &y, z), linear(&t, &y, z), od(z));
    }
}

// Output:
// t = 3: interpolant 0.4026258  linear 0.4159873  truth 0.3887883
// t = 5: interpolant 0.8312495  linear 0.8141777  truth 0.8443214

By hand

B1. Lagrange by hand. Three readings, rounded: \((t, \text{OD}) = (0, 0.05), (2, 0.21), (4, 0.62)\). (a) Compute \(L_0(1), L_1(1), L_2(1)\) and check that they add up to 1. (b) Compute \(p(1)\). Then repeat (a) and (b) for \(t = 3\). (c) The truth is \(N(1) = 0.1059\) and \(N(3) = 0.3888\). How large are the errors? (d) Which weight is negative at \(t = 1\), and why does it make sense that the reading at 4 h pulls the estimate at 1 h down?

B2. Newton by hand. (a) Build the divided-difference table for the three readings of B1 and write \(p\) in Newton form. Check \(p(3)\) against B1. (b) A fourth reading arrives: \((6, 1.01)\). Extend the table by one diagonal and write the cubic. Compute \(p(3)\) again. (c) Explain why adding the term \(a_3(t-0)(t-2)(t-4)\) cannot spoil the agreement at the first three readings. (d) Is the cubic better or worse than the quadratic at \(t = 3\) (truth 0.3888)? Does more data always help at a given point?

B3. How far apart may readings be? Use the error bound for linear interpolation (fact 4). (a) Show that \(|(t - t_0)(t - t_1)|\) is largest at the midpoint of \([t_0, t_1]\), where it equals \(h^2/4\), so \(|f - p| \le \tfrac{h^2}{8}\max|f''|\). (b) For the OD curve, \(\max|f''| = 0.074\) OD/h². How far apart may readings be if linear interpolation between them must be within 0.01 OD everywhere? (c) What happens to the bound when you read twice as often? (d) Check the bound on the lecture’s example: readings at 2 h and 4 h, estimate at 3 h, actual error 0.027.

B4. The node polynomial. (a) Five equally spaced nodes on \([-1, 1]\): \(-1, -0.5, 0, 0.5, 1\). Compute \(|w(0.25)|\) and \(|w(0.75)|\). Which is larger, and by what factor? (b) The five Chebyshev nodes on \([-1, 1]\) are \(\pm 0.9511\), \(\pm 0.5878\) and \(0\). Compute \(|w(0.25)|\) and \(|w(0.75)|\) again. (Hint: pair the nodes, \((t - a)(t + a) = t^2 - a^2\).) Compare with the smallest possible maximum, \(2^{-4} = 0.0625\). (c) Turn the Chebyshev nodes into five sampling times for a 48-h growth run. Where do they cluster?

B5. Noise in the readings. Three readings at 0, 2 and 4 h; the reading at 2 h is off by \(+0.02\) OD. (a) By how much does the interpolant change at \(t = 3\)? At \(t = 5\) (beyond the last reading)? Use the \(L_1\) values from B1 or compute \(L_1(5)\). (b) For 13 hourly readings over 12 h the Lebesgue constant is 89 (fact 6). With a noise of 0.02 OD per reading, what is the worst case error of the interpolant from noise alone? And for 13 Chebyshev times (Lebesgue constant 2.6)? (c) Three candidate models for 13 noisy readings (noise sd 0.02 OD): degree 12 (residuals all 0), degree 4 (residual sd 0.023), degree 2 (residual sd 0.081). Which do you use, and why not the other two?

B6. Barycentric by hand. The same three readings as in B1. (a) Compute the barycentric weights \(w_0, w_1, w_2\) and evaluate \(p(3)\) with the barycentric formula. Compare with B1. (b) Multiply all three weights by 8. Does \(p(3)\) change? (c) The fourth reading \((6, 1.01)\) arrives. Update the weights: divide each old \(w_j\) by \((t_j - 6)\), and compute the new \(w_3\). Evaluate \(p(3)\) and compare with B2(b).

In code

C1. Three forms, one polynomial. Use the five readings at \(t = 0, 2, 4, 6, 8\) h from the true curve. (a) Write lagrange(x, y, xx), divdiff(x, y) and newton_eval(x, a, xx), and also solve the Vandermonde system. Evaluate all three at \(t = 1, 3, 5, 7\) and compare with the truth. (b) Check your answers to B1 and B2 with your functions.

C2. The error formula, checked. The derivatives of the logistic curve follow from \(u = N/K\), \(u' = r\,u(1 - u)\): if \(u^{(k)} = r^k P_k(u)\) for a polynomial \(P_k\), then \(P_{k+1}(u) = P_k'(u)\,(u - u^2)\), starting from \(P_1(u) = u - u^2\). (a) Compute \(P_2, \dots, P_5\) as coefficient vectors, and from them \(f''(3)\), \(\max|f''|\) and \(\max|f^{(5)}|\) on \([0, 8]\) (compare with the lecture: 0.0592, 0.074, 0.0983). (b) For the degree-4 interpolant of C1, compare the actual error \(|f - p|\) with the bound \(\tfrac{\max|f^{(5)}|}{5!}|w(t)|\) at \(t = 1\) and \(t = 3\), and check that the bound holds on a fine grid. How pessimistic is it?

C3. Runge on a 48-hour run. (a) A 48-h run is read every 4 h (13 readings). Interpolate with the barycentric formula and evaluate on a grid with step 0.01 h. What is the lowest OD the interpolant claims, and when? What is the largest error? (b) Repeat with 13 Chebyshev times on \([0, 48]\). (c) Runge’s own example: \(f(x) = 1/(1 + 25x^2)\) on \([-1, 1]\). Compare the largest error for \(n = 5, 10, 20\) with equally spaced and with Chebyshev nodes.

C4. Error against degree. For \(n = 4, 8, 12, 16, 20, 30, 40\), compute the largest error of the degree-\(n\) interpolant for three designs: equally spaced on \([0, 8]\), equally spaced on \([0, 48]\), Chebyshev on \([0, 48]\). Plot the three on a log scale. Which converge? What happens to the first design at large \(n\)?

C5. When monomial coefficients fail. (a) Build the Vandermonde matrix for the 13 readings of C3(a), times in hours. What is its condition number? What does solve do (R)? Force a solution (R: solve(V, y, tol = 0); numpy never refuses) and compare its values with the barycentric interpolant. (b) At Chebyshev times on \([0, 48]\) for \(n = 8, 12, 20, 30, 40, 60, 80\): compare the largest error of three ways to evaluate the same polynomial: monomials in hours, monomials in \(s = (t - 24)/24 \in [-1, 1]\), and the barycentric formula with Chebyshev weights. Also print \(\kappa\) of the rescaled Vandermonde matrix.

C6. Interpolation vs fitting. Thirteen hourly readings with plate-reader noise (sd 0.02 OD): y12 = 0.0375, 0.1095, 0.1959, 0.4207, 0.6259, 0.8279, 1.0188, 1.1207, 1.1673, 1.1736, 1.2210, 1.2037, 1.1857 at \(t = 0, 1, \dots, 12\) h. (a) Interpolate (degree 12). What range of OD does the interpolant claim, and what is its largest error against the truth? (b) Fit least-squares polynomials of degree 2 to 8. For each, print the residual standard deviation \(\sqrt{\text{RSS}/(13 - d - 1)}\) and the largest error against the truth. Which degree would you choose without knowing the truth? (c) Compare with piecewise linear interpolation. (d) A check that needs no truth: the largest difference between the interpolant and the degree-5 fit. Compare it with the noise level.

C7. A gene-expression time course. An immediate-early gene is induced at \(t = 0\); its fold change follows \(g(t) = 1 + 6(e^{-0.25t} - e^{-1.5t})\). It is sampled at the usual uneven times \(0, 0.5, 1, 2, 4, 8, 12, 24\) h. (a) Interpolate with one polynomial (degree 7) and with piecewise linear interpolation. Compare both with the truth at 3, 6, 10 and 18 h. (b) What range of fold changes does the polynomial claim between 0 and 24 h? Where is its largest error? (c) Leave out each interior time point in turn, interpolate from the others, and compare with the left-out value. Would this check have warned you without knowing \(g\)?

E1. (Runge on a 48-h run) Start from the preset 48 h, every 4 h. Read the largest error, where it occurs, the lowest OD and the Lebesgue constant. Then move the degree slider to \(n = 16\), \(20\) and \(30\) and note the largest error each time. Does reading more often help? Now click Chebyshev and repeat for \(n = 12, 20, 30\).

Answer E1

At \(n = 12\) (13 readings, every 4 h) the largest error is \(0.252\) OD at \(t = 1.1\) h, and the interpolant dips to OD \(-0.148\) at \(0.86\) h, a negative cell density in lag phase. Lebesgue constant \(89\). More readings do not help: \(0.132\) at \(n = 16\), \(0.342\) at \(n = 20\), \(0.200\) at \(n = 30\); the red curve in panel (b) jumps up and down between about \(0.03\) and \(0.4\) (from \(n = 3\) on) and never converges. With the same number of readings at Chebyshev times: \(0.0386\) (at \(5.9\) h, no negative OD, Lebesgue constant \(2.6\)), \(0.0041\) at \(n = 20\) and \(2.7\times10^{-4}\) at \(n = 30\): the blue curve falls steadily, as in C3 and C4.

E2. (a short run converges) Click 0–8 h, every 2 h (the lecture’s first five readings) and read the error. Then increase \(n\) to \(8\), \(16\) and \(30\). Why does equal spacing work here and not on the 48-h run? Compare the Lebesgue constants at \(n = 12\) for the two runs: what does that tell you?

Answer E2

\(n = 4\): \(0.024\) OD (at \(0.8\) h); \(n = 8\): \(2.4\times10^{-3}\); \(n = 16\): \(4.9\times10^{-5}\); \(n = 30\): \(8.8\times10^{-8}\). Over 0–8 h the red curve in panel (b) falls geometrically, by a factor of about 1.6 per extra reading. The error formula has \(f^{(n+1)}/(n+1)!\) times \(w(t)\): on a short run the readings are close together, \(|w|\) is small, and the factorial wins; on a run six times longer each factor of \(w\) is six times larger and the growth of \(w\) near the ends wins. The Lebesgue constant at \(n = 12\) is \(89\) on both runs: it depends only on the pattern of the times, not on the time unit or the curve. It measures how much reading errors can be amplified, not the interpolation error of an exact curve.

E3. (one wrong reading) Back to 48 h, every 4 h. Choose drag moves: value and pull the reading at 24 h (in the middle of the plateau) up by about 0.1 OD, from 1.2 to 1.3. What happens to the interpolant near 0–2 h and near 46 h? Click reset, then 48 h, Chebyshev, and do the same with the middle reading (24 h). Explain with the Lagrange basis \(L_6\).

Answer E3

With equally spaced times the bump of 0.1 OD at 24 h makes the interpolant plunge to about OD \(-1.9\) at \(1.1\) h (largest error about \(2.0\)) and swing near the end of the run as well; between 8 and 40 h hardly anything changes except the bump itself. The change is \(0.1\,L_6(t)\), and the basis polynomial of the middle node reaches \(|L_6| \approx 18\) near the ends (lecture: “the largest single \(L_i\) reaches 18”). A Lebesgue constant of 2.6 instead of 89 means a reading error is passed on, not amplified.

Hints

Hint 1 — Lagrange and Newton by hand (B1, B2, B6)

For \(L_i(t)\): the numerator has a factor \((t - t_j)\) for every other node, the denominator the same factors with \(t\) replaced by \(t_i\). Check that the \(L_i\) add up to 1. For the divided-difference table, each new entry is (lower-left minus upper-left) divided by (last time minus first time it covers); the top diagonal holds \(a_0, a_1, \dots\). Barycentric weights are the reciprocals of the Lagrange denominators.

Hint 2 — the error bound (B3, B4, C2)

\((t - t_0)(t - t_1)\) is a parabola that is zero at both readings; its extreme is halfway. For (b) solve \(0.074\,h^2/8 \le 0.01\) for \(h\). In B4, multiply the factors \((t - t_i)\) one by one; with the Chebyshev nodes, \(w(t) = t(t^2 - 0.9511^2)(t^2 - 0.5878^2)\).

Hint 3 — polynomials as coefficient vectors (C2)

Store \(a_0 + a_1u + a_2u^2 + \dots\) as c(a0, a1, a2, ...). The derivative is a[-1] * seq_len(length(a) - 1); a product is a convolution of the two vectors (write a double loop). In Python, numpy.polynomial.Polynomial does all of this: P.deriv(), P * Q, P(u). R also has symbolic derivatives with D(), which you can apply five times to quote(1.2 / (1 + 23 * exp(-0.8 * t))) to check.

Hint 4 — barycentric interpolation and Chebyshev nodes (C3, C4)

Copy bary_weights and bary_eval from the lecture (R), or use scipy.interpolate.BarycentricInterpolator / barycentric_interpolate (Python). Do not use scipy.interpolate.lagrange for more than a handful of points: its documentation warns that it is numerically unstable (it returns monomial coefficients). Chebyshev nodes: (a + b) / 2 - (b - a) / 2 * cos((2 * (0:n) + 1) * pi / (2 * n + 2)); numpy has chebpts1 for \([-1, 1]\). Use which.min / np.argmin to find where the minimum is.

Hint 5 — Vandermonde and condition numbers (C5)

R: outer(t, 0:n, "^"), solve (its tol argument sets when it refuses), kappa(V, exact = TRUE). Python: np.vander(t, n + 1, increasing=True), np.linalg.solve, np.linalg.cond. Hint 6 — least squares and linear interpolation (C6, C7)

R: lm(y ~ poly(t, d)) and predict with data.frame(t = tt); resid(fit) for the residuals. Python: Polynomial.fit(t, y, deg=d), which rescales \(t\) internally (like poly()), and evaluate with fit(tt). fn lagrange(x: &[f64], y: &[f64], z: f64) -> f64 {
    let mut p = 0.0;
    for i in 0..x.len() {
        let mut li = 1.0;
        for j in 0..x.len() {
            if j != i {
                li *= (z - x[j]) / (x[i] - x[j]);
            }
        }
        p += li * y[i];
    }
    p
}

// polynomials in u as coefficient vectors [a0, a1, a2, ...]
fn pmul(a: &[f64], b: &[f64]) -> Vec<f64> {
    let mut out = vec![0.0; a.len() + b.len() - 1];
    for i in 0..a.len() {
        for j in 0..b.len() {
            out[i + j] += a[i] * b[j];
        }
    }
    out
}

    (1..a.len()).map(|i| a[i] * i as f64).collect()
}
fn peval(a: &[f64], x: f64) -> f64 {
    a.iter().rev().fold(0.0, |s, &c| s * x + c) // Horner
}

use std::f64::consts::PI;

const K: f64 = 1.2;
const N0: f64 = 0.05;
const R: f64 = 0.8;

fn od(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}

fn bary_weights(x: &[f64]) -> Vec<f64> {
    (0..x.len())
        .map(|j| 1.0 / (0..x.len()).filter(|&k| k != j).map(|k| x[j] - x[k]).product::<f64>())
        .collect()
}
fn bary_eval(x: &[f64], y: &[f64], w: &[f64], z: f64) -> f64 {
    let (mut num, mut den) = (0.0, 0.0);
    for j in 0..x.len() {
        let d = z - x[j];
        if d == 0.0 {
            return y[j]; // z is a node
        }
        num += w[j] * y[j] / d;
        den += w[j] / d;
    }
    num / den
}
fn interp(x: &[f64], y: &[f64], zs: &[f64]) -> Vec<f64> {
    let w = bary_weights(x);
    zs.iter().map(|&z| bary_eval(x, y, &w, z)).collect()
}
fn cheb(n: usize, a: f64, b: f64) -> Vec<f64> {
    (0..=n)
        .map(|k| (a + b) / 2.0 - (b - a) / 2.0 * ((2 * k + 1) as f64 * PI / (2 * n + 2) as f64).cos())
        .collect()
}
fn max_abs_diff(p: &[f64], q: &[f64]) -> f64 {
    p.iter().zip(q).map(|(a, b)| (a - b).abs()).fold(0.0, f64::max)
}

// C5: monomial coefficients (Vandermonde + LU) against the barycentric formula.
use nalgebra::{DMatrix, DVector};
use std::f64::consts::PI;

const K: f64 = 1.2;
const N0: f64 = 0.05;
const R: f64 = 0.8;

fn od(t: f64) -> f64 {
    K / (1.0 + (K / N0 - 1.0) * (-R * t).exp())
}

fn bary_weights(x: &[f64]) -> Vec<f64> {
    (0..x.len())
        .map(|j| 1.0 / (0..x.len()).filter(|&k| k != j).map(|k| x[j] - x[k]).product::<f64>())
        .collect()
}
fn bary_eval(x: &[f64], y: &[f64], w: &[f64], z: f64) -> f64 {
    let (mut num, mut den) = (0.0, 0.0);
    for j in 0..x.len() {
        let d = z - x[j];
        if d == 0.0 {
            return y[j]; // z is a node
        }
        num += w[j] * y[j] / d;
        den += w[j] / d;
    }
    num / den
}
fn interp(x: &[f64], y: &[f64], zs: &[f64]) -> Vec<f64> {
    let w = bary_weights(x);
    zs.iter().map(|&z| bary_eval(x, y, &w, z)).collect()
}
fn cheb(n: usize, a: f64, b: f64) -> Vec<f64> {
    (0..=n)
        .map(|k| (a + b) / 2.0 - (b - a) / 2.0 * ((2 * k + 1) as f64 * PI / (2 * n + 2) as f64).cos())
        .collect()
}
fn max_abs_diff(p: &[f64], q: &[f64]) -> f64 {
    p.iter().zip(q).map(|(a, b)| (a - b).abs()).fold(0.0, f64::max)
}


fn vander(x: &[f64], m: usize) -> DMatrix<f64> {
    DMatrix::from_fn(x.len(), m, |i, j| x[i].powi(j as i32))
}
fn cond(a: &DMatrix<f64>) -> f64 {
    let s = a.clone().svd(false, false).singular_values;
    s.max() / s.min()
}
// solve V c = y by LU (nalgebra never refuses unless exactly singular), evaluate at xe
fn mono_vals(x: &[f64], y: &[f64], xe: &[f64]) -> Vec<f64> {
    let m = x.len();
    let cf = vander(x, m).lu().solve(&DVector::from_column_slice(y)).unwrap();
    (vander(xe, m) * cf).iter().cloned().collect()
}

fn linear(x: &[f64], y: &[f64], z: f64) -> f64 { // like approx() / np.interp
    let i = (1..x.len()).find(|&i| z <= x[i]).unwrap();
    y[i - 1] + (y[i] - y[i - 1]) * (z - x[i - 1]) / (x[i] - x[i - 1])
}

fn main() {
    let g = |t: f64| 1.0 + 6.0 * ((-0.25 * t).exp() - (-1.5 * t).exp()); // fold change
    let ts = [0.0, 0.5, 1.0, 2.0, 4.0, 8.0, 12.0, 24.0]; // sampling times (h)
    let y: Vec<f64> = ts.iter().map(|&t| g(t)).collect();
    let tq = [3.0, 6.0, 10.0, 18.0]; // (a)
    let pq = interp(&ts, &y, &tq);
    for i in 0..4 {
        println!("t = {:2}  poly {:9.3}  linear {:6.3}  truth {:6.3}",
                 tq[i], pq[i], linear(&ts, &y, tq[i]), g(tq[i]));
    }
    let tt: Vec<f64> = (0..=2400).map(|i| i as f64 * 0.01).collect(); // (b)
    let p = interp(&ts, &y, &tt);
    let err: Vec<f64> = tt.iter().zip(&p).map(|(&t, &v)| (v - g(t)).abs()).collect();
    let imax = (0..err.len()).max_by(|&i, &j| err[i].total_cmp(&err[j])).unwrap();
    let pmin = p.iter().cloned().fold(f64::INFINITY, f64::min);
    let pmax = p.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
    println!("range {pmin:.1} to {pmax:.1}, max error {:.1} at {:.2} h", err[imax], tt[imax]);
    for i in 1..7 { // (c) leave one out
        let (xs, ys): (Vec<f64>, Vec<f64>) = (0..8).filter(|&k| k != i).map(|k| (ts[k], y[k])).unzip();
        println!("leave out {:4} h: poly {:+9.3}  linear {:+6.3}", ts[i],
                 interp(&xs, &ys, &[ts[i]])[0] - y[i], linear(&xs, &ys, ts[i]) - y[i]);
    }
}

Where this leads

  • Splines (next unit): piecewise cubic polynomials through the same readings keep the error formula local (only \(h\) and nearby derivatives matter), cannot produce Runge oscillations, and smoothing splines handle noisy readings with a controlled bias–noise trade-off. The growth rate as the derivative of a smoothed OD curve is done there.
  • Fourier series and the FFT: interpolation with sines and cosines instead of powers, the natural basis for periodic data such as circadian time courses.
  • Numerical differentiation and Numerical integration (Part 7): finite-difference stencils are built there from Taylor series, but each is also the derivative of a local interpolating polynomial (the first divided difference is the forward difference); Simpson’s rule integrates the quadratic interpolant, and Gaussian quadrature chooses its nodes cleverly, as Chebyshev points did here.
  • Least-squares polynomial fits and their conditioning were the subject of Least squares: normal equations vs QR.
