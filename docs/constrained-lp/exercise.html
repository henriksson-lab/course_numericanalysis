Exercise: constraints and linear programming

Goal

By the end of this exercise you should be able to:

  • write biological restrictions (positive rates, proportions, capacities, steady state) as constraints, and say which are active at a solution,
  • fit a model with bounds (L-BFGS-B) and with a reparameterisation (\(e^\theta\), softmax), and recognise when each one fails,
  • solve a small constrained problem with a Lagrange multiplier and read the multiplier as a shadow price,
  • solve a 2-variable linear program by drawing it and by walking along edges (the simplex idea), and recognise ties, unbounded and infeasible LPs,
  • set up flux balance analysis for a small metabolic network, compute flux variability ranges, knock-outs and shadow prices, and check the solver’s status.

The by-hand part needs pen, paper and a calculator. The code part uses R’s optim and lpSolve::lp, Python’s scipy.optimize, and Rust’s minilp and argmin crates.

Background

Facts used below:

  1. A constraint restricts the allowed parameters: an equality (\(\sum_i p_i = 1\), \(S\mathbf v = \mathbf 0\)) or an inequality (\(c \ge 0\), \(v_\text{glc} \le 10\)). The allowed set is the feasible set. An inequality is active at a point if it holds with equality there.
  2. Bounds (\(\ell \le \theta \le u\)): L-BFGS-B projects every step back into the box. At a solution on a bound the gradient is not zero in that parameter; it points out of the box.
  3. Reparameterisation: optimise a free \(\theta\) and set \(c = e^\theta > 0\), or \(p = \text{softmax}(\theta)\), \(p_i = e^{\theta_i}/\sum_j e^{\theta_j}\), with \(\theta_1 = 0\). It cannot reach the boundary: if the best \(c\) is 0, \(\theta\) runs off towards \(-\infty\).
  4. Lagrange: to optimise \(f\) subject to \(g = b\), solve \(\nabla f = \lambda \nabla g\) together with \(g = b\). The multiplier \(\lambda\) is the shadow price: the best \(f\) changes by about \(\lambda\,\Delta b\) when \(b\) changes by \(\Delta b\). For an inequality, the multiplier is \(\ge 0\) when active and \(0\) when inactive (KKT conditions).
  5. A linear program (LP) has a linear objective and linear constraints. Its feasible set is a convex polytope; if an optimum exists, it is at a corner (vertex). The simplex method walks from corner to corner along edges that improve the objective, and stops when no edge does. An LP can also have a whole optimal edge (a tie), be unbounded, or be infeasible.
  6. Flux balance analysis (FBA): fluxes \(\mathbf v\) (reaction rates), stoichiometric matrix \(S\) (rows = metabolites, columns = reactions). Maximise the biomass flux subject to \(S\mathbf v = \mathbf 0\) (steady state), \(\mathbf v \ge \mathbf 0\) and uptake bounds. Flux variability analysis (FVA) fixes the growth at its maximum and minimises and maximises every flux in turn.

// Background: the ATP linear program with the minilp crate (Rust's lpSolve::lp / linprog).
use minilp::{ComparisonOp, OptimizationDirection, Problem};

fn main() {
    let mut p = Problem::new(OptimizationDirection::Maximize);
    // add_var(objective coefficient, (lower bound, upper bound))
    let x1 = p.add_var(6.0, (0.0, f64::INFINITY)); // respiration flux
    let x2 = p.add_var(3.0, (0.0, f64::INFINITY)); // fermentation flux
    p.add_constraint(&[(x1, 1.0), (x2, 1.0)], ComparisonOp::Le, 6.0); // carbon
    p.add_constraint(&[(x1, 4.0), (x2, 1.0)], ComparisonOp::Le, 12.0); // proteome
    let sol = p.solve().unwrap(); // Err(Infeasible) or Err(Unbounded) if it fails
    println!("{} {}", sol[x1], sol[x2]);
    println!("{}", sol.objective());
    // minilp reports no shadow prices; C3 gets them by re-solving
}

// Output:
// 2 4
// 24

lp maximises or minimises; linprog only minimises, so Python passes \(-c\) and flips the signs of the objective and of the marginals. minilp gives no shadow prices; we measure them by re-solving.

By hand

B1. Constraints in biology. Write each restriction as one or more constraints, and say how many free parameters remain. (a) The proportions \(p_1, \dots, p_5\) of five cell types in a bulk sample. (b) An irreversible reaction and a reversible one in a metabolic model (genome-scale models bound reversible fluxes by \(\pm 1000\)). (c) At the bounded decay fit from the lecture, \((A, k, c) = (1.0152, 0.5214, 0)\), the gradient of the SSE is \((0, 0, 0.105)\). Which constraint is active? Is this a constrained minimum? What would a gradient of \((0, 0, -0.105)\) at the same point mean?

B2. A Lagrange multiplier. Counts of three cell types in an image are \(n = (12, 6, 2)\). Maximise \(f(p) = \sum_i n_i \log p_i\) subject to \(p_1 + p_2 + p_3 = 1\). (a) Write \(\nabla f = \lambda \nabla g\) component by component and solve for \(p\) and \(\lambda\). (b) Use \(\lambda\) to predict how much the best \(f\) would change if the constraint were \(\sum p_i = 1.05\). Compare with the exact change \(N \log 1.05\), \(N = 20\).

B3. A diet on the edge of the triangle. In Gaussian elimination as LU, a consumer with isotope values \((\delta^{13}\text{C}, \delta^{15}\text{N}) = (-24, 9)\) came out with diet fractions \((0.55, -0.20, 0.65)\) for C3 plants \((-26, 2)\), maize \((-10, 6)\) and fish \((-18, 14)\). Find the best diet with all fractions \(\ge 0\), in the least-squares sense: minimise \(\|A\mathbf p - \mathbf{obs}\|^2\) over \(p_i \ge 0\), \(\sum p_i = 1\), where the columns of \(A\) are the sources. (a) Guess which constraint is active. Set maize \(= 0\) and fish \(= 1 - p_1\), and write the squared misfit as a function of \(p_1\) alone. (b) Minimise it: find \(p_1\), the diet and the misfit. (c) KKT check. The gradient of the misfit with respect to \(\mathbf p\) is \(2A^\top \mathbf r\), \(\mathbf r = A\mathbf p - \mathbf{obs}\). Compute it. Show that the components for plants and fish are equal (why must they be?), and that moving a little weight from fish to maize makes the misfit worse.

B4. A diet formulation LP. A fish farm mixes two feeds. Feed A has 2 units of protein and 1 of lipid per kg and costs 5; feed B has 1 of protein and 3 of lipid and costs 5. A batch needs at least 8 units of protein and 9 of lipid. Minimise the cost. (a) Draw the feasible region in the \((a, b)\) plane. Is it bounded? (b) List its corners, the cost at each, and the optimum. (c) Find the shadow prices of the protein and lipid requirements by re-solving with 9 protein, and with 10 lipid. (d) How expensive must feed B become before the optimal mix changes? What happens at exactly that price?

B5. The simplex by hand. Add an oxygen limit \(x_1 \le 1.5\) to the ATP LP. (a) Start at \((0, 0)\). Which variable should enter first? How far can it go, and which constraint stops it? (b) From that corner, which edge improves ATP, at what rate, and where does it end? (c) Show that the corner you reached is optimal. Which constraints are active, which is inactive? (d) Find the shadow prices of carbon, proteome and oxygen by writing \((6, 3)\) as a combination of the gradients of the active constraints.

B6. Four LPs that misbehave. For each, sketch the feasible set and say whether the LP has a unique optimum, a tie, is unbounded or infeasible (\(x_1, x_2 \ge 0\) always). (a) \(\max\ x_1 + x_2\) subject to \(x_1 + x_2 \le 4\). (b) \(\max\ x_1 - x_2\) subject to \(x_2 \ge 1\). (c) \(\max\ x_1\) subject to \(x_1 + x_2 \le 2\), \(x_1 \ge 3\). (d) \(\max\ 2x_1 + x_2\) subject to \(x_1 + x_2 \le 4\), \(x_1 \le 4\). What is special about the optimal corner?

B7. A five-reaction network. R1: → A (uptake, \(\le 10\)); R2: A → B; R3: A → C; R4: A → C (an isozyme of R3); R5: B + 2 C → biomass. (a) Write the stoichiometric matrix \(S\) (rows A, B, C). (b) Write \(S\mathbf v = \mathbf 0\). What is the rank of \(S\), and the dimension of its null space? (c) Maximise \(v_5\). Give every flux, or its range. (d) Flux variability: with \(v_5\) at its maximum, what are the ranges of \(v_3\) and \(v_4\)? (e) Predict the maximal growth after knocking out R3; R2; R3 and R4 together. (f) What is the shadow price of the uptake bound?

B8. The toy FBA by hand. Use the toy network from the Background, with glucose uptake \(g = 10\). (a) Assume no fermentation (FER = 0) and that all glucose is used. Write the P and ATP balances and solve for RES and BIO. Is the oxygen bound active? What are the shadow prices of glucose and of oxygen? (b) Now limit oxygen uptake to 4 (so RES = 2). Solve the P and ATP balances for FER and BIO. (c) In general, show that \(\text{BIO} = (2g + 5\,\text{RES})/3\) when oxygen limits. What are the shadow prices of glucose and oxygen? (d) In the oxygen-limited case, a lab can double either the glucose supply or the oxygen supply. Which gives more growth? Is that what the shadow prices suggest?

Hints

Hint 1 — bounds and KKT (B1, C1)

At a minimum on the bound \(c \ge 0\), decreasing \(c\) is not allowed and increasing it must not help, so \(\partial\,\text{SSE}/\partial c \ge 0\). In code, the gradient at a point: R numDeriv::grad, Python scipy.optimize.approx_fprime. Bounded fits: R optim(method = "L-BFGS-B", lower, upper), Python scipy.optimize.minimize(method="L-BFGS-B", bounds=...). Our Rust crates have no L-BFGS-B: the solution uses that the model is linear in \((A, c)\) for fixed \(k\).

Hint 2 — Lagrange (B2, B3)

\(\partial f/\partial p_i = n_i/p_i\) and \(\nabla g = (1, 1, 1)\), so every \(n_i/p_i\) equals the same \(\lambda\). Sum \(p_i = n_i/\lambda\) over \(i\). In B3 the constraint \(\sum p_i = 1\) has its own multiplier, and that is why the gradient components of the free fractions must be equal.

Hint 3 — drawing an LP (B4, B5, B6)

Draw each constraint as a line (find where it crosses the axes), shade the allowed side, and find corners by solving two line equations at a time. For a minimum, slide the cost line down until it last touches the region. A shadow price is the change in the optimal value when one right-hand side grows by 1, with the same constraints active. For the simplex, the rate of change along an edge is the change in the objective when the entering variable grows by 1 and the variables on the active constraint adjust.

Hint 4 — stoichiometry (B7, B8, C5)

Column \(j\) of \(S\) lists what reaction \(j\) makes (+) and uses (−). Row \(i\) of \(S\mathbf v = \mathbf 0\) says: production of metabolite \(i\) = consumption. Rank in code: R qr(S)$rank, Python np.linalg.matrix_rank, Rust DMatrix::rank (nalgebra). In B8, subtract the P balance from the ATP balance to eliminate \(2g\).

Hint 5 — LP solvers (C3, C5–C8)

R: lpSolve::lp(direction, objective.in, const.mat, const.dir, const.rhs, compute.sens = TRUE); all variables are \(\ge 0\), upper bounds and knock-outs are extra rows; $duals lists constraint shadow prices first, then reduced costs; $status is 0 (success), 2 (infeasible) or 3 (unbounded). Python: scipy.optimize.linprog(c, A_ub, b_ub, A_eq, b_eq, bounds, method="highs") minimises; shadow prices of inequality rows are in res.ineqlin.marginals, of variable bounds in res.upper.marginals (flip the signs when you minimised \(-f\)). Rust: minilp: Problem::new, add_var(cost, (lo, hi)), add_constraint, solve() returns Err(Infeasible) or Err(Unbounded) on failure.

Hint 6 — FVA and knock-outs (C6)

FVA is \(2n\) LPs with the same constraints plus BIO \(=\) its optimum, and objective \(\pm v_j\). Loop with sapply (R) or a list comprehension (Python). A knock-out sets the upper bound of that flux to 0.

Solutions

Solution

B1. (a) \(p_i \ge 0\) for \(i = 1, \dots, 5\) and \(p_1 + \dots + p_5 = 1\): 4 free parameters (the fifth follows from the sum). (b) Irreversible: \(v \ge 0\). Reversible: \(-1000 \le v \le 1000\); the \(\pm 1000\) means “no real limit” (a direction-free reaction can also be split into two irreversible ones). (c) \(c \ge 0\) is active (\(c = 0\)). In \(A\) and \(k\) the gradient is 0, as at any minimum. In \(c\) it is \(+0.105\): the SSE would decrease if \(c\) decreased, but that is forbidden; increasing \(c\) increases the SSE. So it is a constrained minimum, with multiplier 0.105. A gradient of \(-0.105\) would mean that increasing \(c\) (allowed) lowers the SSE, so the optimiser stopped too early.

B2. (a) \(n_i/p_i = \lambda\) for each \(i\), so \(p_i = n_i/\lambda\). The constraint gives \(\sum n_i/\lambda = 1\), \(\lambda = N = 20\), and \(p = (12, 6, 2)/20 = (0.6, 0.3, 0.1)\). (b) \(\Delta f \approx \lambda \cdot 0.05 = 1.0\). Exactly: the new optimum is \(p = 1.05\,(0.6, 0.3, 0.1)\), and \(f\) increases by \(\sum n_i \log 1.05 = 20 \log 1.05 = 0.976\). The multiplier gives the first-order change.

B3. (a) Maize is the fraction that came out negative, so try maize \(= 0\), fish \(= 1 - p_1\): \(\delta^{13}\)C misfit: \(-26p_1 - 18(1 - p_1) + 24 = 6 - 8p_1\); \(\delta^{15}\)N misfit: \(2p_1 + 14(1 - p_1) - 9 = 5 - 12p_1\). Squared misfit \(h(p_1) = (6 - 8p_1)^2 + (5 - 12p_1)^2\). (b) \(h'(p_1) = -16(6 - 8p_1) - 24(5 - 12p_1) = 416 p_1 - 216 = 0\), so \(p_1 = 216/416 = 27/52 = 0.5192\). Diet: plants 0.519, maize 0, fish 0.481. Residuals \(\mathbf r = (6 - 8\cdot 0.5192,\ 5 - 12\cdot 0.5192) = (1.846, -1.231)\), misfit \(1.846^2 + 1.231^2 = 4.923\). // C1: decay fit with background c, free and with c >= 0. Our crates have no
// L-BFGS-B, so this is hand-written: for fixed k the model A e^{-kt} + c is
// linear in (A, c), solved exactly; a golden-section search then finds k.
fn inner(k: f64, t: &[f64], y: &[f64], bounded: bool) -> (f64, f64, f64) {
    let e: Vec<f64> = t.iter().map(|&ti| (-k * ti).exp()).collect();
    let n = t.len() as f64;
    let (se, see) = (e.iter().sum::<f64>(), e.iter().map(|v| v * v).sum::<f64>());
    let sy: f64 = y.iter().sum();
    let sey: f64 = e.iter().zip(y).map(|(a, b)| a * b).sum();
    // normal equations [see se; se n] (A, c) = (sey, sy)
    let det = see * n - se * se;
    let (mut a, mut c) = ((sey * n - se * sy) / det, (see * sy - se * sey) / det);
    if bounded && c < 0.0 {
        c = 0.0; // the bound is active: refit A alone with c fixed at 0
        a = sey / see;
    }
    let sse = e.iter().zip(y).map(|(ei, yi)| (yi - a * ei - c).powi(2)).sum();
    (a, c, sse)
}

fn golden(f: impl Fn(f64) -> f64, mut lo: f64, mut hi: f64) -> f64 {
    let g = (5f64.sqrt() - 1.0) / 2.0;
    while hi - lo > 1e-10 {
        let (x1, x2) = (hi - g * (hi - lo), lo + g * (hi - lo));
        if f(x1) < f(x2) { hi = x2 } else { lo = x1 }
    }
    (lo + hi) / 2.0
}

fn main() {
    let t: Vec<f64> = (0..9).map(|i| i as f64).collect();
    let y = [1.020, 0.577, 0.378, 0.243, 0.125, 0.062, 0.020, 0.010, -0.012];
    for (name, bounded) in [("free", false), ("bound", true)] {
        let k = golden(|k| inner(k, &t, &y, bounded).2, 0.05, 2.0);
        let (a, c, sse) = inner(k, &t, &y, bounded);

    }

fn softmax(th: &[f64]) -> [f64; 3] {
    let e = [1.0, th[0].exp(), th[1].exp()]; // first theta fixed at 0
    let s: f64 = e.iter().sum();
    [e[0] / s, e[1] / s, e[2] / s]
}

        Ok((0..2).map(|i| ((0..3).map(|j| a[i][j] * p[j]).sum::<f64>() - obs[i]).powi(2)).sum())
    }
}

}

vertex_lp <- function(obj, A, b) {
  best <- NULL; best_val <- -Inf; nv <- 0
  for (pr in combn(nrow(A), 2, simplify = FALSE)) {

    }

}

def vertex_lp(obj, A, b):
    best, best_val, nv = None, -np.inf, 0
    for pr in itertools.combinations(range(len(b)), 2):
        M = A[list(pr)]
        if abs(np.linalg.det(M)) < 1e-12:            # parallel lines: no corner
            continue
        v = np.linalg.solve(M, b[list(pr)])
        if np.all(A @ v <= b + 1e-9):                 # feasible corner
            nv += 1
            if obj @ v > best_val:
                best, best_val = v, obj @ v
    return best, best_val, nv

// C4: a 2-variable LP by checking every corner (vertex enumeration), std only.
// All constraints are rows of A x <= b, including -x1 <= 0 and -x2 <= 0.
fn vertex_lp(obj: [f64; 2], a: &[[f64; 2]], b: &[f64]) -> ([f64; 2], f64, usize) {
    let (mut best, mut best_val, mut nv) = ([f64::NAN; 2], f64::NEG_INFINITY, 0);
    for i in 0..b.len() {
        for j in (i + 1)..b.len() {
            let det = a[i][0] * a[j][1] - a[i][1] * a[j][0];
            if det.abs() < 1e-12 { continue; } // parallel lines: no corner
            // Cramer's rule for the 2x2 system of rows i and j
            let v = [(b[i] * a[j][1] - a[i][1] * b[j]) / det,
                     (a[i][0] * b[j] - b[i] * a[j][0]) / det];
            let feasible = a.iter().zip(b).all(|(r, &bi)| r[0] * v[0] + r[1] * v[1] <= bi + 1e-9);
            if feasible {
                nv += 1;
                let val = obj[0] * v[0] + obj[1] * v[1];
                if val > best_val { best = v; best_val = val; }
            }
        }
    }
    (best, best_val, nv)
}

fn choose(n: u32, k: u32) -> f64 {
    (1..=k).fold(1.0, |acc, i| acc * (n - k + i) as f64 / i as f64)
}

fn main() {

def fba(ub=(10, 15), ko=(), obj=None, maximise=True, fix_bio=None):
    obj = np.eye(9)[8] if obj is None else np.asarray(obj, dtype=float)
    bounds = [(0, ub[0]), (0, ub[1])] + [(0, None)] * 7
    for j in ko:
        bounds[j] = (0, 0)
    if fix_bio is not None:

    res.value = -res.fun if (maximise and res.status == 0) else res.fun
    return res

       -> Result<(f64, Vec<f64>), Error> {

fn fba(lo: [f64; 9], hi: [f64; 9], obj: [f64; 9], dir: OptimizationDirection)
       -> Result<(f64, Vec<f64>), Error> {
    let mut p = Problem::new(dir);
    let v: Vec<_> = (0..9).map(|j| p.add_var(obj[j], (lo[j], hi[j]))).collect();
    for row in S.iter() {
        let terms: Vec<_> = (0..9).filter(|&j| row[j] != 0.0).map(|j| (v[j], row[j])).collect();
        p.add_constraint(terms, ComparisonOp::Eq, 0.0);
    }
    let sol = p.solve()?;
    Ok((sol.objective(), v.iter().map(|&x| sol[x]).collect()))
}

    hi[0] = glc;
    hi[1] = o2;
    ([0.0; 9], hi)
}

Where this leads

  • The SVD, rank deficiency and regularisation (Part 4) used NNLS, a constrained least-squares problem; its optimality check is the KKT condition of this unit. B3 and C2 do the same for proportions that must also sum to 1.
  • Identifiability and uncertainty of fitted parameters (Part 9): a parameter at a bound, and a flux with an FVA range, are both answers the data or the objective cannot pin down.
  • Part 10 (The diffusion (heat) equation by finite differences onwards) returns to differential equations, now in space and time. Large sparse linear systems, as in genome-scale LPs, are the computational core there.
  • Not covered: nonlinear constrained optimisation in general (sequential quadratic programming, interior-point methods for nonlinear problems), integer programming (on/off decisions, e.g. gene knock-out design with OptKnock), and dynamic FBA, which couples FBA to an ODE for the medium (Part 8).
